# 勺子Claw 上线准备方案

## 一、Windows打包（今天做）

### 环境准备（在Windows电脑上）

**Step 1: 安装Node.js**
1. 打开浏览器访问：`https://nodejs.org/dist/v22.12.0/node-v22.12.0-x64.msi`
2. 下载后双击安装，一路点 **Next** → **Install** → **Finish**
3. 安装完后打开 PowerShell（按 Win+X，选"终端"或"PowerShell"）
4. 验证：`node --version` → 应该显示 `v22.12.0`

**Step 2: 安装Rust**
1. 浏览器访问：`https://rustup.rs`
2. 下载 `rustup-init.exe`，双击运行
3. 按提示安装（默认选项就行，按回车）
4. 安装完后**重启PowerShell**
5. 验证：`cargo --version` → 应该显示版本号

**Step 3: 复制项目文件**
1. 把 Mac 上的 `shaoziclaw-app/frontend` 整个文件夹复制到 Windows 电脑
2. 建议放到简单路径，比如 `C:\shaoziclaw\frontend`

**Step 4: 运行打包**
两种方法：

**方法A（推荐）：用脚本**
1. 把 `build-windows.ps1` 放到 `frontend` 同级目录
2. 右键 `build-windows.ps1` → "使用 PowerShell 运行"
3. 等待完成（约10-15分钟）

**方法B：手动**
```powershell
cd C:\shaoziclaw\frontend
npm install                    # 安装依赖，约2分钟
npm run tauri build            # 打包，约5-10分钟
```

**Step 5: 拿到安装包**
打包完成后，安装包在：
```
frontend\src-tauri\target\release\bundle\nsis\ShaoziClaw_4.3.1_x64-setup.exe
```

把这个 `.exe` 文件发给我，我上传到官网。

## 二、服务器评估

### 结论：必须要有服务器

如果你只做**本地单机版**（像现在一样），不需要服务器。

但你要做**会员制+支付**，就必须有：

| 功能 | 是否需要服务器 | 原因 |
|------|--------------|------|
| 会员权限验证 | ✅ 必须 | App启动时要联网验证"这个人付过钱没" |
| 支付回调 | ✅ 必须 | 微信/支付宝付完钱要通知服务器"这笔订单成功了" |
| 用户登录 | ✅ 必须 | 需要账号系统区分谁是谁 |
| 数据存储/日志 | ⚠️ 建议有 | 可选，但有了可以做用户画像、Bug追踪 |

### 最小可行架构（MVP）

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   用户设备    │     │   官网(前端)  │     │  后端API服务  │
│  (Mac/Win)   │◄───►│ shaoziclaw   │◄───►│  阿里云ECS   │
│              │     │   .com       │     │  或Vercel   │
└──────────────┘     └──────────────┘     └──────┬───────┘
                                                  │
                    ┌─────────────────────────────┘
                    ▼
            ┌──────────────┐     ┌──────────────┐
            │   数据库      │     │   支付平台    │
            │  PostgreSQL  │     │ 微信/支付宝   │
            └──────────────┘     └──────────────┘
```

### 推荐技术方案

**后端服务（2选1）**：
- **方案A（轻量）**：Vercel Serverless Functions + PostgreSQL（NeonDB免费版）
  - 成本：免费起步，流量大了约￥50-100/月
  - 适合：快速上线，不用管服务器运维
- **方案B（自主）**：阿里云ECS 1核2G + MySQL
  - 成本：约￥100-200/月
  - 适合：数据自主可控，后续扩展空间大

**数据库表设计**：
```sql
-- 用户表
users (id, email, phone, created_at, updated_at)

-- 会员订阅表
subscriptions (id, user_id, status, started_at, expires_at, payment_id)

-- 支付订单表
payments (id, user_id, amount, channel, status, transaction_id, paid_at)

-- 设备激活表（App绑定）
activations (id, user_id, device_id, device_type, activated_at)
```

## 三、支付系统

### 实现路径

**Phase 1: 接入微信支付（推荐先做这个）**
1. 注册微信支付商户号（需要企业营业执照）
2. 官网集成微信支付JSAPI（扫码支付）
3. 用户扫码 → 支付成功 → 微信回调服务器 → 服务器开通会员

**Phase 2: 接入支付宝（可选）**
1. 注册支付宝企业账号
2. 集成支付宝当面付/网页支付

**Phase 3: App鉴权**
1. App启动时检测本地token
2. 无token → 弹出登录窗口
3. 有token → 调用服务器 `/api/check-membership` 验证
4. 未付费 → 显示"开通会员"页面（嵌入网页或弹窗）
5. 已付费 → 正常使用

## 四、macOS公证（解决"不信任"提示）

### 操作步骤

**Step 1: 生成App专用密码**
1. 访问 https://appleid.apple.com
2. 登录你的 Apple ID
3. 进入 **"登录与安全"** → **"App专用密码"**
4. 点击 **"生成App专用密码"**
5. 标签写：`ShaoziClaw Notarization`
6. 复制生成的密码（格式类似 `abcd-efgh-ijkl-mnop`）

**Step 2: 配置环境变量**
在 Mac 终端执行（替换你的Apple ID邮箱和密码）：
```bash
export APPLE_ID="你的Apple ID邮箱"
export APPLE_PASSWORD="刚才生成的App专用密码"
export APPLE_TEAM_ID="7LKY65K92Q"
```

**Step 3: 重新打包**
```bash
cd shaoziclaw-app/frontend
rm -rf src-tauri/target/aarch64-apple-darwin/release/bundle/
npm run tauri build --target aarch64-apple-darwin
```

这次打包时 Tauri 会自动上传公证，完成后用户下载就不会有安全警告。
