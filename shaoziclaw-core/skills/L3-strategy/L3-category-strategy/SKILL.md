## Skill 元信息

**名称**：L3-category-strategy
**分类**：L3 战略决策 · 战略部
**级别**：高级 · 战略决策专家
**版本**：1.0
**触发词**：「品类机会」「要不要进这个赛道」「品类选择」「赛道分析」「市场规模」「品类趋势」「要不要做这个品类」「品类战略」「创业方向」

---

## 触发场景

当用户需要判断品类机会、制定品类战略、决定是否进入某个赛道、或进行品类升维/降维时，启用此 Skill。

---

## 输入

- 目标品类
- 品牌现状（是否已在此品类）
- 可投入资源（资金/团队/时间）
- 目标市场

## 工作流程

### Step 1：品类吸引力评估

```
【品类吸引力评估矩阵】

| 评估维度 | 权重 | 评估内容 | 得分(1-5) | 加权分 |
|----------|------|----------|------------|--------|
| 市场规模 | 20% | 年市场规模/增速 | | |
| 竞争强度 | 15% | 头部集中度/进入壁垒 | | |
| 盈利空间 | 20% | 品类平均净利率 | | |
| 增长潜力 | 15% | 未来3年增速 | | |
| 准入门槛 | 10% | 资金/技术/资源要求 | | |
| 政策环境 | 10% | 政策支持/限制 | | |
| 供应链成熟度 | 10% | 供应链完善程度 | | |
| 合计 | 100% | | | |

【品类规模与增速参考（2025-2026数据）】
| 品类 | 市场规模 | 增速 | 净利率参考 |
|------|----------|------|-----------|
| 火锅 | 6000亿+ | 5-8% | 8-15% |
| 茶饮 | 1500亿+ | 10-15% | 10-20% |
| 快餐简餐 | 1万亿+ | 8-12% | 8-15% |
| 烘焙 | 3000亿+ | 5-8% | 8-12% |
| 烧烤 | 2000亿+ | 10-15% | 10-18% |
| 卤味 | 1500亿+ | 8-12% | 10-20% |
```

### Step 2：竞争格局分析

```
【品类竞争格局评估】

□ 头部集中度：CR3（前三大品牌）份额
  - 高集中（CR3>50%）：领先者优势明显，进入门槛高
  - 中集中（CR3 20-50%）：有空间，但需要差异化
  - 低集中（CR3<20%）：碎片化，进入机会大

□ 区域壁垒：是否有明显的地域保护
  - 全国性品类：品牌认知全国通行（火锅/茶饮）
  - 地域性品类：区域品牌有机会（湘菜/川菜）

□ 差异化机会：这个品类是否有差异化空间？
  - 产品差异化：食材/口味/工艺
  - 场景差异化：堂食/外卖/零售
  - 客群差异化：年龄/收入/场景
  - 模式差异化：连锁/单店/混合
```

### Step 3：自身能力匹配

```
【能力匹配度自评】

□ 我有供应链优势吗？（原材料成本能控制吗？）
□ 我有差异化能力吗？（能做出不一样的东西吗？）
□ 我有获客能力吗？（能让目标顾客知道我吗？）
□ 我有运营能力吗？（能把店开好管好吗？）
□ 我有资金能力吗？（能撑过养店期吗？）

【能力-品类匹配矩阵】
        能力强
          △
          │
  战略蓝海   │  战略核心区
(我能做好，   │(我强+品类好)
 市场机会大)   │(重点进入)
              │
─────────────┼─────────────→ 能力弱
              │
  战略放弃    │  战略修复区
(我弱+市场差)  │(我弱但品类好)
              │ (谨慎进入/
              │ 需要补能力)
              │
              ▼
          能力弱
          市场规模大
```

### Step 4：品类战略选择

```
【品类战略四象限】

第一象限：进入（能力强+品类好）
□ 快速进入，抢占市场份额
□ 集中资源，做品类代表

第二象限：慎重（能力弱+品类好）
□ 深度研究，找到细分切入点
□ 借助外部资源（加盟/合伙/学习）
□ 快速验证，小步试错

第三象限：观望（能力强+品类差）
□ 等待品类机会
□ 或用现有能力跨界

第四象限：放弃（能力弱+品类差）
□ 不进入
□ 找其他机会
```

### Step 5：品类进入路径设计

```
【进入路径选择】

路径一：单点突破
- 先开1-2家模型店
- 验证产品和盈利模型
- 再考虑复制扩张

路径二：收购整合
- 收购已有门店/品牌
- 用资金换时间和能力

路径三：加盟学习
- 加盟成熟品牌
- 学习运营体系
- 再考虑自创

路径四：联创合伙
- 找有能力的合伙人
- 弥补自身短板
```

## 核心方法论

### 品类选择的三个问题

1. **这个品类够大吗？**——市场规模决定天花板
2. **我能做到前20%吗？**——竞争决定能不能活
3. **我能比现在更好吗？**——机会成本决定值不值得

### 品类战略三忌

1. **忌追热门**：今天火的品类明天可能死
2. **忌低估门槛**：看起来简单的品类竞争最激烈
3. **忌贪大求全**：找到自己能做好的细分切入
