# L3-brand-strategy：品牌战略与资产管理

> 制定长期品牌战略，实现品牌资产持续增值

---

## 触发场景

- 品牌老化，想重新定位但不知道怎么做
- 品牌太多太乱，想梳理品牌架构
- 想建立强势品牌但不知道方向
- 品牌知名度有但美誉度不够
- 品牌被山寨/抄袭，不知道怎么保护
- 品牌想升级但担心丢失老客户

---

## 核心方法论

### 一、品牌战略框架

#### 1. 品牌战略三层模型

```markdown
品牌战略三层：

战略层（顶层设计）
- 品牌使命：我们为什么存在
- 品牌愿景：我们想成为什么
- 品牌价值观：我们如何做事

规划层（中层架构）
- 品牌定位：我们是谁
- 品牌主张：我们给顾客什么承诺
- 品牌个性：我们是什么性格

执行层（落地支撑）
- 品牌标识：视觉识别系统
- 品牌语言：话语体系
- 品牌体验：产品/服务/环境
```

#### 2. 品牌价值评估

```markdown
品牌价值评估模型：

品牌价值 = 知名度 × 美誉度 × 忠诚度 × 溢价能力

一、知名度（市场渗透）
- 第一提及度：___
- 提示后知名度：___
- 无提示知名度：___
- 评估：□高 □中 □低

二、美誉度（口碑评价）
- 好评率：___%
- NPS净推荐值：___分
- 舆情正面率：___%
- 评估：□优 □良 □差

三、忠诚度（行为黏性）
- 复购率：___%
- 会员活跃度：___%
- 推荐意愿：___%
- 评估：□高 □中 □低

四、溢价能力（价格接受度）
- 相对竞品溢价：___%
- 顾客价格敏感度：□低 □中 □高
- 评估：□强 □中 □弱

综合品牌力：
- 得分≥80分：强势品牌
- 得分60-80分：知名但不够强
- 得分<60分：弱势品牌
```

### 二、品牌定位重塑

#### 1. 定位诊断方法

```markdown
品牌定位诊断四问：

问1：我们代表什么？
- 品类代表：是否是品类代名词？
- 价值代表：是否提供了独特价值？
- 情感代表：是否建立了情感连接？

问2：顾客为什么选择我们？
- 核心利益：功能性/情感性/自我表达性
- 差异化优势：与竞品有何不同？
- 可信度：顾客凭什么相信？

问3：我们的承诺是否兑现？
- 产品体验：是否持续提供承诺的品质？
- 服务体验：是否兑现服务承诺？
- 品牌体验：是否传递品牌承诺？

问4：定位是否与时俱进？
- 市场变化：定位是否适应新需求？
- 竞争变化：定位是否保持差异化？
- 自身变化：定位是否需要升级？

定位问题识别：
□ 定位模糊（什么都有，什么都不突出）
□ 定位过时（不符合新时代消费需求）
□ 定位混乱（内部不统一，传播不一致）
□ 定位过度（过于小众，市场太小）
```

#### 2. 定位重塑流程

```markdown
品牌定位重塑六步法：

Step 1：市场调研
- 消费者访谈
- 竞品分析
- 趋势研究
- 自我审视

Step 2：机会识别
- 品类机会
- 差异化机会
- 情感机会
- 场景机会

Step 3：定位确定
- 目标人群选择
- 差异化概念
- 信任背书
- 品牌主张

Step 4：验证测试
- 消费者测试
- 小范围试点
- 风险评估

Step 5：系统重塑
- 视觉升级
- 话语体系
- 产品调整
- 服务优化

Step 6：传播落地
- 品牌发布会
- 传播campaign
- 持续沟通
```

#### 2. 品牌保护策略

```markdown
品牌保护三道防线：

防线一：法律保护
- 全类注册（45类全注册）
- 近似商标注册
- 境外注册（如有海外市场）
- 监测与维权

防线二：运营保护
- 品牌使用规范（VI/SI执行）
- 供应链品质管控
- 渠道管控（授权管理）
- 打假行动

防线三：传播保护
- 品牌声量维护
- 舆情监控
- 消费者教育
- 价值传播

品牌维权流程：
1. 发现侵权（监测系统）
2. 证据保全（公证/截图）
3. 侵权认定（法律分析）
4. 维权行动（协商/投诉/诉讼）
5. 结果跟踪（执行+复盘）
```

### 四、品牌升级路径

#### 1. 品牌升级时机

```markdown
品牌升级信号：

市场信号：
□ 顾客流失率上升
□ 客单价下降
□ 年轻客群占比下降
□ 品牌搜索量下降

竞争信号：
□ 新品牌不断出现
□ 竞品升级成功
□ 差异化被缩小

内部信号：
□ 产品创新乏力
□ 服务体验下降
□ 员工士气低落
□ 老板/团队有升级意愿

升级时机判断：
- 市场繁荣期：升级好时机
- 逆势期：谨慎升级
- 重大转折点：必须升级

升级类型选择：
- 微调升级：优化细节，保持连续性
- 渐进升级：逐步调整，降低风险
- 颠覆升级：大刀阔斧，重新来过
```

#### 2. 品牌升级策略

```markdown
品牌升级三策略：

策略一：产品驱动升级
- 策略：通过产品创新带动品牌升级
- 适用：产品有升级空间
- 案例：某茶饮品牌通过新品带动品牌年轻化
- 注意：产品必须支撑品牌承诺

策略二：体验驱动升级
- 策略：通过服务/环境/体验升级
- 适用：服务/环境有提升空间
- 案例：某快餐品牌升级门店体验
- 注意：体验必须可感知、可传播

策略三：传播驱动升级
- 策略：通过品牌传播重塑形象
- 适用：需要改变认知
- 案例：某老字号通过国潮传播年轻化
- 注意：传播必须与产品体验一致

升级执行要点：
- 内部先行：员工认同才能外部传播
- 小步快跑：先试点再推广
- 持续投入：升级是长期工程
- 风险预案：准备回滚方案
```

### 五、品牌危机管理

#### 1. 品牌危机类型

```markdown
品牌危机四大类型：

类型一：产品危机
- 食品安全事故
- 产品质量问题
- 服务质量事故
- 案例：某品牌食安事件导致品牌受损

类型二：舆论危机
- 负面媒体报道
- 网络舆情爆发
- KOL负面评价
- 案例：某品牌被曝光卫生问题

类型三：信任危机
- 高管失德
- 企业丑闻
- 数据泄露
- 案例：某品牌创始人言论不当

类型四：竞争危机
- 品牌被山寨
- 商标被抢注
- 假冒泛滥
- 案例：某网红品牌被大量仿冒

危机分级：
- 一级（灾难级）：需创始人直接介入
- 二级（严重级）：需高管介入
- 三级（一般级）：部门处理即可
```

#### 2. 品牌危机应对

```markdown
品牌危机应对五步法：

Step 1：快速响应（黄金4小时）
- 成立危机小组
- 收集事实真相
- 制定应对策略
- 发布首个声明

Step 2：真诚沟通
- 官方声明要真诚
- 不推卸责任
- 主动承认问题
- 给出解决方案

Step 3：行动证明
- 立即整改问题
- 公开整改进度
- 邀请监督见证
- 持续透明沟通

Step 4：修复关系
- 顾客安抚
- 媒体沟通
- 员工稳定
- 合作方维护

Step 5：总结复盘
- 原因分析
- 经验总结
- 机制完善
- 品牌修复

危机沟通原则：
- 速度第一：第一时间发声
- 真诚第二：不撒谎、不狡辩
- 行动第三：解决方案比解释重要
- 持续第四：保持沟通直到平息
```

### 六、品牌文化塑造

#### 1. 品牌故事体系

```markdown
品牌故事三大类型：

类型一：创始故事
- 讲述创始初心
- 创业艰难历程
- 核心价值观形成
- 案例：某品牌创始人为孩子做一碗好面的故事

类型二：产品故事
- 产品的诞生历程
- 背后工艺/匠心
- 食材/产地故事
- 案例：某品牌10年坚持用某地食材的故事

类型三：顾客故事
- 顾客与品牌的故事
- 品牌陪伴顾客的时光
- 真实情感连接
- 案例：某品牌见证了某对情侣从恋爱到结婚

故事传播渠道：
- 官网/公众号：品牌故事专栏
- 门店铺设：品牌墙/故事墙
- 社交媒体：故事化内容
- PR传播：媒体采访/报道
- 员工传递：培训时讲述
```

#### 2. 品牌IP打造

```markdown
餐饮品牌IP打造路径：

路径一：虚拟形象
- 原创IP：设计品牌吉祥物/人物
- 案例：某品牌的卡通形象
- 应用：门店陈列/包装/传播

路径二：创始人IP
- 创始人故事化
- 创始人个人品牌
- 案例：某品牌创始人的匠人形象
- 注意：与品牌形象保持一致

路径三：员工IP
- 打造明星员工
- 员工故事传播
- 案例：某品牌"最帅服务员"的故事

路径四：产品IP
- 产品拟人化
- 产品故事化
- 案例：某品牌的"招牌鸡"有自己的名字和故事

IP运营要点：
- 持续性：长期投入，持续运营
- 一致性：与品牌调性统一
- 互动性：与用户产生互动
- 商业化：IP商业变现
```

## 使用说明

1. **顶层设计**：品牌战略是顶层设计，不能随意更改
2. **内外一致**：品牌承诺必须与产品/服务体验一致
3. **持续投入**：品牌建设是长期工程，不能急功近利
4. **保护意识**：品牌是无形资产，要做好保护
5. **与时俱进**：品牌也要与时俱进，但核心价值要坚守
