### 触发场景描述
品牌授权和联名是餐饮品牌扩展影响力的重要手段。本skill帮助品牌方理解授权和联名的逻辑，做出正确决策。

## 核心方法论

### 授权vs联名

```
两者区别：

品牌授权：
- 把品牌借给别人用
- 对方付授权费
- 我方提供IP/标准
- 风险共担，利益共享

跨界联名：
- 两个品牌一起做活动
- 双方共同投入
- 共同品牌曝光
- 互补共赢
```

### 品牌授权类型

```
餐饮品牌授权分类：

1. 品类授权
   - 把某个品类授权给别人
   - 例：XX品牌授权做火锅底料
   - 收益：授权费+销售分成

2. 区域授权
   - 把某个区域的经营权授权
   - 例：XX品牌XX区域代理
   - 收益：加盟费+管理费

3. 产品授权
   - 品牌出联名产品
   - 例：XX奶茶联名XX游戏
   - 收益：联名费+销量分成

4. 体验授权
   - 授权别人用品牌开快闪店
   - 例：XX品牌咖啡馆快闪
   - 收益：场地费+品牌露出
```

### 授权价值评估

```
品牌授权定价：

1. 品牌知名度
   - 全国知名：¥100万+
   - 区域知名：¥10-50万
   - 新锐品牌：¥5-20万

2. 品类热度
   - 热门品类：溢价30-50%
   - 成熟品类：正常价格
   - 衰退品类：折价

3. 授权范围
   - 全球：10倍溢价
   - 全国：3-5倍
   - 区域：正常价格

4. 授权期限
   - 长期（3年+）：打包价优惠
   - 短期（1年内）：按月计费
```

### 联名合作逻辑

```
联名成功的关键：

1. 品牌契合度
   - 目标人群重叠
   - 品牌调性匹配
   - 避免强行联名

2. 内容共创
   - 不是简单贴logo
   - 共同打造有趣内容
   - 让用户有参与感

3. 时机选择
   - 蹭热点/造热点
   - 品牌上升期合作
   - 不要在下坡路联名

4. 风险控制
   - 对方品牌是否有负面
   - 联名内容是否合规
   - 应急预案
```

## 操作流程

### Step 1：明确合作目的

```
合作目的：
□ 品牌曝光
□ 产品销售
□ 用户获取
□ 品牌升级
□ 跨界破圈
```

### Step 2：筛选合作方

```
筛选标准：
- 品牌调性是否匹配
- 目标人群是否重叠
- 对方品牌是否正向
- 合作诚意和能力
```

### Step 3：设计合作方案

```
方案要素：
- 合作形式（授权/联名）
- 合作内容（产品/活动/内容）
- 时间周期
- 费用分摊/收益分配
- 双方权责
```

### Step 4：合同与执行

```
合同必备条款：
- 授权范围和期限
- 质量标准和要求
- 费用和结算方式
- 违约责任
- 终止条件
```

### 五、合作建议

**结论：值得合作，但需要优化条件**

#### 优化点：
1. **降低投入风险**
   - 建议保底分成，减少我方风险
   - 首批物料少做，试水后再加

2. **提升分成比例**
   - IP方只出授权，我方承担主要投入
   - 建议分成比例提升到65%/35%

3. **增加品牌权益**
   - IP方推广资源要明确量化和执行
   - 联合营销要有持续性

#### 推荐方案：
```
合作期限：3个月（试水）
投入：¥80万（我方）
收益分配：我方65%/IP方35%
保底：IP方确保¥30万推广资源
```

### 七、注意事项

**合同必须明确的：**
1. IP使用范围和期限
2. 产品质量标准

4. 收益结算和审计权

**执行要点：**
1. 联名不能伤害品牌形象
2. 产品要好喝/好吃，联名是加分项
3. 推广资源要落实到位
4. 做好应急准备（IP方负面时的预案）

## 专家点评（避坑提示）

**联名误区**：
1. **只看热度** → 不考虑品牌契合度
2. **投入过大** → 联名效果不确定
3. **只看曝光** → 不看转化和口碑
4. **合同不清** → 事后纠纷多

**正确姿势**：
- 品牌契合比热度更重要
- 先小规模试水，不要all in
- 联名是锦上添花，不是救命稻草
- 合同要明确，丑话说前头
