## 核心方法论

### 餐饮融资阶段

```
餐饮企业融资路径：

天使轮 → A轮 → B轮 → C轮 → 上市

天使轮：50-200万
- 熟人/天使投资人
- 验证模式

A轮：500-2000万
- 机构投资人
- 打磨单店模型

B轮：3000万-1亿
- 知名机构
- 规模化扩张

C轮+：亿级以上
- PE/战略投资
- 冲刺上市

IPO：上市
- 主板/港股/美股
- 公众公司
```

### 融资利弊分析

```
融资的好处：
✓ 快速扩张
✓ 获得资源（资源/人脉/经验）
✓ 提升品牌
✓ 规范治理

融资的代价：
✗ 股权稀释
✗ 控制权减弱
✗ 短期业绩压力
✗ 信息披露
✗ 退出压力
```

### 什么时候融资

```
适合融资的情况：
✓ 单店模型成熟，能盈利
✓ 有可复制的标准化
✓ 扩张需要资金
✓ 需要资源赋能
✓ 创始人愿意接受资本规则

不适合融资的情况：
✗ 单店还没跑通
✗ 纯靠老板能力
✗ 不愿意稀释股权
✗ 想保持低调
```

### 餐饮估值方法

```
餐饮估值逻辑：

1. PS估值（市销率）
   - 估值 = 营收 × 倍数
   - 餐饮参考：1-3倍

2. PE估值（市盈率）
   - 估值 = 利润 × 倍数
   - 餐饮参考：10-20倍

3. 单店估值
   - 估值 = 单店利润 × 门店数 × 倍数
   - 餐饮参考：3-5倍

4. 市场法
   - 参考同类品牌融资/并购案例
```

## 使用示例

### 场景：是否融资决策

**用户输入**：
> 我是区域连锁品牌，8家直营店，年营收3000万，利润300万，有人想投我，要稀释30%股权，值不值得？

**Skill输出**：
```
## 餐饮品牌融资评估

### 一、现状数据
| 项目 | 数值 |
|------|------|
| 直营门店 | 8家 |
| 年营收 | ¥3,000万 |
| 年利润 | ¥300万 |
| 利润率 | 10% |
| 单店营收 | ¥375万 |
| 单店利润 | ¥37.5万 |

### 二、估值计算

#### 多种估值方法：
| 方法 | 计算 | 估值 |
|------|------|------|
| PS估值（2倍） | ¥3000万×2 | ¥6,000万 |
| PE估值（15倍） | ¥300万×15 | ¥4,500万 |
| 单店估值（4倍） | ¥37.5万×8×4 | ¥1,200万 |

#### 估值分析：
```
三种估值差异大的原因：
- PS高是因为餐饮营收规模大
- PE中等说明利润还行
- 单店估值低说明规模还不够

合理估值区间：¥3,000-5,000万
取中间：¥4,000万
```

### 三、融资方案分析

#### 投资方条件：
```
- 稀释股权：30%
- 我方持股：70%
- 投后估值：¥4,000万
- 融资金额：¥4,000万×30%/70% = ¥1,700万
```

#### 融资后股权：
```
创始人：70%（原80%稀释30%后）
投资人：30%
```

### 四、融资利弊分析

#### 好处：
| 好处 | 说明 |
|------|------|
| 资金¥1,700万 | 可开4-5家新店 |
| 资源加持 | 投资人可能有资源 |
| 品牌背书 | 知名机构投资 |
| 规范治理 | 资本要求规范 |

#### 代价：
| 代价 | 说明 |
|------|------|
| 股权稀释30% | 以后上市少拿钱 |
| 控制权减弱 | 投资人有一票否决权 |
| 业绩压力 | 年增长30%+要求 |
| 退出压力 | 投资人5-7年要退出 |

### 五、决策建议

#### 建议融资的情况：
- 有明确的扩张计划，需要资金
- 团队能力能支撑扩张
- 愿意接受资本规则和压力
- 估值合理

#### 建议不融资的情况：
- 现在活得挺好，不差钱
- 不愿意被管
- 扩张计划不清晰
- 估值不满意

### 六、谈判建议

如果决定融资，争取更好的条件：
```
1. 降低稀释比例
   - 目标：20-25%
   - 理由：品牌有价值

2. 争取业绩对赌
   - 不要固定增长要求
   - 设置合理的对赌条件

3. 保护性条款
   - 优先清算权要公平
   - 反稀释条款要合理
   - 一票否决权范围要限制

4. 融资用途明确
   - 钱花在刀刃上
   - 给投资人清晰的回报路径
```

### 七、最终建议

**综合评估：**

| 因素 | 评估 | 权重 |
|------|------|------|
| 估值合理性 | 中等（30%换¥1,700万） | 30% |
| 融资必要性 | 中（现有资金可能够用） | 25% |
| 条款友好度 | 待谈判 | 20% |
| 投资人质量 | 未知 | 25% |

**结论：**
- 如果扩张计划清晰、资金缺口大 → 值得谈
- 如果现状挺好、估值不满意 → 再等等
- 无论如何，要请专业律师看合同

### 八、不融资的发展路径

如果不融资，也可以通过以下方式扩张：
1. **利润再投入** → 每年开1-2家
2. **合伙人模式** → 员工/外部投资开店
3. **加盟模式** → 轻资产扩张
4. **银行贷款** → 不稀释股权
```

## 专家点评（避坑提示）

**融资误区**：
1. **以为融资就是成功** → 融资只是开始
2. **估值越高越好** → 高估值意味着高压力
3. **只要钱不要资源** → 好投资人有资源加持

**正确姿势**：
- 想清楚为什么融资
- 估值不是越高越好
- 选择认可你的投资人
- 请专业的人（律师/FA）帮你看条款
