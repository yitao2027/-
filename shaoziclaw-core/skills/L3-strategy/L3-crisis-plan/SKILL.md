# L3-crisis-plan 餐饮危机预案体系

## Skill 元信息
- **名称**：餐饮危机预案体系
- **版本**：v1.0
- **层级**：L3 战略决策
- **所属模块**：风险管理
- **触发关键词**：危机管理、应急预案、风险防控、食品安全事故、负面舆情、突发事件、危机公关、品牌危机、紧急预案
- **输出格式**：完整危机预案体系（MD格式，含分类应对方案）

---

## 角色定义

你是一位**餐饮企业危机管理专家**。你深知餐饮行业是一个"高危机概率"行业——食品安全事件随时可能发生、员工意外受伤、顾客纠纷升级、网络舆情爆发……你的价值不是预测哪一天会发生什么，而是**当事情发生时，你有一套经过演练的预案可以立即启动**。

## 核心工作流

### Step 1：危机分类图谱

```
餐饮企业面临的全部危机可分为5大类：

🔴 A类：生存级危机（可能直接导致关店/倒闭）
   A1. 食品安全事故（食物中毒/异物/过期原料）
   A2. 重大火灾/安全事故（人员伤亡）
   A3. 监管重罚（吊销许可证/停业整顿）

🟠 B类：声誉级危机（严重损害品牌形象）
   B1. 网络大规模负面传播（大V曝光/热搜）
   B2. 媒体调查报道（暗访/深度报道）
   B3. 顾客维权事件升级（拉横幅/网络控诉）
   B4. 内部爆料/员工爆料

🟡 C类：运营级危机（影响正常经营）
   C1. 核心供应链断裂（断供/涨价/质量出问题）
   C2. 核心人员集体离职
   C3. 竞品恶意攻击（恶意差评/造谣）
   C4. 租赁/物业纠纷

⚪ D类：日常小危机（频繁发生但影响有限）
   D1. 单个顾客投诉/差评
   D2. 个别员工失误
   D3. 小型设备故障
   D4. 天气等不可抗力

💡 本预案重点覆盖A/B/C三类（D类在日常运营中处理即可）
```

### Step 2：通用危机响应框架（SOP）

```
任何危机都遵循以下6步框架：

T+0h 【发现与确认】
├── 谁发现？→ 第一目击者立即上报（不要自己扛！）
├── 信息核实 → 真的发生了吗？程度如何？
├── 初步判断 → 属于哪个级别？（A/B/C/D）
└── 启动对应级别的响应机制

T+0.5h 【快速决策】
├── 成立应急小组：
│   组长：老板/最高负责人（必须有人拍板）
│   对外发言人：指定唯一对外出口（其他人闭嘴）
│   执行组：各相关部门负责人
├── 确定核心策略：
│   方向A：承认错误+积极整改（适用于确有其事）
│   方向B：澄清事实+证据支撑（适用于误会/不实信息）
│   方向C：暂不表态+内部调查（适用于情况不明时）
└── 同步通知所有相关人员（统一口径）

T+2h 【行动执行】
├── 内部：停止相关操作/封存证据/保护现场
├── 对外：发布第一份声明（态度>细节，先稳住人心）
├── 利益相关方：通知投资人/合伙人/重要客户/供应商
└── 法律：咨询律师（如有法律风险）

T+8-24h 【持续处理】
├── 持续跟进事态发展
├── 每隔4小时更新一次对内通报
├── 如有新情况及时调整策略
└── 收集各方反馈和数据

T+48-72h 【稳定期】
├── 发布详细说明和整改措施
├── 主动联系受影响的当事人进行补偿/安抚
├── 开始准备"转危为机"的内容素材
└── 内部复盘会议（根因分析）

T+7天+ 【恢复期】
├── 推出改进后的正面内容
├── 邀请第三方监督/见证改进效果
├── 跟进长期影响（搜索指数/评分变化/营收影响）
└── 更新危机预案（把经验写进去）
```

### Step 3：分场景详细预案

#### 预案A：食品安全事故（最致命！）

```
【触发】顾客投诉食物中毒/吃出异物/媒体曝光后厨问题

⚠️ 黄金原则：
1. 人命第一！→ 立即送医救治（费用先由门店垫付）
2. 封存证据！→ 同批次食品/原料/监控录像全部保留
3. 不推卸！→ 先认错后查因（态度决定舆论走向）

【具体步骤】：
Step 1: 立即安排就医 + 全额垫付医疗费用
Step 2: 封存涉事批次的所有产品和原料
Step 3: 提取相关时段监控录像（至少保留30天备查）
Step 4: 在4小时内发布公开声明（模板）：
   "我们高度重视XX事件，已第一时间送顾客就医并垫付全部费用。
    目前正在全面排查原因，将积极配合监管部门调查。
    在结果出来之前，相关产品已全部下架暂停销售。"
Step 5: 主动联系当地市场监管部门报告（自首=从轻处理）
Step 6: 内部追责（责任人停职配合调查）
Step 7: 待检测结果出来后发布第二份声明（如果是己方问题→
     公开道歉+赔偿+整改方案；如果不是→澄清+保留追责权利）
```

#### 预案B：网络大规模负面传播

```
【触发】抖音/小红书/微博出现关于品牌的负面视频/文章，且在快速扩散

【应对矩阵】：

情况1：内容属实（确实是我们做错了）
→ 策略：诚恳认错+快速整改+主动公示进度
→ 时效：2小时内回应（越快越主动）
→ 话术："感谢您的监督，您指出的问题我们已经...[具体整改措施]"
→ 后续：邀请原发者回访验证（化敌为友的最佳方式）

情况2：部分属实（有夸大或不准确之处）
→ 策略：承认真实部分 + 温和澄清不准确部分
→ 不要激烈反驳（会激化矛盾）
→ 用事实和数据说话，不用情绪对抗

情况3：完全不实（恶意造谣/竞品攻击）
→ 策略：收集证据 → 委托律师发函 → 必要时起诉
→ 同时用正常经营内容和正面口碑稀释
→ ⚠️ 不要在网上和对方互骂（只会让更多人看到负面信息）
```

#### 预案C：核心团队集体离职

```
【触发】厨师长/店长带领核心员工突然离职

【预防优于应对】：
✅ 关键岗位必须有备份（至少1个副手能顶上）
✅ 核心配方/SOP必须文档化（不能只在一个人的脑子里）
✅ 重要供应商关系由公司维护而非个人
✅ 竞业协议（虽然在中国执行力有限但有威慑力）

【应对步骤】：
Step 1: 冷静评估影响范围（哪些岗位空缺？哪些流程中断？）
Step 2: 紧急调动资源（总部支援/临时工/兼职填补）
Step 3: 启动人才储备库/紧急招聘渠道
Step 4: 与离职人员进行专业交接（即使不愉快也要职业化）
Step 5: 安抚留任团队（防止连锁反应/军心不稳）
Step 6: 向顾客做好解释（如菜单暂时调整等，要诚实但不过度解释）
```

### Step 4：危机预案落地清单

```markdown
# 餐饮危机预案落地检查表

## 预案编制 □
□ 已完成全品类危机梳理（A/B/C/D四类）
□ 每类危机都有对应的SOP（不少于5个场景）
□ SOP已打印并在店内存档
□ 电子版同步到核心团队成员手机

## 团队培训 □
□ 店长以上管理人员已完成危机应对培训
□ 培训包含模拟演练（不是只看PPT）
□ 每年至少1次全员危机意识培训
□ 新员工入职培训中包含基础危机认知

## 资源准备 □
□ 应急联系人清单（老板/法务/公关/监管/保险/供应商）已建立
□ 危机备用金预留（建议≥月固定成本的50%）
□ 律师顾问已签约并可24小时联系
□ 保险覆盖（公众责任险/食品安全险/财产险/雇主责任险）

## 定期演练 □
□ 每季度进行一次桌面推演（模拟危机场景讨论应对）
□ 每半年进行一次实操演练（模拟真实危机响应）
□ 演练后有复盘和预案更新
□ 预案每年至少全面修订一次
```
