# L3-multi-store-management
# 多店连锁管控体系

**层级：** L3 战略决策  
**部门归属：** 战略运营部  
**触发词：** 多店管理、连锁管控、多门店、连锁体系、远程管理、多店运营、区域管理

---

## 一、Skill 定位

**解决什么问题：**  
帮助已有2家以上门店的餐饮经营者建立可扩张的多店管控体系，解决品质不一致、人员管理混乱、信息不透明等扩张期核心痛点。

**扩张规律：**
- 1→3家：管理者亲自盯，勉强撑得住
- 3→10家：必须建立体系，否则乱
- 10家以上：必须有专业管理团队，否则崩

---

## 二、核心方法论

### 2.1 多店管控四层体系

```
                  战略层
              （老板/创始团队）
                    ↓
                 总部支持层
          （标准/培训/供应链/营销）
                    ↓
               区域管理层
          （区域经理/督导，管5-15家店）
                    ↓
               门店执行层
         （店长+各岗位员工）
```

**各层级核心职责：**

| 层级 | 主要职责 | 关键数字 |
|------|---------|---------|
| 战略层 | 品牌方向/开店节奏/资本运营 | 整体ROI/品牌健康度 |
| 总部支持 | 标准制定/供应链/培训/营销 | SOP执行率/标准化得分 |
| 区域管理 | 督导执行/人员管理/数据监测 | 管辖区域综合评分 |
| 门店执行 | 日常运营/成本控制/顾客服务 | 单店各项KPI |

### 2.2 多店品质一致性管控

```
品质一致性是多店最大挑战，三道防线：

【第一道防线：标准化】
→ 核心菜品的SOP文档化（配方/工艺/摆盘标准）
→ 服务流程标准化（迎宾/点餐/出菜/送客标准话术）
→ 环境标准化（VI规范/卫生标准/陈设要求）

【第二道防线：培训认证】
→ 新店开业前：所有员工通过标准化考核
→ 老店定期：每季度核心技能复训
→ 认证机制：通过考核方可上岗（不合格者暂缓）

【第三道防线：督导检查】
→ 定期督导：每家门店每月至少1次督导检查
→ 神秘顾客：每季度安排神秘顾客体验（顾客视角）
→ 数字化监控：通过POS数据/摄像头远程监控关键指标
→ 交叉互查：A区店长检查B区（发现更多问题，减少人情分）
```

### 2.3 关键KPI体系设计

**多店统一监控的核心指标：**

```
财务指标（每月）：
□ 月营业额（对比预算/对比同期）
□ 食材成本率（目标区间）
□ 人力成本率（目标区间）
□ 房租成本率（目标区间）
□ 单店净利润率（优先看趋势）

运营指标（每周）：
□ 日均客单量（趋势：增/减/平）
□ 翻台率/出杯数（效率指标）
□ 平均客单价（产品结构健康度）
□ 差评率（<1%为目标）

团队指标（每月）：
□ 月度离职人数（目标：离职率≤10%/月）
□ 新员工培训完成率
□ 督导检查综合得分（满分100，目标≥85）

品牌指标（每季度）：
□ 大众点评综合评分（各店）
□ 神秘顾客评分
□ 顾客NPS（净推荐值）
```

### 2.4 店长选拔与管理

```
店长是多店管控的核心节点，选人比管人重要：

店长画像（从优秀员工中选拔）：
→ 技能：能顶任意一个岗（不能"眼高手低"）
→ 性格：负责任、抗压、沟通能力强
→ 数字：理解基本财务逻辑（成本率/利润率）
→ 人际：员工愿意跟着他/她干

店长赋能体系：
□ 授权清晰：明确店长可以自主决策的范围
  （例：单笔支出≤X元可自主/人事变动需总部确认）
□ 数据透明：店长每天看哪些数据，怎么解读
□ 定期沟通：每周1次店长会议（线上视频/电话）
□ 激励设计：店长薪酬与门店利润挂钩（利润分红制）

防坑清单：
❌ 店长只会干活，不会管人（管理能力断层）
❌ 总部微管理，店长无法有效决策（授权不足）
❌ 店长薪酬固定，与门店好坏无关（激励失效）
❌ 没有接班人机制，店长离职=门店瘫痪
```

### 2.5 多店供应链统一管理

```
多店规模带来的供应链优势（必须主动抓取）：

① 集采降本
→ 3家以上：可以跟供应商谈整体供货，要求批量折扣
→ 5家以上：可以考虑自建中央厨房（部分半成品统一加工）
→ 10家以上：建立稳定供应商合作协议（锁价/专供）

② 统一采购流程
→ 总部集中采购：统一谈价，分配到各门店
→ 各店日常补货：按标准用量申请，总部审批
→ 财务对账：每月统一结算，不各自为政

③ 中央厨房可行性评估
→ 适合：有标准化工艺的菜品/需要统一口味的食材
→ 不适合：需要现场烹饪体现"锅气"的菜品
→ 投入阈值：单独核算中央厨房成本，3年内回正则值得

④ 供应链品控
→ 统一供应商评级体系
→ 定期审计核心供应商（品质/稳定性/应急能力）
→ 关键食材必须有备用供应商
```

### 2.6 多店数字化管控系统

```
建议优先级（按投入产出排序）：

优先级1：统一POS系统（必须）
→ 所有门店用同一套POS，数据统一汇总
→ 老板随时在手机APP查看各门店实时营业额
→ 推荐系统：美团收银/客如云/商米等

优先级2：进销存管理（高优先）
→ 统一采购管理：知道每家店用了多少食材
→ 数据价值：发现成本异常的门店（可能是浪费/被盗）

优先级3：员工打卡考勤（高优先）
→ 远程查看员工到岗情况
→ 连接工资核算，减少考勤纠纷

优先级4：门店摄像（中优先）
→ 后厨/收银关键区域
→ 远程巡店，发现问题及时响应

优先级5：客户数据管理（中优先）
→ 统一会员体系（各店通用）
→ 顾客消费数据分析
```

## 四、触发条件与输出

**输入收集：**
```
请告诉我：
1. 目前门店数量？（已开的和计划开的）
2. 管理层配置？（有无区域经理/专职督导）
3. 目前最大管控痛点？（品质不一/数据不透明/店长问题）
4. 目前是否有统一POS/进销存系统？
5. 扩张计划？（1年内还会开几家）
```

**输出内容：**
- 多店管控体系设计方案（四层架构）
- 品质一致性三道防线建议
- 核心KPI指标体系
- 店长选拔和激励方案
- 数字化系统建议（按优先级）
