餐饮老板从"自己干"到"带人干"，从"管店"到"管人"，是最大的成长门槛。本skill帮助餐饮老板提升领导力。

## 核心方法论

### 餐饮老板成长阶段

```
老板成长四阶段：

阶段1：自己干（1-2家店）
- 亲力亲为
- 技术型老板
- 精力有限

阶段2：找人干（3-5家店）
- 开始招人
- 不放心别人
- 累但扩张慢

阶段3：用人干（5-10家店）
- 学会授权
- 建团队
- 系统化管理

阶段4：用系统干（10家+）
- 机制代替人
- 数字化管理
- 平台化运营
```

### 领导力三要素

```
领导力 = 愿景力 × 执行力 × 凝聚力

愿景力：让团队知道去哪里
执行力：让团队能到达
凝聚力：让团队愿意一起走
```

### 餐饮老板常见问题

```
常见问题诊断：

问题1：亲力亲为
- 表现：什么事都要自己管
- 原因：不放心/不会授权
- 结果：自己累死，团队长不大

问题2：情绪化
- 表现：高兴就好说话，不高兴就骂人
- 原因：没有管理情绪
- 结果：团队没有安全感，离心离德

问题3：只管业务
- 表现：只关心营业额，不管团队
- 原因：不懂带团队
- 结果：人员流失率高

问题4：小气
- 表现：不舍得分钱/分享
- 原因：格局不够
- 结果：留不住人才
```

## 操作流程

### Step 1：自我评估

```
领导力自评：
□ 是否亲力亲为过多
□ 是否情绪化
□ 是否只管业务不管人
□ 是否舍得分享
□ 是否有愿景
□ 是否愿意学习
```

### Step 2：针对性提升

```
提升路径：
亲力亲为 → 学会授权
情绪化 → 管理情绪、就事论事
只管业务 → 建立人才梯队
小气 → 设计激励机制
```

### Step 3：建立机制

```
机制建设：
□ 会议机制（周会/月会/年会）
□ 汇报机制（日报/周报）
□ 激励机制（KPI/分红/股权）
□ 培训机制（带教/晋升）
```

## 使用示例

### 场景：老板成长瓶颈

**用户输入**：
> 我开了3家店，每家店我都盯得很紧，但店里还是问题不断，团队也不稳定，是不是我的管理方式有问题？

**Skill输出**：
```
## 餐饮老板领导力诊断与提升

### 一、问题诊断

根据你的描述，可能存在以下问题：
| 问题 | 表现 | 根本原因 |
|------|------|----------|
| 亲力亲为 | 每家店都盯 | 不放心授权 |
| 团队不稳定 | 离职率高 | 激励不足/文化缺失 |
| 问题不断 | 各种小问题 | 没有标准化/检查机制 |

### 二、核心问题：亲力亲为

**为什么亲力亲为是问题：**
```
你的精力：100%
分配到3家店 = 每家33%

vs

专业店长精力：100%
专注1家店 = 100%

结论：你管的力度 < 店长管的力度
```

**从亲力亲为到授权：**

Step 1：明确什么必须自己管
```
老板管：
✓ 战略方向
✓ 重大投资
✓ 核心人才
✓ 品牌定位

店长管：
○ 日常运营
○ 员工管理
○ 销售达成
○ 顾客服务
```

Step 2：找到/培养店长
```
选项A：外部招聘
- 招聘有经验的店长
- 薪资：¥8,000-15,000+提成
- 注意：背调要充分

选项B：内部培养
- 从员工中提拔
- 需要时间，但忠诚度高
- 建立晋升通道
```

Step 3：建立授权机制
```
授权 checklist：
□ 明确职责边界
□ 设定目标和KPI
□ 定期汇报机制
□ 重大事项上报机制
□ 监督检查机制
□ 奖惩激励机制
```

### 三、提升领导力行动计划

#### 第一阶段：转变心态（1-3个月）
| 行动 | 目标 | 验证 |
|------|------|------|
| 减少亲自巡店 | 从每天3次→每天1次 | 门店是否正常运转 |
| 培养核心员工 | 每人带1个徒弟 | 是否有骨干成长 |
| 参加管理培训 | 至少1次系统学习 | 管理思维提升 |

#### 第二阶段：建立机制（3-6个月）
| 行动 | 目标 | 验证 |
|------|------|------|
| 建立店长例会 | 每周1次 | 团队是否对齐 |
| 设定店长KPI | 明确考核指标 | 是否有激励 |
| 建立会议制度 | 日/周/月会 | 信息是否通畅 |

#### 第三阶段：系统管理（6-12个月）
| 行动 | 目标 | 验证 |
|------|------|------|
| 培养第二梯队 | 每个岗位有备份 | 人才梯队形成 |
| 数字化管理 | 经营数据看板 | 管理效率提升 |
| 激励机制落地 | 分红/股权方案 | 团队稳定性提升 |

### 四、关键认知升级

**从"我"到"我们"：**
```
之前：我的店、我的员工、我的客户
现在：我们的店、我们的团队、我们的客户
```

**从"做事"到"育人"：**
```
之前：店是我开的，我要负责
现在：培养人，让人为自己负责
```

**从"控制"到"激励"：**
```
之前：不放心，所以要盯着
现在：定好规则，让员工为自己干
```

### 五、团队稳定性提升

**离职原因TOP3：**
1. 钱不够（薪酬不公平/低于市场）
2. 看不到希望（没有晋升通道）
3. 干得不开心（老板脾气差/文化差）

**解决方案：**
| 原因 | 解决方案 |
|------|----------|
| 薪酬低 | 薪酬设计（底薪+绩效+提成+分红） |
| 没晋升 | 建立晋升通道（员工→主管→店长） |
| 不开心 | 改进沟通方式，建立正向文化 |
```

## 专家点评（避坑提示）

**勇哥原话**："餐饮老板最大的成长，是学会放手。学会放手，你才能从一家店到十家店，从十家店到一百家店。"

**常见误区**：
1. **以为自己是救火队长** → 累死自己
2. **以为员工和自己一样上心** → 现实打脸
3. **以为钱能解决一切** → 留人更要留心

**正确姿势**：
- 建系统，用机制代替人
- 培养人，让人为自己干
- 领导力是让别人愿意跟着你干
