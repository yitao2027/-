### 触发场景描述
加盟纠纷是加盟体系中最棘手的问题。本skill帮助品牌方和加盟商正确处理纠纷，保护自身权益。

## 核心方法论

### 常见加盟纠纷类型

```
加盟纠纷TOP5：

1. 区域保护纠纷
   - 品牌方在保护范围内又开了店
   - 加盟商认为违约

2. 服务支持纠纷
   - 加盟商认为品牌方支持不到位
   - 承诺的东西没兑现

3. 物料采购纠纷
   - 强制采购/价格过高
   - 私采被罚

4. 合同解除纠纷
   - 品牌方单方解除
   - 加盟商被清退

5. 品牌违规纠纷
   - 品牌方虚假宣传
   - 资质问题
```

### 纠纷预防

```
预防大于处理：

品牌方预防：
✓ 合同条款清晰明确
✓ 承诺落实到书面
✓ 区域保护写进合同
✓ 定期沟通，了解问题

加盟商预防：
✓ 合同要看清楚
✓ 口头承诺要落实
✓ 保留沟通记录
✓ 了解自己权利
```

### 纠纷处理原则

```
处理原则：

1. 先协商后法律
   - 协商是首选，成本低
   - 法律是最后手段

2. 事实为依据
   - 拿出证据
   - 不要情绪化

3. 利益平衡
   - 双方都有诉求
   - 找共同利益点

4. 及时止损
   - 不要让纠纷扩大
   - 尽快解决
```

## 使用示例

### 场景：品牌方处理加盟纠纷

**用户输入**：
> 加盟商说我们在他的区域又开了一家店，违反了区域保护，要告我们，但我们合同写的是"尽量不在保护范围内开店"，这个怎么处理？

**Skill输出**：
```
## 加盟纠纷处理方案

### 一、纠纷诊断

| 项目 | 内容 |
|------|------|
| 纠纷类型 | 区域保护纠纷 |
| 加盟商诉求 | 赔偿损失/解除合同 |
| 合同条款 | "尽量不开"（非承诺） |
| 我方立场 | 合同未明确承诺 |
| 对方态度 | 强硬，要起诉 |

### 二、法律分析

**我方优势：**
- 合同写的是"尽量"，不是"承诺"
- 没有明确的法律责任

**我方劣势：**
- "尽量"字眼可能被解读为软性承诺
- 从商业诚信角度有道义责任
- 加盟商可能有舆论优势

**法律风险：**
| 风险 | 可能性 | 后果 |
|------|--------|------|
| 赔偿损失 | 中 | 赔付1-3年加盟费 |
| 解除合同 | 低 | 合同履行多年 |
| 舆论影响 | 高 | 对品牌伤害大 |

### 三、解决方案

#### 方案1：协商和解（推荐）

**主动联系加盟商：**
```
沟通策略：
1. 承认理解有误，表达了歉意
2. 解释当时的情况（新店选址的考量）
3. 提出补偿方案
4. 争取和解
```

**补偿方案：**
| 方案 | 内容 | 成本 |
|------|------|------|
| 方案A | 延长加盟期2年+减免部分费用 | ¥3-5万 |
| 方案B | 现金补偿¥5万+优先开下家店 | ¥5万 |
| 方案C | 免1年管理费+下次加盟优先权 | ¥2-3万 |

#### 方案2：法律应对

如果协商不成：
- 准备合同条款解释
- 收集选址合理性证据
- 准备应诉材料
- 考虑反诉可能

### 四、谈判话术

```
开场：
"李总，感谢您这么多年对品牌的支持。关于新店的事，我们也一直在关注这个区域的规划，当时选址确实没有提前和您沟通，这是我们的疏忽..."

表达诚意：
"您的感受我们理解，合同写的是'尽量'，但我们也应该更谨慎，避免给您造成困扰。"

提出方案：
"我们愿意给出一些补偿...你看这样行不行..."

收尾：
"我们希望能够妥善解决这件事，继续保持长期合作。"
```

### 五、预防措施

**后续改进：**
1. 合同改"尽量"为明确的承诺或排除
2. 开新店前主动和区域加盟商沟通
3. 建立选址通报机制
4. 定期和加盟商沟通区域规划

### 六、结论

**建议：主动和解**

理由：
1. 法律风险存在
2. 舆论风险更大
3. 和解成本可控
4. 维护长期关系

**和解底线：** 赔偿不超过¥8万

**执行：** 尽快联系加盟商，协商解决
```

## 专家点评（避坑提示）

**纠纷处理误区**：
1. **以为合同写了就没事** → 解释可能不一样
2. **强硬对抗** → 舆论风险更大
3. **拖延不处理** → 小事拖成大事

**正确姿势**：
- 预防为主，合同写清楚
- 协商优先，法律是最后手段
- 及时处理，不要让舆论发酵
