## 工作流程

### Step 1：竞争地位判断

```
【竞争地位五段位】

第一（领先者）：市场份额>30%，品类代表
- 战略：扩大领先优势，防守为主
- 关键词：品类代表、品牌领导

第二（挑战者）：市场份额10-30%，有野心
- 战略：主动进攻，抢夺份额
- 关键词：差异化、速度

第三（跟随者）：市场份额5-10%，跟随策略
- 战略：选择性进攻，找细分市场
- 关键词：性价比、差异化

第四（补缺者）：市场份额<5%，小而美
- 战略：深耕细分，区域为王
- 关键词：特色、忠诚度

第五（新进入者）：刚进入市场
- 战略：站稳脚跟，找到立足点
- 关键词：差异化切入、快速迭代
```

### Step 2：四类竞争战略选择

```
【战略一：防御战（适合领先者）】

核心逻辑：保护自己的领先地位，不是主动进攻

行动原则：
□ 找到领先地位的"裂缝"并堵住
□ 永远不要认为自己已经赢了
□ 主动封堵竞争对手的最强进攻

具体行动：
- 持续创新，不给对手可乘之机
- 在竞争对手崛起的市场加大投入
- 推出侧翼产品封堵进攻空间

【战略二：进攻战（适合挑战者）】

核心逻辑：在领先者的优势中找弱点

行动原则：
□ 找到领先者可以做到但没有做到的事
□ 在单一维度形成压倒性优势
□ 不四面出击，集中火力攻一点

具体行动：
- 如果领先者做高端，我就做性价比
- 如果领先者做堂食，我就做外卖
- 如果领先者全国铺开，我就在区域深耕

【战略三：侧翼战（适合跟随者/补缺者）】

核心逻辑：在领先者忽视的战场开战

行动原则：
□ 找到一个未被满足的小市场
□ 投入足够的资源打透
□ 成功后再考虑扩张

具体行动：
- 专注某个细分人群（学生/老人/白领）
- 专注某个细分场景（夜宵/早餐/一人食）
- 专注某个细分区域（某个社区/某条街）

【战略四：游击战（适合小品牌/区域品牌）】

核心逻辑：在巨头不愿/不屑进入的领域生存

行动原则：
□ 找到大品牌看不上的小市场
□ 保持灵活性，打得过就打，打不过就跑
□ 建立区域性忠诚度

具体行动：
- 在特定社区深耕，建立人情网络
- 做本地特色，建立情感连接
- 做连锁品牌不屑做的服务（定制/特殊需求）
```

### Step 3：竞争战略制定

```
【战略选择决策树】

第一步：我的竞争地位是什么？
→ 领先者 → 防御战
→ 挑战者 → 进攻战
→ 跟随者 → 侧翼战
→ 补缺者 → 游击战

第二步：我的核心优势是什么？
□ 产品差异化强 → 产品领先战略
□ 服务体验好 → 服务差异化战略
□ 价格有优势 → 成本领先战略
□ 渠道覆盖广 → 渠道渗透战略
□ 品牌有认知 → 品牌溢价战略

第三步：竞争对手最怕什么？
□ 怕我们的价格 → 价格战
□ 怕我们的产品 → 产品战
□ 怕我们的速度 → 速度战
□ 怕我们的服务 → 服务战
□ 怕我们的创新 → 创新战

第四步：我愿意付出什么代价？
□ 愿意牺牲短期利润 → 烧钱抢市场
□ 愿意放弃某些市场 → 聚焦核心
□ 愿意持续投入 → 长期主义
```

### Step 4：战略实施路径

```
【战略落地三阶段】

阶段一（1-3个月）：战略锁定
□ 明确战略方向，不摇摆
□ 集中资源于核心战场
□ 快速验证战略有效性

阶段二（3-12个月）：战略执行
□ 组织架构配合战略调整
□ 资源向战略方向倾斜
□ 建立战略KPI追踪机制

阶段三（1-3年）：战略迭代
□ 根据市场反馈调整战略
□ 从单一战略向组合战略演进
□ 建立竞争壁垒
```

## 核心方法论

### 竞争战略四问

1. **我要打谁？**——选对竞争对手，不要四面树敌
2. **我在哪里打？**——选对战场，不要在别人的主场作战
3. **我怎么打？**——用什么武器，投入多少资源
4. **我能撑多久？**——战略要有持久力，不是一锤子买卖

### 竞争战略三大忌

1. **忌模仿领先者**：跟随策略短期可行，长期没有出路
2. **忌全面战争**：资源分散=处处挨打
3. **忌忽视小对手**：小对手往往是最灵活的竞争者
