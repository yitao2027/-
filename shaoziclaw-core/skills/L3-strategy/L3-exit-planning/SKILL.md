### 触发场景描述
餐饮退出是老板必须考虑的问题。本skill帮助理解退出的方式、时机和正确流程，实现资产价值最大化。

## 核心方法论

### 退出时机判断

```
退出时机判断：

信号1：连续亏损
- 亏损超过6个月
- 看不到扭亏希望
- → 及时止损

信号2：精力不济
- 老板不想干了
- 身体/家庭原因
- → 体面退出

信号3：更好的机会
- 有更好的投资项目
- 餐饮已经不是最优选择
- → 价值最大化退出

信号4：被动退出
- 商场撤场
- 物业问题
- 合同到期不续
- → 提前规划
```

### 退出方式

```
餐饮退出五大方式：

1. 转让给个人
   - 卖给其他餐饮人
   - 卖给想入行的人
   - 优点：灵活、隐私
   - 缺点：价格谈判长

2. 转让给品牌
   - 被其他品牌收购
   - 加盟转直营
   - 优点：价格可能更高
   - 缺点：条件苛刻

3. 加盟商退出
   - 品牌方回购
   - 转让给新加盟商
   - 优点：有品牌方支持
   - 缺点：受品牌约束

4. 关店清算
   - 直接关闭
   - 处理设备/库存
   - 优点：干净利落
   - 缺点：资产浪费

5. 转型
   - 换品类
   - 换模式
   - 换定位
   - 优点：延续价值
   - 缺点：需要投入
```

### 资产估值

```
餐饮资产估值方法：

1. 整体转让估值
   - 看利润：年利润×年数
   - 看营收：月营收×3-6个月
   - 看位置：商圈价值

2. 设备转让
   - 二手设备行情
   - 折旧后的价值
   - 通常是原价的20-40%

3. 装修残值
   - 通常不算钱
   - 有时甚至要贴钱拆
   - 看下一家能不能用

4. 存货处理
   - 食材尽快处理
   - 临期品打折卖
   - 库存尽快清
```

## 操作流程

### Step 1：评估退出类型

```
退出类型判断：
□ 主动退出（不看好/精力不济）
□ 被动退出（亏损/物业问题）
□ 转型退出（换品类/换模式）
```

### Step 2：价值最大化准备

```
准备清单：
□ 整理账目（清晰展示经营情况）
□ 整理设备清单（拍照/估价）
□ 整理合同（租约/品牌合同）
□ 准备转让材料（转让说明书）
□ 清理库存（尽快变现）
```

### Step 3：寻找买家

```
寻找渠道：
- 同行业打听
- 58同城/百姓网
- 餐饮圈社群
- 中介/FA
- 品牌方（如果是加盟）
```

### Step 4：谈判与成交

```
谈判要点：
- 价格（不要报底价）
- 付款方式（尽量一次性）
- 交接时间（给足时间清货）
- 员工安置（谁负责）
- 债务处理（谁承担）
```

## 使用示例

### 场景：关店退出决策

**用户输入**：
> 我在商场开了一家餐厅，租约还有2年，但已经连续亏损8个月，每月亏2万，商场可能明年不续约了，是继续撑还是现在退出？

**Skill输出**：
```
## 餐饮退出决策分析

### 一、现状数据
| 项目 | 数值 |
|------|------|
| 月亏损 | ¥20,000 |
| 累计亏损 | ¥160,000 |
| 剩余租约 | 2年 |
| 商场续约可能 | 低（可能明年不续） |
| 继续撑到合同到期总亏损 | ¥20,000×24 = ¥480,000 |

### 二、继续撑的分析

**继续撑的代价：**
| 成本项 | 金额 |
|--------|------|
| 剩余24个月亏损 | ¥480,000 |
| 人工成本（老板时间） | 难以量化 |
| 机会成本 | 可能错过其他机会 |

**继续撑的可能结果：**
1. 扭亏为盈 → 需要做什么改变？
2. 维持现状 → 再亏48万
3. 越来越差 → 亏得更多
4. 被商场提前解约 → 更被动

### 三、现在退出的分析

**退出收益：**
| 收入项 | 金额 | 说明 |
|--------|------|------|
| 转让费 | ¥50,000-100,000 | 含设备+位置溢价 |
| 押金回收 | ¥30,000-50,000 | 商场押金 |
| 库存处理 | ¥5,000-10,000 | 尽快清货 |
| **合计** | **¥85,000-160,000** | |

**退出成本：**
| 成本项 | 金额 | 说明 |
|--------|------|------|
| 违约金 | ? | 看合同 |
| 员工赔偿 | ¥20,000-50,000 | N+1 |
| 剩余房租 | 已付，不退 | |
| 中介费 | ¥5,000-10,000 | 如果找中介 |
| **合计** | **¥25,000-60,000** | |

### 四、对比分析

```
继续撑24个月：
- 代价：¥480,000 + 机会成本
- 结果：可能扭亏，可能更亏

现在退出：
- 收益：¥85,000-160,000
- 成本：¥25,000-60,000
- 净收益：¥30,000-130,000
- 节省：¥480,000-¥130,000 = ¥350,000
```

### 五、决策建议

**建议：现在退出**

理由：
1. **经济账清晰**：继续撑至少再亏35万
2. **商场不续约概率高**：明年被动退出更被动
3. **早退早解脱**：精力用在更有价值的事上
4. **市场窗口**：现在餐饮转让市场还算活跃

### 六、退出执行计划

#### 第一阶段：准备（1-2周）
```
□ 整理经营数据（账目/流水/会员）
□ 设备清单和估价
□ 合同梳理（租约/品牌合同）
□ 员工情况摸底
□ 制作转让说明书
```

#### 第二阶段：挂牌（2-4周）
```
□ 确定转让价格：¥80,000-120,000
□ 选择渠道：中介/自己找/品牌方
□ 发布转让信息
□ 接待咨询
```

#### 第三阶段：谈判（2-4周）
```
□ 筛选意向买家
□ 安排看店
□ 价格谈判（底价¥80,000）
□ 付款方式（一次性优先）
□ 交接条件
```

#### 第四阶段：成交（1周）
```
□ 签转让合同
□ 收取转让款
□ 员工安置
□ 设备交接
□ 工商变更
□ 钥匙交接
```

### 七、注意事项

**必须处理清楚：**
| 事项 | 处理方式 |
|------|----------|
| 员工 | 提前通知，依法赔偿 |
| 供应商 | 结清货款 |
| 会员卡 | 退卡或转让给接店方 |
| 平台账号 | 关闭/转让外卖平台 |
| 税务 | 完成最后的报税 |
| 工商 | 注销或变更 |

**合同要注意：**
- 转让款付清再交钥匙
- 明确交接日期和时间
- 约定债权债务归属
- 约定竞业禁止（如果有）

### 八、退出的心理建设

**不要太执着：**
- 退出不是失败，是止损
- 及时止损比死撑更明智
- 餐饮是长跑，不是百米冲刺

**下一步：**
- 总结经验教训
- 分析失败原因
- 想清楚下一步做什么
- 餐饮还能不能做/要不要做
```

## 专家点评（避坑提示）

**退出误区**：
1. **以为再撑撑就好** → 越亏越多
2. **转让要价太高** → 挂一年没人问
3. **不处理员工** → 劳动纠纷
4. **匆忙退出** → 贱卖资产

**正确姿势**：
- 提前规划，不要等弹尽粮绝
- 合理定价，快速出手
- 依法合规，善后干净
- 总结经验，下次更好
