### Step 2：关键时刻（MOT）识别

**服务MOT设计矩阵**

| 触点 | 关键时刻？ | 顾客情绪峰值？ | 超预期机会？ | 优先级 |
|------|-----------|--------------|------------|--------|
| 入店等位 | ★★★ | ★★☆ | ★★★ | P1 |
| 点单过程 | ★★☆ | ★☆☆ | ★★☆ | P2 |
| 等菜阶段 | ★★★ | ★★☆ | ★★★ | P1 |
| 上菜瞬间 | ★★★ | ★★★ | ★★☆ | P1 |
| 结账离店 | ★★☆ | ★☆☆ | ★★☆ | P2 |

> **P1（核心MOT）**：必须做好的关键体验节点
> **P2（标准MOT）**：达到基本期望，不出差错

### Step 3：服务标准设计（SMART原则）

**P1关键时刻标准示例**

```
【MOT 1：等位体验设计】
触发场景：高峰期等位>10分钟

服务标准：
□ 超过5分钟，主动送水/小吃
□ 超过10分钟，店长致歉+小菜赠送
□ 超过20分钟，启动"下次再来打折"承诺

超预期设计：
□ 提供美甲/擦鞋/儿童玩具（视业态）
□ 设置等位拍照打卡点（制造社交素材）
□ 叫号时称呼顾客姓名（如有会员系统）

验收标准：等位>10分钟无投诉

【MOT 2：上菜体验设计】
触发场景：任何顾客入座后

服务标准：
□ 前菜/小菜5分钟内上桌（哪怕只有一道）
□ 主菜不超过15分钟（有凉菜先上）
□ 上菜时主动介绍菜品

超预期设计：
□ 店长/厨师特别介绍"今日推荐"
□ 给寿星提供免费甜品

验收标准：顾客等待>15分钟未上主菜≤5%

【MOT 3：投诉处理】
触发场景：任何顾客表达不满

服务标准：
□ 5秒内回应（表示听到了）
□ 10秒内致歉（不管是否是我的错）
□ 30秒内给出解决方案
□ 解决后24小时内回访确认

授权设计：
□ 普通员工：可免单≤50元
□ 店长：可免单≤200元
□ 总部：可免单≥200元

验收标准：差评回复率100%，差评转化率≥30%
```

## 核心方法论

### 服务三角形

```
        顾客期望
           △
          / \
         /   \
        /  服  \
       /  务   \
      /   标   \
     /   准    \
    /___________\
  企业能力     员工满意
```

**服务三角形的三个顶点必须平衡**：
- 顾客期望（锚点，决定定价和定位）
- 服务标准（设计，决定体验基准）
- 员工能力（执行，决定体验上限）

### 服务超预期公式

```
超预期 = 顾客期望 + X（X=体验-期望）

X为正 → 惊喜 → 口碑传播
X为0  → 满意 → 被动复购
X为负 → 不满 → 差评/流失

【制造超预期的5种方法】
1. 时机超预期：比顾客预期更快
2. 数量超预期：给顾客多一点
3. 态度超预期：热情超过职业要求
4. 意外超预期：超出正常服务范围
5. 个性化超预期：记住顾客的名字/喜好
```

## 注意事项

1. **不要过度服务**：超过品牌定位的服务是浪费
2. **承诺要兑现**：承诺了超预期就要做到，做不到不如不承诺
3. **员工授权要明确**：员工不知道能免多少单，就不会主动处理投诉
4. **服务标准要培训**：写在纸上的标准≠员工会的标准
5. **关注员工情绪**：服务态度的根本是员工满意度
