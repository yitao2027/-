# L1-labor-cost
# 人力成本管控与排班优化

**层级：** L1 部门基础  
**部门归属：** 人力资源部  
**触发词：** 人力成本、排班、人效、员工成本、劳动力管理、排班优化、人员配置

---

## 一、Skill 定位

**解决什么问题：**  
帮助餐饮门店科学控制人力成本，通过合理排班和人员配置，在保证服务质量的前提下把人力成本率控制在合理范围内。

**行业参考基准（人力成本率 = 人工成本 ÷ 营业额）：**
```
快餐/外卖为主：18-25%（优秀≤20%）
正餐/休闲：25-35%（优秀≤28%）
火锅：22-30%（优秀≤25%）
茶饮咖啡：20-28%（优秀≤22%）

⚠️ 警戒线：超过35%需立即干预
```

## 二、核心方法论

### 2.1 人力成本构成分析

```
人力成本总额 = 
  基本工资 + 绩效奖金 + 餐补/住补/交通补 + 
  五险一金（单位部分）+ 加班费 + 节假日工资 + 
  招聘培训成本 + 离职补偿成本

各项占比参考（以月度为例）：
- 基本工资：60-70%
- 绩效/奖金：10-20%
- 社保（单位）：15-20%（因城市不同）
- 其他（补贴/加班/培训）：5-10%
```

### 2.2 人效公式与优化方向

```
人效 = 月营业额 ÷ 全月人工成本（元/元）
人均产出 = 月营业额 ÷ 在职员工总人数（元/人）

行业参考人均月产出：
- 快餐：15,000-30,000元/人（优秀≥25,000）
- 正餐：10,000-20,000元/人（优秀≥15,000）
- 火锅：12,000-22,000元/人

提升人效的三条路：
① 减人（精简编制，兼岗合并）→短期见效快，风险是服务下降
② 增收（做好营销，提升营业额）→根本解法
③ 提效（优化流程，减少无效时间）→可持续
```

### 2.3 排班优化六步法

```
STEP 1 绘制客流热力图（历史1个月数据）
→ 找出每天/每周的高峰、平峰、低谷时段

STEP 2 确定各时段最低岗位需求
→ 高峰：满编（前厅X人，后厨X人）
→ 平峰：最小编（前厅X人，后厨X人）

STEP 3 设计排班方案
→ 主班（全天） + 高峰补班 + 弹性兼职
→ 避免"平峰时段满编浪费"

STEP 4 兼岗设计（减少总人数）
→ 哪些岗位可以一人兼任？（如：收银+前台/配菜+打荷）
→ 每兼一岗需要技能培训（不能影响品质）

STEP 5 弹性用工设计
→ 长期兼职：负责高峰时段（餐饮高峰一般只有3-4小时）
→ 成本对比：全职工资全天付 vs 兼职只付工作时段

STEP 6 效果监测
→ 每周检查：人力成本率/服务质量投诉率/员工加班情况
→ 每月调整：根据淡旺季动态调整排班
```

### 2.4 排班模板（参考）

**50-100㎡快餐店（日营业额3,000-8,000元）：**

| 时段 | 前厅人数 | 后厨人数 | 备注 |
|------|---------|---------|-----|
| 开档准备（8:00-10:00） | 1 | 2 | 备料备菜 |
| 午高峰（11:00-13:30） | 2-3 | 3-4 | 满编 |
| 午休（13:30-16:30） | 1 | 1-2 | 最小编 |
| 晚高峰（17:00-20:00） | 2-3 | 3-4 | 满编 |
| 收档（20:00-21:30） | 1 | 1-2 | 轮流 |

**总编制建议：全职5-6人 + 高峰兼职2-3人（可节省15-20%人力成本）**

### 2.5 薪酬结构设计基础

```
基础薪酬结构：底薪 + 绩效工资

底薪：保障基本生活（根据当地最低工资标准+15-20%）
绩效工资：与个人/门店业绩挂钩
- 营业额达标奖：门店月营业额超过基准线，全员奖励
- 个人绩效指标（KPI）：
  前厅：顾客满意率/翻台率达成/投诉率
  后厨：出成率/出餐速度/浪费率

常见陷阱：
❌ 只有底薪没有绩效：员工没有做多做少都一样
❌ 绩效太复杂：员工看不懂，激励失效
❌ 绩效扣款为主：变成惩罚机制，打击积极性

✅ 正确方向：以奖励为主、扣款为辅，让员工看到"多做多得"
```

## 四、触发条件与输出

**输入收集：**
```
请告诉我：
1. 门店规模？（座位数/面积/月营业额）
2. 目前员工人数？（全职几人/兼职几人）
3. 目前月度人力成本大概多少？
4. 主要问题：人力成本太高？还是服务人手不足？
5. 营业时间安排？（几点开到几点/是否有明显高峰期）
```

**输出内容：**
- 人力成本诊断报告（含行业对标）
- 优化排班方案（含高峰/平峰/兼职建议）
- 兼岗可行性分析
- 人力成本降低预测（预计节省金额）
