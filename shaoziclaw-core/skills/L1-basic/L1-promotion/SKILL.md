---

## 触发场景

当用户需要策划促销活动、设计开业营销方案、制定节日活动、执行短期引流活动时，启用此 Skill。

---

## 输入

- 活动类型：开业促销 / 节日营销 / 日常引流 / 应对竞品 / 清库存
- 目标：提升营业额 / 引流获客 / 提升客单价 / 清理库存
- 预算（若有）
- 活动档期

## 核心方法论

### 促销活动的三个境界

1. **第一境：引流** ——把人请进来（开业/新客活动）
2. **第二境：留存** ——让人再来（会员/复购活动）
3. **第三境：传播** ——让人帮你说（口碑/社交活动）

### 促销设计的禁忌

1. **不能伤害品牌**：折扣要与品牌调性匹配
2. **不能破坏价格体系**：促销后很难恢复原价
3. **不能赔本赚吆喝**：ROI必须为正
4. **不能太复杂**：顾客看不懂 = 参与率低

### 全年营销日历（重点节点）

| 月份 | 节点 | 活动类型 |
|------|------|----------|
| 1-2月 | 春节/元旦 | 节日营销+聚会场景 |
| 3-4月 | 春季上新 | 新品发布 |
| 5月 | 五一 | 出行场景+家庭聚餐 |
| 6月 | 高考/毕业 | 场景营销 |
| 7-8月 | 暑假 | 亲子/家庭场景 |
| 9月 | 中秋 | 节日营销 |

## 注意事项

1. **促销是工具不是目的**：促销是为了达成目标，不是为了"热闹"
2. **频率要控制**：频繁促销=品牌贬值=顾客无感
3. **复盘要量化**：活动效果不能只说"还可以"，要有数字对比
4. **老客优先**：促销优先给老客，不要只想着拉新
5. **线上线下一体**：活动要提前在社交媒体预热，不要只靠自然流量
