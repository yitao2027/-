## 二、创业神人画像分类（勇哥直播间版）

### 类型一：韭菜型（占比最高）

**特征：** 信息极度不对称，轻信快招公司  
**典型案例：**  
- 本想加盟塔斯汀，搜索被截胡，交15万"江湖费"  
- "第4代汉堡"话术深信不疑  
- 考察时感觉"味道还可以"就签约

**致命行为：**  
- 不查资质、不看合同、不访门店
- 听电话销售的话术，被"名额有限"逼单

---

### 类型二：冲动型（年轻创业者）

**特征：** 想当然，凭感觉决策，零市场调研  
**典型案例：**  
- 在写字楼卖玻尿酸羊乳咖啡（目标客群：白领？程序员？谁会喝这个？）  
- 在厂区开轻食店（工人：高热量才实在，谁吃草？）  
- 在饮食清淡的广州老城区开重油麻辣火锅  
- 在村头开酒吧，让父母当服务员

**致命行为：**  
- "我感觉这里有市场"  
- 选址靠"感觉"或"大师罗盘"  
- 从不向周围人求证

---

### 类型三：证明自己型（县城中年人）

**特征：** 职业瓶颈，渴望证明自己，极易被情怀驱动  
**典型案例：**  
- 夫妻一方强烈想开店，说服另一方出资  
- 辞职创业All in，无退路  
- 为证明"不是打工的命"孤注一掷

**致命行为：**  
- 把创业当救命稻草而非商业决策  
- 无止损意识，亏损后继续追加

---

### 类型四：情怀型（女性/年轻人）

**特征：** 因喜欢某件事而创业，不考虑商业逻辑  
**典型案例：**  
- 喜欢鲜花+觉得奶茶火 → 鲜花奶茶复合店 → 定位模糊双双失败  
- 喜欢喝咖啡 → 开了家没人来的精品咖啡店  
- 喜欢某个菜系 → 在完全不适合的地方开了店

## 四、勇哥的"诊断公式"（核心方法论）

每次连麦，勇哥问诊的固定顺序：

```
Step 1: 问基本情况
→ "你现在一天卖多少钱？"
→ "你这个店投了多少钱？"
→ "你开业多久了？"

Step 2: 问选址
→ "你这个位置每天经过多少人？"
→ "旁边有什么竞品？"
→ "转一圈给我看看"

Step 3: 问总部/品牌
→ "总部叫什么名字？"
→ "有特许经营资质吗？"
→ "带店选址是谁选的？"

Step 4: 问数据
→ "毛利率多少？"
→ "租金占比多少？"
→ "人工多少？"

Step 5: 给判决
→ 能救 → "你这个可以这样做..." 
→ 不能救 → "关了吧，赶紧止损，去维权"
```

## 八、为什么这套体系值得深挖

1. **真实性无可替代：** 每个案例都是真实创业者的真实处境，不是编造的
2. **数据颗粒度极细：** 勇哥连麦会问具体数字（日流水/毛利率/租金/人工），数据可直接用
3. **覆盖面极广：** 覆盖餐饮全品类（火锅/烧烤/奶茶/汉堡/烘焙/咖啡/日料/川菜），案例类型全
4. **方法论可执行：** 诊断公式 + 4步选址自测 + 快招识别体系，可直接教给创业者
