## 触发场景

当用户需要了解食品安全合规要求、办理证照、通过食安检查、处理食安问题、或建立食安管理体系时，启用此 Skill。

- 业态类型：堂食 / 外卖为主 / 预制菜 / 中央厨房

- 所在城市/地区

## 工作流程

### Step 1：证照体系梳理

**餐饮必备证照清单**

| 证照名称 | 办理部门 | 办理周期 | 有效期 | 优先级 |
|----------|----------|----------|--------|--------|
| 营业执照 | 市场监管局 | 3-5个工作日 | 长期 | ★★★ |
| 食品经营许可证 | 市场监管局 | 10-15个工作日 | 5年 | ★★★ |
| 环境影响评价批复 | 环保局 | 30-60天 | - | ★（视情况）|
| 消防验收合格证 | 消防支队 | 15-30天 | - | ★★★ |
| 卫生许可证（已并入食品经营许可证） | - | - | - | - |
| 排污许可证 | 环保局 | 30天 | - | ★（视情况）|
| 门头招牌审批 | 城管局 | 3-7天 | - | ★★ |

**关键合规节点**
```
开业前必须完成：营业执照 + 食品经营许可证 + 消防验收
试营业前建议完成：健康证（全员）+ 油烟净化器检测
日常运营持续：健康证到期更新 / 许可证到期换证
```

### Step 2：日常运营合规检查

**每日食安检查表（店长版）**

```
【员工健康】
□ 当日上班员工健康证已公示（电子档案）
□ 有发热/腹泻/手部伤口员工不得上岗
□ 工服工帽整洁，头发不外露

【原料储存】
□ 冷藏柜温度：0-4℃（肉类/海鲜）
□ 冷冻柜温度：-18℃以下
□ 常温库：阴凉干燥，≤25℃
□ 食材先进先出（FIFO），无过期品
□ 生熟分开，无交叉污染

【后厨卫生】
□ 台面/砧板/刀具使用前清洁消毒
□ 抹布分类使用（不同颜色区分）
□ 垃圾桶带盖，半满即清
□ 地面干燥无积水

【出品标准】
□ 食品烧熟煮透（中心温度≥70℃）
□ 冷藏食品2小时内食用或冷藏
□ 添加剂专人管理，有使用记录

【外卖规范】
□ 封口贴使用（防止中途打开）
□ 保温袋规范
□ 配送时间监控（避免超时导致食品安全）
```

### Step 3：食安风险识别

**高风险品类（需特别关注）**

| 高风险品类 | 风险类型 | 控制措施 |
|------------|----------|----------|
| 凉菜/冷菜 | 细菌繁殖 | 当日制作当日销售，冷藏储存 |
| 贝类/海鲜 | 副溶血性弧菌 | 充分加热，杜绝生食 |
| 豆浆/豆类 | 皂苷/抗营养因子 | 彻底加热煮沸 |
| 野生菌 | 毒素中毒 | 禁止采购来源不明菌类 |
| 裱花蛋糕 | 微生物超标 | 冷链储存，保质期内销售 |
| 隔夜菜 | 细菌毒素 | 尽量不剩，剩余需彻底加热 |

### Step 4：供应商合规管理

```
【供应商资质审核清单】

□ 食品经营许可证
□ 对应食品品类生产/流通资质
□ 检测报告（批次检验）
```

## 核心方法论

### 食安核心原则（HACCP简化版）

1. **清洁消毒**：手、设备、台面
2. **生熟分开**：工具/储存/操作三分离
3. **温度控制**：热食≥60℃ / 冷食≤4℃ / 常温≤25℃
4. **时效管理**：制作到食用时间控制
5. **源头把控**：供应商资质审核 + 进货查验

### 食安事故分级与响应

| 级别 | 描述 | 响应时间 | 处理方式 |
|------|------|----------|----------|
| 一级（群体性）| 多人同时出现症状 | 立即 | 停业 + 上报 + 救治 |
| 二级（个案）| 个别顾客投诉 | 2小时内 | 了解情况 + 内部排查 + 沟通 |
| 三级（隐患）| 员工自查发现问题 | 24小时内 | 整改 + 记录 + 复盘 |

### GB 31654-2021 关键要点

- 专间操作（凉菜/裱花）需专用操作间
- 食品处理区禁止明沟排水
- 餐具清洗消毒四步骤：一刮二洗三清四消毒
- 食品留样：≥125g，48小时，-18℃冷冻

## 注意事项

1. **食安无小事**：任何隐患都要及时处理，不能侥幸
2. **记录就是保护**：检查记录/索证记录就是合规证据
3. **主动优于被动**：建立预防体系比事后补救成本低得多
4. **培训要持续**：食安培训不是一次性，是持续性的
5. **不甩锅供应商**：终端门店对食品安全负最终责任
