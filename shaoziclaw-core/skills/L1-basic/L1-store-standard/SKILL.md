# L1-store-standard
# 门店标准化运营体系建立

**层级：** L1 部门基础  
**部门归属：** 营运管理部  
**触发词：** 标准化运营、SOP、操作流程、连锁复制、门店标准、运营手册、流程规范

---

## 一、Skill 定位

**解决什么问题：**  
帮助餐饮门店建立基础SOP体系，把依赖"人"的经验变成可传承的"系统"，为多店复制和连锁扩张奠定基础。

**为什么重要：**
- 没有标准化 = 依赖某个关键员工 = 高风险
- 标准化 = 可复制 = 可扩张 = 可管理
- 标准化也是提升顾客体验一致性的根本方法

---

## 二、核心方法论

### 2.1 餐饮标准化四大模块

```
┌─────────────────────────────────────────┐
│              餐饮标准化体系                │
│                                         │
│  【产品标准】    【服务标准】                │
│  配方/工艺/     服务流程/话术/              │
│  出成率/摆盘    应急处理/投诉              │
│                                         │
│  【环境标准】    【管理标准】                │
│  卫生清洁/      开关店流程/                │
│  设备维护/      盘点/报表/                 │
│  安全检查       员工排班/考核              │
└─────────────────────────────────────────┘
```

### 2.2 SOP文档编写标准

**一份好的SOP必须包含：**

```
SOP编写五要素：

① 操作名称（What）
→ 明确、简短（如：「炸薯条操作SOP」）

② 适用范围（Who）
→ 哪些岗位/哪些场景适用

③ 操作步骤（How）
→ 用数字列清每个步骤（不写模糊词如"适量""差不多"）
→ 每步骤配图片/视频（尤其关键操作）

④ 标准要求（Standard）
→ 每步骤完成的量化标准
→ 如：「油温170-180℃，炸制3分30秒±15秒」

⑤ 注意事项（Caution）
→ 最常见失误和后果
→ 如出现问题的应急处理方法
```

**SOP示例（炒菜出品）：**
```
【宫保鸡丁出品SOP】

适用岗位：炒锅师傅
适用时段：营业期间

步骤：
1. 确认食材备料齐全（鸡丁150g/花生米20g/干辣椒5根/葱花5g）
2. 锅烧热，油温7成热（约200℃，测试：竹筷入油起细泡）
3. 先下干辣椒爆香（10秒），再下鸡丁（翻炒30秒）
4. 沿锅边淋入调味汁（标准份量：1汤勺），翻炒均匀
5. 下花生米/葱花（翻炒5秒），起锅装盘
6. 出品标准：鸡丁色泽金黄，不糊不焦，汁水适中

注意：
- 花生米最后下，防止过软
- 出餐超过10分钟不得出品（影响口感）
- 投诉处理：如顾客反馈过辣，可减少干辣椒至2根
```

### 2.3 关键标准化优先级排序

**建议按此顺序建立SOP（从最影响顾客体验开始）：**

```
第1优先级（立即做）：
□ 核心菜品制作SOP（爆款菜/招牌菜/套餐）
□ 开关店流程SOP
□ 食品安全日检SOP

第2优先级（1-2周内完成）：
□ 前厅服务流程SOP（迎宾/点餐/上菜/结账/送客）
□ 收银操作SOP
□ 食材验收SOP

第3优先级（1个月内完成）：
□ 清洁卫生SOP（日清/周清/月度深度清洁）
□ 设备维护SOP（冰箱/油炸锅/洗碗机等）
□ 新员工培训SOP
□ 突发事件应急SOP（食品安全/顾客投诉/设备故障）

第4优先级（持续完善）：
□ 节假日运营特别SOP
□ 外卖运营SOP
□ 供应商管理SOP
```

### 2.4 标准化落地三步法

```
STEP 1 文档化（2-4周）
→ 把现有做法写成SOP文档
→ 配图或视频记录操作过程
→ 让现有最优秀的员工"示范"后记录

STEP 2 培训化（1-2周）
→ 对所有员工进行SOP培训
→ 考核：操作演示通过方可上岗
→ SOP放在操作区域（员工随时查阅）

STEP 3 监督化（持续）
→ 每周抽查SOP执行情况
→ 发现偏差立即纠正（不能只批评，要给示范）
→ 每季度更新优化SOP（根据实际问题改进）
```

### 2.5 开关店标准SOP（通用模板）

```
【开店前检查SOP】（参考）

□ 卫生检查（地面/桌面/卫生间/后厨）
□ 设备检查（冰箱温度/收银系统/空调/灯光）
□ 食材验收（当日到货品质检查/效期检查）
□ 备料准备（提前切配/备酱/备汤底）
□ 人员到岗（按时间表确认员工在岗/工服整洁）
□ 环境准备（音乐/灯光/空调调至营业状态）
□ 开门时间确认（___时整准时开门）

责任人：___  完成时间：开业前___分钟  签字确认：___

---

【关店前检查SOP】（参考）

□ 食材处理（剩余食材分类储存/标注日期）
□ 设备关闭（炉灶/油炸锅/烤箱确认关闭）
□ 冷链检查（冰箱温度正常/门关紧）
□ 卫生清洁（后厨地面/操作台/地沟盖）
□ 安全检查（燃气阀门/窗户/门锁）
□ 当日报表（营业额/客单/特殊事项记录）
□ 钱款处理（备用金准备好明日）

完成时间：___  责任人：___  签字确认：___
```

## 三、触发条件与输出

**输入收集：**
```
请告诉我：
1. 门店规模？（单店/多店）
2. 目前最大的标准化问题？（出品不稳定/员工离职带走经验/服务参差不齐）
3. 目前是否有任何SOP文档？（完全没有/零散记录/部分有）
4. 未来是否有开分店/加盟计划？（影响标准化深度要求）
5. 哪个模块最紧迫？（产品/服务/环境/管理）
```

**输出内容：**
- 标准化现状评估
- 优先级排序建议（哪些SOP先做）
- 关键SOP模板（2-3个最重要的）
- 标准化落地3个月行动计划
