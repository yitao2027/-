## 核心工作流

### Step 1：门店信息采集

| 信息项 | 说明 | 必填 |
|--------|------|------|
| 品牌/店名 | — | ✅ |
| 品类 | 快餐/火锅/茶饮/中餐/烧烤等 | ✅ |
| 所在城市 | 影响目标人群和投放策略 | ✅ |
| 定位/客单价 | 高端/中档/平价 | ✅ |
| 核心卖点 | 必须有差异化亮点（至少3个） | ✅ |
| 当前状态 | 有无小红书账号？粉丝多少？ | ⚠️ |
| 目标 | 涨粉/引流到店/品牌曝光/新品推广 | ⚠️ |

> 💡 **核心认知**：小红书用户不关心你的品牌，只关心"这家店好不好吃/值不值得去"。一切内容围绕用户利益点展开。

### Step 2：小红书底层逻辑

#### 2.1 平台特征（2026年最新）

| 维度 | 特征 | 运营含义 |
|------|------|---------|
| 用户画像 | 70%女性，18-35岁，一二线城市为主 | 内容要好看、有氛围感、有情绪价值 |
| 消费决策链路 | 种草→搜索→收藏→到店 | SEO关键词覆盖至关重要 |
| 内容偏好 | 真实感 > 专业度，体验 > 介绍 | 拒绝硬广，用"分享"的语气 |
| 流量机制 | 去中心化+搜索权重大 | 标题和首图决定80%的点击率 |

#### 2.2 餐饮类笔记爆款公式

**公式A：颜值种草型**
```
标题：[城市]+[品类]+[形容词]+[结果]
例："成都｜这家藏在巷子里的火锅🔥排队2小时也值得！"
首图：高颜值菜品特写/环境氛围图
正文结构：发现过程 → 视觉冲击 → 口味描述 → 实用信息(地址/人均)
```

**公式B：攻略实用型**
```
标题：数字+[城市]+[场景]+[品类]合集
例："成都8家本地人私藏的苍蝇馆子🤫第3家绝了"
首图：拼图/清单式图片
正文结构：痛点引入 → 清单罗列 → 每家一句话点评 → 收藏建议
```

**公式C：避坑真实型**
```
标题：[品类]+[负面预警]+反转/真相
例："别再被XX网红店骗了‼️这5家才是成都人的真爱"
首图：对比图/打分图/实拍图
正文结构：吐槽网红店 → 推荐真实好店 → 详细对比 → 行动召唤
```

**公式D：性价比型**
```
标题：价格+品类+夸张效果+城市
例："人均30吃到撑😭成都这家中餐厅老板不想赚钱吗"
首图：满桌菜+价格标签
正文结构：价格冲击 → 菜品展示 → 性价比分析 → 地址营业时间
```

> 🔑 **标题关键词库（高频流量词）：**
> - 情绪词：绝了/哭死/真的会谢/谁懂啊/救命/离谱
> - 量词：XX家合集/TopX/必吃榜/0踩雷
> - 地域词：本地人才知道/藏在XX/只有老饕才找得到
> - 场景词：约会/聚餐/独食/带爸妈/公司团建

### Step 4：达人/KOC投放策略

#### 4.1 达人分层模型

| 层级 | 粉丝量 | 单价参考 | 作用 | 选择标准 |
|------|--------|---------|------|---------|
| KOL头部 | 10万+ | ¥3000-20000+/篇 | 大曝光、建立品牌势能 | 垂直领域影响力 |
| KOL腰部 | 1万-10万 | ¥500-5000/篇 | 精准触达、口碑背书 | 互动率高、粉丝精准 |
| KOC/素人 | 1000-1万 | ¥100-800/篇或产品置换 | 真实评价、铺量种草 | 图文质量好、愿意写长文 |
| 真实顾客 | 无 | 免费餐/小福利 | UGC原生传播 | 自然分享、真实体验 |

#### 4.2 投放节奏

```
第一阶段（起号期 第1个月）：
- KOC×10-15篇（铺设基础口碑）
- 素人×20-30篇（增加真实感）
- 自营账号每天1篇（建立内容资产）

第二阶段（增长期 第2-3月）：
- 腰部KOL×3-5篇（引爆话题）
- KOC持续投放（保持声量）
- 重点推1-2篇爆款笔记（投薯条加热）

第三阶段（稳定期 第4月起）：
- 头部KOL×1-2篇/月（维持品牌热度）
- KOC常态化投放（每周3-5篇）
- 重UGC激励（鼓励顾客自发分享）
```

#### 4.3 达人选人 checklist

- [ ] 近7天有发布餐饮相关内容？
- [ ] 笔记平均点赞>100？（KOC级别）/ >1000？（KOL级别）
- [ ] 图片审美在线？（清晰度高、构图好、色调统一）
- [ ] 文案有个人风格？（非模板化）
- [ ] 评论互动积极？（回复评论、与粉丝互动）
- [ ] 无明显广子痕迹？（历史笔记不全是广告）
- [ ] 粉丝地域匹配？（主要粉丝在门店辐射城市范围内）

### Step 5：数据分析框架

| 指标 | 健康值 | 异常处理 |
|------|-------|---------|
| **笔记曝光量** | >1000（新号）/ >5000（成熟号） | 低→优化标题/封面/SEO关键词 |
| **点击率(CTR)** | >8%（图文）/ >5%（视频） | 低→换封面图/优化标题前半段 |
| **互动率**（点赞+收藏+评论/曝光）| >5% | 低→内容不够有吸引力，加强情绪钩子 |
| **收藏率** | >3%（说明内容有实用价值） | 低→增加实用信息（地址/菜单/攻略） |
| **涨粉率** | 新号>3%/篇 | 低→人设不够鲜明，加强账号定位 |
| **私信咨询数** | >2/篇（餐饮类） | 低→行动召唤(CTA)不够强 |

## 避坑清单

### ❌ 常见错误

1. **把小红书当朋友圈发**
   - ❌ "今天店里来了很多客人，开心！"
   - ✅ 用具体场景+画面感+实用信息来呈现

2. **图片丑但内容好**
   - 红书上"颜值即正义"，图片不好看没人点进来
   - ✅ 投资一套拍摄设备（手机+补光灯+背景布），学基础构图

3. **只在自家笔记下互动**
   - ❌ 只回复自己笔记的评论
   - ✅ 主动去竞品笔记下互动、去同城美食话题下露脸

4. **一篇爆款后就躺平**
   - 一篇爆款带来的是短期流量，持续产出才能积累长期资产
   - ✅ 把爆款拆解成模板，复制变体

5. **忽视搜索SEO**
   - 很多用户是搜"XX城市 XX品类"来的，不是刷到的
   - ✅ 标题、正文、标签都要埋入搜索关键词
