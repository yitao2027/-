# L1-new-product-launch
# 新店上线营销推广

**层级：** L1 部门基础  
**部门归属：** 市场营销部  
**触发词：** 新店开业、开业宣传、开业活动、开业引流、新店推广、开业方案、开业促销

---

## 一、Skill 定位

**解决什么问题：**  
帮助餐饮门店制定系统的开业推广方案，在开业前30天到开业后30天内最大化曝光，建立初始客群，避免"开业即顶峰、随后持续下滑"的问题。

**核心认知：**
- 开业期是门店一生中流量最高、营销最有效的时段
- 用对了=客群基础扎实；用错了=花钱买来一次性羊毛党
- 开业营销的目的不是"让顾客来一次"，而是"让顾客想再来"

---

## 二、核心方法论

### 2.1 开业推广三阶段

```
阶段1：预热蓄水（开业前30-14天）
目标：制造期待，积累潜在首批顾客

动作：
□ 门店装修过程透明化（朋友圈/抖音/小红书 同步进展）
□ 神秘感营造（"即将开业"倒计时海报）
□ 征集内测顾客（付定金优先体验/免费内测换评价）
□ 提前联系本地KOL/探店博主（预约开业当天来探店）
□ 周边餐饮从业者/商户提前打招呼

阶段2：开业爆发（开业前7天-开业后14天）
目标：制造话题，快速积累口碑和评价

动作：
□ 开业活动（见下文模板）
□ 开业当天邀请朋友/亲属"助阵"制造人气氛围
□ 主动引导到店顾客发评价（扫码评价礼品激励）
□ 每日拍摄运营花絮（打卡/顾客反应/爆满场景）
□ 及时回复所有线上评论和评价

阶段3：转化留存（开业后15-60天）
目标：把首批顾客转化为会员/复购客

动作：
□ 激活私域会员（小程序注册/微信社群）
□ 二次到店激励（首单留评送优惠券可下次使用）
□ 挖掘种子粉丝（开业期超级喜欢的顾客→发展为"门店之友"）
□ 调整菜单（根据开业期反馈优化）
```

### 2.2 开业活动设计原则

```
避坑原则：
❌ 简单打折（吸引羊毛党，品牌形象受损）
❌ 免单/买一送一（成本高，复购效果差）
❌ 撒传单（到达率低，浪费）
❌ 只做线下活动（错过线上流量机会）

✅ 正确方向：
- 创造"值得分享"的体验（让顾客自愿传播）
- 礼品/权益要有留存价值（如储值卡/会员权益，而不是即时消耗品）
- 每个活动环节都设计"拍照传播"触点
```

**三种开业活动模式：**

**① 体验特供式（推荐中高端餐饮）**
```
开业期间推出2-3款"开业特供菜"（限时不限量）
→ 价格与正常持平或略优惠（5-9折）
→ 强调"开业特供，正式营业后可能调整"
→ 制造稀缺感，让顾客体验独特性
```

**② 积累型福利式（推荐大众快餐）**
```
开业前3天：凭到店消费送"感恩礼包"（适当小礼品）
第4-14天：累计消费满XXX元，升级会员（享折扣/优先订座）
14天后：激励复购（开业礼包凭券次月兑换）
```

**③ 社交裂变式（推荐新茶饮/网红类）**
```
"带朋友来" = 人均消费9折
发朋友圈@门店 = 赠一款特饮
抖音/小红书发打卡内容 = 凭截图兑换小礼品
```

### 2.3 本地KOL探店操作

```
探店博主合作开业策略：

类型选择：
→ 超级KOL（粉丝10万+）：费用高但曝光大，开业核心投放
→ 本地达人（1万-10万粉）：性价比高，最适合餐饮新店
→ 素人/真实顾客（100-1000粉）：可信度高，铺量用

触达方式：
→ 抖音/小红书直接私信本地探店博主
→ 大众点评达人合作（平台有达人资源）
→ 朋友/亲属介绍

合作方式：
→ 纯到店体验（免费餐+不强制发布）：适合有真实影响力的博主
→ 到店体验+发布稿费（500-2000元/篇）：确保发布
→ 拼团/分销（按带来实际客数分成）：效果付费

注意事项：
□ 必须体验真实，不要给博主"特殊版本"菜品
□ 要求真实测评，不强制要求全部正面内容
□ 确认博主账号粉丝质量（真实粉丝，不是买的）
```

### 2.4 开业期数字化营销

```
开业期线上渠道覆盖：

① 大众点评：注册完善/上传高质量图片/获取前20条评价
② 美团（外卖+团购）：上线开业特惠套餐
③ 抖音：拍3-5条开业视频（装修/开业日/爆款菜出镜）
④ 小红书：1-2篇图文（侧重颜值/环境/特色菜）
⑤ 微信：朋友圈持续更新（本人发/员工发）
⑥ 地图平台：百度地图/高德地图完善门店信息+上传图片

数字化营销时间分配建议（开业期30天）：
→ 50%时间：运营抖音（流量最大）
→ 25%时间：维护大众点评/美团评价
→ 25%时间：小红书+朋友圈
```

## 三、执行工具

### 3.1 开业倒计时行动清单

```
【开业倒计时行动清单】

开业前30天：
□ 确定开业日期（预计：___年___月___日）
□ 开业主题/口号确定
□ 开业活动方案确定（见上文三种模式选其一）
□ 联系本地探店达人（目标：___位）

开业前21天：
□ 宣传物料设计完成（海报/菜单/小程序）
□ 预热朋友圈/抖音内容发布开始（每3天1条）
□ 大众点评/美团商家后台完善

开业前14天：
□ 内测顾客邀请（10-20位，换真实评价）
□ 员工开业培训完成
□ 开业礼品/小礼物准备到位

开业前7天：
□ 所有线上平台信息核查（营业时间/地址/菜单）
□ 提醒探店博主开业时间
□ 开业仪式策划（有无剪彩/特殊仪式）

开业当天：
□ 门口布置（气球/横幅，制造热闹感）
□ 拍摄开业日vlog（发各平台）
□ 专人负责引导顾客扫码评价
□ 打包小礼品/开业感恩卡

开业后7天：
□ 汇总开业期数据（营业额/顾客数/评价数）
□ 及时回复所有评论
□ 分析反馈，调整菜单/服务

开业后30天：
□ 完整复盘（转化率/复购率/口碑评分）
□ 调整正式运营方案
```

## 四、触发条件与输出

**输入收集：**
```
请告诉我：
1. 开业时间？（具体日期/倒计时天数）
2. 门店类型？（快餐/正餐/茶饮/火锅）
3. 目标客群？（上班族/家庭/年轻人/中高端）
4. 开业营销预算大概多少？（总预算）
5. 地理位置？（商圈/社区/写字楼/学校附近）
```

**输出内容：**
- 开业营销全案（含3阶段行动方案）
- 开业活动设计方案（最适合的模式）
- 本地KOL合作建议
- 开业倒计时行动清单
- 开业期数字化渠道分配建议
