## 触发场景

当用户需要审核合同（租赁/采购/加盟/劳动合同等）、处理劳动纠纷、了解餐饮行业法律红线、规避法律风险时，启用此 Skill。

---

## 输入

- 合同/问题类型：租赁合同 / 劳动合同 / 采购合同 / 加盟合同 / 劳动纠纷 / 投诉/起诉
- 对方主体：房东 / 员工 / 供应商 / 加盟商 / 顾客
- 具体问题描述

## 工作流程

### Step 1：问题类型判断

```
【餐饮法律问题分类】

一、合同类
□ 商铺租赁合同（选址阶段）
□ 劳动合同（招聘阶段）
□ 采购/供货合同（供应链阶段）
□ 加盟合同（加盟/被加盟）
□ 装修合同（开店阶段）

二、劳动类
□ 员工入职/离职
□ 工伤认定
□ 工资拖欠/克扣
□ 社保公积金
□ 违法解除

三、顾客纠纷类
□ 食安事故索赔
□ 滑倒/烫伤等意外
□ 顾客投诉/举报

四、行政类
□ 食药监局检查
□ 消防检查
□ 工商检查
□ 税务检查
```

### Step 2：合同审核清单

**商铺租赁合同审核要点**

```
【必备条款检查】
□ 租赁用途（必须是餐饮/商业用途）
□ 租赁期限（建议3年+，含续约优先权）
□ 租金及递增方式（年递增≤5%为合理）
□ 免租期（装修期通常1-3个月）
□ 转让费（注意是否合理，是否可退）
□ 押金退还条件
□ 提前解约条款（对我方是否公平）
□ 优先购买权/优先续租权
□ 营业执照协助办理义务
□ 油烟/排烟条件（是否满足餐饮需求）
□ 违约金条款（双方对等）

【高风险条款识别】
⚠ "合同期内不得转让" → 限制经营权灵活性
⚠ "年租金递增10%" → 侵蚀利润
⚠ "房东可随时解除合同" → 极度不公平
⚠ "不退还任何费用" → 押金风险
```

**劳动合同审核要点**

```
【法定必备条款】
□ 合同期限（固定期限/无固定期限）
□ 工作内容和工作地点
□ 工作时间和休息休假
□ 劳动报酬（基本工资+加班费计算方式）
□ 社会保险
□ 劳动保护和劳动条件

【餐饮行业特别注意】
□ 加班费计算（工作日1.5倍/休息日2倍/法定节假日3倍）
□ 年假折算（入职满1年享受5天）
□ 试用期工资（≥正式工资80%且≥当地最低工资）
□ 押金/扣押证件（违法！不得收取）
□ 竞业限制（普通员工不得约定）
```

### Step 3：劳动纠纷预防

```
【常见纠纷预防措施】
□ 签订书面劳动合同（入职30天内）
□ 工资通过银行转账（留证据）
□ 明确工时制度（综合工时/标准工时需审批）
□ 加班记录清晰（员工确认签字）
□ 离职手续完整（书面离职申请+工作交接+物品归还）
□ 规章制度经过民主程序（员工手册需公示签字）

【发生劳动纠纷时的应对步骤】
1. 了解员工诉求（先沟通，不要直接对抗）
2. 核实事实（查工资记录/考勤记录）
3. 评估法律风险（是否违法/员工是否有证据）
4. 制定解决方案（调解优先，诉讼成本高）
5. 如需协商，找专业人士把关
```

### Step 4：加盟合同风险识别

```
【加盟合同高风险条款】
⚠ 高额保证金 → 了解退还条件
⚠ 进货强制绑定 → 确认采购价格是否合理
⚠ 区域保护模糊 → 明确保护范围和条件
⚠ 合同到期后品牌归属 → 区分商标/技术/装修归属
⚠ 违约金极高 → 评估违约成本
⚠ 退出机制缺失 → 了解如何合法退出

【加盟前必做的法律核查】
□ 是否具备特许经营备案（商务部特许经营备案）
□ 是否拥有注册商标（至少2年以上）
□ 直营店数量是否达标（至少2家直营店1年以上）
□ 特许经营合同是否为格式合同（留意不平等条款）
```

### Step 5：食安事故法律风险

```
【责任边界】
□ 顾客在我店出现食安症状
□ 需区分：我方责任 vs 非我方责任

【我方责任时的处理】
□ 立即救治（送医/垫付医疗费）
□ 保留证据（留样/采购记录）
□ 主动沟通（不要逃避）
□ 法律建议：积极和解，诉讼成本更高

【非我方责任时的处理】
□ 保留证据（进货单/检测报告/留样）
□ 申请政府调查（明确责任）
□ 法律建议：必要时反诉诬告
```

## 核心方法论

### 餐饮法律红线清单

| 类别 | 违法行为 | 后果 |
|------|----------|------|
| 劳动 | 不签劳动合同 | 双倍工资赔偿 |
| 劳动 | 拖欠工资 | 工资50-100%赔偿金 |
| 劳动 | 强制加班不给加班费 | 补发+50%赔偿金 |
| 食安 | 无证经营 | 罚款+没收+停业 |
| 食安 | 使用过期/不合格食材 | 罚款+吊证+刑事责任 |
| 消防 | 消防不合规 | 罚款+停业+行政拘留 |
| 加盟 | 无备案开展特许经营 | 罚款（1-10万） |
| 广告 | 虚假宣传 | 罚款+赔偿消费者 |

### 合同审核三步法

1. **识别**——识别合同类型和核心条款
2. **评估**——评估每个条款对我方的公平性
3. **修改**——提出合理的修改建议

## 注意事项

1. **我不是律师**：此Skill提供法律知识普及，不能替代律师
2. **复杂问题找律师**：涉及重大金额/人身伤亡/刑事责任的问题必须请律师
3. **证据要留存**：日常工作做好记录，关键时刻就是证据
4. **预防优于救济**：合规成本 < 纠纷成本
5. **格式合同可协商**：绝大多数合同条款都是可以谈的，不要直接签字
