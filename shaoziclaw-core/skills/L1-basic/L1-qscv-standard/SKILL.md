## Skill 元信息

**名称**：L1-qscv-standard
**分类**：L1 部门基础 · 营运部
**级别**：初级 · 部门入门
**版本**：1.0
**触发词**：「标准化」「QSCV」「运营规范」「门店标准」「如何管理门店」「统一标准」「连锁运营」「督导检查」

---

## 触发场景

当用户需要建立或优化门店标准化运营体系、设计督导检查体系、或进行连锁品牌标准化复制时，启用此 Skill。

---

## 输入

- 品牌规模：单店 / 2-10店 / 10店以上
- 当前标准化程度：无/部分有/基本建立
- 核心问题：执行不统一 / 检查无标准 / 扩张无依据

---

## 工作流程

### Step 1：QSCV框架定义

```
【QSCV标准体系】

Q - Quality（品质）
├─ 产品品质（食材/口感/呈现）
├─ 环境品质（卫生/舒适/氛围）
└─ 服务品质（态度/专业/体验）

S - Service（服务）
├─ 服务标准（响应速度/话术/仪容）
├─ 服务流程（SOP执行/关键时刻）
└─ 服务培训（新员工/在岗培训）

C - Cleanliness（清洁）
├─ 环境卫生（地面/墙面/天花板）
├─ 设备清洁（每日/每周/每月）
└─ 个人卫生（洗手/工服/健康）

V - Value（价值）
├─ 性价比感知（价格/分量/质量）
├─ 品牌价值（认同感/忠诚度）
└─ 社会价值（环保/公益/健康）
```

### Step 2：各维度标准设计

**Q - 品质标准示例（茶饮门店）**

```
【产品品质标准】
□ 原料标准：使用指定供应商/规格/品牌
□ 制作标准：SOP卡张贴，每步有明确参数（温度/时间/用量）
□ 呈现标准：杯子/分量/装饰有统一标准
□ 口感标准：建立标准样品（新员工对比标准）
□ 效期标准：每款产品有最佳饮用时间

【每日产品检查】
□ 开业前：原料库存/设备状态/鲜度检查
□ 营业中：每小时产品品质巡视
□ 闭店前：剩余原料处理/设备清洁
□ 每周：产品感官评审（真实品尝）
```

**S - 服务标准示例**

```
【服务五步曲】
1. 迎宾（3秒内）
   "您好，欢迎光临！"
   
2. 接待（1分钟内）
   "请问需要点什么？"（点单）
   
3. 制作（标准时间）
   "您的饮品正在制作中，请稍等"
   
4. 出品（双手递送）
   "您的饮品好了，请慢用，小心烫"
   
5. 送客（目光送别）
   "欢迎下次光临！"

【服务禁忌】
□ 不允许不打招呼
□ 不允许面无表情
□ 不允许背对顾客
□ 不允许与顾客争辩
```

**C - 清洁标准示例**

```
【清洁检查表】

【每日清洁】（打烊后）
□ 台面擦拭消毒
□ 地面清扫拖干
□ 垃圾桶套袋更换
□ 设备表面擦拭
□ 洗手间清洁消毒
□ 水杯/餐具清洗消毒

【每周清洁】（每周X执行）
□ 冷藏柜除霜清洁
□ 排油烟机表面清洁
□ 墙面/地脚清洁
□ 灯具/空调出风口清洁

【每月清洁】（每月X执行）
□ 全面深度清洁
□ 设备维护保养
□ 消防器材检查
□ 紫外线消毒（如有）
```

### Step 3：督导检查体系设计

```
【检查机制】
□ 自检：员工每日自查（用检查表）
□ 店检：店长每日巡店检查
□ 督导检：总部督导每周巡店（多店）
□神秘顾客：每季度1-2次第三方检查

【巡店检查维度】
| 检查维度 | 权重 | 检查方式 | 频率 |
|----------|------|----------|------|
| Q（品质） | 35% | 现场+产品 | 日检 |
| S（服务） | 30% | 神秘顾客+现场 | 周检 |
| C（清洁） | 20% | 现场检查 | 日检 |
| V（价值） | 15% | 数据+顾客反馈 | 月检 |

【检查结果应用】
□ 与员工绩效挂钩
□ 优秀门店/个人表彰
□ 问题门店整改跟进
□ 标准化持续迭代
```

### Step 4：标准化落地三步法

```
【Step 1：写清楚（标准化文档）】
□ 每个岗位都有SOP卡
□ 每项操作都有明确标准
□ 每项标准都有验收方法

【Step 2：培训会】
□ 新员工培训（理论+实操）
□ 在岗员工定期复训
□ 培训要有考核，不是走过场

【Step 3：检查持续】
□ 有检查表
□ 有检查频率
□ 有奖惩机制
□ 有持续改善
```

## 核心方法论

### 标准化三原则

1. **简单化**——复杂的标准=无法执行的标准
2. **可量化**——不能量化的标准=无效的标准
3. **可检查**——不能检查的标准=形同虚设

### 餐饮标准化不等于失去灵魂

标准化管的是"不能差"的底线，个性化发挥的是"能更好"的空间。
- 前厅服务：80%标准化+20%个性化
- 后厨出品：95%标准化+5%厨师发挥

---

## 质量标准

| 维度 | 标准 |
|------|------|
| 标准可执行 | 每个标准都是可以实际操作的 |
| 检查可量化 | 每个检查项都是可打分的 |
| 培训配套 | 有配套的培训资料 |
| 执行有监督 | 有督导检查机制 |

## 注意事项

1. **标准化是底线，不是天花板**：只规定"不能差"，不限制"能更好"
2. **员工参与制定**：让执行者参与，落地更顺畅
3. **持续迭代**：标准要随运营优化，不是一次定稿
4. **先试点再推广**：新标准先在1-2家店试，跑通了再推广
