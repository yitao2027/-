## 触发场景

当用户需要设计新菜单定价策略、分析现有菜品价格竞争力、进行价格调整、或设计套餐组合时，启用此 Skill。

## 输入

- 业态类型：快餐 / 正餐 / 火锅 / 茶饮 / 烘焙 / 其他

- 品类价格带现状（主要竞品价格区间）
- 菜单结构（菜品列表）

□ 全价格带覆盖（综合型）——覆盖[X]-[Y]元
```

### Step 2：定价方法选择

**三种核心定价方法**

```
【方法一：成本加成定价】
公式：售价 = 食材成本 ÷ 目标成本率

示例：
目标食材成本率 = 32%
某菜食材成本 = 12元
售价 = 12 ÷ 0.32 = 37.5元 → 定价38元

适用：成本结构清晰的快餐/标准化产品


【方法二：竞品对标定价】
公式：售价 = 竞品价格 × (1 ± 差异化系数)

竞品同类菜品：36元
我方差异化价值：+15%（更好的食材）
售价 = 36 × 1.15 = 41.4元 → 定价42元

适用：竞争激烈的成熟品类


【方法三：价值感知定价】
基于顾客认知价值定价，而非成本或竞品

顾客愿意为"干净卫生"多付10%
顾客愿意为"现炒现做"多付20%
顾客愿意为"拍照好看"多付15%
顾客愿意为"不用排队"多付5%

综合价值加成：+30%
基础心理价位：38元
最终定价：38 × 1.30 = 49.4元 → 定价49元

适用：有明显差异化价值的品牌
```

### Step 3：价格带结构设计

```
【松竹梅三档定价法】

| 档位 | 命名 | 价格区间 | 功能 |
|------|------|----------|------|
| 引流档（松） | 招牌/特价 | 价格最低 | 引流进店，制造"便宜感" |
| 主力档（竹） | 畅销品 | 价格中位 | 贡献主要营业额 |
| 利润档（梅） | 高端/特色 | 价格最高 | 提升客单价，赚取利润 |

【各档位菜品数量比例建议】
引流档：2-3道（占菜单15-20%）
主力档：5-8道（占菜单50-60%）
利润档：2-3道（占菜单20-30%）
```

```

### Step 5：套餐组合定价

```
【套餐设计原则】
套餐 ≠ 单品降价，而是创造"划算感"

【套餐定价公式】
套餐售价 = 单品价格之和 × 套餐折扣系数

| 套餐类型 | 折扣系数 | 逻辑 |
|----------|----------|------|
| 引流套餐 | 7-8折 | 吸引初次到店 |
| 常规套餐 | 8-8.5折 | 稳定客单价 |
| 高端套餐 | 9折+ | 提升客单价 |

【套餐利润检验】
单品毛利总额 - 套餐毛利总额 = 牺牲毛利
牺牲毛利 ÷ 新增客流 = 获客成本
获客成本 < 顾客生命周期价值 → 套餐可行
```

## 核心方法论

### 餐饮定价心理学

| 技巧 | 原理 | 应用 |
|------|------|------|
| 尾数定价 | 38比40感觉便宜很多 | 定价38/58/98 |
| 拆解定价 | 把大数字拆小 | 月均[X]元/天 |
| 锚点效应 | 高价衬托低价 | 先推高价再推套餐 |
| 套餐捆绑 | 捆绑后感知更便宜 | 菜品+饮品+小食 |
| 场景定价 | 不同场景不同价格 | 门店/外卖/团购 |

### 定价禁区

1. **不能亏本卖**：再好的营销，亏本卖都是不可持续的
2. **不能随意调价**：调价要系统规划，不是看心情
3. **不能只看成本**：顾客付的是认知价值，不是成本+利润
4. **不能忽视竞品**：完全不顾竞品的价格带会失去市场份额

## 质量标准

| 维度 | 标准 |
|------|------|
| 价格有依据 | 有具体计算逻辑，不是拍脑袋 |
| 价格带有结构 | 引流/主力/利润三档清晰 |
| 毛利率可接受 | 达到品类健康标准 |
| 竞品有参考 | 主流竞品价格有调研 |

## 注意事项

1. **定价不是一次性的**：需要随成本变化、竞品变化、季节变化动态调整
2. **不要陷入价格战**：纯粹的低价竞争没有赢家
3. **价值感要跟上价格**：提价要有对应的产品/服务升级
4. **外卖定价特殊**：平台抽成+配送成本，要单独算
