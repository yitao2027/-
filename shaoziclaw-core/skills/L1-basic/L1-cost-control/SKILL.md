# 食材成本管控 SKILL

## Skill 元信息

**名称**：L1-cost-control
**分类**：L1 部门基础 · 营运部
**级别**：初级 · 部门入门
**版本**：1.0
**触发词**：「成本太高」「食材浪费」「成本怎么算」「损耗大」「利润太薄」「降本增效」

---

## 触发场景

当用户需要分析门店食材成本问题、设计成本管控方案、计算单品成本、或进行损耗分析时，启用此 Skill。

---

## 输入

- 业态类型：快餐 / 正餐 / 火锅 / 茶饮 / 烘焙 / 其他
- 问题类型：整体成本偏高 / 单品成本不清 / 损耗过大 / 采购价格混乱
- 数据：月营业额 / 食材成本金额 / 菜单结构 / 损耗记录（如有）

## 工作流程

### Step 1：数据采集与结构分析

```
【成本结构分析】
月营业额：[    ]元
月食材成本：[    ]元
食材成本率：[食材成本÷营业额] = [%]

【参考标准对比】
| 业态 | 健康标准 | 警戒线 |
|------|----------|--------|
| 快餐 | ≤32% | >38% |
| 正餐 | ≤35% | >40% |
| 火锅 | ≤40% | >45% |
| 茶饮 | ≤45% | >50% |
| 烘焙 | ≤35% | >40% |

[判断：✓安全 / ⚠警戒 / ✗危险]
```

### Step 2：成本问题诊断

**损耗分析（五步法）**

| 损耗类型 | 定义 | 检查方法 | 参考标准 |
|----------|------|----------|----------|
| 采购损耗 | 进货时已损坏 | 进货验货记录 | ≤2% |
| 储存损耗 | 储存期变质 | 库存盘点记录 | ≤3% |
| 加工损耗 | 切配/烹饪损耗 | 出成率记录 | 品类标准 |
| 销售损耗 | 报损/客人剩餐 | 报损记录 | ≤5% |
| 盘点损耗 | 账面vs实际差异 | 月度盘点 | ≤1% |

**成本异常排查清单**

```
□ 食材验收标准是否清晰？
□ 储存温度/效期管理是否执行？
□ 标准化配方（sop卡）是否落地？
□ 员工操作是否按标准执行？
□ 是否有偷拿偷吃？
□ 供应商是否存在短斤少两？
□ 菜单结构是否合理（滞销品多）？
□ 外卖平台是否存在高抽成侵蚀利润？
```

### Step 3：单品成本核算

```
【单品成本计算表】
品名：[      ]
建议售价：[  ]元

食材明细：
| 食材 | 用量 | 单价 | 成本 |
|------|------|------|------|
| [A]  | [X]g | [Y]元 | [Z]元 |
| [B]  | [X]g | [Y]元 | [Z]元 |
| [C]  | [X]g | [Y]元 | [Z]元 |
| 包材  | -    | -    | [X]元 |
| 合计  | -    | -    | [  ]元 |

毛利率 = (售价 - 食材成本) ÷ 售价 × 100%
       = ([售价] - [食材成本]) ÷ [售价] × 100%
       = [%]

【毛利率评判标准】
| 毛利率区间 | 评判 | 建议 |
|------------|------|------|
| ≥70% | 优秀 | 保持 |
| 60-70% | 良好 | 监控 |
| 50-60% | 一般 | 优化结构 |
| 40-50% | 偏低 | 重点关注 |
| <40% | 危险 | 必须调整 |
```

### Step 4：成本控制方案设计

**短期（立即可做）**

```
【立即止血清单】
□ 盘点所有食材当前库存，清理过期品
□ 抽查3种主要食材的实际用量vs标准用量
□ 检查验收标准执行情况
□ 暂停/下架毛利率<40%的菜品
□ 规范打包材料使用
```

**中期（1-2周内）**

```
【系统优化】
□ 建立/完善标准化配方卡（每道菜都有标准）
□ 建立食材出成率记录表
□ 设定主要食材的损耗上限红线
□ 实施先进先出（FIFO）原则
□ 集中采购谈判，降低核心食材单价
```

**长期（1-3个月）**

```
【结构性改善】
□ 优化菜单结构，砍掉滞销高成本菜品
□ 引入供应商竞争机制（每品类至少2家）
□ 建立中央库存管理系统
□ 设计成本激励方案（与员工挂钩）
□ 考虑自有品牌预制品（降成本提效）
```

## 核心方法论

### 餐饮成本铁律

| 成本项 | 健康值 | 警戒值 | 危险值 |
|--------|--------|--------|--------|
| 食材成本率 | ≤35% | 35-40% | >40% |
| 人力成本率 | ≤25% | 25-32% | >32% |
| 租金成本率 | ≤12% | 12-18% | >18% |
| 综合成本率 | ≤85% | 85-92% | >92% |
| 净利率 | ≥10% | 5-10% | <5% |

**净利润 = 营业额 - 食材成本 - 人力成本 - 租金 - 水电煤 - 其他**
**净利润率目标：≥10%**

### 出成率管理

```
出成率 = 净料量 ÷ 原始物料量 × 100%

【参考出成率】
| 食材类型 | 参考出成率 |
|----------|-----------|
| 叶菜类 | 70-85% |
| 根茎类 | 85-95% |
| 禽类 | 65-75% |
| 猪肉 | 75-85% |
| 牛肉 | 55-65% |
| 鱼类 | 45-55% |
| 米饭 | 95-100% |
```

### 成本控制三道防线

1. **事前**：采购标准化（规格/数量/价格三控）
2. **事中**：加工标准化（配方/出成/损耗三控）
3. **事后**：盘点标准化（周期/方法/追责三控）

## 注意事项

1. **成本不是越低越好**：成本控制过度会伤害品质，要平衡
2. **不只关注食材**：人力+租金+运营成本同样重要
3. **损耗要追责**：没有追责的成本管控是空话
4. **不要忽略外卖成本**：平台抽成+补贴+包材，实际利润要重新算
