## 工作流程

### Step 1：内容定位

```
【餐饮抖音内容矩阵】

| 内容类型 | 功能 | 占比建议 | 示例 |
|----------|------|----------|------|
| 引流爆款 | 吸引流量，快速涨粉 | 30% | 猎奇/猎艳/猎笑 |
| 产品种草 | 展示菜品，激发食欲 | 30% | 制作过程/成品特写 |
| 门店氛围 | 建立品牌形象 | 20% | 门店环境/服务场景 |
| 创始人IP | 建立信任 | 10% | 背后故事/理念分享 |
| 热点借势 | 蹭热点获流量 | 10% | 节日/热点/梗 |

【爆款选题方向】
□ 猎奇猎艳类：看起来不可思议的视觉效果
  - "这是我见过最XXX的XXX"
  - "99%的人不知道的XXX"
□ 猎笑类：让人忍不住笑的场景
  - 服务员的花式操作
  - 顾客的搞笑反应
□ 猎艳类：满足视觉享受
  - 食物特写（慢动作/微距）
  - 门店颜值
□ 猎食类：让人饿的
  - 制作过程全景
  - 大口吃的满足感
```

### Step 2：爆款脚本设计

```
【短视频脚本结构（前3秒法则）】

开场（前3秒）——必须抓住注意力
方法：
□ 强冲突："在我店吃完这顿饭，我哭了"
□ 疑问句："你知道一份炒饭为什么卖198吗？"
□ 极限词："这是全城最好吃的XXX"
□ 强视觉：食物特写/爆炸特效
□ 开门见山：直接展示最终产品

中段（3-30秒）——建立价值
□ 产品展示：多角度/制作过程
□ 卖点突出：2-3个核心卖点，用画面说话
□ 信任背书：排队/销量/好评

结尾（最后3秒）——引导行动
□ 召唤："想吃就点击下方链接"
□ 提问："你们觉得怎么样？评论区告诉我"
□ 反转："但是……（留悬念）"

【脚本模板示例】

标题：[吸引人的标题]
时长：[X]秒
拍摄场地：[店内/后厨]

[画面/镜头]        [台词/配音]           [时长]
────────────────────────────────────────────────
特写-厨师切肉      悬念音                  1秒
全景-门店排队      "这家店凭什么天天排队？"  2秒
特写-菜品上桌      "今天我来揭秘"           2秒
中景-顾客表情      展示食物诱人画面          5秒
特写-大口吃        "吃过的都说——"           3秒
字幕+门店信息      "位置：[X]  人均：[X]元"   2秒
结尾-邀请互动      "关注我，带你吃遍全城"   1秒
```

### Step 3：拍摄技巧要点

```
【餐饮短视频拍摄参数】
- 分辨率：1080p以上（推荐4K）
- 帧率：60fps（慢动作素材）
- 比例：9:16竖屏（手机端优先）
- 格式：MOV/MP4

【关键镜头技巧】
□ 食物特写：微距+俯拍，光线充足
□ 制作过程：侧面中景，稳定器拍摄
□ 人物反应：真实抓拍，不要摆拍
□ 门店外观：航拍或仰拍，体现气势
□ 排队场景：俯拍+中景，展示人气

【光线技巧】
- 自然光优先：靠窗位置，中午光线最佳
- 补光：环形补光灯（菜品展示）
- 避免：顶光（会在菜品上投下阴影）
```

### Step 4：发布策略

```
【发布时间建议】
| 品类 | 最佳时间 | 次佳时间 |
|------|----------|----------|
| 快餐/早餐 | 7:00-8:30 | 11:00-12:00 |
| 正餐 | 11:00-12:30 | 17:00-19:00 |
| 下午茶/烘焙 | 14:00-16:00 | 20:00-21:00 |
| 夜宵/烧烤 | 21:00-22:30 | 17:00-18:00 |

【发布设置】
□ 标题：30字以内，含关键词+悬念
□ 话题：蹭热点话题+品牌专属话题
□ 地点：标注门店位置（带POI）
□ @相关账号：官方账号/合作达人

【DOU+投放策略】
新店/新品期：投放「相似达人粉丝」（定向投放）
日常运营期：投放「相似兴趣用户」
爆款续热期：投放「已互动用户相似人群」
```

### Step 5：数据复盘

```
【关键数据指标】
| 指标 | 含义 | 达标值 |
|------|------|--------|
| 完播率 | 看完视频比例 | >40%为优 |
| 点赞率 | 点赞/播放 | >5%为优 |
| 评论率 | 评论/播放 | >1%为优 |
| 转发率 | 转发/播放 | >0.5%为优 |

【内容迭代】
□ 完播率低 → 开头不吸引，需要重做开场
□ 点赞率低 → 内容价值感不够，需要强化卖点
□ 评论率低 → 缺乏互动点，需要在结尾设置问题
□ 转发率低 → 内容传播性不足，需要加强实用性
```

## 核心方法论

### 餐饮抖音爆款公式

```
爆款 = 强开场（前3秒）+ 价值内容（中段）+ 召唤行动（结尾）

强开场5种类型：
1. 强冲突：制造认知反差
2. 疑问句：引发好奇
3. 极限词：引发争议/点赞
4. 强视觉：直接展示
5. 开门见山：直接展示成品
```

### 抖音内容禁忌

1. **不能虚假宣传**：好吃就是好吃，不好吃不要硬夸
2. **不能暴露操作违规**：后厨不规范画面不要拍
3. **不能贬低竞品**：违规且low
4. **不能过度营销**：顾客一眼看穿会被反感
5. **不能忽视评论区**：不回复=不重视

## 注意事项

1. **内容>技术**：手机也能拍出好视频，内容创意比设备重要
2. **坚持>爆款**：持续发布比偶尔一条爆款更有价值
3. **真实>完美**：真实的门店比精心包装的更打动人心
4. **评论区是宝藏**：顾客的真实反馈是最好的选题来源
5. **合规底线**：不能诱导刷单/虚假评价，否则账号被封
