# 开店筹备清单 SKILL

## Skill 元信息

**名称**：L1-opening-checklist
**分类**：L1 部门基础 · 选址开发部
**级别**：初级 · 部门入门
**版本**：1.0
**触发词**：「开店准备」「新店筹备」「开业前准备」「开店清单」「筹备事项」「办什么证」「装修」「采购」「招人」「开业」

---

## 触发场景

当用户筹备新店开业，需要系统梳理开业前所有准备工作时，启用此 Skill。按倒计时120天模板输出。

---

## 输入

- 目标开业日期
- 业态类型
- 门店规模
- 团队情况（是否有经验）

---

## 工作流程

### Step 1：倒计时筹备时间表

```
【开业前120天倒计时】

【D-120 to D-90：战略决策期】
□ 确认选址位置
□ 确定品牌定位
□ 完成资金筹备
□ 组建核心团队
□ 办理意向书/签约

【D-90 to D-60：筹备启动期】
□ 正式签约，缴纳首期租金
□ 启动装修设计
□ 办理营业执照（核名+注册）
□ 招聘核心员工（厨师长/店长）
□ 确定供应商体系

【D-60 to D-30：建设期】
□ 装修施工
□ 办理食品经营许可证（提前申请）
□ 消防申报/验收
□ 采购主要设备
□ 员工培训启动

【D-30 to D-15：冲刺期】
□ 装修收尾/验收
□ 设备安装调试
□ 证照办理完成
□ 员工培训完成
□ 试菜/菜单确定

【D-15 to D-7：开业准备期】
□ 试营业（不对外/对内）
□ 公关/媒体邀请
□ 线上平台开通（外卖/点评）
□ 开业促销活动确定
□ 物料采购完成

【D-7 to D-1：最后检查期】
□ 全员开业动员会
□ 设备最终调试
□ 库存最终确认
□ 开业当天人员排班
□ 危机预案演练

【D-Day：开业日】
□ 提前2小时到岗检查
□ 重点关注出餐/服务
□ 问题实时处理
□ 数据实时监控
□ 当天复盘会议
```

### Step 2：证照办理清单

```
【开业必备证照】
□ 营业执照（工商注册，3-5工作日）
□ 食品经营许可证（食药监局，10-15工作日，需提前申请）
□ 消防验收合格证（消防部门，15-30工作日，需提前申请）
□ 环境影响评价（视情况，30-60工作日）
□ 门头招牌审批（城管，3-7工作日）

【健康证】
□ 全体员工健康证（卫生服务中心，3-5工作日）
□ 老板自己的健康证

【外卖平台入驻】
□ 美团外卖入驻（提前7天申请）
□ 饿了么入驻（提前7天申请）
```

### Step 3：装修与设备清单

```
【装修重点关注项】
□ 上下水（排水必须合规，明沟不行）
□ 油烟管道（通向楼顶，过环评）
□ 电力容量（能否支持厨房设备）
□ 燃气（如需）
□ 通风换气
□ 消防通道

【必备设备清单】
| 类别 | 设备 | 参考价格 | 备注 |
|------|------|----------|------|
| 前厅 | 桌椅/沙发/吧台 | - | 风格统一 |
| 前厅 | 空调/新风 | - | 餐饮专用 |
| 前厅 | 收银系统 | - | 含打印/扫码 |
| 前厅 | 监控系统 | - | 必备 |
| 厨房 | 灶具/油烟机 | - | 功率要够 |
| 厨房 | 冷藏/冷冻柜 | - | 至少2台 |
| 厨房 | 洗碗机（可选） | - | 人效提升 |
| 通用 | 消防器材 | - | 强制要求 |
```

### Step 4：采购清单

```
【开业首批采购（开业前3天）】
□ 食材原料（按预估营业额×3天量×1.2倍）
□ 包装材料（外卖盒/餐具/纸巾）
□ 清洁用品
□ 办公用品
□ 制服/工牌
□ 开业物料（气球/花篮/横幅）

【供应商确定】
□ 主食材供应商（已签约）
□ 调味品供应商（已签约）
□ 包装材料供应商（已签约）
□ 外送平台骑手合作（如需要）
```

### Step 5：人员与培训清单

```
【开业前人员到位】
□ 店长/前厅负责人：开业前60天到位
□ 厨师长：开业前60天到位
□ 服务员：开业前15天到位
□ 厨师团队：开业前30天到位
□ 兼职（可选）：开业前7天到位

【开业前培训内容】
□ 品牌文化与标准
□ 服务SOP培训
□ 产品知识培训
□ 设备操作培训
□ 食品安全培训
□ 收银/外卖系统培训
□ 应急处理培训
□ 开业当天流程演练
```

### Step 6：营销准备清单

```
【线上平台】
□ 大众点评开通并装修店铺
□ 美团/饿了么入驻并设置菜品
□ 抖音账号开通（提前30天养号）
□ 微信/小红书账号（如有）

【开业活动】
□ 开业促销方案确定
□ 物料设计制作（海报/菜单更新）
□ 达人/探店邀请
□ 私域预热（老店引流/社群预热）
□ 媒体邀请（如有）

【舆情准备】
□ 开业前舆情风险排查
```

## 核心方法论

### 开店成败的三个关键时刻

1. **选址决策**（开业前120天）——70%的问题在选址时已埋下
2. **开业前30天**（建设冲刺）——细节决定体验
3. **开业后30天**（养店期）——决定自然流量能否建立

### 开店财务红线

```
启动资金安全线 = 预估月租金×6 + 装修费 + 首月运营费

低于此金额 → 资金链断裂风险极高
等于此金额 → 刚好维持，非常紧张
高于此金额×1.5 → 有安全边际
```

---

## 质量标准

| 维度 | 标准 |
|------|------|
| 时间线清晰 | 每个节点有明确日期 |
| 不遗漏 | 证照/装修/人员/营销全覆盖 |
| 责任到人 | 每项有明确负责人 |
| 可执行 | 不只是清单，有具体行动说明 |

---

## 注意事项

1. **时间要留余量**：每个环节都可能延期，给自己留15天缓冲
2. **证照要提前**：食品经营许可证申请要提前60天开始
3. **团队要早到位**：开业前至少15天所有人到位
4. **试营业不可省**：先对内试，发现问题再对外
5. **开业当天要控节奏**：宁可少接单，不要出事故
