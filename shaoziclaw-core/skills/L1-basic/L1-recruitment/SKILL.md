---

## 触发场景

当用户需要招聘餐饮岗位（厨师/服务员/店长/外卖员等）、设计面试问题、制定试用期考核标准、或解决人员流失问题时，启用此 Skill。

---

## 输入

- 招聘岗位：服务员 / 厨师 / 店长 / 外卖打包员 / 钟点工 / 其他
- 门店规模：1-3人/5-10人/10人以上
- 主要问题：招不到人 / 留不住人 / 人员素质差 / 培训成本高
- 薪酬预算（可选）

### Step 3：面试问题设计

**行为面试法（STAR法则）**

```
S - Situation（情境）：当时是什么情况？
T - Task（任务）：你需要完成什么？
A - Action（行动）：你具体做了什么？
R - Result（结果）：结果如何？学到了什么？
```

**不同岗位面试问题库**

**服务员面试问题：**
```
Q1：上一份工作为什么离职？（考察稳定性）
Q2：遇到难缠的客人你会怎么处理？（STAR追问）
Q3：如果正在忙，客人叫你，你怎么办？（服务意识）
Q4：说说你对我们品牌的了解？（入职意愿度）
Q5：你能接受周末和节假日上班吗？（工作配合度）
```

**厨师面试问题：**
```
Q1：你的拿手菜是什么？一天最多出过多少份？（技术水平）
Q2：上一家店为什么关门的？（对餐饮经营的理解）
Q3：你怎么看待标准化出品和个性化发挥的关系？（融合能力）
Q4：后厨卫生标准你知道多少？（食品安全意识）
Q5：如果我让你做一道你没做过的菜，你会怎么做？（学习能力）
```

**店长面试问题：**
```
Q1：你上一家店的月营业额是多少？你是怎么做到的？（业绩能力）
Q2：店里员工不服你管，你怎么办？（管理能力）
Q3：遇到差评你怎么处理？（危机处理）
Q4：你认为一个好店长最重要的三件事是什么？（认知水平）
Q5：如果这个月业绩下滑20%，你会怎么分析原因？（数据分析）
```

### Step 4：试用期考核设计

```
【试用期考核方案（以服务员为例）】

考核周期：入职第7天 / 第30天 / 第60天（正式转正前）

【考核维度】
| 维度 | 权重 | 考核方式 | 达标标准 |
|------|------|----------|----------|
| 出勤纪律 | 20% | 出勤记录 | 无迟到早退 |
| 操作规范 | 30% | 店长观察+抽查 | 符合SOP |
| 服务态度 | 30% | 顾客反馈+店长观察 | 无投诉 |
| 团队协作 | 10% | 同事/上级评价 | 无明显冲突 |
| 学习进步 | 10% | 培训测试 | 考核得分≥70分 |

【一票否决项】
□ 食品安全违规
□ 偷窃/财务违规
□ 与顾客发生冲突（动手）
□ 连续3天旷工

【转正条件】
60天内无否决项 + 各项考核≥60分 + 综合评分≥75分 → 批准转正
```

### Step 5：留人策略

```
【餐饮留人三维模型】

一、薪酬留人
□ 底薪合理（≥当地最低工资标准）
□ 绩效考核（营业额/满意度挂钩）
□ 工龄工资（每满1年/月薪+100元）
□ 满勤奖（无迟到早退+200-500元/月）

二、情感留人
□ 被尊重（不骂人，不当着客人批评）
□ 被认可（公开表扬/发证书/评优）
□ 有成长（有培训/有晋升机会）
□ 被关心（生日祝福/节日礼品）

三、发展留人
□ 晋升通道清晰（服务员→领班→店长）
□ 技能提升（专业培训/外派学习）
□ 股权激励（核心管理层）
□ 合伙创业（特别优秀的）

【离职预警信号】
□ 突然频繁请假
□ 工作状态明显下降
□ 开始打听其他招聘信息
□ 朋友圈发消极内容

→ 发现信号后立即谈话，了解真实原因
```

## 核心方法论

### 餐饮面试三问法

1. **为什么离开上一份工作？**（稳定性+真实动机）
2. **你对我们店了解多少？**（入职意愿度）
3. **你的职业规划是什么？**（目标感+可持续性）

### 餐饮留人成本账

```
【招人成本】
招聘成本 = 广告费 + 面试时间成本 + 培训成本（约2000-5000元/人）

【离职损失】
□ 直接损失：招聘+培训成本（3000-8000元）
□ 间接损失：交接期间效率下降+新人不稳定期产出低（约1-2个月）

【结论】
留一个人 = 省5000-10000元

所以：防离职成本 < 救离职成本
```

## 注意事项

1. **不要只看经验**：态度比经验重要，餐饮技能可以培训
2. **不要只谈钱**：情感和发展同样重要
3. **不要招关系户**：人情和纪律要平衡
4. **试用期要真考核**：走过场的试用期等于白试
5. **老板要以身作则**：员工看老板怎么做事
