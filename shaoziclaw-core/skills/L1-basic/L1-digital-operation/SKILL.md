### Step 3：舆情分类与优先级

```
【舆情分类】

A类（需立即处理）：
- 粉丝>10万博主/大V发布负面
- 多条帖子集中爆发同一问题
- 涉及食安/人身伤害/重大欺诈
→ 立即上报，启动危机公关预案

B类（24小时内处理）：
- 粉丝1-10万博主发布负面
- 差评内容在扩散中
- 涉及员工态度/服务问题
→ 店长/总部跟进处理

C类（48小时内处理）：
- 普通用户差评
- 单一投诉事件
- 产品/环境小问题
→ 门店直接回复处理

D类（例行监测）：
- 中性内容/咨询帖
- 好评内容
- 竞品对比
→ 存档，持续观察
```

### Step 4：舆情回应策略

```
【不同类型舆情的回应策略】

A类（高影响力）：
- 总部出面，不能让门店单独应对
- 24小时内发布官方声明
- 联系发布者沟通（私信+电话）
- 同步在官方账号发布正面内容

B类（中等影响力）：
- 总部运营+门店联合应对
- 48小时内联系并解决
- 回复要真诚，不能模板化

C类（普通差评）：
- 门店直接回复
- 24小时内回复
- 提供具体解决方案

D类（中性/好评）：
- 感谢互动
- 有内容质量的可以联系合作
```

### Step 5：正面舆情建设

```
【主动制造正面舆情】

1. 鼓励顾客发布好评
   - 收银台/餐桌放置"好评邀请"提示
   - 离店时主动邀请（注意合规，不能诱导）

2. 鼓励UGC内容
   - 设置拍照打卡点
   - 设计专属话题（#XX美食打卡#）
   - 提供分享素材（免费小菜/甜品）

3. 定期发布官方内容
   - 品牌故事/幕后花絮
   - 新品发布
   - 公益活动

4. 达人合作
   - 本地生活达人探店（合规前提）
   - 美食博主合作
```

## 核心方法论

### 舆情生命周期

```
萌芽期 → 扩散期 → 高峰期 → 消退期
  ↑                                   
  └──────── 响应越早，成本越低 ────────┘
```

**萌芽期（1-24小时）**：干预成本最低，效果最好
**扩散期（24-72小时）**：需要系统性应对
**高峰期（3-7天）**：止损为主，减少损失
**消退期（7天后）**：开始修复品牌形象

### 舆情监测三板斧

1. **找**：多平台关键词监测，不遗漏
2. **分**：分类分级，高优先级先处理
3. **应**：回复真诚，解决实际问题

## 质量标准

| 维度 | 标准 |
|------|------|
| 监测覆盖 | 覆盖主要平台，不遗漏 |
| 分类准确 | 正确识别舆情类型和级别 |
| 响应及时 | 达到A类1小时/B类24小时/C类48小时 |
| 处理闭环 | 有回复有跟进有结果 |

## 注意事项

1. **差评是改进机会**：态度端正的差评回复反而能提升品牌形象
2. **不要删帖**：删帖被曝光是灾难性的
3. **回复要真诚**：模板化回复让顾客更生气
4. **关注竞品舆情**：竞品的负面可能是我们的机会
5. **不要买水军**：被识别出来是毁灭性的
