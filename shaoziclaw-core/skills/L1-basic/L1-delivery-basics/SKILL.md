# L1-delivery-basics
# 外卖运营基础与平台管理

> **⚠️ 价值观红线：不作恶、诚信经营、食品安全是底线。** 本Skill仅提供合规运营方法。绝不建议刷单、虚假交易、引导好评等违规操作。

**层级：** L1 部门基础  
**部门归属：** 营运管理部  
**触发词：** 外卖、美团外卖、饿了么、外卖上线、外卖运营基础、外卖起步、外卖管理

---

## 一、Skill 定位

**解决什么问题：**  
帮助初入外卖市场的餐饮门店快速完成平台开通、基础配置和运营启动，避免新手期的常见失误，为后续精细化运营打好基础。

**适用场景：**
- 堂食店首次开通外卖
- 外卖已开通但效果很差、需要基础诊断
- 外卖账号重建（换号/重新申请）

## 二、核心方法论

### 2.1 外卖平台开通流程

**美团外卖/饿了么通用注册步骤：**

```
STEP 1 资质准备（5-7个工作日）
必须准备：
□ 营业执照（有效期内）
□ 食品经营许可证（或小餐饮登记证）
□ 法人身份证正反面
□ 门店实景照片（门头/后厨/操作间，≥5张）
□ 银行账户信息

STEP 2 商家后台注册（1-2天）
→ 美团外卖：waimai.meituan.com → 商家入驻
→ 饿了么：e.ele.me → 我要入驻
→ 填写基本信息，上传资质

STEP 3 审核等待（1-3个工作日）
→ 平台审核资质
→ 审核不通过：按提示补充材料

STEP 4 基础配置（上线前）
□ 店铺信息完善（名称/简介/标签）
□ 配送范围设置（建议首次1.5-3公里）
□ 营业时间设置
□ 起送价设置（参考商圈均值，初期可低5-10元引流）
□ 配送费设置（可设置满额免配送费）

STEP 5 菜单上传
□ 菜品分类（建议4-6个类别）
□ 图片上传（每个SKU单独拍图，不可偷懒）
□ 菜品描述（2-3句话，突出特色）
□ 规格/配料/备注设置
```

### 2.2 外卖菜单基础优化

**外卖菜单与堂食菜单的核心差异：**

| 维度 | 堂食菜单 | 外卖菜单 |
|------|---------|---------|
| 菜品数量 | 30-50道 | 10-20道（精选高频）|
| 图片重要性 | 中 | ★★★★★ |
| 包装适配 | 不重要 | 必须考虑（防溢/保温）|
| 定价 | 标准定价 | 可以微涨（含包装/配送成本）|
| 排列逻辑 | 按品类 | 爆款前置、套餐必须有 |

**外卖菜单必备项：**
```
① 引流单品（低价/大分量，吸引首次下单）
② 主力套餐（2-3款，客单价在商圈均值区间）
③ 爆款单品（评价多/销量高，承担口碑）
④ 高利润单品（附加销售，提升客单价）
⑤ 新客专属活动（首单立减/买一送一，提升转化）
```

### 2.3 外卖评分管理基础

**影响外卖排名的关键指标：**

| 指标 | 说明 | 目标 |
|------|------|------|
| **综合评分** | 顾客评价总分 | ≥4.8分 |
| **出餐速度** | 接单到取餐时间 | ≤20分钟 |
| **准时率** | 按时送达比例 | ≥95% |
| **差评率** | 差评/总订单数 | ≤1% |
| **拒单率** | 拒绝接单比例 | ≤0.5% |

**差评处理基础流程：**
```
差评出现 → 24小时内在后台回复（真诚、不反驳）
           → 私信顾客了解问题
           → 合理补偿（退款/优惠券）
           → 改进对应环节
           → 不可以：买好评、刷单（平台检测风险）
```

### 2.4 外卖包装基础配置

**打包质量直接影响评分，配置清单：**

```
外卖包装必备清单：

□ 打包盒（按菜品尺寸选择，防漏/防变形）
□ 汤类专用密封盒（带密封条）
□ 保温袋（主配送袋）
□ 品牌标签/贴纸（门店名+微信二维码）
□ 一次性餐具（筷子/叉子/汤勺按菜品配套）
□ 纸巾（2-3张每单）
□ 小卡片（手写感谢卡/评价引导）

评分加分项：
□ 防油脂防水包装
□ 分类放置（蔬菜与肉菜隔开）
□ 酱料独立包装（防倒出）
□ 个性化打包（如：折叠心形餐巾纸）
```

### 2.5 新店起步运营策略

**开通前30天关键动作：**

```
第1-7天：基础建立
- 完成菜单上传+拍图优化
- 设置首单优惠（力度需大：如首单减15元或8折）
- 邀请老顾客/亲朋好友下单留好评（真实体验后留）

第8-15天：积累评价
- 目标：积累20条以上高质量评价
- 每单随包放手写小卡片："您好，我们是刚刚开业的新店，如果本次体验不错，希望您能为我们留下宝贵的评价，我们会更努力。"

第16-30天：调整优化
- 分析最初30天数据（点单率/转化率/差评原因）
- 调整菜单排序（把销量高的前置）
- 调整活动力度（根据竞品对比）
```

## 四、触发条件与输出

**输入收集：**
```
请告诉我：
1. 目前外卖状态？（未开通/刚开通/已运营多久）
2. 主要问题是什么？（没人点/差评多/订单少）
3. 主营品类？（快餐/正餐/小吃/甜品等）
4. 商圈特征？（写字楼/住宅区/学校/混合）
5. 目前日均订单量？（如已开通）
```

**输出内容：**
- 外卖账号基础诊断报告
- 菜单优化建议（分类/排序/定价）
- 起步期运营行动计划（30天）
- 包装配置建议清单
- 差评应对话术模板
