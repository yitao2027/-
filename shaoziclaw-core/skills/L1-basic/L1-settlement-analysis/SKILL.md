## 核心工作流

### Step 1：信息采集（必填）

收集以下数据后开始分析：

| 数据项 | 说明 | 来源 |
|--------|------|------|
| 营业日期 | 分析的日期范围 | 收银系统导出 |
| 总营收 | 期内总营业额 | 收银系统 |
| 客单价 | 平均每位顾客消费 | 收银系统 |
| 客流量 | 进店人数 | 点餐系统/计数器 |
| 翻台率 | 桌位周转次数 | 计算=客流÷桌位数 |
| 各渠道收入 | 堂食/外卖/团购/其他占比 | 收银系统分账 |
| 原料成本 | COGS金额 | 采购+库存变动 |
| 人工成本 | 工资+提成+社保 | 考勤系统 |
| 租金水电 | 固定成本 | 合同+抄表 |

> ⚠️ **如果用户无法提供完整数据，用已有数据分析，缺失部分标注"待补充"并说明影响。**

---

### Step 2：结算分析框架

#### 2.1 核心指标计算

```
毛利率 = (总营收 - 原料成本) / 总营收 × 100%
净利率 = (总营收 - 所有成本) / 总营收 × 100%
人效 = 总营收 / 当班员工数
坪效 = 总营收 / 经营面积(m²)
桌效 = 总营收 / 桌位数
费效 = 总营收 / 可控费用
```

**参考标准（不同品类有差异）：**

| 品类 | 目标毛利率 | 正常人效 | 正常坪效 |
|------|-----------|---------|---------|
| 快餐 | 55-65% | 800-1500元/人/天 | 80-150元/m²/天 |
| 火锅 | 50-60% | 600-1200元/人/天 | 60-120元/m²/天 |
| 新茶饮 | 60-70% | 500-1000元/人/天 | 100-200元/m²/天 |
| 中式正餐 | 55-65% | 400-800元/人/天 | 40-80元/m²/天 |
| 西餐轻食 | 58-68% | 500-900元/人/天 | 50-100元/m²/天 |
| 烧烤烤肉 | 52-62% | 700-1300元/人/天 | 70-140元/m²/天 |

> 💡 **专家提示**：以上是行业参考值，实际需结合地段、品牌力、客单价调整。一线城市可上浮5-10%，县城需下调10-15%。

---

#### 2.2 多维度分析矩阵

**时间维度：**
- 今日 vs 昨日 → 日环比
- 本周 vs 上周 → 周环比
- 本月 vs 上月 → 月环比
- 同期去年 → 同比（如适用）

**渠道维度：**
- 堂食 vs 外卖 vs 团购占比及变化
- 各平台（美团/饿了么）表现对比
- 自有渠道（小程序/会员）增长情况

**产品维度：**
- TOP10畅销品贡献率
- 低销量品清理建议
- 新品表现追踪

**时段维度（峰谷分析）：**
- 午市(11:00-14:00) 占比
- 晚市(17:00-21:00) 占比
- 闲时转化机会

---

### Step 3：异常检测（关键！）

以下信号出现时必须标注⚠️：

| 异常类型 | 判断标准 | 可能原因 | 处理优先级 |
|----------|---------|---------|-----------|
| 营收骤降 | 日环比跌超15% | 天气/竞品/差评/断货 | 🔴 紧急 |
| 毛利率异常 | 偏离正常值±5% | 浪费/偷吃/定价错误/损耗 | 🟠 高 |
| 客单价下跌 | 连续3天下跌 | 促销过度/客群变化 | 🟡 中等 |
| 外卖退款率高 | 超3% | 出餐慢/品质问题/骑手 | 🟠 高 |
| 人工成本超标 | 人效低于正常值30% | 排班不合理/生意淡 | 🟡 中等 |
| 原料浪费大 | 报废率超3% | 预估不准/存储不当 | 🟡 中等 |

## 避坑清单（来自真实踩坑案例）

### ❌ 常见错误

1. **只看营收不看利润**：很多老板盯着日营收涨了就开心，但毛利在悄悄下降
   - ✅ 正确做法：每天盯"有效营收"=营收-退单-优惠-平台扣点

2. **忽略外卖平台的隐形扣费**：看起来外卖卖了1万，实际到手可能只有7500
   - ✅ 正确做法：各渠道分别计算"到手净收入"

3. **月底才看一次账**：等到月报出来发现问题已经晚了
   - ✅ 正确做法：日清日结，异常当天处理

4. **把个人消费混入门店支出**：导致成本虚高，决策误判
   - ✅ 正确做法：公私账户严格分离

5. **不计入隐形成本**：设备折旧、装修摊销、自有资金利息
   - ✅ 正确做法：月度结算加入"管理折旧"科目
