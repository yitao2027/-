# 危机公关预案 SKILL

## Skill 元信息

**名称**：L1-crisis-pr
**分类**：L1 部门基础 · 公关部
**级别**：初级 · 部门入门
**版本**：1.0
**触发词**：「危机公关」「舆情应对」「负面评价」「媒体曝光」「投诉处理」「公关危机」「危机响应」「网上曝光」

---

## 触发场景

当用户遇到或预判即将遇到公关危机时（差评爆发、媒体曝光、食安事故、员工丑闻、网络舆情）启用此 Skill。**危机公关是时间敏感型任务，响应越快越好。**

---

## 输入

- 危机类型：食安事故 / 差评爆发 / 媒体曝光 / 员工事件 / 竞争对手攻击 / 政策风险
- 危机发展阶段：预警期 / 爆发期 / 高峰期 / 消退期 / 修复期
- 已掌握的事实：具体事件描述、时间、地点、涉及人数
- 当前应对状态：是否已有公开回应

## 工作流程

### Step 1：危机分级评估

```
【危机分级】

一级危机（重大）：
- 造成人员伤亡/集体性身体不适
- 被主流媒体报道（央视/省级卫视等）
- 监管部门介入调查
- 应对时间：黄金1小时

二级危机（较大）：
- 大规模差评爆发（>50条/天）
- 知名博主/大V公开批评
- 区域性媒体关注
- 应对时间：黄金6小时

三级危机（一般）：
- 零散差评/投诉
- 小范围舆情（本地社群/小红书）
- 应对时间：黄金24小时
```

### Step 2：事实收集（30分钟内完成）

```
【危机事实清单】
□ 事件发生时间：
□ 事件发生地点：
□ 涉及人数/对象：
□ 主要症状/诉求：
□ 顾客已采取的行动（发帖/投诉/投诉部门）：
□ 已有证据（照片/视频/医院证明）：
□ 我方已掌握的内部情况：
□ 涉事员工/供应商信息：

【信息核实】
□ 事实本身是否属实？
□ 严重程度是否与描述相符？
□ 是否存在夸大/歪曲？
□ 是否涉及竞争对手恶意行为？
```

### Step 3：危机响应

**第一时间行动（按优先级）**

```
【P0：止血行动】
□ 立即停售涉事产品/关闭涉事门店
□ 配合监管部门调查（如已介入）
□ 救治/安抚涉事顾客
□ 隔离证据（保留原始证据，不删除不修改）

【P1：内部管控】
□ 成立危机处理小组（最小化知情人范围）
□ 指定单一发言人（避免口径不一）
□ 通知内部员工（统一口径，禁止私下接受采访）
□ 联系法务/律师（评估法律风险）

【P2：外部沟通】
□ 舆情监控：启动全网监测（微博/小红书/抖音/大众点评）
□ 准备官方回应
□ 通知合作伙伴/平台（小范围）
□ 确定下一步行动计划
```

### Step 4：官方回应撰写

```
【回应原则】
1. 速度第一：早说比晚说好，主动说比被动说好
2. 态度诚恳：先道歉再解释，不狡辩不推卸
3. 事实清晰：说清楚已知事实，未知部分明确告知正在调查
4. 行动明确：给出具体解决方案，不是空话

【回应模板】

[情况说明类]
模板：
"关于[时间]在我[门店/平台]发生的[事件描述]，我们已于第一时间关注到。

经核实：[说明事实，如事实与顾客描述有出入，可以温和纠正但不要指责顾客]

我们将：[具体行动，如：1.已与顾客取得联系并积极协商解决方案；2.已对相关产品进行下架处理；3.正在配合相关部门进行调查]

对此事件造成的影响，我们深感抱歉。欢迎顾客联系我们：[联系方式]，我们将在24小时内给出正式处理结果。"

[涉及食安的升级版]
"关于[事件]，我们已启动内部紧急调查，同时全力配合[监管部门的名称]的检查。

我们郑重承诺：[具体安全措施]

如需了解进展，请联系：[官方渠道]"
```

### Step 5：差评/舆情分级处理

```
【舆情分级处理】

A类（高影响力）：
- 粉丝>10万博主发布
- 主流媒体报道
- 监管部门介入
→ 应对：总部出面，24小时内给出正式声明，必要时召开发布会

B类（中等影响力）：
- 粉丝1-10万的本地博主
- 本地媒体关注
- 集中差评（>20条/天）
→ 应对：店长+总部运营联合，6小时内回复，联系博主沟通

C类（低影响力）：
- 零散差评/投诉
- 小红书/微博<100互动
→ 应对：门店直接回复，24小时内处理
```

### Step 6：舆情回复话术

```
【真诚道歉型】
"您好，感谢您的反馈。对于您[具体问题]，我们深表歉意。我们已[处理方式]，并对[责任人/流程]进行了[整改措施]。期待下次有机会为您提供更好的体验。"

【了解详情型】
"您好，感谢您的反馈。我是[品牌]的[职务]，关于您提到的情况，能否联系我们[电话/微信]详细说明？我们非常重视每一位顾客的体验，将在第一时间跟进处理。"

【承认错误型】
"您好，您的反馈完全正确，这是我们工作的失误，我们诚恳道歉。目前已[处理结果]，并对相关问题进行了全面排查，杜绝再次发生。"
```

## 核心方法论

### 危机公关5S原则

| 原则 | 说明 | 执行要点 |
|------|------|----------|
| 承担责任（Shoulder） | 主动承担，不推卸 | 真诚道歉+行动证明 |
| 真诚沟通（Sincerity） | 主动告知，不隐瞒 | 早说比晚好 |
| 速度第一（Speed） | 响应要快 | 黄金1-6小时 |
| 系统运行（System） | 有序应对，不混乱 | 成立小组+单一发言 |
| 权威证实（Standard） | 第三方的背书 | 政府/专家/第三方认证 |

### 危机响应时间标准

| 危机等级 | 首次响应 | 正式声明 | 解决方案 |
|----------|----------|----------|----------|
| 一级 | 1小时内 | 6小时内 | 48小时内 |
| 二级 | 3小时内 | 12小时内 | 72小时内 |
| 三级 | 24小时内 | 48小时内 | 一周内 |

---

## 质量标准

| 维度 | 标准 |
|------|------|
| 响应速度 | 达到危机等级对应时间标准 |
| 态度诚恳 | 道歉真诚，不推卸责任 |
| 口径统一 | 内部无矛盾信息 |
| 行动具体 | 有明确的后续行动，不是空话 |
| 持续跟踪 | 有舆情监测和效果评估 |

## 注意事项

1. **不要删帖**：删帖是火上浇油
2. **不要对骂**：和顾客争论永远输
3. **不要甩锅**：推给供应商/员工会激怒公众
4. **不要沉默**：沉默会被解读为默认
5. **不要越级**：按内部流程走，不要擅自对外发言
6. **危机后要复盘**：避免同类事件再次发生
