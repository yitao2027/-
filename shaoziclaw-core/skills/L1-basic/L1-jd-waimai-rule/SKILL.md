## 核心方法论

### 一、平台架构认知（必知基础）

```
京东外卖双品牌体系：

┌─────────────────┬──────────────────────┐
│   京东到家       │      京东秒送         │
│  （即时零售模式） │   （即时配送/外卖模式） │
├─────────────────┼──────────────────────┤
│ 生鲜/超市/O2O    │ 餐饮外卖为主          │
│ 配送时效:1小时   │ 配送时效:30-60分钟     │
│ 商家自配/达达    │ 专送骑手              │
│ 门店模式为主     │ 可支持纯外卖           │
└─────────────────┴──────────────────────┘

关键认知：
- 两个平台的规则体系有差异，需分别了解
- 违规处理规则通用但细则不同
- 结算和账期可能因业务类型而异
```

### 二、入驻规则

#### 入驻基本条件

| 条件项 | 要求 | 说明 |
|--------|------|------|
| 营业执照 | 有效期内 | 营围含相关品类 |
| 食品经营许可证 | 必须有 | 餐饮类目必须 |
| 法人身份证 | 正反面 | 与营业执照一致 |
| 门店实景照 | ≥5张 | 门头/后厨/操作间 |
| 银行账户 | 对公或法人账户 | 用于结算 |

**入驻流程：**
```
STEP 1 准备资质材料（营业执照+食安证+身份证）
STEP 2 在京东商家后台提交申请
STEP 3 平台审核（1-3个工作日）
STEP 4 签署平台协议（服务协议+结算协议）
STEP 5 缴纳保证金（按类目要求）
STEP 6 店铺配置上线
```

**入网审查登记规范要点：**
- 平台会对入网餐饮提供者进行审查登记
- 包括主体资格审查、食品经营许可审查
- 审查不通过需补充或更正材料
- 审查记录需留存备查

#### 商家分类标准

京东根据商家类型进行分类管理，不同分类对应不同的管理要求和服务标准。具体分类包括但不限于：
- 品牌连锁店
- 单店经营者
- 新店/老店分级
- 不同品类的差异化标准

### 三、经营管理核心规则

#### 价格管理规范

```
【价格合规要求】

✅ 允许的定价行为：
- 自主定价（在合理区间内）
- 参与平台促销活动时的价格调整
- 不同渠道差异化定价（但需合理）

❌ 禁止的价格行为：
- 虚标原价/虚假折扣
- 先涨价后降价
- 价格欺诈
- 恶意低价倾销扰乱市场秩序
- 价格与实物严重不符
```

**价格异常监控：**
- 平台会监测价格波动
- 异常价格可能触发人工审核
- 价格违规将按违规处理规则处置

#### 门店命名规范

```
【命名规则】
- 店铺名称须与营业执照名称一致或包含字号
- 不得使用"最""第一""国家级"等绝对化用语
- 不得侵犯他人商标权/字号权
- 不得含有虚假/误导性信息
- 名称长度限制（通常2-20字）

【修改规则】
- 开业后修改名称需要审核
- 频繁改名可能影响权重
- 品牌授权店铺需上传品牌授权书
```

#### 配送距离规则

- 平台设定配送最远距离限制
- 超出范围的订单系统自动拦截
- 商家可自行设置合理配送范围（建议≤5公里）
- 配送范围过大可能导致超时率上升

### 四、违规处理规则（重点！）

#### 违规分级体系

| 等级 | 违规类型 | 处罚措施 | 影响范围 |
|------|----------|----------|----------|
| **严重违规** | 售假/假冒商品 | 下架商品+扣除保证金+永久封店 | 全店 |
| **严重违规** | 冒用京东官方名义 | 警告+罚款+降权/封店 | 全店 |
| **严重违规** | 发布混淆信息 | 删除信息+扣分+下架 | 商品级 |
| **一般违规** | 侵权违规 | 删除侵权内容+警告 | 商品级 |
| **一般违规** | 品牌信息不一致 | 要求整改+逾期处罚 | 商品级 |
| **轻微违规** | 信息发布不规范 | 提醒整改 | 商品级 |

#### 京东秒送专项违规细则

**1. 出售假冒商品**
- 一经核实，立即下架
- 扣除全额保证金
- 永久关停合作
- 移交司法机关（涉嫌犯罪的）

**2. 冒用京东官方名义**
- 禁止在店铺名称/宣传中使用"京东官方""京东认证"等字样
- 禁止伪造京东授权文件
- 发现即严肃处理

**3. 发布混淆信息**
- 不得模仿知名品牌名称/Logo
- 不得使用容易引起消费者误解的文字/图片
- 商品标题/描述不得含误导性信息

**4. 发布禁限售品牌商品**
- 遵守平台禁售品牌清单
- 未经授权不得销售受限品牌商品
- 违者下架+扣分处理

**5. 违规引流**
- 禁止诱导用户脱离平台交易
- 禁止在商品/评价中留下联系方式
- 禁止引导用户到其他平台下单

#### 违规处理流程

```
发现违规 → 系统预警/用户举报 → 平台核查 → 违规确认
                                                      ↓
                                    ┌─────────────────┼──────────────────┐
                                    ↓                 ↓                  ↓
                                 轻微违规          一般违规          严重违规
                                    ↓                 ↓                  ↓
                               提示整改          扣分+警告        重罚+封店
                                                            ↓
                                                       可申诉通道
```

**申诉要点：**
- 在规定时间内提起申诉
- 提供有效证据（截图/视频/票据等）
- 申诉理由需清晰具体
- 一次申诉不成功可二次申诉（需新证据）

### 五、评价管理规则

#### 评价体系

- 用户可对订单进行多维度评价（商品质量/配送速度/服务态度等）
- 评价直接影响店铺综合评分和排名
- 差评应及时响应和处理

#### 评价管理要点

```
【好评维护】
- 保证出餐质量和速度
- 包装完整、保温到位
- 附带小礼物/感谢卡
- 及时回复每条评价

【差评应对】
- 24小时内回复（态度诚恳）
- 不争辩、不推卸责任
- 合理情况主动联系顾客协商补偿
- 通过后台正常渠道申诉恶意差评

【禁止行为】
- 禁止刷好评（检测到直接处罚）
- 禁止骚扰用户修改评价
- 禁止通过利益交换获取好评
```

#### 申诉流程及标准

当认为评价不合理（如恶意差评/与事实不符），可通过商户评价申诉流程提出申诉。申诉需提供证据证明评价存在问题。

### 六、结算与资金管理

#### 结算协议要点

- 结算周期：通常T+N（具体看协议约定）
- 结算方式：银行转账至绑定账户
- 发票管理：按规则开具和管理发票

#### 保证金管理

| 业务类型 | 保证金金额 | 退还条件 |
|----------|-----------|---------|
| 餐饮外卖 | 按类目标准 | 合约结束且无未结违规 |
| 品牌商家 | 可能更高 | 同上 |

**保证金扣除情形：**
- 售假/假冒商品
- 严重违反平台规则
- 未履行售后义务
- 其他协议约定的扣除情形

#### 账期管理

- 不同类型商家可能有不同账期
- 账期长短影响现金流周转
- 新店初期可能有较长账期约束
- 经营良好后可申请缩短账期

### 七、食品安全管控

#### 食品安全管控实施细则

```
【京东外卖食品安全管控要点】

一、入网审查
□ 食品经营许可证核验（有效期/经营范围）
□ 门店实地审核（部分类目）
□ 从业人员健康证明抽查

二、日常监管
□ 食品安全自查制度执行
□ 抽查监测（定期/不定期）
□ 用户投诉食品问题快速响应

三、违规处置
□ 食品安全问题分级处理
□ 严重问题立即下线整改
□ 多次违规升级处罚直至清退

四、事故处理
□ 食品安全事故报告机制
□ 配合监管部门调查
□ 问题批次追溯召回
```

### 八、交易纠纷处理

#### 京东秒送交易纠纷处理规则

| 纠纷类型 | 处理原则 | 商家责任 |
|----------|----------|----------|
| 食品质量问题 | 以用户反馈+证据为准 | 退款/补偿 |
| 配送超时 | 区分责任方 | 商家出餐延迟→商家责任；配送延迟→骑手责任 |
| 漏发/错发 | 核实后补发或退款 | 商家全责 |
| 描述不符 | 以实际收到为准 | 退换货+可能的处罚 |
| 用户体验投诉 | 综合判断 | 视情况承担责任 |

#### 配送纠纷争议处理

- 明确商家与配送方的责任边界
- 出餐及时性由商家负责
- 配送过程由配送方负责
- 双方配合解决争议

### 九、代运营服务商管理

#### 代运营服务商规范

如果商家委托第三方代运营：

- 服务商需符合平台代运营管理规范
- 商家与服务商之间的权责需明确
- 代运营行为的最终责任在商家
- 选择正规备案的服务商
