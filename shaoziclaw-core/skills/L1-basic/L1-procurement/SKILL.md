## 触发场景

当用户需要开发新供应商、谈判采购价格、评估现有供应商、处理采购纠纷、或设计采购流程时，启用此 Skill。

---

## 输入

- 采购品类：蔬菜肉类 / 调味品 / 包材 / 设备 / 其他
- 问题类型：新供应商开发 / 议价 / 现有供应商评估 / 采购流程
- 采购规模：单店 / 3-5店 / 10店以上
- 当前供应商情况（可选）

## 工作流程

### Step 1：供应商开发

```
【供应商来源渠道】
□ 同行推荐（最靠谱）
□ 食材批发市场现场找
□ 行业展会（良之隆/中食展等）
□ 美菜/快驴等B2B平台（对标参考）
□ 政府农超对接平台
□ 厂家直销

【供应商初筛条件】
□ 营业执照+食品经营许可证
□ 配送能力（覆盖范围/冷链）
□ 最低起订量（MOQ）
□ 结算周期
□ 售后服务
```

### Step 2：供应商评估

```
【供应商评估矩阵】

| 评估维度 | 权重 | 供应商A | 供应商B | 供应商C |
|----------|------|---------|---------|---------|
| 价格竞争力 | 30% | | | |
| 品质稳定性 | 30% | | | |
| 配送时效 | 20% | | | |
| 账期支持 | 10% | | | |
| 服务配合度 | 10% | | | |
| 综合得分 | 100% | | | |

【评估标准说明】
- 价格竞争力：与市场均价比，低5%=5分，低10%=4分，高5%=3分，高10%=2分
- 品质稳定性：连续3批次品质稳定=5分，偶尔波动=4分，波动大=3分
- 配送时效：准时≥95%=5分，90-95%=4分，85-90%=3分，<85%=2分
- 账期支持：月结30天=5分，周结=4分，现结=3分
- 服务配合度：好=5分，中=3分，差=2分
```

### Step 3：采购谈判

```
【谈判准备】
□ 了解市场均价（至少3个渠道询价）
□ 明确自己的采购量（量大才有谈判筹码）
□ 确定目标价格（比市场均价低10-20%为目标）
□ 准备备选供应商（形成竞争压力）

【谈判策略】
1. 先摸底：问对方"你们的报价是？"，不先暴露自己的预期
2. 量换价：承诺量的增加换价格的下降
3. 现金换价：现款结算换3-5%的价格优惠
4. 竞品施压：用备选供应商的报价施压
5. 长期合作：签订年度框架协议换稳定价格

【谈判话术】
"我们计划长期合作，月均采购量[X]吨，如果能拿到[X]元/吨的价格，我们可以签全年框架协议，保证稳定订单。"
```

### Step 4：采购合同要点

```
【必备条款】
□ 产品规格（品名/等级/产地/规格）
□ 价格及调整机制（超过X%可重新议价）
□ 最低起订量（MOQ）
□ 送货时间/地点
□ 验收标准（外观/规格/检测报告）
□ 质量问题处理（退换货流程）
□ 付款方式（月结X天/现结）
□ 违约责任
□ 合同期限
```

### Step 5：采购成本优化路径

```
【短期（1-2周）】
□ 多家比价（至少3家供应商）
□ 现金采购换折扣
□ 调整采购规格（换大规格降单价）

【中期（1-3月）】
□ 集中采购（多店联合增大采购量）
□ 源头直采（绕过批发商）
□ 季节性采购（应季食材价格低）
□ 自有渠道开发（农场/工厂）

【长期（3-12月）】
□ 中央厨房/集中配送（降低物流成本）
□ 供应商战略合作（年度框架协议）
□ 订单预测优化（减少临时采购）
□ 库存周转优化（减少资金占用）
```

## 核心方法论

### 供应商四象限分类

```
                价格高
                  △
                  │
    战略型       │      问题型
  (高价值/难替代)│     (需要帮扶)
                  │
─────────────────┼─────────────────→ 价格低
                  │
   交易型        │     优化型
 (低价值/易替代) │    (议价重点)
                  │
                  ▼
                价格低
                      质量稳定性高
```

- **战略型**：建立长期合作关系，不轻易更换
- **问题型**：帮助提升品质或开发备选
- **交易型**：按需采购，不投入过多精力
- **优化型**：重点谈判对象，要求降价或提升品质

### 采购降本公式

```
实际降本 = 原价 × (1 - 目标降幅%) × (1 - 现金折扣%) × (1 + 品质溢价%)

示例：
原价：10元/kg
目标降幅：15% → 8.5元
现金折扣（现结）：3% → 8.245元
品质溢价（更高等级）：+5% → 8.66元/kg

最终采购价：8.66元/kg（原10元）
降本幅度：13.4%
```

## 质量标准

| 维度 | 标准 |
|------|------|
| 供应商评估 | 有具体评分，不是印象判断 |
| 谈判有策略 | 有准备有策略，不是随机谈判 |
| 合同完整 | 核心条款都有，不是口头协议 |
| 成本可量化 | 有具体降本数字，不是模糊承诺 |

## 注意事项

1. **价格不是唯一标准**：品质稳定+配送可靠往往比便宜更重要
2. **账期是双刃剑**：长账期可能换来更高价格
3. **不要把所有鸡蛋放一个篮子**：主供应商至少2家
4. **合同要书面**：口头协议出问题无凭据
5. **食品安全是底线**：再便宜，无资质的供应商也不能用
