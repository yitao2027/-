# L1-cash-flow
# 餐饮现金流管理与财务基础

**层级：** L1 部门基础  
**部门归属：** 财务管理部  
**触发词：** 现金流、财务管理、收支管理、资金周转、账目、利润计算、月底对账、财务健康

---

## 一、Skill 定位

**解决什么问题：**  
帮助餐饮老板建立最基础的财务管理意识和日常账务管理习惯，及时发现资金风险，避免"账面有收入但没钱"的经营困境。

**核心认知：**
- 营业额≠利润：能拿到手的才算
- 现金流断裂比亏损更危险：亏损可以慢慢好转，断流可能直接倒闭
- 餐饮老板不需要成为会计，但必须看得懂这几个数字

### 2.2 餐饮四率健康基准

```
【四率监控表】

成本率 = 食材成本 ÷ 营业额 × 100%
→ 目标：快餐≤30%，正餐≤35%，火锅≤35%

人力成本率 = 人工成本 ÷ 营业额 × 100%  
→ 目标：≤25%（快餐≤20%）

房租成本率 = 月租金 ÷ 月营业额 × 100%
→ 目标：≤10%（超过15%高风险）

综合成本率 = 总成本 ÷ 营业额 × 100%
→ 目标：≤75%（利润率≥25%）

⚠️ 警戒组合（任意2项触发）：
- 食材成本率 >40%
- 人力成本率 >30%
- 房租成本率 >15%
- 综合成本率 >85%（月利润几乎为0）
```

### 2.3 餐饮盈亏平衡点计算

```
盈亏平衡点（保本营业额）计算：

固定成本（每月必须支出，与营业额无关）：
- 房租：___元
- 固定人工：___元
- 设备折旧：___元（总投资÷使用年限÷12）
- 其他固定：___元
固定成本合计：___元/月

变动成本率（随营业额同比例变化）：
- 食材成本率：___%
- 包装成本率：___%
变动成本率合计：___%

盈亏平衡营业额 = 固定成本 ÷ (1 - 变动成本率)
= ___元 ÷ (1 - __%) = ___元/月

意义：每月营业额必须超过___元才不亏损
      目前日均需达到：___元/天（=___元÷30天）
```

### 2.4 资金安全管理原则

**餐饮资金管理的五条铁律：**

```
1. 公私分开（最基础）
→ 门店收入进单独账户，老板个人消费不走门店账户
→ 混账是财务混乱之源，也是税务风险之源

2. 现金储备（安全垫）
→ 账户内保持1-2个月固定成本的现金储备
→ 理由：旺季囤货/突发修缮/员工工资都需要现金

3. 先付供应商（信誉资产）
→ 与供应商维持良好付款记录
→ 账期延期=信誉损耗=供应链稳定性下降

4. 大额支出需审批
→ 单笔≥X元的支出需老板审批（X = 月营业额的1-2%）
→ 避免员工大额采购失控

5. 月度复盘（财务体检）
→ 每月底做一次完整的盈亏分析
→ 找到当月成本超标项，下月重点控制
```

### 2.5 常见财务陷阱预警

| 风险类型 | 危险信号 | 应对方式 |
|---------|---------|---------|
| 食材成本失控 | 月度成本率突然增加3%以上 | 立即排查损耗/被盗/定价问题 |
| 工资刚性增长 | 营业额下降但人力成本不降 | 审视排班，适当减人或引入兼职 |
| 租金压力增大 | 房租率超15% | 重谈租金或评估迁址 |
| 应付账款堆积 | 欠供应商账款超30天 | 立即优先偿还，避免断供 |
| 意外大额支出 | 设备故障/翻新/罚款 | 建立专项应急储备金（建议月营业额的5%） |

## 三、触发条件与输出

**输入收集：**
```
请告诉我：
1. 门店月营业额大概多少？
2. 月租金/月员工工资大概多少？
3. 目前最大的财务担忧是什么？（总是不够钱/不知道钱去哪了/利润太低）
4. 有没有在记日账？（完全没有/简单记录/有系统）
5. 是否有贷款？（影响现金流分析）
```

**输出内容：**
- 盈亏平衡点计算（当前保本营业额）
- 四率健康诊断（对标行业基准）
- 现金流风险等级评估
- 建议建立的最简财务记录体系（3张表）
- 优先改善的财务项目
