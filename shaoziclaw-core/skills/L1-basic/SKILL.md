- 小红书运营

### 触发场景描述
小红书是餐饮品牌曝光的重要阵地，特别是针对女性用户和年轻群体。本skill帮助规划小红书运营策略，产出高质量种草内容。

## 核心方法论

### 餐饮小红书内容矩阵

```
内容矩阵 = 引流款内容 × 3 + 特色款内容 × 2 + 人设款内容 × 1
```

### 内容类型与效果

| 内容类型 | 目的 | 效果 | 频率 |
|----------|------|------|------|
| 打卡类 | 曝光引流 | 高 | 每天 |
| 探店类 | 转化到店 | 中 | 每周2-3篇 |
| 种草类 | 口碑沉淀 | 慢 | 每周1篇 |
| 福利类 | 互动增粉 | 中 | 每月1-2次 |

### 爆款笔记公式

```
爆款 = 强选题 + 好封面 + 真实感 + 平台调性
```

### 餐饮小红书选题库

#### 引流款选题（高频）
- "XX元吃饱！XX这条街没人敢惹这家店"
- "被问疯了！XX最好吃的隐藏菜单"
- "XX终于有了！等位1小时也值得"
- "XX人从小吃到大！本地人才知道"

#### 特色款选题（中频）
- "XX做法第一人！老板任性只卖一道菜"
- "开了XX年！记录三代人的味道"
- "XX宝藏小店！人均50吃到撑"

#### 人设款选题（低频）
- "90后餐饮人：我的第XX家店"
- "辞职开餐厅的第XX天"
- "餐饮人的一天"

## 操作流程

### Step 1：确定账号定位

```
输入：
- 品牌类型（网红/传统/平价/高端）
- 目标人群（学生/白领/家庭/游客）
- 核心卖点（口味/价格/环境/服务）
- 竞争差异化（有什么别人没有的）
```

### Step 2：规划内容矩阵

```
引流款：占60%
- 紧跟热点话题
- 强视觉冲击
- 价格/性价比钩子

特色款：占30%
- 差异化卖点
- 背后故事
- 专业内容

人设款：占10%
- 创始人故事
- 团队日常
- 顾客好评
```

### Step 3：设计爆款封面

```
封面公式：
- 【人群】+【数字】+【情绪词】+【品类】
- 例子："打工人の续命食堂！人均20撑到哭"
- 例子："XX终于有正宗的！等位2小时也值"

图片要求：
- 竖版3:4为主（信息量大）
- 菜品占60%以上画面
- 色彩饱和度高
- 文字简短有力
```

### Step 4：撰写高点击正文

```
正文结构：
1. 开头：痛点/场景/冲突（前3行决定收藏）
2. 中间：环境/菜品/体验（细节描写）
3. 结尾：店铺信息/福利钩子/互动引导

避坑：
- 不要写成大众点评风格
- 不要过度修图（假）
- 不要写太长（600字以内）
```

## 专家点评（避坑提示）

**小红书运营误区**：
1. **过度精致**：修图太假，粉丝会觉得被骗
2. **写成点评**：小红书不是大众点评，要有故事感
3. **只发不发**：发完不互动，账号权重低
4. **追热点过头**：不是所有热点都适合自己品牌

**正确心态**：
- 小红书是"种草"，不是"打广告"
- 粉丝信任你，才会来消费
- 真实 > 完美
