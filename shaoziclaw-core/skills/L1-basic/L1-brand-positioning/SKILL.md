# 品牌定位分析 SKILL

## Skill 元信息

**名称**：L1-brand-positioning
**分类**：L1 部门基础 · 品牌部
**级别**：初级 · 部门入门
**版本**：1.0
**触发词**：「品牌定位」「差异化」「品类机会」「怎么让人记住」「定位」「和竞品怎么区分」

---

## 触发场景

当用户需要分析品牌当前定位、寻找差异化定位机会、评估定位合理性、或为新品牌做定位规划时，启用此 Skill。

---

## 输入

- 品牌名称与业态类型
- 目标市场与客群
- 核心产品/服务
- 主要竞品（2-3个）
- 已有定位描述（可选）

## 工作流程

### Step 1：现有品牌定位诊断

```
【定位现状评估】
品牌名称：[     ]
品类归属：[     ]（例：火锅/茶饮/快餐）
目标客群：[     ]
核心价值主张：[     ]
价格定位：[     ]（高/中/低）

【定位五要素检查】
□ 我是谁（品类）
□ 我卖什么（产品）
□ 给谁卖（客群）
□ 凭什么买（差异化）
□ 什么感受（品牌调性）
```

### Step 2：竞争格局分析

```
【竞争地图绘制】

品类竞争层级：
第一层：[直接竞争对手]（同品类，同价格带）
第二层：[间接竞争对手]（不同品类，抢同一批客群）
第三层：[潜在威胁]（可能进入本品类的大品牌）

【差异化空间判断】
| 维度 | 主要竞品 | 我的机会 |
|------|----------|----------|
| 品类 | | |
| 价格 | | |
| 产品 | | |
| 服务 | | |
| 场景 | | |
| 情感 | | |
```

### Step 3：定位机会识别

**四步定位法**

```
第一步：品类选择
- 我要进入/占据什么品类？
- 这个品类足够大吗？（年市场规模>100亿）
- 品类在增长还是萎缩？
- 我的优势能在这个品类发挥吗？

第二步：差异化确立
- 核心差异点：[       ]
- 差异化来源：
  □ 产品差异化（口味/食材/工艺）
  □ 服务差异化（体验/态度/效率）
  □ 价格差异化（极致低价/高端溢价）
  □ 场景差异化（特定场景/特定时段）
  □ 情感差异化（身份认同/价值观）

第三步：信任背书设计
- 凭什么让顾客相信我的差异化是真的？
- 可验证的事实：[       ]
- 可感知的体验：[       ]

第四步：语言钉设计
- 一句话品牌定位（≤15字）：[       ]
- 品类+差异化+信任：[       ]
```

### Step 4：定位检验

**定位质量评估矩阵**

| 检验维度 | 问题 | 通过标准 |
|----------|------|----------|
| 真实性 | 这个差异化是真实的吗？ | 有可验证的事实支撑 |
| 重要性 | 这个差异对顾客重要吗？ | 目标客群普遍在意 |
| 可差异化 | 竞品做不到或不愿做？ | 竞品短期内难以复制 |
| 可沟通性 | 顾客能快速理解吗？ | 3秒内说清楚 |
| 可持续性 | 能长期坚持吗？ | 不伤害利润和运营 |
| 盈利性 | 支持更高的定价？ | 差异化能带来溢价 |

> 5个以上"通过"→ 强定位
> 3-4个"通过"→ 可优化定位
> 少于3个"通过"→ 需要重新思考

## 核心方法论

### 定位理论核心四问（借鉴经典定位理论）

1. **你是什么？**——品类归属是第一识别
2. **有何不同？**——差异化要具体可感
3. **何以见得？**——信任状是差异化的支撑
4. **值得多少钱？**——定位决定价格天花板

### 餐饮常见定位类型

| 定位类型 | 代表业态 | 核心逻辑 |
|----------|----------|----------|
| 产品主义 | 火锅/牛排/日料 | 品质即品牌 |
| 服务至上 | 正餐/宴请 | 体验即溢价 |
| 极致效率 | 快餐/小吃 | 速度/便利/低价 |
| 场景溢价 | 酒吧/下午茶 | 场景即产品 |
| 情感连接 | 茶饮/烘焙 | IP/文化即品牌 |

### 品类选择决策矩阵

| | 品类增长 | 品类成熟 |
|---|---|---|
| **我的能力强** | 领先机会大，进入 | 差异化强，进入 |
| **我的能力弱** | 培育期长，谨慎 | 竞争激烈，不进入 |

---

## 质量标准

| 维度 | 标准 |
|------|------|
| 差异化分析 | 具体，不模糊（不是"服务好"而是"等位时提供XX服务"） |
| 竞品对比 | 有具体数据支撑 |
| 定位检验 | 有量化评估，不是感觉判断 |
| 可执行性 | 定位能转化为具体产品/服务/传播动作 |

## 注意事项

1. **品类第一，差异化第二**：先说清楚"我是什么"，再说"我有什么不同"
2. **不追求全面**：什么都好=什么都没有，要有所取舍
3. **定位要可放弃**：能说清楚"我不做什么"，定位才清晰
4. **不需要教育市场**：选择已经被认知的品类机会，降低传播成本
5. **定位是动态的**：随竞争格局变化，定位需要迭代
