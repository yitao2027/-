# L1-customer-complaint
# 顾客投诉处理与满意度管理

**层级：** L1 部门基础  
**部门归属：** 营运管理部  
**触发词：** 顾客投诉、投诉处理、差评、顾客不满、纠纷、客诉、顾客抱怨、退款

---

## 一、Skill 定位

**解决什么问题：**  
帮助餐饮门店一线管理人员和员工专业地处理顾客投诉，把投诉危机转化为顾客忠诚度提升的机会，避免投诉扩散造成品牌损失。

**核心认知：**
- 投诉的顾客比默默离开的顾客更有价值（他们给了你一次改进的机会）
- 处理好的投诉，顾客复购率反而高于从未投诉过的顾客
- 投诉处理速度是关键：越快，伤害越小

---

## 二、核心方法论

### 2.1 投诉分类处理矩阵

```
投诉严重程度划分：

A级（紧急处理，15分钟内响应）：
- 食品安全问题（发现异物/顾客身体不适/食物中毒疑似）
- 顾客受伤（就餐中摔倒/烫伤/割伤）
- 顾客激烈情绪（大声吵闹/威胁行为）
- 涉及媒体/网络曝光风险

B级（1小时内处理）：
- 菜品质量问题（偏咸/偏淡/不熟/变味）
- 服务态度投诉（员工无礼/态度冷漠）
- 账单/定价纠纷
- 等待时间过长

C级（当日内处理）：
- 一般体验不满（座位嘈杂/环境问题/分量偏少）
- 网络平台差评（大众点评/美团）
- 建议性反馈（不是负面只是改进建议）
```

### 2.2 投诉处理五步法（LASER）

```
L - 聆听（Listen）
→ 让顾客把话说完，不打断，不反驳
→ 肢体语言：点头/前倾/眼神接触
→ 绝不说：「但是……」「这不是我们的问题……」

A - 表态（Acknowledge）
→ 表达理解和歉意（即使不确定是否是门店的错）
→ 话术：「非常抱歉让您有了这样的体验，我理解这让您感到不舒服。」
→ 注意：表歉意≠承认过错

S - 澄清（Seek clarification）
→ 温和地询问更多细节，了解问题全貌
→ 话术：「方便告诉我具体是哪道菜/哪位员工吗，我们来确认一下。」

E - 解决（Execute）
→ 提出具体解决方案（不是"我们会注意"这种废话）
→ 方案要有实质性：退款/重新制作/优惠券/免单
→ 解决力度匹配问题严重程度（见下文标准）

R - 回访（Review）
→ 解决后确认顾客满意度
→ 话术：「这样处理您是否满意？如果还有任何不满，请告诉我。」
→ 留下联系方式，后续跟进（重大投诉）
```

### 2.3 投诉补偿标准（参考）

```
补偿原则：「让顾客感到被重视」 > 「保住成本」

【轻微问题（B级/C级）】
- 上错菜：免费替换，可赠送小食/甜品表示歉意
- 菜品不够好（偏咸/偏淡）：主动询问是否重做，赠饮料或折扣
- 等待太久：赠送前菜/甜品，结账打折（9折/8.5折）
- 服务态度问题：当场道歉+当餐9折+下次来给优惠券

【中等问题（B级）】
- 菜品有异物（头发/沙子）：免掉该道菜费用，赠小礼品
- 餐具不洁/桌面脏：重换餐具，赠饮品
- 账单错误（多收钱）：纠正+赠优惠券（面值约多收金额2倍）

【严重问题（A级）】
- 食品安全疑虑/身体不适：全单免费+陪同就医（如有需要）+保留食品留样
- 顾客受伤：立即协助处理+记录经过+联系管理层

⚠️ 重要原则：
1. 一线员工有权在___元以内自主处理（授权额度，各店设定）
2. 超过授权额度立即呼叫店长
3. 现金退款：要当场处理，不拖到下次
```

### 2.4 不同场景投诉话术库

**场景一：菜品质量问题**
```
顾客：「这个菜太咸了/味道不对」
员工：「非常抱歉！我们马上为您换一份，同时我把您的反馈记录下来，这对我们改进很重要。这份菜我们不收您的费用，您看可以吗？」
```

**场景二：等位/上菜太慢**
```
顾客：「等了这么久了，菜还没上！」
员工：「真的非常抱歉让您久等了！您点的___正在紧急出餐，大约还需要___分钟。为了表达我们的歉意，先给您上一份___（小食/饮品），请稍等。」
```

**场景三：员工态度问题**
```
顾客：「你们服务员态度太差了！」
员工（管理者）：「感谢您告诉我这件事，我代表门店向您诚挚道歉，这不是我们应有的服务水准。请问是哪位员工/什么情况？我需要了解一下……（听完后）我会立即处理，这次用餐我们为您打9折，希望您能给我们一次再次证明的机会。」
```

**场景四：账单争议**
```
顾客：「账单不对，我没有点这道菜！」
员工：「非常抱歉给您造成困扰，我们立刻核查订单……（核查后，如确实出错）您完全正确，这是我们的失误，我为您马上更正，并送上___作为道歉。」
（如顾客记忆有误）：「我把订单详细和您确认一下，（当着顾客面读出订单），这些都是您点的菜，不知道是否有什么误解？」（语气保持温和，不对立）
```

### 2.5 网络平台差评应对

**大众点评/美团差评回复原则：**
```
公开回复三要素：
1. 感谢反馈（不是客套，而是认可他的权利）
2. 真诚道歉（具体到哪个问题，不是泛泛道歉）
3. 改进承诺（具体的，而非"我们会注意"）

示例（菜品偏咸投诉）：
「感谢您的评价，看到您提到___菜咸了我们深感抱歉，这与我们的出品标准有偏差。我们已经跟后厨进行了专项沟通，并调整了配方配比。如果方便，希望您再给我们一次机会，届时可以联系我们直接安排，我们一定让您满意。」

禁止行为：
❌ 反驳顾客（「这是正常口味/其他顾客都没有投诉过」）
❌ 指责顾客（「您误解了/您的口味比较特殊」）
❌ 冷漠回复（「好的/我们知道了/感谢」）
❌ 拖延回复（超过48小时才回复）
```

## 四、触发条件与输出

**输入收集：**
```
请告诉我：
1. 具体投诉内容是什么？
2. 顾客目前的情绪状态？（愤怒/失望/平静在询问）
3. 投诉发生在哪里？（现场/电话/网络平台）
4. 是否涉及食品安全或人身安全？（最高优先级）
5. 门店目前有无对应授权政策？（一线可处理的最大金额）
```

**输出内容：**
- 投诉级别判断
- 当场处理建议（具体话术+补偿方案）
- 后续跟进步骤
- 网络平台回复话术（如需）
- 内部改进建议（避免同类投诉再次发生）
