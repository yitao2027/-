# 商圈人流分析 SKILL

## Skill 元信息

**名称**：L1-location-traffic
**分类**：L1 部门基础 · 选址开发部
**级别**：初级 · 部门入门
**版本**：1.0
**触发词**：「看铺子」「选址分析」「人流量」「商圈评估」「这个位置行不行」「人流统计」

---

## 触发场景

当用户在选址阶段需要评估一个铺面或商圈的人流情况、位置价值时，启用此 Skill。

---

## 输入

- 铺面位置描述（地址/商圈名称/附近地标）
- 业态类型：快餐 / 正餐 / 茶饮 / 烘焙 / 火锅 / 其他
- 预估客单价范围
- 目标客群描述
- 铺面基本信息：面积、租金、转让费（如有）

## 工作流程

### Step 1：位置基础画像

```
【商圈分类】
□ 商业中心（购物中心/商场）
□ 商业街（步行街/美食街）
□ 办公区（写字楼/产业园区）
□ 社区（住宅区/社区底商）
□ 交通枢纽（地铁站/火车站/机场）
□ 校园区（大学/中学）

【人流时段特征】
- 早高峰：[时间/人流类型]
- 午高峰：[时间/人流类型]
- 晚高峰：[时间/人流类型]
- 夜经济：[时间/人流类型]
- 周末特征：[与工作日差异]
```

### Step 2：人流定量评估

**自然人流估算（三段计时法）**

| 时段 | 时间段 | 观察时长 | 人流数（男/女/合计）| 有效客流比例 |
|------|--------|----------|----------------------|--------------|
| 早 | 7:00-9:00 | 2小时 | / | |
| 中 | 11:30-13:30 | 2小时 | / | |
| 晚 | 17:30-19:30 | 2小时 | / | |

> **有效客流定义**：符合目标客群特征的路人（含等位、路过进店意向）
> **估算方法**：掐表计数×时间系数（10分钟数据×12=1小时）

**竞品拦截率评估**

| 竞品 | 距离 | 位置 | 预估截流比例 |
|------|------|------|-------------|
| [竞品A] | [X]米 | [街口/拐角/同侧] | [%] |
| [竞品B] | [X]米 | [位置] | [%] |
| [竞品C] | [X]米 | [位置] | [%] |

**拦截后剩余客流** = 自然人流 × (1 - 主要竞品截流率)

### Step 3：营业额预估

```
【核心公式】
预估月营业额 = 有效日均客流 × 捕获率 × 客单价 × 30天

【品类捕获率参考】
- 快餐/简餐：10-20%
- 正餐：5-10%
- 茶饮：8-15%
- 烘焙：6-12%
- 火锅：3-8%

【示例计算】
假设：日均有效客流500人，捕获率12%，客单价45元
月营业额 = 500 × 12% × 45 × 30 = 81,000元
```

### Step 4：租金可行性评估

```
【租金红线检测】
月租金上限 = 月预估营业额 × 15%（警戒线20%）

若月租金8,100元 → 租金占比10% → ✓ 通过
若月租金16,200元 → 租金占比20% → ⚠ 警戒
若月租金24,300元 → 租金占比30% → ✗ 不通过

【建议租金区间】
- 安全区间：≤10%营业额
- 警戒区间：10-15%营业额
- 危险区间：>15%营业额
```

### Step 5：位置优劣势评分

| 评估维度 | 权重 | 评分（1-5）| 加权得分 |
|----------|------|------------|----------|
| 自然人流 | 20% | | |
| 可见性/曝光 | 15% | | |
| 可达性/动线 | 15% | | |
| 竞品竞争度 | 15% | | |
| 租金性价比 | 15% | | |
| 周边配套 | 10% | | |
| 未来发展潜力 | 10% | | |

> 评分说明：5=极佳，4=优秀，3=一般，2=偏差，1=差
> **总分≥3.5** → 推荐进入下一轮深度评估
> **总分2.5-3.5** → 需要更多证据支持
> **总分＜2.5** → 建议放弃

## 核心方法论

### 选址四力模型

1. **可见性**（Visibility）——路人对门店的第一眼识别能力
2. **可达性**（Accessibility）——目标客群到达门店的便利程度
3. **聚客点**（Anchor）——周边是否有强引力吸引点
4. **节流率**（Conversion）——截留路过客流的能力

### 品类选址差异化

| 品类 | 核心选址逻辑 | 首选位置类型 |
|------|-------------|-------------|
| 快餐 | 高客流+快速决策 | 交通枢纽/办公区/学校 |
| 正餐 | 社交场景+稳定客群 | 社区/商业街/聚餐聚集区 |
| 茶饮 | 年轻女性+冲动消费 | 商业中心/学校/步行街 |
| 烘焙 | 社区粘性+口碑 | 社区底商/办公区 |
| 火锅 | 聚餐+特定时段 | 商业街/社区/夜经济区域 |

### 千分选址快速评估维度（精简版）

1. 门前人流（300分）——主客流方向/过路频次
2. 竞品距离（200分）——周边同类竞品数量与距离
3. 可见展示（150分）——门头展示面积/拐角位置加分
4. 租金性价比（150分）——租金/月营业额比值
5. 交通停车（100分）——停车便利性/公共交通

## 质量标准

| 指标 | 标准 |
|------|------|
| 人流估算 | 有量化数据，不只是"人挺多" |

| 财务测算 | 有具体盈亏测算，不只是印象判断 |
| 决策建议 | 明确不建议/可考虑/推荐 |

## 注意事项

1. **人流数据保守估计**：不要乐观，截流率取区间下限
2. **品类特性区分**：不同品类捕获率差异巨大，不要套用同一公式
3. **时段要完整**：只看午高峰≠真实情况，早晚高峰同样重要
4. **不只看租金**：便宜的位置未必是好的，综合评分更重要
