# 智能邮件撰写

## Skill 元信息

| 字段 | 内容 |
|------|------|
| **名称** | 智能邮件撰写 |
| **层级** | L1 - 通用办公基础 |
| **分类** | 通用办公 > L1级 |
| **来源** | 勺子Claw 内置 Skill |
| **版本** | v1.0 |

## 功能描述

根据主题、收件人、语气要求，自动撰写各类商务邮件（回复/邀请/通知/道歉/感谢等）

## 特色功能

支持中文英文，自动适配语气正式程度

## 适用场景

1. 餐饮企业日常办公需求
2. 创业者的文书工作自动化
3. 团队协作中的文档标准化

## 使用方式

在 勺子Claw 中选择此 Skill → 输入具体需求 → 自动生成对应文档

## 输出格式

根据场景自动选择最合适的输出格式：
- Word (.docx) — 正式文件
- Excel (.xlsx) — 数据表格
- PPT (.pptx) — 演示文稿
- PDF (.pdf) — 报告/打印
