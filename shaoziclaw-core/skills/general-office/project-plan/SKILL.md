# 项目管理计划

## Skill 元信息

| 字段 | 内容 |
|------|------|
| **名称** | 项目管理计划 |
| **层级** | L2 - 办公专项能力 |
| **分类** | 通用办公 > L2级 |
| **来源** | 勺子Claw 内置 Skill |
| **版本** | v1.0 |

## 功能描述

为新店开业/活动策划/系统升级等项目制定完整执行计划

## 特色功能

含时间线、里程碑、资源需求、风险预案

## 适用场景

1. 餐饮企业日常办公需求
2. 创业者的文书工作自动化
3. 团队协作中的文档标准化

## 使用方式

在 勺子Claw 中选择此 Skill → 输入具体需求 → 自动生成对应文档

## 输出格式

根据场景自动选择最合适的输出格式：
- Word (.docx) — 正式文件
- Excel (.xlsx) — 数据表格
- PPT (.pptx) — 演示文稿
- PDF (.pdf) — 报告/打印
