# 商务信函模板

## Skill 元信息

| 字段 | 内容 |
|------|------|
| **名称** | 商务信函模板 |
| **层级** | L1 - 通用办公基础 |
| **分类** | 通用办公 > L1级 |
| **来源** | 勺子Claw 内置 Skill |
| **版本** | v1.0 |

## 功能描述

各类商务信函模板（合作邀请函/催款函/解约函/推荐信等）

## 特色功能

符合中国商业惯例

## 适用场景

1. 餐饮企业日常办公需求
2. 创业者的文书工作自动化
3. 团队协作中的文档标准化

## 使用方式

在 勺子Claw 中选择此 Skill → 输入具体需求 → 自动生成对应文档

## 输出格式

根据场景自动选择最合适的输出格式：
- Word (.docx) — 正式文件
- Excel (.xlsx) — 数据表格
- PPT (.pptx) — 演示文稿
- PDF (.pdf) — 报告/打印
