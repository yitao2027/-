# PPT Generator - AI生成专业PPT

**核心思路**：每一页PPT由大模型设计，风格统一但内容多样。

## 设计哲学

- **风格统一** - 定义品牌色/字体/布局规则，全局一致
- **页页不同** - 每页内容单独设计，发挥AI创意
- **专业输出** - HTML截图 → PPTX，直接可用

## 生成流程

### Step 1: 收集品牌信息
- 品牌名称、创立时间、核心数据
- 品牌色（主色、辅助色、强调色）
- 参考图片路径

### Step 2: 定义风格指南
```
## 统一风格规范
- 主色: #XXXXXX
- 辅助色: #XXXXXX  
- 强调色: #XXXXXX
- 字体: 微软雅黑
- 布局: 左右分栏/居中/卡片式
- 背景: 渐变/纯色/纹理
```

### Step 3: 生成每页内容（JSON）
```json
[
  {"page": 1, "title": "封面", "content": "..."},
  {"page": 2, "title": "品牌故事", "content": "..."},
  ...
]
```

### Step 4: AI生成每页HTML
为每一页调用大模型，生成专业HTML设计：
- 包含风格指南
- 包含当页内容
- 要求设计感、专业感

### Step 5: 截图组装
- Playwright截图每页HTML
- python-pptx组装成PPTX

## 输出

- 10-15页专业PPT
- 16:9横版
- 直接可用的PPTX文件

## 技术栈

- 大模型（MiniMax/Claude）：生成HTML
- Playwright：截图
- python-pptx：组装PPTX

## 示例：蓝湘子品牌介绍

**风格指南**：
- 主色: #1B4FAB (绅士蓝)
- 辅助: #3B7DD8 (浅蓝)
- 强调: #C8A840 (金色)
- 字体: 微软雅黑

**10页结构**：
1. 封面 - 品牌名+数据条
2. 品牌故事 - 里程碑卡片
3. 品牌定位 - 三大支柱
4. 发展历程 - 时间轴
5. 核心数据 - 数字卡片
6. 招牌菜品 - 图片网格
7. 门店体验 - 服务列表
8. 全国布局 - 数据展示
9. 加盟优势 - 优势卡片
10. 结尾页 - 联系方式
