# SWOT战略分析

## Skill 元信息

| 字段 | 内容 |
|------|------|
| **名称** | SWOT战略分析 |
| **层级** | L2 - 办公专项能力 |
| **分类** | 通用办公 > L2级 |
| **来源** | 勺子Claw 内置 Skill |
| **版本** | v1.0 |

## 功能描述

对企业/品牌/门店做系统的SWOT分析

## 特色功能

优势/劣势/机会/威胁 + 战略建议

## 适用场景

1. 餐饮企业日常办公需求
2. 创业者的文书工作自动化
3. 团队协作中的文档标准化

## 使用方式

在 勺子Claw 中选择此 Skill → 输入具体需求 → 自动生成对应文档

## 输出格式

根据场景自动选择最合适的输出格式：
- Word (.docx) — 正式文件
- Excel (.xlsx) — 数据表格
- PPT (.pptx) — 演示文稿
- PDF (.pdf) — 报告/打印
