## 工作流使用指南

### 1. 选择工作流
根据当前需求选择对应工作流：
- 新开一家店 → WF-001 选址开业流
- 想做品牌 → WF-002 品牌定位流
- 外卖要提升 → WF-003 外卖运营流
- 准备开放加盟 → WF-004 加盟扩张流
- 遇到危机了 → WF-005 危机公关流
- 想数字化转型 → WF-006 数字化转型流
- 人才是瓶颈 → WF-007 人才战略流
- 供应链有问题 → WF-008 供应链管控流
- 要研发新品 → WF-009 产品研发流
- 多店要管控 → WF-010 多店管理流

### 2. 按顺序执行
工作流中的Skills有先后依赖关系，请按流程顺序执行

### 3. 灵活组合
实际工作中可根据需要选择工作流中的部分Skills组合使用
