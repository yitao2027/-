- **2025年分化**：头部品牌差距拉大，直营 vs 加盟路线对比鲜明

## 二、蜜雪冰城：6万店的平价之王

**基本信息**
- 创立：1997年，郑州
- 创始人：张红超 → 张渊（CEO接班）
- 2024年营收：**248.29亿元**
- 净利润：**44.54亿元**
- 门店：**46,479家**（全球），超越星巴克成全球现制饮品门店数第一
- 2025年：突破6万家，营收335亿元

**商业模式核心**

```
蜜雪 = 供应链公司 + 加盟品牌
收入来源 = 卖原料给加盟商（占总收入90%+）
```

**蜜雪的秘密武器**

| 维度 | 蜜雪策略 | 效果 |
|---|---|---|
| 价格 | 3-8元极致低价 | 下沉市场无敌 |
| 产品 | 爆款少而精（柠檬水/冰淇淋） | 供应链简单 |
| 供应链 | 自建供应链，核心原料自产 | 成本最低 |
| 加盟费 | 低门槛（20万起） | 快速扩张 |
| 品牌 | IP营销（雪王） | 年轻人认知度极高 |

**加盟商视角的蜜雪**

- 启动资金：20万元起
- 实际投入：可能不止20万（装修/租金/设备）
- 真实盈利：客单价低，但高翻台率补量
- 风险：门店太密，单店日均杯数下滑

**老板级洞察**：蜜雪的本质不是茶饮公司，是**供应链公司**。它靠卖原料赚钱，加盟商只是它的"渠道"。**如果你做茶饮不自建供应链，你永远在为蜜雪打工。**

## 三、霸王茶姬：东方星巴克的野心

**基本信息**
- 创立：2017年，云南
- 创始人：张俊杰（90后孤儿出身，10岁丧父丧母）
- 2025年Q1门店：**6,681家**（全球），同比增长63.6%
- 注册会员：**1.924亿**（活跃会员4,490万）
- 2025年：上市，营收~200亿

**差异化核心**

```
"茶+奶" 大单品策略 ≠ 水果茶/奶茶混搭
招牌：伯牙绝弦（茉莉茶底+牛乳）
```

**伯牙绝弦的威力**

- 单款产品占营收30%+
- 年销超1亿杯
- 成为品牌符号，像星巴克的"拿铁"

**扩张密码**

| 策略 | 做法 |
|---|---|
| 大单品 | 只做"茶+奶"，SKU精简到20+ |
| 数据驱动 | 每家店用BI系统优化运营 |
| 健康化 | 公布热量，对标健身人群 |
| 对标星巴克 | 开旗舰店，做"第三空间" |
| 出海 | 东南亚156家，布局全球 |

**2025年的挑战**

- 营收下滑，加盟商信心下降
- 过度依赖伯牙绝弦，创新乏力
- 价格带尴尬：比蜜雪贵太多，比喜茶又没品牌溢价

**老板级洞察**：霸王茶姬的成功=大单品+效率。**茶饮品牌的护城河不在门店数量，在"我想喝茶的时候就想到你"。找到那个产品，让它成为你品牌的代名词。**

## 四、古茗：闷声发大财的加盟之王

**基本信息**
- 创立：2010年，浙江
- 2024年营收：**129.14亿元**
- 净利润：**31.09亿元**（净利率24%）
- 门店：9000+家
- **盈利增速行业第一**

**为什么古茗能赚钱？**

1. **区域密度策略**：不在全国铺开，而是在优势区域密集开店
2. **下沉市场**：主攻三四线城市，避开一二线竞争
3. **供应链效率**：自建仓储物流，冷链覆盖率高
4. **加盟商管控**：严格筛选，不是给钱就能开

**数据对比**

| 品牌 | 净利率 | 关键差异 |
|---|---|---|
| 古茗 | 24% | 加盟管控+区域密度 |
| 蜜雪 | 18% | 规模+供应链 |
| 茶百道 | 15% | 中规中矩 |
| 奈雪 | 亏损 | 直营太重 |

**老板级洞察**：古茗证明了**三四线城市才是茶饮的主战场**。在一线城市卷到头，不如在县城建立密度优势。**区域王者的利润，往往高于全国铺摊子的品牌。**

## 五、喜茶 & 奈雪：直营之殇

**喜茶（2024-2025）**
- 2024年：4477家门店，2025年10月缩至3977家（关店500家）
- 2025年：直营收缩，开始开放加盟
- 问题：客单价高（30元+），下沉难，与蜜雪/霸王不在一个竞争维度

**奈雪的茶（2024）**
- 日均亏损251万（媒体报道）
- 门店收缩，直营模式拖累
- 尝试PRO店（缩小面积）降成本

**直营模式的问题**

```
直营 = 高人力成本 + 高租金 + 高管理成本
vs
加盟 = 轻资产 + 靠加盟商承担运营成本
```

**老板级洞察**：茶饮的尽头是加盟。**喜茶和奈雪的教训说明，在茶饮这个赛道，品牌溢价很难覆盖直营的成本。与其硬撑直营的"面子"，不如早点开放加盟赚"里子"。**

## 六、财务模型铁律

### 6.1 新茶饮 vs 快餐 vs 火锅

| 成本项 | 新茶饮 | 快餐 | 火锅 |
|---|---|---|---|
| 食材原料 | 30-35% | 30-35% | 38-45% |
| 人力成本 | 15-20% | 20-25% | 22-28% |
| 租金占比 | 15-20% | 8-12% | 10-15% |
| 包装耗材 | 5-8% | 1-3% | - |
| **净利率** | **10-25%** | 8-15% | 8-15% |

### 6.2 新茶饮成本特殊性

**包装耗材是大头**
- 纸杯+吸管+杯套+封口膜+手提袋
- 高端品牌包装成本占比可达5-8%
- 蜜雪靠规模压低包装成本

**租金弹性大**
- 商场店：租金高但客流大
- 街边店：租金低但曝光少
- 社区店：租金低，适合复购

### 6.3 加盟商盈利模型

```
月净利润 = 月营收 × (1 - 原料成本率 - 租金率 - 人力)
         - 加盟费摊销（按月）
```

**蜜雪加盟商**（乐观估算）
- 客单价：6-8元
- 日均杯数：200-300杯
- 月营收：4-7万元
- 净利率：约10-15%
- 回本周期：2-3年

## 七、供应链：茶饮品牌的真正护城河

### 7.1 茶饮供应链四大件

| 原料 | 占成本比 | 关键点 |
|---|---|---|
| **茶叶** | 15-20% | 茉莉/乌龙/普洱，品质差异大 |
| **奶制品** | 10-15% | 鲜奶/植脂末/乳粉 |
| **糖** | 5-8% | 蔗糖/果糖/代糖 |
| **配料** | 10-15% | 珍珠/椰果/芋圆/水果 |

### 7.2 蜜雪的供应链壁垒

- **自建柠檬基地**：在四川、海南等地签约种植户
- **自建糖厂**：压低糖原料成本
- **中央仓+冷链**：覆盖全国的物流网络
- **结果**：蜜雪的原料成本比竞争对手低20-30%

### 7.3 霸王茶姬的供应链策略

- 公布热量表：倒逼供应链标准化
- 自建茶园：在云南有自己的茶园
- 精简SKU：只用20+个SKU，供应链简单可控

## 八、选址逻辑：茶饮与快餐/火锅的本质差异

### 8.1 茶饮选址的特殊性

| 维度 | 茶饮特点 |
|---|---|
| 面积要求 | 20-50㎡（小而精） |
| 客单价 | 10-30元 |
| 翻台速度 | 快（打包/外带为主） |
| 黄金位置 | 商场/学校/写字楼/地铁口 |
| 致命因素 | 同街同类竞品超过2家 |

### 8.2 选址公式

```
月营收 = 日均杯数 × 客单价 × 30天

日均杯数关键因素：
= 门前人流 × 进店率 × 捕获率

进店率参考：
- 商场店：8-15%
- 街边店：3-8%
- 写字楼店：5-10%（午/下午高峰）
```

## 九、老板级复盘：新茶饮最值得记住的5件事

### 1. 加盟是茶饮的正确答案，直营只是特例

蜜雪、古茗、霸王茶姬的成功都证明：茶饮是一个"轻资产"赛道，品牌赚供应链的钱，加盟商赚运营的钱。**如果你想做茶饮，先想清楚你要做品牌还是做加盟商。**

### 2. 大单品是茶饮品牌的生死线

霸王茶姬的伯牙绝弦贡献30%+营收，证明了一个爆款的威力远大于100个平庸产品。**与其做100款产品，不如把1款做到极致。**

### 3. 供应链即护城河，蜜雪证明了这一点

蜜雪的核心竞争力不是门店数量，是供应链成本。**在你有能力建立供应链之前，你只是在为上游供应商打工。**

### 4. 三四线城市是茶饮的主战场

古茗的24%净利率证明了区域密度策略的价值。**与其在全国开1000家，不如在一个省开500家做到密度第一。**

### 5. 健康化是下一个机会窗口

霸王茶姬公布热量表的策略成功了——健康溢价是真实存在的消费需求。**未来茶饮的竞争不在口味，在"喝了不胖"这个承诺。**
