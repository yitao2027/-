## Skill 元信息

**名称**：catering-trend-monitor
**分类**：L0 通用工具
**级别**：初级 · 通用
**版本**：1.0

---

## 触发场景

当用户需要了解餐饮行业最新动态、市场热点、竞品动向、政策变化时，启用此 Skill。

---

## 输入

- 监测范围（可选）：全行业 / 指定品类（火锅/茶饮/快餐/烘焙等）/ 指定地域
- 监测时间窗口：今日 / 本周 / 本月 / 指定日期
- 关注维度：热度数据 / 政策动态 / 竞品动向 / 消费者趋势 / 投融资

---

## 工作流程

### Step 1：多源并行采集

按以下优先级执行（至少3种方法并行）：

| 优先级 | 数据源 | 采集内容 |
|--------|--------|----------|
| ★★★★★ | 新榜（newrank.cn/search/trend）| 公众号热度文章、关键词热度 |
| ★★★★☆ | 微博热搜 | 实时突发热点、舆情事件 |
| ★★★★☆ | 百度指数/搜索风云榜 | 搜索热度趋势、关键词热度 |
| ★★★☆☆ | 抖音热榜 | 餐饮相关内容热度 |
| ★★★☆☆ | 知乎热榜 | 专业讨论与行业洞察 |
| ★★★☆☆ | 红餐网/36氪/虎嗅 | 行业深度报道 |

### Step 3：选题价值评估

对热度事件进行选题价值评估：

| 评估维度 | 权重 | 评分标准 |
|----------|------|----------|
| 热度指数 | 20% | 高/中/低 |
| 受众共鸣度 | 25% | 强共鸣/中等/弱 |
| 传播裂变潜力 | 20% | 易传播/一般/难 |
| 内容创作空间 | 20% | 丰富/一般/有限 |
| 与目标受众契合度 | 15% | 高/中/低 |

综合得分≥75分的热点，标记为「高价值选题」。

## 核心方法论

### 热点判断标准

餐饮热点的生命周期通常为**3-7天**，判断标准：

1. **社会性**——是否触达大众情绪（焦虑/共鸣/好奇/愤怒）
2. **餐饮关联度**——与餐饮行业的直接/间接关联
3. **信息密度**——是否有足够的二次创作空间
4. **受众覆盖**——是否覆盖目标用户群

### 采集质量控制

- 同一事件至少2个独立来源确认
- 数据尽量量化（播放量/阅读量/讨论量）
- 标注信息来源和时间节点
- 区分事实陈述与推测评论

---

## 质量标准

| 指标 | 标准 |
|------|------|
| 覆盖数据源 | ≥3种 |
| 热点事件数量 | ≥5个 |
| 输出完整性 | 含热度/政策/竞品/趋势四维度 |
| 时效性 | 数据为最近30天内 |
| 选题推荐 | ≥3个高价值选题 |

## 注意事项

1. 重大政策类信息优先核实官方文件原文
2. 涉及具体品牌的负面舆情，客观描述事实不偏向任何一方
3. 投融资信息需标注数据来源及时间节点
4. 不要基于单一来源下结论
