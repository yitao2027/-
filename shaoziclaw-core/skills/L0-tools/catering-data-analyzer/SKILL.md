# 餐饮数据分析 SKILL

## Skill 元信息

**名称**：catering-data-analyzer
**分类**：L0 通用工具
**级别**：初级 · 通用
**版本**：1.0
**触发词**：「分析数据」「门店数据」「看数据报表」「数据有问题」「指标分析」

---

## 触发场景

当用户需要分析门店/品牌的经营数据、财务数据、运营指标、竞品数据时，启用此 Skill。

---

## 输入

- 数据类型：销售数据 / 成本数据 / 客流数据 / 评价数据 / 竞品数据
- 数据格式：表格 / 截图 / 描述性文字
- 分析目的：诊断问题 / 评估表现 / 对标竞品 / 决策支持

---

## 工作流程

### Step 1：数据接收与预处理

接收用户提供的原始数据，检查数据质量：

```
【数据完整性检查】
- 时间范围：是否连续？
- 数据字段：是否完整？
- 异常值：是否有明显不合理的数据点？

【数据标准化】
- 统一计量单位（万元/元、份/客）
- 统一时间粒度（月/周/日）
```

### Step 2：指标计算

根据数据类型，计算以下核心指标：

**运营指标**
| 指标 | 公式 | 参考标准 |
|------|------|----------|
| 客单价 | 总营业额 ÷ 来客数 | 品类均值±20% |
| 翻台率 | 总桌位数 ÷ 用餐批次 | 正餐≥2次，快餐≥4次 |
| 上座率 | 实际接待 ÷ 可接待量 × 100% | ≥70%为优 |
| 人效 | 月营业额 ÷ 员工人数 | 品类差异大 |
| 坪效 | 月营业额 ÷ 面积(㎡) | 一线城市≥150元/㎡ |

**财务指标**
| 指标 | 公式 | 参考标准 |
|------|------|----------|
| 毛利率 | （营收-食材成本）÷ 营收 × 100% | 中餐≥55%，快餐≥65% |
| 食材成本率 | 食材成本 ÷ 营收 × 100% | ≤35% |
| 人力成本率 | 人力成本 ÷ 营收 × 100% | ≤30% |
| 租金成本率 | 租金 ÷ 营收 × 100% | ≤15% |
| 净利率 | 净利润 ÷ 营收 × 100% | ≥10% |

**评价指标**
| 指标 | 计算方式 | 参考标准 |
|------|----------|----------|
| 星级均值 | 评价总分 ÷ 评价数 | ≥4.5为优 |
| 好评率 | 好评数 ÷ 总评价 × 100% | ≥85% |
| 差评响应率 | 已回复差评 ÷ 总差评 × 100% | 100% |
| 复购预估 | 回头客 ÷ 总客数 × 100% | 品类差异大 |

### Step 3：多维对比分析

```
【与行业基准对比】
- 所在品类均值对比
- 目标商圈均值对比
- 与规模相近品牌对比

【时间维度对比】
- 环比（上周/月同期）
- 同比（去年同期）
- 趋势判断：上升/平稳/下降

【结构分析】
- 菜品维度：哪些菜贡献最大/最小？
- 时段维度：哪个时段产出最高？
- 渠道维度：堂食/外卖/外带的比例？
```

### Step 4：问题诊断与建议

识别关键问题，按优先级排序：

```
【核心问题】（影响净利润，需立即处理）
[问题描述] → [根本原因] → [可落地建议]

【次要问题】（影响效率，中期优化）
[问题描述] → [优化路径] → [建议措施】

【潜在风险】（预警项，持续观察）
[指标异动] → [可能原因] → [监控建议】
```

### Step 5：输出分析报告

```
## 餐饮数据分析报告
**分析对象**：[门店/品牌名称]
**数据周期**：[时间范围]
**分析时间**：[当前日期]

---

### 一、核心指标概览
[仪表盘式摘要：关键数字+趋势箭头]

### 二、运营表现分析
[翻台率/客单价/上座率详细分析]

### 三、财务健康度评估
[成本结构/利润空间/盈亏判断]

### 四、评价数据解读
[星级/好评率/差评分布/响应质量]

### 五、竞品对标（如有数据）
[与主要竞品的关键指标对比]

### 六、问题诊断清单
[按优先级列出问题]

### 七、优化建议
[具体可执行的建议TOP5]

### 八、行动优先级
[立即做/本周做/本月做 分类]
```

## 核心方法论

### 数据分析三板斧

1. **比**——与基准比（行业均值/历史数据/竞品）
2. **拆**——拆解到最小单元（单品/时段/渠道/员工）
3. **追**——追溯到根本原因（5Why分析法）

### 餐饮财务黄金比例

| 指标 | 健康 | 警戒 | 危险 |
|------|------|------|------|
| 食材成本率 | ≤32% | 32-38% | >38% |
| 人力成本率 | ≤25% | 25-32% | >32% |
| 租金成本率 | ≤12% | 12-18% | >18% |
| 综合成本率 | ≤85% | 85-92% | >92% |

### 决策树：数据异常判断

```
发现指标异常 → 是核心指标吗？ → 否 → 记录观察
                            ↓ 是
                    与历史数据比 → 正常波动 → 持续监控
                            ↓异常
                        与行业比 → 低于均值 → 进入诊断流程
                            ↓高于均值
                        排除数据误差 → 确认为优势 → 提炼成功因素
```

## 注意事项

1. 数据保密：用户提供的经营数据不外传，不用于他途
2. 量化优先：能算数字的不要只说"还可以"
3. 建议可执行：避免"加强管理""提高意识"等空话
4. 承认局限：数据不足时明确说明假设前提
