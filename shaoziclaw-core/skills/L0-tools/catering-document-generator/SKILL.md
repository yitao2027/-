# 餐饮文档生成 SKILL

## Skill 元信息

**名称**：catering-document-generator
**分类**：L0 通用工具
**级别**：初级 · 通用
**版本**：1.0
**触发词**：「生成文档」「帮我写」「写个方案」「出份报告」「做个SOP」「写个工作流程」

---

## 触发场景

当用户需要生成各类餐饮行业专业文档时启用，包括但不限于：开店计划书、品牌手册、运营SOP、培训资料、合同模板、商业计划等。

---

## 输入

- 文档类型：开店计划书 / 品牌手册 / 运营手册 / 培训资料 / 合同模板 / 商业计划书 / 可行性报告 / 其他
- 目标读者：老板/管理层 / 店长 / 员工 / 投资人 / 加盟商 / 政府审批
- 详细程度：概要版（1-3页）/ 标准版（10-20页）/ 完整版（30页以上）
- 品牌/门店基本信息（需用户提供）

---

## 工作流程

### Step 1：确认文档类型与需求

```
【文档类型确认】
类型：[选择或描述]
目标读者：[谁会看这份文档]
用途：[内部使用/对外展示/申请审批]
详细程度：[概要/标准/完整]
```

### Step 2：根据类型选择模板框架

**开店计划书框架**
```
一、项目概述
二、市场分析（品类/竞争/选址）
三、产品与服务
四、商业模式（堂食+外卖+零售）
五、运营模式
六、营销策略
七、投资估算与财务预测
八、风险分析
九、进度计划
十、团队介绍
```

**品牌手册框架**
```
一、品牌故事
二、品类定位
三、目标客群
四、品牌理念与价值观
五、视觉识别系统（VI）
六、产品展示
七、门店形象标准
八、服务标准
九、品牌传播策略
```

**运营SOP框架**
```
一、文档说明（目的/适用范围/负责人）
二、岗位说明（职责/任职要求/汇报关系）
三、每日工作流程（时间节点+操作标准）
四、每周工作内容
五、每月工作内容
六、异常情况处理
七、考核标准
八、相关表单
```

**商业计划书框架（融资用）**
```
一、执行摘要（1页）
二、项目介绍
三、市场机会（数据支撑）
四、产品与商业模式
五、竞争优势（护城河）
六、市场策略
七、核心团队
八、财务预测（3年）
九、融资计划
十、退出机制
```

### Step 3：填充内容

根据用户提供的品牌/门店信息，填充各模块内容：

```
【必填信息】
- 品类/业态：
- 品牌名称（如有）：
- 目标客群：
- 选址位置：
- 门店面积：
- 预估投资额：
- 团队规模：

【可选信息】
- 已有数据（销售/客流/成本）：
- 差异化特色：
- 已有资源：
```

### Step 4：生成文档

按以下格式标准输出：

```
【排版标准】
- 字体：中文微软雅黑，英文Arial
- 标题层级：一级黑体18px / 二级黑体14px / 正文宋体12px
- 页边距：上下2.54cm，左右3.17cm
- 行距：1.5倍

【内容标准】
- 数据有来源标注
- 方案有具体数字
- 流程有操作步骤
- 禁止空洞话术
```

### Step 5：交付格式

根据用户需求输出：

| 格式 | 适用场景 |
|------|----------|
| Markdown | 内部参考、进一步修改 |
| Word（.docx） | 正式文档、打印使用 |
| PPT（.pptx） | 汇报展示、投资人演示 |

## 核心方法论

### 餐饮开店计划书必须包含的数字

| 模块 | 必含数字 |
|------|----------|
| 市场分析 | 目标品类市场规模、增长率、竞争门店数 |
| 选址 | 预估客流、捕获率、客单价 |
| 投资 | 启动资金、各项成本占比、回本周期 |
| 财务 | 月均营收、盈亏平衡点、毛利率预测 |
| 运营 | 员工数、排班表、人效目标 |

### 商业计划书投资人最关心的3个问题

1. **市场够不够大** → 品类数据+增长趋势
2. **凭什么是你** → 差异化+团队+资源优势
3. **怎么赚钱** → 可信的财务模型+里程碑

### 好的SOP标准

- 每个步骤≤3句话
- 每步有明确判断标准（数字/温度/时间）
- 有图不写字（操作类优先图示）
- 异常情况单独标注

## 质量标准

| 维度 | 标准 |
|------|------|
| 结构完整 | 包含该类型文档的所有必要模块 |
| 内容专业 | 使用餐饮行业标准术语 |
| 数据合理 | 数字符合行业基准，有来源 |
| 格式规范 | 排版统一，层级清晰 |
| 可执行性 | 方案具体可落地，非泛泛而谈 |

## 注意事项

1. **数据核实**：财务预测数据要有行业依据，不能凭空捏造
2. **避免暴露**：不提及具体参考品牌名称，用"行业标杆""某头部品牌"代替
3. **尊重版权**：生成的内容为原创，不复制任何来源文件原文
4. **标注假设**：所有预测数据标注假设前提
5. **适配读者**：投资人口味≠店长口味，输出前先确认读者
