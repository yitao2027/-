# 餐饮"四效"指标体系：人效·费效·坪效·桌效

**来源**：九数云/网易号（2025-09-18）+ 重庆云析数智财税（2025-04-11）
**采集时间**：2026-03-31
**质量评级**：★★★★★
**适用场景**：所有餐饮业态的经营健康度诊断

---

## 核心定义与公式

| 指标 | 核心定义 | 计算公式 |
|------|---------|---------|
| **人效** | 每位员工创造的收入价值 | `人效 = 营业收入 ÷ 人员数量` |
| **费效** | 每投入1元运营费用带来的收入回报 | `费效 = 营业收入 ÷ 运营费用` |
| **坪效** | 每平方米营业面积产生的收入 | `坪效 = 营业收入 ÷ 营业面积` |
| **桌效** | 单张餐桌在特定时间内贡献的收入 | `桌效 = 营业收入 ÷ 餐桌数量` |

---

## 进阶计算公式（更精准）

### 翻台率标准算法
```
实际翻台率 = Σ各时段翻台数 ÷ 总餐位数 × 经营时段系数
时段系数：早市0.8 / 午市1.0 / 晚市1.2
```

### 人效标准算法（含岗位系数）
```
标准人效 = Σ(岗位系数 × 有效工时) ÷ 总薪资支出 × 100%
岗位系数参考：厨师1.2 / 服务员1.0 / 收银0.9
有效工时：扣除休息、准备等非服务时间
```

### 毛利率精准算法
```
毛利率 = (月销售额 - 食材成本 - 分摊能源费用30%) ÷ 月销售额 × 100%
注：食材损耗要计入（如100斤牛肉实际出菜83斤，损耗17%）
```

## 案例对比：大店 vs 小店哪个更赚钱

| 指标 | 甲店（大店） | 乙店（小店） | 结论 |
|------|------------|------------|------|
| 日营业额 | 8181元 | 6666元 | 甲店收入更高 |
| **人效** | 514元/人·日 | **567元/人·日** | 乙店人更高效 |
| **坪效** | 37元/㎡·日 | **41元/㎡·日** | 乙店空间利用更好 |
| **桌效** | 511元/桌·日 | **555元/桌·日** | 乙店餐桌更值钱 |
| **费效** | 3.33元 | **5.00元** | 乙店成本控制碾压 |

**核心结论**：乙店虽然营业额低，但运营效率更高，是更健康的模型，适合作为开新店的范本。

## 各指标优化方向

### 人效优化
1. 培训多面手：交叉培训，一人顶多岗，灵活排班
2. 数字化减负：点餐系统+后厨KDS，让员工专注高价值服务
3. 分时配置：高峰加人，低谷减人，按客流动态排班
4. **注意**：新员工培训前3周按50%产能计算

### 费效优化
1. 供应链精细化：减少食材损耗，按"期初+采购-期末"倒推实际消耗
2. 能耗管控：建立能耗监控系统，避免跑冒滴漏
3. 精准营销：分析ROI，把预算集中在能带来复购的渠道

### 坪效优化
1. 科学布局：规划动线，保证舒适度前提下增加有效座位
2. 空间多功能：午餐高峰扩座，非餐期转为外卖打包区或休闲区

### 桌效优化
1. 提升出餐效率：优化点餐和出餐流程，缩短用餐周期
2. 菜单策略：高峰期推制作快捷套餐，加速翻台
3. 数字化排队：线上取号+会员预约，平滑高峰，减少等位流失

## 使用方法：经营健康度诊断

**快速自检清单：**
- [ ] 毛利率是否达到品类对标水平？
- [ ] 日均翻台率是否低于行业均值？
- [ ] 月均人效是否低于5万元？（快餐）/ 4万元？（正餐）
- [ ] 费效是否高于3.0？
- [ ] 坪效是否高于同期同位置竞品？

**数据化管理系统价值**：
引入人效管理系统，可提升效率**22%-35%**（来源：重庆云析数智，2025）

---

## 重要注意事项

1. **四效是整体**：不能孤立看单项，必须综合评估
2. **不同品类不可直接横比**：快餐人效天花板高，日料翻台天然低
3. **防"表面盈利"陷阱**：四效高但现金流紧张，照样死门店
4. **每季度更新对标库**：餐饮数据变化快，静态对标标准会失效
