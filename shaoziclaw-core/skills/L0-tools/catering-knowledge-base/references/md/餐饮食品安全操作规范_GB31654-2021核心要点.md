# 餐饮食品安全操作规范：GB 31654-2021核心要点（2022年实施）

**来源**：中国标准化研究院/国家市场监管总局（2021-03-18发布，2022-02-22实施）
**采集时间**：2026-03-31
**质量评级**：★★★★★
**适用范围**：所有餐饮服务提供者（含外卖、堂食、外烩）

---

## 法律地位

> GB 31654-2021 是我国首部餐饮服务行业**规范类**食品安全国家标准。
> 所有餐饮经营者必须遵守，违规可面临行政处罚甚至刑事追责。

---

## 一、温度控制：最核心的食品安全指标

### 烹饪温度要求

| 食品类型 | 中心温度要求 | 说明 |
|---------|------------|------|
| 普通食品 | **≥ 70°C** | 充分杀灭致病菌 |
| 特殊工艺 | 低于70°C需**严格控制原料安全** | 如生食、醉制等 |

### 再加热要求

```
烹饪后易腐食品存放要求：
- 冷藏温度以上、60°C以下 → 存放时间 ≤ 2小时
- 超过2小时未变质 → 食用前再加热至 ≥70°C
- 超过2小时已变质 → 立即废弃
```

### 供餐存放（堂食+外卖通用）

| 存放条件 | 时间限制 | 处置方式 |
|---------|---------|---------|
| 60°C以上 | 无明确限制 | 保持热食状态 |
| 冷藏温度以上、60°C以下 | **≤ 2小时** | 再加热或废弃 |
| 冷藏（≤4°C） | ≤ 24小时 | 尽快使用 |

## 二、食材存储规范

### 核心原则

| 原则 | 操作要求 |
|------|---------|
| **隔墙离地** | 所有食品必须离地≥10cm，离墙≥5cm |
| **分隔存放** | 原料、半成品、成品分区存放 |
| **先进先出** | 按入库日期顺序使用 |
| **标识清晰** | 散装食品标注品名、生产日期、保质期 |

### 禁止行为

- ❌ 使用**亚硝酸盐**（国家禁止在餐饮业使用）
- ❌ 使用过期、变质、回收食品
- ❌ 重复使用一次性餐具
- ❌ 食品与非食品混放

### 冷冻/冷藏食品

| 要求 | 操作规范 |
|------|---------|
| 验收时 | 尽量缩短在常温下暴露的时间 |
| 解冻后 | 及时加工使用，禁止反复解冻 |
| 储存温度 | 冷藏≤4°C，冷冻≤-18°C |

---

## 三、加工操作标准

### 专间与专用操作区要求

| 场景 | 要求 |
|------|------|
| 直接入口易腐食品加工 | 必须在**专间**或**专用操作区**进行 |
| 操作前 | 台面、空气消毒 |
| 操作人员 | 专用工作服+口罩+洗手消毒 |

### 清洁消毒规范

| 项目 | 标准 |
|------|------|
| 餐用具消毒 | 符合GB 14934标准 |
| 清洁剂 | 食品级，不得混用 |
| 抹布 | 分类使用（厨房/餐桌/卫生间分开） |

---

## 四、人员健康管理

### 上岗要求

| 要求 | 说明 |
|------|------|
| 健康证明 | 接触直接入口食品人员**必须持证** |
| 健康检查 | 每年一次体检 |
| 健康异常 | 立即调离直接接触食品的岗位 |

### 操作卫生

| 时机 | 操作要求 |
|------|---------|
| 操作前 | 洗手消毒 |
| 手部污染后 | 立即洗手消毒 |
| 专间操作 | 全程佩戴口罩 |

---

## 五、外卖配送安全规范

| 环节 | 核心要求 |
|------|---------|
| 保温 | 热食温度≥60°C，冷食温度≤4°C |
| 封签 | 使用食安封签，防止中途打开 |
| 时效 | 全程控制在2小时内送达 |
| 包装 | 食品与外卖员物理隔离 |
| 配送箱 | 每日清洁消毒 |

---

## 六、证照管理清单

| 证照 | 有效期 | 公示要求 |
|------|-------|---------|
| **食品经营许可证** | 5年（到期提前30天续期） | 公示上墙，亮证经营 |
| **健康证** | 每年一换 | 员工公示栏 |
| **营业执照** | 长期有效 | 公示上墙 |

---

## 七、常见违规与处罚

| 违规行为 | 处罚标准 |
|---------|---------|
| 无证经营 | 没收违法所得+5万-10万罚款 |
| 使用过期食材 | 没收+罚款，情节严重吊销许可证 |
| 食品中心温度不达标 | 责令改正+警告，拒不改正罚款 |
| 无健康证上岗 | 每人次500-5000元罚款 |
| 操作间不符合规范 | 责令停产停业+罚款 |

---

## 八、餐饮老板"食安保命三招"

| 招数 | 操作 | 目的 |
|------|------|------|
| **第一招：温度红线** | 每道菜出餐前测温，≥70°C记录 | 从源头杜绝生熟不分 |
| **第二招：日期标记** | 所有食品标注日期，按日期使用 | 杜绝过期食品 |
| **第三招：晨检制度** | 每天开店前检查员工健康状况 | 杜绝带病上岗 |
