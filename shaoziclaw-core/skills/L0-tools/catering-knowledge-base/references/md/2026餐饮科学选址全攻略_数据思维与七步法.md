## 三大必须避开的选址陷阱

### 陷阱1：盲目追求高人流
- **误区**：旅游区、步行街人流量大就选
- **真相**：旅游客流多为一次性消费，回头率极低
- **正确做法**：评估"有效客流"（目标客群占比×回头频次）

### 陷阱2：忽视商圈生态位
- **误区**：只看单一位置的条件
- **真相**：周边业态互补才能产生协同效应
- **金角**：商圈主入口、交叉路口→适合品牌旗舰店
- **银边**：主街边缘→适合中高频消费
- **草肚皮**：商圈内部→适合高频社区型（早餐/便当）

### 陷阱3：凭经验直觉决策
- **误区**："感觉这里人气不错"
- **真相**：感觉≠数据，65%的失败源于直觉决策
- **正确做法**：建立数据模型，至少实地蹲点3天测量

## 四大黄金选址模型

### 模型1：社区深耕型
**适合业态**：早餐、便当、高频简餐
| 指标 | 标准 |
|------|------|
| 小区户数 | 800-1500户 |
| 入住年限 | 5-15年（稳定社区） |
| 出入口结构 | 单一出入口（客流集中） |
| 优先避开 | 新建小区（入住率不稳定） |

### 模型2：写字楼配套型
**适合业态**：快餐、午餐、下午茶
| 指标 | 标准 |
|------|------|
| 写字楼入驻率 | >80% |
| 企业数量 | >50家 |
| 距写字楼距离 | <300米（步行5分钟内）|
| 优先选 | 周边无强竞品的空白区 |

### 模型3：商业体寄生型
**适合业态**：正餐、小吃、茶饮
- **B1层**（地下一层）：随机消费型，适合小吃/饮品
- **餐饮层近电梯口**：必经之路，流量自然分配
- **L1层临街面**：外卖流量+路过流量双叠加

### 模型4：交通枢纽延伸型
**适合业态**：司机快餐、旅客餐
- 目标区域：机场/高铁站周边1公里内
- 重点区域：员工区（稳定客流）、停车区（停留等待）、酒店区

## 科学选址七步法

### Step 1：线上数据扫描（3天内完成）
```
工具：人口热力图 + 外卖平台数据 + 高德地图POI
分析：
- 目标商圈半径500米内人口密度
- 外卖点单热力图（哪个时段哪个位置订单最多）
- 竞品数量和评分分布
```

### Step 2：实地蹲点观察（工作日+周末各1天）
```
记录内容：
- 早/中/晚不同时段（06:00/12:00/18:00/21:00）人流量
- 进店率：路过的人中有多少进店（>10%为合格）
- 顾客特征：年龄、性别、是否带孩子、消费能力判断
- 停留时长：路过客流>5分钟停留的比例
```

### Step 3：竞争环境分析
```
制作"竞争地图"：
- 500米内所有同品类竞品
- 各家月销量估算
- 市场空白识别（哪个品类缺失？哪个时段没人做？）
```

### Step 4：成本收益测算（硬红线）
```
租金占比：≤15%营业额（红线：>20%必死）
人工占比：≤20%营业额
投资回收期：18-24个月
日均保本线 = 月固定成本 ÷ 30天
```

### Step 5：合同风险排查
```
必查项目：
□ 房产证明（确认房东有权出租）
□ 证照办理条件（营业执照/食品经营许可/消防）
□ 续租条款（有没有优先续租权）
□ 租金年增幅（谈判目标：≤5%）
□ 转让条款（能否把店转让给下家）
```

### Step 6：应急预案准备
```
设定止损点：
- 开业3个月日均营业额低于保本线60%→触发应急方案
- 应急方案内容：降价引流/增加品类/调整营业时间
- 极限止损：开业6个月无法盈利→评估是否关店
```

### Step 7：谈判争取最优条款
```
目标条款：
- 免租期：3-6个月装修免租（正常可谈到）
- 租金年增幅上限：≤5%（写进合同）
- 优先续租权（确保做好了不被赶走）
- 首月固定+后续浮动（销售额提成，降低初期风险）
```
