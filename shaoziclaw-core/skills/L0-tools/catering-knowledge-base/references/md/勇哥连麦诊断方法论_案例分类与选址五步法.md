## 勇哥连麦诊断的本质

**不是教你怎么赚钱，是教你怎么不亏死。**

核心逻辑链：**能活 → 能赚**
先判断能不能活，再谈能不能赚。

---

## 连麦诊断五项必问信息

| 问题 | 目的 |
|------|------|
| 日营业额、月营业额 | 确认收入规模 |
| 房租/人工/水电杂费 | 计算固定成本 |
| 总投资额及是否有负债 | 判断抗风险能力 |
| 是加盟还是自营，有无餐饮经验 | 判断项目匹配度 |
| 周边同业态店铺的日营业额 | 判断商圈天花板 |

**核心公式**：
```
保本线 = 月固定成本 ÷ 30天
日营业额 ≥ 保本线 → 至少能活
日营业额 ≥ 保本线 × 1.5 → 有赚钱空间
```

## 三类连麦案例分类

| 类型 | 特征 | 勇哥建议 | 典型案例 |
|------|------|---------|---------|
| **直接劝退型** | 成本高、负债重、客流少 | 立即止损，越早关越少亏 | 长治七层奶茶大厦 |
| **整改尝试型** | 成本可控、位置尚可但转化低 | 短期引流活动测试，1个月无改善→关 | 山东果汁店 |
| **可行优化型** | 成本达标、客流充足但差异化不足 | 精细化运营提升盈利 | 江苏李姐面馆（免费续面+社群） |

## 勇哥选址五步法

### 第1步：选品匹配
- 产品是否适合目标商圈客群？
- 社区：适合快餐、家常菜、早餐
- 商圈/购物中心：适合茶饮、快时尚餐
- 写字楼：适合商务快餐、轻食

### 第2步：投资预算控制
- 总投资是否在可控范围？
- **硬规则**：不要借钱创业，更不要负债加杠杆
- **安全线**：投资额=能承受全部亏损的金额

### 第3步：商圈实地评估
- **必做动作**：360°实景拍摄
- **必问信息**：周边店铺日营业额（验证商圈天花板）
- **判断维度**：客流质量、竞争密度、周边业态互补性

### 第4步：成本盈利预测
- 严格计算保本日营业额
- 判断：在该商圈，自己的品类能否稳定达到保本线？

### 第5步：风险预案
- **止损点**：明确亏损几个月关门（建议最多亏3个月）
- **最低流水**：设定连续7天低于X元，立即检讨
- **保留退路**：不要把所有资金一次性全部投入

## 勇哥核心金句（高频传播观点）

1. **"穷人的钱，好骗，但不好赚。"**
   - 解释：快招骗局让穷人掏30万，但服务好穷人让他们持续消费极难

2. **"餐饮不是梦想，是生意。"**
   - 解释：带着情怀开店是死路，用数据跑通逻辑才能活

3. **"你连自己每天保本需要多少钱都不知道，你凭什么说你能赚钱？"**
   - 解释：经营数字盲=创业盲，必须建立财务意识

4. **"商圈天花板决定你的上限，成本结构决定你的下限。"**
   - 解释：选址前先调研周边最好的同类店能做多少，这就是你的最好结果

## 勇哥方法论的本质结构

```
判断能否开店：
1. 商圈天花板 > 我的保本线 × 1.5 → 可以尝试
2. 商圈天花板 ≤ 我的保本线 → 死路一条，不要开

判断已开店是否该关：
1. 连续3个月低于保本线 → 趋势确认，止损关店
2. 有明确可改善问题（位置/菜单/价格）→ 给1个月整改机会
3. 成本结构根本不对（租金>20%营业额）→ 根本性问题，难救
```
