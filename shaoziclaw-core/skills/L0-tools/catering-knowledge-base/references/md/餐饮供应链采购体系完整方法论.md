## 一、供应商管理

### 供应商分类（四象限）

| 类型 | 定义 | 举例 | 策略 |
|------|------|------|------|
| **战略型** | 核心食材、独家 | 特定品牌牛肉、海鲜、独家酱料 | 长期伙伴关系，深度合作开发 |
| **杠杆型** | 标准化、可替代 | 大米、面粉、食用油 | 集中采购，招标竞价 |
| **瓶颈型** | 小众、有独特风味 | 特定产地香料 | 保证供应安全，建立备选 |
| **常规型** | 非核心产品 | 办公用品、清洁用品 | 简化流程，追求效率 |

### 供应商选择流程

**第一步：寻源**
- 行业展会
- B2B平台（阿里巴巴等）
- 同行推荐
- 产地直采

**第二步：资质审核**
- 基础：营业执照、食品经营许可证、产品检测报告
- 实力：生产/仓储能力、财务状况、技术水平
- 现场：生产环境、质量管理体系、卫生标准

**第三步：加权打分评估**
- 权重分配：价格(25%)、质量(30%)、交付准时率(20%)、服务(15%)、技术能力(10%)

## 二、采购策略

### 集中采购 vs 分散采购

| 模式 | 适用场景 | 优势 | 劣势 |
|------|---------|------|------|
| **集中采购** | 连锁餐饮企业 | 规模议价、品质一致 | 灵活性差 |
| **分散采购** | 单店/小规模 | 灵活、响应快 | 议价能力弱 |
| **混合策略** | 大多数连锁企业 | 兼顾规模与灵活 | 管理复杂 |

**混合策略实操**：
- 核心食材（肉类、调味料）→ 集中采购
- 区域时蔬、鲜活水产 → 分散/本地直采
- 应急物资 → 就近采购

### 五种采购模式

1. **招标采购**：适用于大宗标准商品（粮油）
2. **询价采购**：向选定供应商发出询价单对比
3. **战略合作/长期协议**：锁定价格和供应量
4. **产地直采**：蔬菜、水果、鲜活水产，减少中间环节
5. **期货采购**：价格波动大商品（进口牛肉），低点远期采购

## 三、议价技巧

### 议价前准备

- **成本分析**：了解原材料成本、生产成本、物流成本 → 估算合理利润空间
- **市场调研**：清楚市场价格、替代品、供需关系
- **设定目标**：理想价格 / 目标价格 / 底线价格
- **备选方案**：永远要有B供应商，增加议价筹码

### 核心议价技巧

1. **规模优势**：强调长期大批量合作潜力
2. **打包采购**：多商品打包给一个供应商 → 整体折扣
3. **关注总成本**：不仅谈单价，还谈账期、物流费、售后
4. **非价格优惠**：
   - 更长账期
   - 免费仓储服务
   - 更快送货响应
5. **双赢思维**：压榨供应商 = 质量风险，保持良好关系

## 四、成本控制方法

### 三道防线

```
防线1：源头控制（标准化+菜单工程联动）
防线2：过程控制（采购流程+验收+库存）
防线3：数据分析（趋势分析+损耗分析）
```

### 源头控制

**食材规格书**：
- 每种食材制定严格的规格标准
- 避免"差不多就行"导致的浪费
- 明确品级、重量、鲜度要求

**菜单工程联动**：
- 采购与菜单设计紧密结合
- 优先采购成本效益高、出成率高的食材
- 定期（每月/每季度）淘汰低效菜品

### 过程控制

**采购流程六步**：
```
请购 → 审批 → 下单 → 验收 → 入库 → 付款
```

**验收三核查**：
- 数量核查（与订单对比）
- 质量核查（按规格书）
- 重量核查（实际重量 vs 标注重量）

### 损耗控制

| 环节 | 损耗来源 | 控制方法 |
|------|---------|---------|
| 采购 | 规格不清、验收不严 | 规格书+双人验收 |
| 储存 | 过期、变质、损耗 | 先进先出+温控 |
| 加工 | 切配浪费、出成率低 | 标准化切配SOP |
| 出品 | 厨房浪费、顾客浪费 | 合理份量设计 |

**行业数据**：许多餐厅因库存浪费损失高达**10%的收入**
