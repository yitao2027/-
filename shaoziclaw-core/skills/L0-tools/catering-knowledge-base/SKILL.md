# 餐饮知识库查询 SKILL

## Skill 元信息

**名称**：catering-knowledge-base
**分类**：L0 通用工具
**级别**：初级 · 通用
**版本**：1.0
**触发词**：「查一下」「有没有」「知识库」「方法论」「参考案例」「行业规范」「标准是什么」

---

## 触发场景

当用户需要查询餐饮行业专业知识、方法论、操作规范、行业数据、案例参考时，启用此 Skill。

---

## 输入

- 查询问题：具体的问题或主题
- 知识类型（可选）：方法论 / 操作规范 / 行业数据 / 案例 / 法律法规 / 工具模板
- 适用规模（可选）：小微企业（1-3店）/ 中型（4-20店）/ 大型（20店以上）
- 紧迫程度（可选）：即时参考 / 深入研究

---

## 工作流程

### Step 1：理解查询意图

```
【查询类型判断】
□ 方法论查询 → 寻找系统性方法
□ 规范查询 → 寻找标准操作或法规
□ 数据查询 → 寻找行业数字或报告
□ 案例查询 → 寻找实战案例参考
□ 工具查询 → 寻找模板或计算器
□ 综合查询 → 多种类型组合
```

### Step 2：知识库检索

检索以下知识来源：

**知识库层级（按优先级）**

| 层级 | 来源 | 内容类型 |
|------|------|----------|
| L0 | 内部知识库（shaozi-claw） | 已结构化的方法论与工具 |
| L1 | 行业研究报告（红餐/窄门/NCBD） | 市场数据与品类报告 |
| L2 | 专业书籍（选址/品牌/运营/财务） | 经典方法论 |
| L3 | 行业专家课程（B站/公众号） | 实战经验与案例 |
| L4 | 法律法规（食安/劳动/广告法） | 合规依据 |

**检索策略**
- 精确检索：直接关键词匹配
- 模糊检索：相关领域扩展
- 交叉检索：多维度综合分析

### Step 3：答案组织

根据查询类型，组织答案格式：

**方法论类**
```
【问题】[用户问题]
【方法论名称】[名称]
【适用场景】[何时使用]
【核心步骤】
1. [步骤一]
2. [步骤二]
3. [步骤三]
【关键公式/工具】[如有]
【参考标准】[行业基准数据]
【注意事项】[易错点/风险点]
```

**数据类**
```
【问题】[用户问题]
【数据来源】[来源+时间]
【核心数据】
- [数据点1]：[数字]
- [数据点2]：[数字]
【数据解读】
[数据含义分析]
【应用建议】
[如何使用这些数据]
```

**规范类**
```
【问题】[用户问题]
【法规/规范名称】[名称+文号]
【核心要求】
[列出关键条款]
【适用范围】
[适用对象]
【违规后果】
[法律责任]
【操作建议】
[如何合规]
```

**案例类**
```
【问题】[用户问题]
【案例背景】[行业/品类/规模/时间]
【核心做法】[具体方法]
【效果数据】[量化结果]
【可借鉴点】[提炼要点]
【注意事项】[复制时的注意点]
```

### Step 4：知识补充

如果知识库中找不到精确答案，主动补充：

1. **邻近知识**：提供相关领域的参考信息
2. **方法推断**：基于行业逻辑推导合理建议
3. **来源说明**：明确告知知识来源和置信度

## 核心方法论

### 知识质量分级

| 级别 | 来源 | 置信度 | 适用场景 |
|------|------|--------|----------|
| ★★★★★ | 权威机构报告+多源印证 | 极高 | 决策依据 |
| ★★★★☆ | 专业书籍+行业验证 | 高 | 方案参考 |
| ★★★☆☆ | 行业经验+逻辑推导 | 中 | 方向参考 |
| ★★☆☆☆ | 单来源+推断 | 低 | 启发思考 |

### 知识转化流程

```
原始知识 → 提炼核心观点 → 适配不同规模 → 输出可操作建议 → 关联相关知识
```

### 常见问题快速索引

| 问题类型 | 推荐知识领域 |
|----------|--------------|
| 选址相关 | 选址学/商圈分析/千分选址法 |
| 品牌相关 | 定位理论/视觉锤/超级符号 |
| 运营相关 | QSCV体系/MOT关键时刻 |
| 财务相关 | 成本结构/盈亏平衡/财务报表 |
| 营销相关 | 定价策略/促销方法/私域运营 |
| 法律相关 | 食品安全法/劳动法/广告法 |
| 人力相关 | 薪酬激励/培训体系/文化打造 |

## 质量标准

| 维度 | 标准 |
|------|------|
| 答案相关性 | 直接回答问题，不跑题 |
| 内容准确性 | 核心数据有来源标注 |

| 时效性 | 区分时效性和长期有效内容 |

## 注意事项

1. **区分时效**：标注数据的时间范围，"2024年数据"不等于"2026年仍然准确"
2. **规模适配**：餐饮知识往往与规模强相关，给建议时注明适用规模
3. **法律边界**：涉及法律合规的内容，建议用户咨询专业律师
4. **知识局限**：承认知识库的边界，不懂的不瞎编
5. **持续更新**：发现知识错误时主动更新
