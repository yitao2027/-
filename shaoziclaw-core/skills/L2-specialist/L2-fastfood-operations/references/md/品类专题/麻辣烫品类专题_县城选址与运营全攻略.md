## 二、选址避坑（5大经典错误）

### ❌ 错误1：盲目追"黄金地段"
- **坑点**：县城最繁华路口租金极高，但人流以购物为主，不是目标就餐客群
- **结果**：看的多，吃的少，营业额覆盖不了高租金

### ❌ 错误2：只看人流量，不分析人群体质
- **坑点**：学校门口=学生多=消费力有限；医院门口=匆忙无心就餐
- **正确做法**：区分"人流"和"客流"，要看有效客流

### ❌ 错误3：只看"有没有麻辣烫竞争"判断市场
- **坑点**：没麻辣烫≠能开麻辣烫，可能整个区域餐饮消费力就弱
- **正确做法**：观察米线、面条、小吃店的生意作为隐性竞争参照

### ❌ 错误4：忽略停车和可达性
- **坑点**：县城居民以电动车/私家车为主，停车难=劝退顾客
- **连锁影响**：外卖骑手取餐也不方便，影响外卖占比

### ❌ 错误5：被低租金诱惑进死角位
- **坑点**："酒香也怕巷子深"，品牌初创期自然曝光是关键
- **结果**：引流成本远高于省下的租金

## 三、选址成功公式（县城版）

```
成功选址 = 稳定目标客群（居民/学生/上班族）
          × 有效人流密度
          × 良好可见性
          × 合理租金（≤月营收10%）
```

### 优先位置排序
1. **A级**：成熟居民区出入口、菜市场附近 → 复购率最高
2. **B级**：大学/高职周边、办公园区附近 → 午餐+晚餐双高峰
3. **C级**：新兴社区底商（有时间成本风险）

### 实地调研方法
- 不同时段蹲守（工作日午晚高峰 + 周末）
- 观察"提袋率"（进店人数/路过人数）
- 数竞对店铺进店人次，对比估算

## 四、县城麻辣烫两极分化真相

### ✅ 成功模型（辽宁绥中县案例）
| 要素 | 数据 |
|------|------|
| 月租金 | 7500元（县城核心位置） |
| 人员 | 2.5人（含老板） |
| 营收结构 | 麻辣烫83% + 饮品17% |

| 关键 | 总部全程带教 + 鲜熬汤底 + 产品口碑 |

### ❌ 失败模型（县城通病）
| 问题 | 说明 |
|------|------|
| 消费低 | 县城客单价上不去（通常8-15元） |
| 毛利低 | 竞争激烈价格战 + 食材成本管控难 |
| 食材受控 | 供应链不稳定，鲜度难保障 |
| 同质化 | 一条街开七八家，张亮/杨国福/砂锅麻辣烫混战 |

## 五、快招识别（麻辣烫专项）

### 红旗信号
- ⚠️ 加盟费异常低（<5000元）但后续物料费极高
- ⚠️ 不提供实地选址支持
- ⚠️ "区域代理权"作为签约诱惑
- ⚠️ 样板间考察 vs 真实门店考察（只让你看样板间）

### 合规品牌核查清单
- [ ] 在张亮/杨国福官网查资质
- [ ] 要求看3家以上真实加盟商门店
- [ ] 核查加盟合同中的退出条款
- [ ] 对比当地已有门店的真实营收数据

## 六、咨询话术（麻辣烫专项）

### 场景1：客户说"我想在县城开一家麻辣烫"
**勇哥式提问：**
> "你这个县城麻辣烫店，打算开在哪里？学校门口还是居民区？那个位置现在有没有麻辣烫？有没有其他快餐品类？"

### 场景2：客户说"麻辣烫好像投资不大"
**回应：**
> "麻辣烫看起来门槛低，但县城客单价上不去，你的日均要卖到1500才能打平，这需要先蹲点看看人流够不够。"

### 场景3：客户说"我考察了，没看到麻辣烫店"
**回应：**
> "没麻辣烫≠能开麻辣烫。可能这个区域整体餐饮消费力就弱。你要看这条街上米线店、面条店生意怎么样。"
