# 案例05：45万"第四代汉堡"快招加盟诈骗·完整还原

**来源：** 勇哥餐饮说·第197集 / BV1rxadzRELF（2025年9月）  
**咨询者画像：** 37岁男性，河南上秋市区，曾在北京打工做小生意，存款基本投入  
**投资额：** 45万（加盟费15.8万 + 设备等约20万 + 房租9万）  
**状态：** 开业13天，外卖+堂食日均约300元，每天亏损约559元

---

## 一、完整事件还原

### 决策链条（全错）

```
想加盟塔斯汀 → 未找到官网/官方电话 → 搜索被截胡 → 接到快招公司来电
→ "我们是塔斯汀高管出来做的第4代汉堡" → 第一次让交定金，没交
→ 第二次被说服，交了 → 带去郑州总部考察 → 现场签约
→ 交了15.8万江湖费 + 5万带店费 + 7万物料设备 ≈ 27.8万给总部
→ 装修9万 → 选址由"选址老师"负责 → 选在塔斯汀/华莱士旁边
→ 开业11天，日均300元，已亏损
```

### 关键数据

| 项目 | 数字 |
|------|------|
| 日营业额 | 300元（含外卖200+堂食100） |
| 日亏损 | 559元（人工333+水电100+平台抽成126） |
| 外卖占比 | 约50%，毛利率仅35% |
| 平台抽成 | 约15% |
| 华莱士日单 | 约100单（3个平台），塔斯汀在对面 |
| 位置类型 | 阴街商场背面，对面商场有完整餐饮城 |

### 合同与资质问题

- **无特许经营资质**（商务部门可查）
- 合同中各项扶持标准模糊，无法追责
- 签约时制造"今天不签别人就签了"的紧迫感
- 选址老师故意选在竞品旁边（华莱士/塔斯汀），创业者以为是"跟随策略"，实则快招公司利用其不懂选址逻辑

## 二、勇哥核心点评（全记录）

### 灵魂拷问

> **"你45万为什么不直接去塔斯汀旁边开个塔斯汀？"**

> **"你为什么不把钱拿去街上撒了？那还至少撒得爽一点。"**

> **"你知道吗，我每天在直播间卖课199，讲的口干舌燥，你们就是不买课。转手过来15.8万，说给就给。"**

### 选址逻辑的荒谬

- 选址老师给选了4个位置，全部紧邻华莱士/塔斯汀
- 快招公司明知旁边有强势竞品，却故意选此处
- 创业者以为"跟在旁边能蹭流量"，实则对方70-80%靠外卖，堂食根本没机会

### 餐饮品类的残酷真相

> **"我再说一遍，中产破产四件套：奶茶、汉堡、咖啡、烘焙。为什么不能做？因为头部品牌太明显。"**

> **"你根本连谈毛利的资格都没有——因为根本没人点你。"**

> **"人家不认你这个品牌，懂吗？"**

## 四、维权路径

1. **第一优先：谈判协商**
   - 要求退还所有费用（加盟费+带店费+物料费）
   - 附上合同问题清单：虚假宣传+无资质+选址欺诈

2. **第二优先：投诉举报**
   - 商务部门：举报无特许经营资质违法经营
   - 市场监管部门：虚假宣传
   - 发送律师函施压

3. **第三：起诉（万不得已）**
   - 周期长、成本高、心力消耗大
   - 但快招公司往往在多地都有诉讼，容易被盯上

4. **特别注意**
   - 不要被总部威胁吓住（他们比你更怕曝光）
   - 不要在群里跟其他加盟商"诉苦求安慰"，赶紧行动
   - 找专门打这类官司的律师，不是普通法律咨询

---

## 五、核心教训

> **1. 加盟前必须做：核实品牌资质 + 随机走访3-5家已加盟门店**  
> **2. 选址必须自己做：别把命交给"选址老师"**  
> **3. 奶茶/汉堡/咖啡/烘焙：县城中产破产四件套，头部品牌效应太强**  
> **4. 45万可以：买套房/买辆车/环游中国/存起来——不要扔进一个根本不懂的生意里**  
> **5. 最关键的止损点：交定金之前、去总部考察之前、签合同之前——每个节点都可以退出**
