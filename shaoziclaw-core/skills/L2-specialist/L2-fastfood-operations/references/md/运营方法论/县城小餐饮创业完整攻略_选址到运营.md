### 选址公式

```
日均潜在客群 = 覆盖住户数 × 每户人口(2.5) × 入住率 × 消费转化率(3%)
```

**案例**：
- 县城中学周边800米覆盖4个社区（约2000户）
- 潜在客群：2000 × 2.5 × 80% × 3% = **120人/天**

### 租金红线

```
月租金 ≤ 月固定成本 × 20%
月租金 ≤ 3000元（县城参考值）
```

## 运营策略

### 熟人经济打法

**县城特有的优势**：
- 人口固定，流动性低
- 口碑传播快
- 回头客比例高

**核心策略**：
1. **记住常客的名字和口味**（最强黏性）
2. **建立微信社群**（100人小群比500人大群更活跃）
3. **会员生日赠菜**（某面馆因此月储值增长47%）
4. **老人/学生折扣**（定向优惠，培养习惯）

### 损耗控制

**中央厨房+现场加工模式**：
```
预制酱料统一配送 → 现场完成配菜组合
食材损耗率：12% → 5%
每月节省：超1500元
```
