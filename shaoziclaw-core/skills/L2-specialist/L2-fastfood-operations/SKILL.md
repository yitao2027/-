# 快餐简餐门店核心运营体系

**层级：** L2 专项能力  
**部门归属：** 品类专项 - 快餐简餐  
**触发词：** 快餐运营、简餐经营、快餐成本、出餐速度、快餐效率、工作餐、便民餐

---

## 一、Skill 定位

**解决什么问题：**  
专门帮助快餐/简餐品类经营者解决核心运营挑战，包括出餐速度、午市高峰运营、成本控制和外卖堂食双线协调。

**快餐品类核心特征：**
- 顾客停留时间短（15-30分钟）
- 出餐速度是核心体验（顾客最在乎）
- 翻台率高（午市可达4-6次）
- 价格敏感度高（客单15-35元为主流）
- 外卖占比可达50%以上
- 复购频率极高（工作日每周3-5次）

## 二、核心方法论

### 2.1 快餐成本结构管理

```
快餐典型成本结构（客单20-35元）：

食材成本：28-35%（行业均值约30%）
├── 主食材（肉/蛋/豆腐类）：15-20%
├── 蔬菜配菜：6-10%
└── 米/面/主食：4-6%

人力成本：20-28%
房租：10-18%
其他（水电/包装/损耗）：5-8%
综合成本率：65-85%
净利润：15-35%

快餐成本控制三大抓手：
① 米饭/主食标准化（避免多加浪费）
② 荤菜份量标准化（用固定克重工具）
③ 高峰期备菜预判（减少临时加工）
```

### 2.2 快餐出餐效率工程

```
快餐出餐目标：
- 堂食点餐→收到餐：≤5分钟（快餐标准）
- 外卖接单→骑手取餐：≤12分钟

出餐效率四要素：

① 菜品标准化预制（最关键）
→ 根据历史销量数据，提前备制高频菜（午市前备好70%的菜量）
→ 肉类提前腌制/切割备好
→ 汤类/底汤提前熬好
→ 预估备菜量 = 过去3天同时段均值 × 1.2（20%安全余量）

② 后厨动线设计
→ 「接单→拿餐盘→打菜→主食→结束」一条龙动线
→ 高频菜置于前端（随手可取）
→ 备餐台高度舒适（减少弯腰/踮脚）

③ 人岗分工清晰
→ 高峰期：收银1人/打菜2-3人/主食1人/收台1人
→ 避免同一人既打菜又收银（高峰期会拖慢所有环节）

④ 菜单精简
→ 日销菜品控制在15-25道（减少顾客选择时间）
→ 设置"今日推荐"减少决策成本
→ 快速"配套套餐"（主食+1菜+汤，3秒决策）
```

### 2.3 午市高峰运营管理

```
午市是快餐的黄金时段（11:30-13:30占全天营业额40-60%）

午市高峰"三提前"原则：
提前1：备菜（10:30前备好80%菜量）
提前2：检查（11:15完成设备/清洁/摆台检查）
提前3：满员（11:20前所有班次员工到岗）

高峰期应急预案：
情况1：某菜品卖完
→ 应对：板书"已售完"立即更新，推荐替代菜品

情况2：后厨出菜跟不上
→ 应对：收银暂停接收新订单（约3-5分钟），先出已有订单
→ 不要让客人等超过10分钟

情况3：停电/设备故障
→ 应对：立即通知收银停止点餐，有条件用备用电
→ 已付款顾客退款或等待，安抚话术准备好

午市高峰顾客分流策略：
□ 提前点单：支持APP/微信提前15分钟下单
□ 外卖分流：主动告知外卖稍慢但有优惠，引导外卖客错峰
□ 自助取餐：设置自助区（纸巾/餐具/调料），减少服务员往返
```

### 2.4 快餐外卖专项策略

```
快餐外卖运营四个关键：

① 外卖菜单精选（不是全部堂食菜都适合外卖）
→ 不适合外卖的菜：汤汁多容易洒/变形影响口感的/装盘复杂的
→ 外卖专属套餐：主食+2-3款配菜+饮品（标准套餐化，提效）

② 外卖包装配置
→ 防溢盖+外袋整洁
→ 酱汁/调料独立小包（不提前淋在菜上）
→ 热菜与冷食/水果分开打包

③ 高峰期外卖策略
→ 午市高峰前30分钟关闭外卖（或减少接单）
→ 理由：同时应对堂食+外卖=都体验差
→ 下午1:30后再开外卖：堂食客散了，专注外卖

④ 外卖评分维护
→ 外卖客单较低但量大，差评影响排名
→ 每日查看外卖差评，24小时内回复
→ 每月分析外卖TOP5差评原因，专项改进
```

### 2.5 快餐菜单健康迭代

```
快餐菜单迭代频率建议：
- 日常核心菜品：保持稳定（不要频繁变动，顾客需要依赖感）
- 季节特色菜：每季度更换1-2款
- 节日/营销限定：节假日前1周上线，节后下线

菜品健康度评估（每月1次）：
→ 用ABC分类法评估当月所有菜品：
  A类（高频高销）：保留并重点推广
  B类（中频中销）：维持/优化
  C类（低频低销）：下架或改版
→ 下架标准：连续2个月点单率<3%，且无改进空间

快餐新品上市最快路径：
1. 选材：使用已有供应链中的食材（无需新开供应商）
2. 工艺：沿用现有烹饪设备（不增加新设备）
3. 测试：内部试吃后直接上线（不需要长时间测试）
4. 上市：堂食+外卖同步推出，前2周"新品推荐"标注
```
