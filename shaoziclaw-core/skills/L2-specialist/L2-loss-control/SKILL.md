## 工作流程

### Step 1：损耗现状诊断

```
【损耗结构分解】

月食材损耗 = 采购损耗 + 储存损耗 + 加工损耗 + 销售损耗 + 盘点损耗

【各类型损耗诊断】
□ 采购损耗：验货不严，收到了不合格食材
□ 储存损耗：温度不当/储存过久导致变质
□ 加工损耗：切配浪费/出成率低
□ 销售损耗：备货过多/点单后顾客取消
□ 盘点损耗：账实不符，丢失或记录错误

【损耗率行业参考值】
| 损耗类型 | 健康值 | 警戒值 | 危险值 |
|----------|--------|--------|--------|
| 叶菜类 | 5-8% | 8-12% | >12% |
| 根茎类 | 3-5% | 5-8% | >8% |
| 禽肉类 | 3-6% | 6-10% | >10% |
| 猪肉类 | 2-5% | 5-8% | >8% |
| 牛羊肉类 | 5-10% | 10-15% | >15% |
| 水产类 | 5-12% | 12-18% | >18% |
| 豆制品 | 3-5% | 5-8% | >8% |
| 调味品 | 0.5-1% | 1-2% | >2% |
```

### Step 2：出成率管理

```
【出成率定义】
出成率 = 净料量 ÷ 原始物料量 × 100%

【各品类标准出成率】
| 品类 | 品名 | 原始规格 | 净料量 | 出成率 |
|------|------|----------|--------|--------|
| 叶菜 | 油菜 | 500g | 350g | 70% |
| 根茎 | 土豆 | 500g | 400g | 80% |
| 猪肉 | 五花肉 | 500g | 400g | 80% |
| 猪肉 | 里脊 | 500g | 420g | 84% |
| 牛肉 | 腱子肉 | 500g | 320g | 64% |
| 鸡腿 | 鸡腿 | 500g | 380g | 76% |

【出成率监控机制】
□ 每天记录主要食材的出成率
□ 与标准出成率对比，超过±5%预警
□ 定期抽检（每周一次）
□ 损耗超过标准，分析原因（人员/储存/设备）
```

### Step 3：效期管理（先进先出FIFO）

```
【FIFO执行标准】
原则：先入库的先出库，不混放，不遮挡

【色标管理法】
□ 绿色标签：当日使用（保质期≤1天）
□ 黄色标签：2天内使用（保质期2-3天）
□ 蓝色标签：本周使用（保质期4-7天）
□ 白色标签：常规批次（保质期>7天）

【每日效期检查（闭店前）】
□ 冷藏柜/冷冻柜检查
□ 效期临界食材提前处理
□ 记录当天报废食材及原因
□ 次日优先使用昨日余货

【效期临界处理流程】
临期食材（距保质期≤2天）：
→ 优先推销（员工餐/特价菜/套餐组合）
→ 超过1天未用 → 报损处理
```

### Step 4：损耗控制三道防线

```
【第一道防线：事前预防】

□ 精准订货（按销售数据预测，避免过量）
  - 日均销售量×1.2倍备货（节假日1.5倍）
  - 滞销品减量，畅销品加量
  
□ 验收标准化（不合格食材不入库）
  - 感官检查：色泽/气味/状态
  - 规格检查：与订单一致
  - 票据核对：随货单据齐全

□ 储存标准化（减少储存损耗）
  - 温度达标才收货
  - 分类储存：生熟/荤素/干货分区
  - 密封保存：防虫防潮

【第二道防线：事中控制】

□ 切配标准化（减少加工损耗）
  - 培训标准切配方法
  - 边角料利用率目标（如≥30%）
  - 建立边角料再利用菜
  
□ 出餐管理（减少报损）
  - 点单后再准备（可预估的除外）
  - 顾客取消及时处理
  - 外卖特殊要求备注清楚

【第三道防线：事后复盘】

□ 每日盘点：当天采购 vs 当天销售 vs 当天损耗
□ 损耗分析：找出Top3损耗来源
□ 周度复盘：分析损耗异常原因
□ 月度考核：与员工绩效挂钩
```

### Step 5：损耗考核设计

```
【损耗考核表（月度）】

| 岗位 | 考核指标 | 权重 | 达标值 | 超标处理 |
|------|----------|------|--------|----------|
| 厨师长 | 综合损耗率 | 40% | ≤品类均值 | 扣绩效 |
| 仓管 | 库存准确率 | 30% | ≥98% | 扣绩效 |
| 前厅负责人 | 退菜率 | 30% | ≤3% | 扣绩效 |

【奖惩标准示例】
□ 月损耗率≤健康值：奖励损耗价值的10%
□ 月损耗率=警戒值：不奖不罚
□ 月损耗率>危险值：扣除损耗价值20%
□ 连续3月超标：岗位调整
```

## 核心方法论

### 损耗控制三原则

1. **精准订货**：订货量 = 预估销售量 × 安全系数，宁少勿多
2. **标准操作**：出成率有标准，切配有规范，不靠员工感觉
3. **追责到人**：没有追责的损耗管理等于空话

### 边角料利用公式

```
边角料利用率 = 边角料利用重量 ÷ 边角料总重量 × 100%

目标：≥30%
方法：
- 边角料做员工餐
- 边角料做特价菜（如"厨师推荐-仅今日"）
- 边角料做创意小碟（如泡椒边角/凉拌边角）
```

## 注意事项

1. **损耗不是越低越好**：为了追求零损耗而断货，损失更大
2. **不能降质控损**：用劣质食材减少损耗是本末倒置
3. **边角料要合法处理**：过期变质的不能做成菜品
4. **记录要坚持**：没有记录的损耗等于没有管理
