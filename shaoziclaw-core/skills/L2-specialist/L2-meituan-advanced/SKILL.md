## ⚠️ 2026年美团核心变化

```
来自勺子课堂直播回放(04-02)的权威信息：

1. 客单价权重变化最大（今年最关键的指标！）
   - 低客单价快餐今年非常危险
   - 平台鼓励高客单→佣金更高

2. 复购率权重提升
   - 近7天复购率≥10%才算合格，15%以上优秀
   - 复购不合格单量拉不上去也稳不住

3. 经营水平权重提升
   - 配送时间由平台测算（商家不能自己改了）
   - 出餐慢要扣钱

4. 会员红包升级为阶梯形式
   - 影响菜单设计和套餐组合
   - 设计产品结构时要把红包规划进去

5. 神枪手升级
   - ❌ 做单品太不赚钱，影响综合客单价和单均利润
   - ✅ 可以做套餐/加购品

6. 拼好饭门槛变高
   - 品质要求更高
   - 价格保持低但品质要上去

7. AI"龙虾"上线
   - 既to B又to C
   - 未来修改后台更便捷
   - ⚠️ 只做基础运维的运营会被替代！

结论：低品质+低客单+纯外卖将不再有流量
    今年是外卖这几年里最难做的一年（去年最好做）
```

## 一、美团四大曝光渠道

### 渠道总览

| 渠道 | 特点 | 转化效率 | 优化难度 |
|------|------|---------|---------|
| 商家列表曝光 | 最大流量入口 | 中等 | 低 |
| 搜索曝光 | **转化率最高！** | ★★★★★ | 中 |
| 购物车曝光 | 加购后二次触达 | 高 | 中 |
| 订单曝光 | 老客复购为主 | 最高 | 高 |

### 1.1 商家列表曝光优化

```
诊断指标：进店率
- <4% → 无效流量太多，需缩小配送范围+补精准单提升排名
- 4%-6% → 及格线，有优化空间
- >6% → 良好
- >8% → 优秀

优化动作：
□ 头像优化（热气腾腾招牌菜+"现炒"/"手作"关键词）
□ 店名优化（品牌+品类+爆款单品结构）
□ 满减力度合理（略低于竞品但要有感知）
□ 评分维护（≥4.8）
□ 配送费和起送价设置合理
```

### 1.2 搜索曝光优化（重点！）

```
为什么搜索曝光最重要：
- 搜索转化率在所有渠道中最高！
- 用户主动搜索=意图明确=下单概率大

操作方法：

① 点金推广搜索加价
   - 搜索定向加0.3元起步
   - 推广实况中保持搜索排名前五

② 关键词植入菜品名
   - 打开袋鼠店长
   - 查看"城市搜索关键词"
   - 找到高交易量关键词
   - 将这些词放入你的菜品名称中

例：城市搜索"猪脚饭""卤肉饭""快餐"热度高
→ 菜品名改为："招牌卤肉饭·大块带骨猪脚饭"
```

### 1.3 购物车曝光优化

```
核心逻辑：加购率高→购物车曝光多→二次下单机会多

优化方法：
□ 将加购率>15%的商品放在菜单前面
□ 设置凑单小食/饮品（9.9元档位）引导加购
□ 利用"近1小时XX人下单"的分组标签提升信任感
□ 加购品选择：小食/饮料/加料选项（低成本高感知）
```

### 1.4 订单曝光（老客）优化

```
核心逻辑：老客订单越多→平台给更多老客专属曝光

提升方法：
□ 下单返券（2-3元，7天内使用最有效）
□ 四季老客曝光（设置25-2即可）
□ 精准营销定期给老客发券（每两天一次）
□ 粉丝群运营引导私域复购

关键指标：
- 新老客占比黄金比例5:5
- 近7天复购率<10%需要紧急干预
```

## 二、点金推广精细化操作

### 2.1 核心原则

```
⚠️⚠️⚠️ 最重要的原则：
越没单越不要推广！！！
没单的核心问题是转化不是流量。
店铺基础搭建不合格时推广毫无意义。
日单量<30单的新店绝对不要开推广！
```

### 2.2 推广前自检清单

```
□ 日稳定单量 ≥ 30单
□ 入店率 ≥ 6%
□ 下单转化率 > 商圈均值
□ 推广判断公式：入店率×下单转化率÷100 > 1.5
□ 以上任一条件不满足→先不要推广！
```

### 2.3 定向设置（只开3项！）

```
✅ 必须开的3项定向：
┌─────────────────┬────────┐
│ 定向类型         │ 加价   │
├─────────────────┼────────┤
│ 品类潜力         │ +0.3   │
│ 新客搜索         │ +0.3   │
│ 潜力新客         │ +0.3   │
└─────────────────┴────────┘

❌ 其他全部关闭！（避免无效曝光浪费钱）
```

### 2.4 出价策略

```
基础出价 = 系统推荐值（黄线）的一半

动态调整：
- 推不动 → 每次+0.1
- 推太快（消耗过快）→ 每次-0.1
- 高峰期出价 ≤ 0.3
- 非高峰期基础出价0.1

排名策略：
- 不争第一！排名3-5位性价比最高
- 单次点击成本更低
- 转化率差异不大

预算分配：
- 80%预算投放到3个高峰时段
- 非营业时段手工暂停推广
- 实时监控消耗速度
```

### 2.5 推广效果监控

```
每30分钟检查一次：
□ 消耗速度是否正常（太快→降价/太慢→提价或停）
□ 进店率是否>6%（低→检查头图和满减）
□ 下单转化率是否正常（低→检查菜单和价格）

每日复盘：
□ 今日ROI = （订单数×平均利润）÷ 推广花费
□ ROI>3 → 可加大投入
□ ROI 1-3 → 维持现状观察
□ ROI<1 → 暂停推广排查问题
```

### 2.6 美团推广特殊机制

```
此消彼长关系：
- 付费推广与自然曝光存在"此消彼长"
- 限流状态下推广会挤压自然曝光
- 这就是为什么没单时越推越少！

正确做法：
- 先关推广让自然曝光恢复
- 双转合格后再逐步开启
- 新店期不要猛砸推广
- 否则停推广后自然曝光也停
```

## 三、破限流完整SOP

### 3.1 如何判断被限流

```
打开路径：经营数据 → 流量板块

限流标志：
□ 新客曝光远低于同行均值
□ 新客转化远低于同行均值
□ 曝光量突然断崖式下跌（非正常波动）
□ 单量连续3天下滑且无明显原因
□ 开了推广但进店率极低
```

### 3.2 破流四步法

```
Step1：关掉推广
- 先完全停止所有付费推广
- 让店铺自然曝光恢复1-2天
- 观察自然曝光是否有回升

Step2：优化双转（根本！）
- 入店率<6%→优化头像/店名/满减/评分
- 下单率<20%→优化菜单分组/图片/描述/套餐
- 目标：双转达到商圈前10%

Step3：精准补单拉数据
- 在福利区设0.01元新老客同享产品
- 高峰期集中做活动（满减叠加优惠券）
- 快速拉升单量突破层级限制
- 大单策略：对比商圈前十均值差值×1.3=需补金额，连补4天

Step4：重新开推广（如果需要）
- 定向投放（只开3项）
- 高峰期前半小时开始
- 控制进店率6%以上
- 曝光频率每分钟10-12次
```

### 3.3 防止再次限流

```
日常注意事项：
□ 不要频繁编辑菜单栏
□ 不要频繁改价
□ 不要批量上下架商品
□ 不要盲目刷单
□ 保证不卡餐不拒单不超时
□ 保持评分稳定上升
```

## 四、负反馈与申诉

### 4.1 什么是负反馈

```
两种类型：
① 服务负反馈：用户反馈服务问题（态度/包装/漏送等）
② 食品安全负反馈：用户反馈食安问题（异物/变质/不新鲜等）

后果：
- 直接影响店铺权重和流量分配
- 严重者扣分甚至下架
- 必须及时处理！
```

### 4.2 查看路径

```
规则中心 → 体检中心 → 查看食品安全和服务两个负反馈
```

### 4.3 申诉模板（通过率99%）

```
【服务负反馈模板】
尊敬的平台审核团队，
我方已核实情况，外卖正常出餐，无用户反馈的负面情况。
附：餐品图片或制作视频

【食品安全负反馈模板】
尊敬的平台审核团队，
我方已核实情况，确认无食品安全问题。用户反馈可能与保存方式有关，
属非食安问题，申请撤销处罚。
附：监控图片和采购记录截图
```

### 4.4 进阶申诉技巧

```
场景：异物/食材不新鲜投诉
话术："骑手告知此单为同行点单，相关差评已申诉通过，
望平台撤销本次处罚"

场景：包装破损/餐品撒漏投诉
话术："产品出品前已逐件检查，破损撒漏为配送导致，与本店无关"

场景：多次类似差评（恶意评价）
话术："该用户多次给出类似差评，属恶意评价，
请求平台核查该用户行为"

⚠️ 支持二次申诉！第一次不通过可以再次提交
```

### 4.5 恶意差评防护体系

```
预防：
1. 打开规则中心→风险顾客提示
2. 查看系统推送的恶意差评顾客
3. 选择"确认异常"后系统自动追踪
4. 后续差评自动拦截不影响评分

事后处理：
1. 24小时内后台回复（真诚不反驳）
2. 私信联系顾客了解情况
3. 合理补偿（退款/优惠券/免费赠送）
4. 后台服务中心→限制恶意下单→拉黑
```

## 五、美团独有工具使用指南

### 5.1 袋鼠店长

```
功能：美团官方数据分析工具
开通时机：新店第三周左右（基础稳定后）
核心用途：
- 城市搜索关键词分析
- 同行数据对标
- 流量来源拆解
- 延长新店特权时间（重要用法！）

高级玩法：
当测试发现新店特权效果比点金好时
→ 用袋鼠店长延长新店特权时间
→ 继续享受免费加权流量
```

### 5.2 神会员

```
2026年升级要点：
- 变成阶梯形式（不同消费门槛不同红包力度）
- 影响菜单设计时要考虑进去
- 设置建议：新客追加1-2元 / 全时段追加0.5元
- 增加商家列表曝光权重
```

### 5.3 神枪手

```
2026年升级要点：
❌ 不能再做单品了（太不赚钱影响客单价）
✅ 要做套餐（提升综合客单价和利润）
✅ 可以做加购品
- 神枪手上的品要配合主套餐逻辑
```

### 5.4 赏金联盟

```
设置：佣金8%（比同行略高即可）
作用：激励骑手优先接你家订单
效果：恶劣天气/高峰期配送更有保障
```

### 5.5 精准营销

```
发券对象（每两天一次）：
- 复购顾客
- 昨日进店未下单顾客
- 近30天未下单的老顾客（流失召回）

发券金额：
- 通常25-2（25元门槛减2元）
- 或设置为客单价的1.2倍门槛
- 金额不用太大2-3元就够

配合点金推广老客加0.2元效果更好
```

### 5.6 营销魔方

```
功能：比点金推广更智能的营销工具
适用：有一定数据积累后的店铺

操作：
- 推广魔方→菜品引爆
- 设置预算20元左右
- 出价0.4元
- 选择超抢手套餐精准引流
```
