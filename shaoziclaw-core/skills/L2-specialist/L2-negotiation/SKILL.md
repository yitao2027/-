### 触发场景描述
餐饮老板每天都在谈判：房东、供应商、员工、加盟商。本skill提供系统性的谈判方法论，帮助餐饮人谈出好条件。

## 核心方法论

### 餐饮谈判四场景

```
1. 房东谈判（租金/续约/免租期）
2. 供应商谈判（价格/账期/独家）
3. 员工谈判（工资/分成/股权）
4. 加盟商谈判（加盟费/区域/管控）
```

### 谈判前准备

```
谈判准备清单：
□ 了解对方底线（通过各种渠道打听）
□ 明确自己底线（绝对不能让步的条件）
□ 准备替代方案（BATNA）
□ 收集有利证据（市场数据/案例）
□ 设定目标（理想/合理/底线三档）
□ 准备让步清单（可以让步什么）
```

### 谈判筹码

```
餐饮老板常用筹码：
1. 承诺量（承诺月销量，换取优惠）
2. 付款方式（预付/现金，换取折扣）
3. 长期合作（签长约，换取稳定价格）
4. 介绍资源（介绍客户，换取优惠）
5. 退出威胁（有备选，随时可以换）
```

### 餐饮谈判话术

```
开场话术：
- "我们诚心想长期合作，这是我们XX店的流水，你看下"
- "我们已经和XX品牌签了，想对比一下条件"

试探话术：
- "这个价格能再商量吗？"
- "同行XX给的条件是XX，你们能匹配吗？"

施压话术：
- "我们还有其他选择，不过更希望和你们合作"
- "如果我们签3年，你们能给到什么条件？"

让步话术：
- "如果你能把价格降5%，我们可以预付半年"
- "我们可以接受，但需要你答应XX条件"
```

## 操作流程

### Step 1：明确谈判类型

```
□ 租金谈判（找铺/续约）
□ 供应商谈判（采购）
□ 员工谈判（招聘/晋升）
□ 加盟谈判（招商/加盟）
□ 其他
```

### Step 2：收集情报

```
情报收集清单：
- 对方历史案例
- 对方当前压力（资金/业绩压力）
- 市场竞争情况
- 替代选项
```

### Step 3：制定策略

```
策略框架：
- 核心目标（必须达成）
- 理想目标（最好情况）
- 让步空间（可以放弃什么）
- 底线（绝对不让步）
- 备选方案（谈崩怎么办）
```

### Step 4：执行谈判

```
谈判执行：
1. 开局：建立关系，展示诚意
2. 探底：试探对方底线
3. 博弈：交换条件，寻求共识
4. 收尾：确认细节，尽快签约
```

### 谈判策略

**第一阶段：建立关系**
- 表明诚意：考察了多家，这是首选
- 展示实力：品牌连锁XX家门店
- 了解需求：询问商场对这个铺位的期待

**第二阶段：价格试探**
- "XX商场租金多少？"
- "这个价格能谈吗？"
- "旁边XX店才XX，你们贵了XX"

**第三阶段：施压**
- "我们更倾向这里，但价格要和市场接轨"
- "如果能降到XX，我们可以签3年+"
- "如果不合适我们可能考虑XX"

**第四阶段：交换条件**
- 价格降 → 付款方式优化（季付改月付）
- 价格降 → 装修期延长（免租2个月）
- 价格降 → 承诺保底业绩

## 专家点评（避坑提示）

**勇哥原话**："谈判不是吵架，是交易。你要清楚自己能给出什么，才能换来你要的东西。"

**常见错误**：
1. **没有准备** → 被对方牵着走
2. **暴露底线** → 一开口就报最低价
3. **只谈价格** → 忽视其他条件（免租期/付款方式）
4. **不会放弃** → 谈崩了不知道走

**正确姿势**：
- 永远不要接受第一次报价
- 准备三档目标，底线绝不退让
- 价格谈不下，就谈其他条件
