# 门头设计法则 SKILL

## Skill 元信息

**名称**：L2-signage-design
**分类**：L2 专项能力 · 品牌部
**级别**：中级 · 品牌视觉专家
**版本**：1.0
**触发词**：「门头设计」「招牌设计」「门店外观」「视觉设计」「门头战略」「吸引顾客」「怎么设计门头」「门店曝光」

---

## 触发场景

当用户需要设计门头、分析门头问题、或提升门店曝光率时，启用此 Skill。

---

## 输入

- 品牌名称与品类
- 门店位置：街边店 / 商场店 / 社区底商
- 目标客群
- 已有门头（分析问题）或新门头（全新设计）

---

## 工作流程

### Step 1：门头诊断五要素

```
【门头五要素检测】

1. 我是谁（品类名）
   □ 门头有品类关键词吗？（如：火锅/面馆/奶茶）
   □ 品类名够大够清晰吗？
   □ 5米外能看清品类名吗？

2. 我叫什么（品牌名）
   □ 品牌名清晰可见吗？
   □ 字够大够醒目吗？
   □ 字形有品牌调性吗？

3. 我卖什么（产品图/符号）
   □ 有视觉符号让人一眼识别吗？
   □ 产品图能激发食欲吗？
   □ 符号够简洁吗？

4. 我有什么不同（价值主张）
   □ 有差异化卖点吗？（如：正宗/人气/便宜）
   □ 口号简洁有力吗？

5. 我在哪（地址/指引）
   □ 路过的人能看懂怎么进店吗？
   □ 有基础的营业时间标注吗？
```

### Step 2：门头设计法则

```
【门头设计四原则】

一、远大近小
□ 5米外能看到品类名
□ 3米外能看到品牌名
□ 1米内能看到详细价值主张

二、色香味触
□ 色：颜色鲜明，对比强烈，吸引眼球
□ 香：香气扑鼻（如果门店有气味的话）
□ 味：菜品展示（让路人想到吃的感觉）
□ 触：质感（门把手/材质给人好印象）

三、一看就懂
□ 不要玩创意，大多数路人不会停下来猜
□ 品类优先，品牌其次
□ 符号>图片>文字

四、差异化展示
□ 与左右邻居形成差异
□ 让自己在整条街上最醒目
□ 符合品类调性（快餐重效率，正餐重品质）
```

### Step 3：门头设计结构

```
【门头内容层次】

第一层（5米外可见）：
├─ 品类名（大字，最醒目）
├─ 品牌名（次大字）
└─ 超级符号（图形，辅助识别）

第二层（3米外可见）：
├─ 价值主张/Slogan
├─ 产品展示（图片/模型）
└─ 价格区间（吸引路过决策）

第三层（1米内可见）：
├─ 详细产品/菜单
├─ 营业时间
├─ 外卖/堂食标识
└─ 促销活动信息

【门头高度与字体大小参考】
| 门头高度 | 品类名字号 | 品牌名字号 | Slogan字 号 |
|---------|-----------|-----------|------------|
| 3-4米   | ≥40cm    | ≥30cm    | ≥20cm     |
| 2-3米   | ≥30cm    | ≥20cm    | ≥15cm     |
| <2米    | ≥20cm    | ≥15cm    | ≥10cm     |
```

### Step 4：不同位置门头策略

```
【街边店门头】
□ 横向要宽，竖向要亮
□ 利用立面空间（1层到2层）
□ 霓虹灯/发光字晚上更醒目
□ 橱窗展示（让路人看到里面热闹）

【商场店门头】
□ 商场指引标识要清晰
□ 楼层指示配合
□ 在通道交汇处的位置加分
□ 品牌符号要够大（竞争激烈）

【社区底商门头】
□ 融入社区氛围（亲切感）
□ 突出便利性（营业时间/logo）
□ 社区亲和力（颜色/风格不要太高冷）
```

### Step 5：门头迭代检查

```
【门头问题诊断】

问题：路过的人不进店
□ 门头不够显眼 → 加大/加亮
□ 品类不清晰 → 加品类名
□ 形象太旧 → 重新设计
□ 位置被遮挡 → 改善遮挡物

问题：进店的人不消费
□ 门头吸引的不是目标客群
□ 门头与店内体验落差太大
□ 价格与门头定位不符

问题：成本太高
□ 减少高度（够用就行）
□ 减少材质（耐用就行）
□ 减少变化（稳定更省钱）
```

## 核心方法论

### 门头战略三问

1. **5米外能看到吗？**——品类名够大够亮
2. **3米外能理解吗？**——品牌+价值主张够清晰
3. **1米内想进来吗？**——细节+氛围吸引进店

### 门头ROI

```
门头投资 = 制作成本

门头回报 = 曝光量×进店转化率×客单价

结论：好门头让路过的人进店率提升50-100%
      一张好门头图 = 长期的免费广告牌
```
