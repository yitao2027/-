## 案例概要

**当事人**：35岁夫妻，有装修建材工厂，年营业额200万  
**项目**：镇上建材市场二楼火锅+演艺店  
**总面积**：1600平米，75张桌  
**总投资**：110万（含装修+设备+转让，不含房租）  
**经营数据**：
- 月营业额：6-7万（每天2000-3000元）
- 毛利率：约50%
- 月人工：2.56万（8人）
- 月水电：5000-6000元（不开空调）；开空调每天500-600元
- 月亏损：约1万元
- 房租：1.2万/月（400元/天）

---

## 踩的坑

### 坑1：面积严重过大
- 1600平米，75张桌——超过镇上消费承载力
- **勇哥金句**："你一个镇上，没有这么多人啊，你得花多少流量才能把这75桌给填满？"
- 对比：成都2000万人口，1600平的火锅店都很少见
- 建议规模：镇上300-500平米最合理

### 坑2：选址在建材市场二楼
- 市场离镇上10分钟车程
- 市场停车收费
- 二楼，顾客需要专门上去
- 一楼是装饰材料店——来的都是买建材的人，不是来吃饭的
- **核心问题**：位置本身没有人流

### 坑3：没有自然人流
- 镇上+建材市场+二楼+停车收费
- 四重debuff叠加，自然客流接近于零
- 完全依赖线上引流

### 坑4：演艺火锅模式不可持续
- 每天请人来唱歌跳舞（演出费800元/天）
- 开业时请过网红探店，只推了3次
- 开业后没有持续做推广
- **老板夫妻**：开工厂的，完全不懂流量运营
- 自己做直播，新号，流量很差

### 坑5：想靠"演艺"做差异化，但选错了品类
- 火锅+演艺：顾客去一次尝鲜，不会去第二次
- **勇哥点评**："我吃过一次演艺火锅，吃完不会再去了。太吵了，没有任何体验感。"
- **对比**：烧烤本身就有大排档属性，演艺+烧烤比演艺+火锅更合理

### 坑6：想复制"老厂模式"但没搞清本质
- 看人家烧烤"老厂模式"火，就改成火锅
- 但"老厂模式"火的原因是有烟火气、有氛围
- 改成火锅后，烟火气和氛围反而没了

### 坑7：成本失控
- 中央空调6万多
- 人数从26人裁到8人
- 演出费800元/天
- 固定成本太高

## 核心教训（可执行清单）

| 教训 | 行动项 |
|------|--------|
| 镇上开店不能超过500平米 | 先算客流，再定规模 |
| 选址不能只看租金便宜 | 人流才是核心 |
| 二楼选址慎重 | 必须有电梯/扶梯/明显指引 |
| 不懂流量就不要开大店 | 资金不够做流量=大坑 |
| 演艺火锅不是护城河 | 体验感差，顾客复购率低 |
| 先测试再扩张 | 用小成本测试模式可行，再投大钱 |

---

## 勇哥的救命建议（分租模式）

**核心思路**：把1600平拆成3-4家小店

```
1600平整体（现状：亏）
  ↓ 分割
├─ A区：烧烤店（独立老板）
├─ B区：火锅店（独立老板）
├─ C区：其他品类（独立老板）
└─ D区：自营一个品类
```

**执行方式**：
1. 把装修好、空调装好、现成的空间分租出去
2. 月租金5000-6000元（低于市场价，含装修）
3. 每家独立经营，自带流量
4. 自己只留一块做核心品类

**收益测算**：
- 3个分租出去：15000-18000元/月
- 房租相当于不要钱
- 降低风险，不再独自承担75桌的流量压力
