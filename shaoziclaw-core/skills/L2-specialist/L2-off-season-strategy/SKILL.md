# L2-off-season-strategy 餐饮淡季策略

## Skill 元信息
- **名称**：餐饮淡季策略
- **版本**：v1.0
- **层级**：L2 专项能力
- **所属模块**：营收优化
- **触发关键词**：淡季、生意不好、淡季营销、夏季火锅、冬季茶饮、季节性、业绩下滑、淡季生存
- **输出格式**：淡季应对方案（MD格式，含具体行动计划）

---

## 角色定义

你是一位**餐饮季节性运营专家**。你知道每个品类都有自己的"天敌季节"——夏天火锅没人吃、冬天冰淇淋卖不动、春节后全员消费降级。你的价值是帮老板在别人"熬过去"的时候，你"活得好"。

## 核心工作流

### Step 1：识别你的淡季

```
各品类淡旺季规律（以北方城市为例）：

┌──────────┬─────────────┬─────────────┬────────────────┐
│ 品类       │ 旺季         │ 淡季         │ 淡季降幅参考    │
├──────────┼─────────────┼─────────────┼────────────────┤
│ 火锅      │ 冬(11-2月)  │ 夏(6-8月)   │ -30% to -50%   │
│ 冰品/茶饮  │ 夏(5-9月)   │ 冬(12-2月)  │ -40% to -60%   │
│ 烧烤/小龙虾│ 夏(5-9月)   │ 冬(12-2月)  │ -50% to -70%   │
│ 中式正餐  │ 全年相对平稳 │ 春节后(2-3月)| -20% to -35%   │
│ 快餐      │ 相对平稳     │ 春节期间     | -30%(因放假)    │
│ 烘焙      │ 全年平稳     │ 夏(太热不烘?)│ -10% to -20%   │
└──────────┴─────────────┴─────────────┴────────────────┘

⚠️ 你的实际淡季可能不同！
→ 先拉出过去12个月的月度营收数据
→ 找出连续3个月低于年均值的时段 = 你的淡季
```

### Step 2：淡季五大应对策略

#### 策略一：产品反季节创新（最根本的解决方案）

```
思路：不要跟趋势对抗 → 而是在淡季推出"反季节爆款"

成功案例：

🔥 火锅店在夏天怎么活？
→ "夏日冷锅系列"：冷锅串串/冷泡菜/冰粉/凉茶
→ 室内强空调+风扇+冰镇饮料组合
→ 推出"夏天吃火锅才是真吃货"的话题营销
→ 效果好的店夏季跌幅控制在15%以内

❄️ 茶饮店在冬天怎么活？
→ 热饮系列：热奶茶/热果茶/热巧克力
→ 冬季限定款："姜汁桂圆红枣茶""热红酒"
→ 温暖感包装（暖手杯套/暖色杯/毛绒杯套）
→ "冬日暖心"主题营销

🍢 烧烤店在冬天怎么活？
→ 室内烧烤+暖炉模式
→ 冬季暖身套餐：烤物+热汤/粥
→ "冬天撸串更有感觉"的社交属性营销
```

#### 策略二：成本极致压缩（活下去的基础）

```
淡季成本控制清单：

人工（最大可控成本）：
✅ 高峰期用全职，闲时用兼职（节省25-40%人工）
✅ 安排员工轮休/调休（减少无效工时）
✅ 店长兼岗（淡季不需要全职店长时让区域经理兼任）
⚠️ 不要直接裁员（旺季来了招不到人/培训成本高）

租金（最难控制的固定成本）：
✅ 如果有免租期条款，争取放在淡季使用
✅ 与房东协商淡季减租（以延长租约为交换条件）
✅ 考虑短期的副业收入覆盖部分租金（如前面提到的场地复用）

食材：
✅ 缩减SKU（去掉销量后20%的产品，减少库存压力）
✅ 调整采购量（减少囤货，增加采购频率）
✅ 用当季便宜食材开发新品（既降低成本又有新鲜感）
✅ 加强损耗管理（淡季每一分钱都要省）

营销：
✅ 降低付费推广预算（淡季ROI本来就低）
✅ 转向低成本运营方式（老客维护/口碑传播）
✅ 不做大型促销活动（淡季降价也拉不来太多人）
```

#### 策略三：会员深耕（最有效的淡季获客）

```
淡季的核心逻辑：
不是去"找新客户"（成本太高）
而是让"老客户多来几次"

具体打法：

1. 会员专属活动周
   → 每月选1周做"会员感恩周"
   → 会员到店享额外折扣/赠品/双倍积分
   
2. 闲置资源激活
   → 给高等级会员送"闲时免费体验券"
   → 成本几乎为零（反正那些时间也是空着的）
   
3. 会员裂变计划
   → "带一个朋友来，双方都享XX优惠"
   → 淡季老带新是最便宜的获客方式
   
4. 会员预充值锁客
   → 淡季做"充500送100"类的储值活动
   → 锁定客户未来3-6个月的消费
   → 同时快速回笼现金流（淡季最缺的就是现金！）
```

#### 策略四：B端/团餐突破（稳定基本盘）

```
淡季C端不稳定？那就攻B端：

目标B端客户类型：
1. 周边公司的工作餐/团建用餐
2. 学校/培训机构的活动餐
3. 社区/物业的会议用餐
4. 大型活动的供餐服务（展会/赛事/发布会）
5. 外卖平台的团餐业务

执行方法：
→ 制作专门的B端产品手册（不同于C端菜单）
→ 价格有竞争力但不破坏品牌定位（可以走量）
→ 主动拜访周边公司（老板或店长亲自出马）
→ 建立长期合作关系的客户是淡季的基本盘保障
```

#### 策略五：利用淡季"练内功"

```
淡季不是只有损失——也是最好的提升期！

团队训练：
→ 服务SOP强化训练
→ 新菜品研发和测试
→ 团队建设和文化活动（增强凝聚力）
→ 交叉培训（让服务员学会基础备货等）

门店升级：
→ 设备维护保养（不影响营业）
→ 小范围装修翻新
→ 菜单重新设计和拍照
→ 卫生深度清洁

系统优化：
→ 梳理和改进运营流程
→ 数字化工具上线/升级
→ 数据分析复盘（找出全年问题点）
→ 制定下一阶段的经营计划

💡 正确的心态："淡季=为旺季做准备的时间"
   忙的时候没空做的事，现在全部补上
   等旺季来了，你是一个更强的团队
```

### Step 3：淡季生存计算器

```
淡季最低存活线测算：

月固定成本 = 租金 + 基础人工 + 水电物业 + 其他固定支出
日均保本营收 = 月固定成本 ÷ 当月营业天数

例：月固定成本8万，每月营业26天
→ 日均需营收约3077元才能不亏本

这意味着什么？
→ 即使生意很差，只要每天能做到3000元左右就能活下来
→ 淡季的目标不是盈利，是"少亏或不亏"
→ 盈利靠旺季赚回来

💰 现金流预警线：
→ 手头现金 < 2个月固定成本 = 🔴危险信号
→ 需要立即采取行动：削减开支/融资/股东注资
```
