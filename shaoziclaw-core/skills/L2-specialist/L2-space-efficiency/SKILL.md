# L2-space-efficiency
# 门店坪效优化与空间运营

**层级：** L2 专项能力  
**部门归属：** 营运管理部  
**触发词：** 坪效、空间利用、座位效率、翻台率、空间优化、面积规划、座位设计

---

## 一、Skill 定位

**解决什么问题：**  
帮助餐饮门店最大化每平方米的产出价值，通过科学的空间布局、座位设计和高峰期管理，在不扩大面积的前提下提升坪效和营业额。

**核心公式：**
```
坪效 = 月营业额 ÷ 营业面积（元/㎡/月）

行业参考基准：
- 快餐/简餐：5,000-15,000元/㎡/月（优秀≥10,000）
- 正餐：3,000-8,000元/㎡/月（优秀≥6,000）
- 茶饮咖啡：8,000-20,000元/㎡/月（优秀≥15,000）
- 火锅：4,000-10,000元/㎡/月（优秀≥7,000）
```

## 二、核心方法论

### 2.1 坪效三要素分析

```
坪效 = 翻台率 × 客单价 × 有效座位率

【翻台率】= 当日接待桌次 ÷ 座位总桌数
- 快餐目标：午市3-5翻，晚市2-3翻
- 正餐目标：午市1.5-2翻，晚市1-1.5翻

【客单价】= 当日营业额 ÷ 当日接待人次
- 每季度至少做一次客单价分析
- 区分高峰/平峰时段差异

【有效座位率】= 实际收益座位 ÷ 总座位数
- 等位死角位、过道位、临厕位是"无效座位"
- 目标：有效座位率≥90%
```

### 2.2 空间功能区划分原则

**餐饮空间五大功能区配比（以100㎡为例）：**

```
┌─────────────────────────────────────┐
│  功能区     │ 建议面积占比 │ 快餐 │ 正餐 │ 火锅 │
│─────────────┼────────────┼─────┼─────┼─────│
│  顾客就餐区 │ 50-65%      │ 65% │ 55% │ 50% │
│  后厨操作区 │ 20-30%      │ 20% │ 30% │ 30% │
│  收银/等位区│ 5-10%       │ 5%  │ 8%  │ 8%  │
│  卫生间走廊 │ 5-10%       │ 5%  │ 5%  │ 7%  │
│  员工/仓储区│ 3-8%        │ 5%  │ 2%  │ 5%  │
└─────────────────────────────────────┘
```

**座位密度参考标准（㎡/座）：**
- 快餐/茶饮：1.0-1.2㎡/座（紧凑型）
- 休闲餐厅：1.5-2.0㎡/座（舒适型）
- 正餐/中式：2.0-2.5㎡/座（宽松型）
- 火锅/烧烤：2.5-3.5㎡/座（特宽型）

### 2.3 座位布局优化策略

**提升坪效的座位设计技巧：**

**① 灵活组合式座位**
```
固定大桌（6-8人）→ 改为可拼接的2人/4人桌
好处：
- 周末/节假日拼成大桌接待聚餐
- 平日分成小桌接待情侣/独食客
- 有效座位利用率提升15-25%
```

**② 高效翻台区设计**
```
靠近门口区域 → 设计为快翻区（较小桌/较硬椅）
核心区域 → 设计为体验区（舒适座位/有私密感）
窗边区域 → 设计为景观/打卡区（网红位，溢价空间）
```

**③ 消除死角**
```
常见坪效死角及改造方案：
- 柱子旁：设计卡座，变缺陷为特色（私密感反成卖点）
- 卫生间附近：增加绿植/香氛隔离，提升体验
- 过道位：加宽或减少，不强行设座
- 楼梯下：设计储物或展示区，不设座位
```

### 2.4 时间维度坪效管理

**分时段坪效优化：**

| 时段 | 特征 | 优化策略 |
|------|-----|---------|
| 早餐（6-9点） | 快速、独食为主 | 减少桌位、增加吧台、快速翻台 |
| 午市高峰（11:30-13:30） | 上班族为主、时间紧 | 提前备餐、快速出餐、控制用餐时长（暗示） |
| 下午茶（14-17点） | 低峰 | 灵活转化为咖啡/甜品场景、降低成本 |
| 晚市高峰（17:30-20:00） | 聚餐为主、时间宽裕 | 体验优先、翻台不强求 |
| 夜宵（21点后） | 夜猫子/年轻群体 | 按需营业、精简菜单 |

**平峰期提升坪效三招：**
1. **场景叠加**：下午茶时段引入轻食/甜品场景
2. **外卖补仓**：平峰时段专门接外卖订单（利用后厨空闲产能）
3. **包场业务**：开发生日包场/企业聚餐/团建包场，填充低峰时段

### 2.5 坪效提升项目优先级矩阵

```
                 实施成本
                  低   │   高
              ─────────┼─────────
高 坪效       快赢机会  │  重点投资
提           （优先做） │  （计划做）
升           ─────────┼─────────
潜           填补时间  │  暂不考虑
力           （酌情做） │  
低            低   │   高
```

**快赢机会（低成本高产出）：**
- 优化等位管理（减少翻台间隔浪费）
- 调整菜单出餐速度（快消菜优先）
- 优化前厅动线（减少服务走动距离）
- 增加自助取餐/点餐环节（节省服务员时间）

## 三、坪效诊断工具

### 3.1 坪效现状诊断表

```
【门店坪效诊断】

基本信息：
- 营业总面积：___㎡（含就餐区___㎡、后厨___㎡）
- 总座位数：___个（桌数：___桌）
- 营业时段：___（共___小时/天）

本月经营数据：
- 月营业额：___元
- 当前坪效：___元/㎡/月（计算：营业额÷面积）
- 行业参考坪效：___元/㎡/月

翻台率分析：
- 午市平均翻台：___次/桌
- 晚市平均翻台：___次/桌
- 高峰等位时长：___分钟
- 高峰满座率：___%

空间使用问题：
□ 有明显死角座位（位置描述：___）
□ 高峰期等位时间过长（≥20分钟）
□ 下午/平峰期空置率过高（≥60%）
□ 座位组合不灵活（固定大桌为主）
□ 后厨面积过大/过小（标准：总面积的25-30%）

坪效目标设定：
- 当前坪效：___元/㎡/月
- 目标坪效：___元/㎡/月（建议提升20-30%为阶段目标）
- 主要提升路径：□翻台率 □客单价 □平峰场景 □座位优化
```

## 四、触发条件与输出

**输入收集：**
```
请告诉我：
1. 门店面积和座位数？（总面积___㎡，座位___个）
2. 目前月营业额大概多少？（当前坪效估算）
3. 主要问题是什么？（等位时间长/空置率高/翻台慢/空间浪费）
4. 是自有房产还是租赁？（影响改造投入建议）
5. 门店主营类型？（快餐/正餐/火锅/茶饮）
```

**输出内容：**
- 坪效现状诊断报告（含行业对标）
- 空间改善优先级建议（快赢机会+中长期投资）
- 座位布局优化方案
- 分时段场景运营建议
- 坪效提升预测（方案实施后目标坪效估算）
