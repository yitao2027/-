# L2-supply-chain-quality：供应链品质管控体系

> 建立从源头到门店的食品安全与品质保障全链路管控系统

---

## 触发场景

- 门店频繁出现食材品质问题（口感不稳定、食材过期等）
- 供应商管理混乱，没有准入标准和评估机制
- 食安事故频发，不知道问题出在哪个环节
- 想建立稳定的供应链体系但不知从何入手
- 门店数量扩张后，品控难度加大
- 进口/生鲜等高风险品类管理能力不足

---

## 核心方法论

### 一、供应链质量管理体系（SQMS）

#### 1. 四阶段品质管控模型

```
原料采购 → 仓储物流 → 门店验收 → 存储使用
    ↓           ↓          ↓          ↓
源头管控    过程管控    入口管控    使用管控
```

#### 2. 各阶段责任边界

| 阶段 | 责任主体 | 管控重点 | 关键指标 |
|------|----------|----------|----------|
| 采购 | 采购部 | 供应商资质、价格、交付 | 准时交付率≥98% |
| 仓储 | 仓储部 | 温度、效期、防护 | 损耗率<2% |
| 物流 | 物流部 | 冷链完整性、时效 | 冷链达标率100% |
| 验收 | 门店 | 感官检测、温度、数量 | 拒收率<3% |
| 存储 | 门店 | 效期、温度、先进先出 | 过期报废<0.5% |

---

### 二、供应商管理五步法

#### Step 1：供应商资质审查（准入门槛）

**基础资质清单**：

| 资质类型 | 必须项 | 备注 |
|----------|--------|------|
| 营业执照 | ★ | 真实有效 |
| 食品生产/经营许可证 | ★ | 有效期内 |
| 法定代表人身份证 | ★ | - |
| 行业资质 | ★ | 生产许可证/流通许可证 |
| 检测报告 | ★ | 型式检验报告（批次检测） |
| 社保缴纳证明 | ○ | 判断是否为正规企业 |
| 过往客户案例 | ○ | 餐饮行业经验 |

**实地考察清单**（高风险食材必须）：

| 考察项目 | 评估要点 |
|----------|----------|
| 工厂环境 | 卫生状况、设备状态、布局合理性 |
| 生产流程 | 工艺标准、关键控制点、人员操作 |
| 质检体系 | 检验设备、留样制度、不合格品处理 |
| 仓储条件 | 温度控制、防虫防鼠、库存管理 |
| 物流能力 | 冷链设备、保温测试、应急方案 |
| 员工素质 | 健康证、培训记录、操作规范 |

#### Step 2：供应商分级评估

**评分模型（100分制）**：

```markdown
总分 = 资质合规(20分) + 品质稳定性(30分) + 价格竞争力(20分) + 交付能力(15分) + 服务响应(15分)
```

**分级标准**：

| 等级 | 分数 | 采购策略 | 复审周期 |
|------|------|----------|----------|
| A级（战略供应商） | ≥90 | 优先采购、联合研发、长期合同 | 1年1次 |
| B级（合格供应商） | 75-89 | 正常采购、竞争性谈判 | 半年1次 |
| C级（观察供应商） | 60-74 | 限制采购、问题预警 | 季度1次 |
| D级（不合格） | <60 | 淘汰、启动新供应商开发 | - |

#### Step 3：合同品质条款设计

**必须包含的合同条款**：

```markdown
## 品质保证条款

1. 来料检验
   - 需方有权对到货进行抽样检验
   - 抽检不合格批次，整批退货处理

2. 品质标准
   - 必须符合国家食品安全标准（GB系列）
   - 必须符合双方约定的企业标准
   - 感官指标：色泽/气味/口感/组织状态 需符合封样标准

3. 质量问题处理
   - 质量问题导致需方损失，供方承担全部责任
   - 食安事故：供方承担法律责任+无限连带责任
   - 质量问题响应时间：24小时内到场处理

4. 品质改善
   - 连续2批次不合格，启动专项改善
   - 年度品质合格率<95%，合同终止

5. 审计权
   - 需方有权对供方进行飞行检查
   - 检查前不需提前通知
```

#### Step 4：日常品质监控

**月度品质报告模板**：

| 监控指标 | 计算方式 | 目标值 | 预警值 |
|----------|----------|--------|--------|
| 到货合格率 | 合格批次/总批次×100% | ≥98% | <95% |
| 食安投诉率 | 食安投诉次数/订单数×100% | 0 | >0 |
| 准时交付率 | 准时订单数/总订单数×100% | ≥98% | <95% |
| 品质异常响应 | 24小时响应率 | 100% | <95% |
| 问题批次追溯 | 追溯成功率 | 100% | <99% |

#### Step 5：供应商退出机制

**淘汰触发条件**：

| 触发项 | 严重程度 | 处理方式 |
|--------|----------|----------|
| 证照造假/过期 | 致命 | 直接淘汰+追责 |
| 食安事故主责 | 致命 | 直接淘汰+追责 |
| 连续3批次不合格 | 严重 | 暂停采购+整改 |
| 拒不接受飞行检查 | 严重 | 暂停采购+整改 |
| 价格欺诈 | 中等 | 警告+扣分 |
| 交付延迟>48h | 中等 | 警告+扣分 |

### 三、采购品类风险分级

#### 1. 食材风险四象限

```
            需求量大
               ↑
     ┌─────────┼─────────┐
     │ Ⅰ.战略品类 │ Ⅱ.瓶颈品类 │
     │ (猪肉/大米) │ (活鲜/进口) │
     ├─────────┼─────────┤
     │ Ⅳ.常规品类 │ Ⅲ.杠杆品类 │
     │ (调味品)   │ (招牌食材) │
     └─────────┴─────────┘
            供应风险
```

**Ⅰ类-战略品类**：大量采购，关系稳定，锁定价格
**Ⅱ类-瓶颈品类**：高风险，建立备选+库存策略
**Ⅲ类-杠杆品类**：标准化采购，降本重点
**Ⅳ类-常规品类**：多源采购，降低依赖

#### 2. 高风险品类管控要点

| 品类 | 风险类型 | 管控措施 |
|------|----------|----------|
| 鲜肉/禽类 | 抗生素/瘦肉精 | 必须检疫证明+检测报告 |
| 水产品 | 抗生素/孔雀石绿 | 源头可追溯+快检 |
| 蔬菜 | 农药残留 | 农药检测+供应商承诺书 |
| 进口冷链 | 核酸/病毒风险 | 核酸检测+消杀证明 |
| 豆制品 | 添加剂超标 | 重点检测+实地考察 |
| 熟食/卤味 | 微生物超标 | 效期管控+冷链要求 |

### 四、冷链管理体系

#### 1. 温度控制标准

| 品类 | 存储温度 | 运输温度 | 超温处理 |
|------|----------|----------|----------|
| 冷藏食品 | 0-4℃ | 0-7℃ | 拒收 |
| 冷冻食品 | -18℃以下 | -15℃以下 | 拒收 |
| 常温食品 | 10-25℃ | 常温 | 避免暴晒 |
| 鲜活水产 | 12-15℃ | 带水充氧 | 即到即验 |

#### 2. 冷链验收四步法

```
Step 1：查温度
- 测量车厢温度（≤-15℃冷冻/≤7℃冷藏）
- 测量食材中心温度
- 记录温度数据

Step 2：看外观
- 包装完整性
- 是否有解冻再冻痕迹（冰晶判断）
- 产品颜色/形态是否正常

Step 3：验单据
- 检疫证明
- 核酸检测报告（进口/冷链）
- 送货单与订单一致性

Step 4：入库
- 符合标准：入库
- 不符合：拍照留证+拒收+通知采购
```

### 五、仓储管理规范

#### 1. 仓库分区管理

```
┌─────────────────────────────────┐
│          办公区/检测区           │
├─────────┬───────────┬───────────┤
│ 常温库  │   冷藏库  │   冷冻库  │
│ 15-25℃ │   0-4℃   │  -18℃以下 │
├─────────┴───────────┴───────────┤
│         收货/发货月台            │
└─────────────────────────────────┘
```

#### 2. 存储管理五原则

| 原则 | 说明 | 操作规范 |
|------|------|----------|
| 离地离墙 | 防止潮气/虫害 | 货架离墙≥30cm，离地≥15cm |
| 生熟分开 | 防止交叉污染 | 生食/熟食分区，色标管理 |
| 先进先出 | 效期管理核心 | 正面朝外，批次标注 |
| 分类存放 | 便于管理 | 按品类/供应商分区 |
| 密封保存 | 防潮防虫 | 原包装不拆封/专用容器 |

#### 3. 效期管理三级预警

| 预警等级 | 时间节点 | 处理方式 | 责任人 |
|----------|----------|----------|--------|
| 一级预警 | 临期7天 | 优先使用/促销 | 仓库主管 |
| 二级预警 | 临期3天 | 禁止出品/报损 | 店长 |
| 三级预警 | 已过期 | 立即下架/销毁 | 食品安全员 |

### 六、门店验收标准

#### 1. 验收四步骤

```
第一步：单据核对
- 送货单与系统订单一致
- 生产日期/批号与检测报告一致
- 数量核对（称重/计数）

第二步：温度检测
- 冷藏≤7℃、冷冻≤-15℃
- 温度超标直接拒收

第三步：感官验收
- 颜色正常、无异味
- 包装完整、无破损
- 无解冻再冻痕迹

第四步：检测留样
- 高风险食材留样封存
- 保存至效期后7天
- 建立留样台账
```

#### 2. 常见拒收标准

| 问题类型 | 表现 | 处理 |
|----------|------|------|
| 温度不合格 | 冷藏>7℃/冷冻>-12℃ | 拒收 |
| 包装破损 | 胀袋/漏气/变形 | 拒收 |
| 感官异常 | 颜色/气味/口感异常 | 拒收 |
| 证照缺失 | 无检疫/检测报告 | 拒收 |
| 数量不足 | 短斤少两 | 拒收+扣款 |
| 临期食材 | 距效期<1/3 | 拒收或议价 |

### 七、食品安全国家标准（GB 31654-2021要点）

| 条款 | 核心要求 | 违规风险 |
|------|----------|----------|
| 场所布局 | 生熟分开/专间专用 | 停业整改 |
| 人员健康 | 健康证100%/体检记录 | 行政处罚 |
| 原料控制 | 索证索票/可追溯 | 重大处罚 |
| 加工操作 | 烧熟煮透/避免交叉污染 | 食安事故 |
| 清洗消毒 | 餐具消毒/清洁剂管理 | 食安投诉 |
| 废弃物 | 专区存放/日产日清 | 行政处罚 |
| 昆虫控制 | 防蝇/防鼠/防虫 | 行政处罚 |

## 关联技能

- **前置技能** → L1-food-safety（食品安全合规）、L1-procurement（采购谈判与供应链）
- **配套技能** → L2-loss-control（损耗控制）、L1-opening-checklist（开店筹备清单）
- **支持系统** → L0-catering-data-analyzer（数据分析）
- **进阶技能** → L2-franchise-design（加盟体系设计）

---

## 使用说明

1. **采购决策**：先建立供应商档案，再开始采购
2. **风险排序**：优先建立高风险品类（Ⅱ类）的供应商体系
3. **动态管理**：每季度复盘供应商表现，及时调整
4. **冷链红线**：温度超标零容忍，直接拒收
5. **可追溯**：所有采购记录必须保存2年以上
