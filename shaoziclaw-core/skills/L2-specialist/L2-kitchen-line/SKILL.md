### 触发场景描述

## 核心方法论

### 后厨动线五区分离

```
后厨分区原则：生熟分离 / 干湿分离 / 冷热分离 / 洁污分离

五区分布：
┌─────────────────────────────────────┐
│  收货区 → 存储区 → 备菜区 → 烹饪区 → 出餐区  │
└─────────────────────────────────────┘
        ↑                               ↑
    原料入口                        成品出口
```

### 各区功能定义

| 区域 | 功能 | 关键设备 | 注意事项 |
|------|------|----------|----------|
| 收货区 | 验收食材 | 称重台、冷藏暂存 | 远离烹饪区 |
| 存储区 | 原料储存 | 冷库/常温库 | 分类存放、先进先出 |
| 备菜区 | 食材预处理 | 切配台、水池 | 与烹饪区相邻 |
| 烹饪区 | 加热制作 | 灶台、烤箱、蒸柜 | 排油烟要强 |
| 出餐区 | 装盘出菜 | 传菜口、保温台 | 靠近前厅 |

### 动线设计黄金原则

```
1. 单向流动：避免交叉往返
2. 就近原则：常用设备放手边
3. 最短距离：减少走动时间
4. 分区明确：每个区域职责清晰
5. 安全第一：热区与冷区分开
```

### 餐饮业态动线差异

| 业态 | 重点区域 | 特点 |
|------|----------|------|
| 快餐 | 烹饪区+出餐区 | 出餐速度第一 |
| 正餐 | 备菜区+烹饪区 | 品质和速度兼顾 |
| 火锅 | 切配区 | 食材量大，集中切配 |
| 茶饮 | 调配区 | 操作台流水线 |
| 烘焙 | 制作区+冷房 | 需要冷链 |

## 操作流程

### Step 1：评估现有布局

```
输入：
- 后厨平面图/尺寸
- 主要业态
- 员工数量
- 高峰出餐量
```

### Step 2：绘制理想动线

```
按照五区分离原则，绘制单向流动动线
检查点：
- 是否有交叉污染风险
- 是否有往返动线
- 各区面积配比是否合理
```

### Step 3：优化设备摆放

```
设备摆放 Checklist：
□ 灶台离油烟口近
□ 切配台靠近冰箱
□ 出餐口靠近前厅
□ 洗碗区在角落（洁污分离）
□ 员工通道够宽（至少80cm）
```

## 使用示例

### 场景：快餐店后厨优化

**用户输入**：
> 我是一家中式快餐店，后厨40平，高峰期出餐跟不上，前厅等菜等很久，经常被投诉出餐慢，后厨布局该怎么调整？

**Skill输出**：
```
## 快餐店后厨动线优化方案

### 现状分析
| 项目 | 现状 |
|------|------|
| 后厨面积 | 40㎡ |
| 员工 | 6人（午高峰） |
| 出餐量 | 150份/小时 |
| 问题 | 高峰期出餐跟不上 |

### 动线诊断
| 分区 | 现状 | 问题 |
|------|------|------|
| 收货区 | 在角落 | ✅ 位置合理 |
| 存储区 | 冷库在角落 | ✅ 符合要求 |
| 备菜区 | 在中间，和灶台远 | 🔴 往返浪费 |
| 烹饪区 | 灶台离出餐口远 | 🟡 动线交叉 |
| 出餐区 | 在最里面 | 🔴 传菜距离长 |

### 核心问题
1. **备菜区离灶台远** → 厨师来回走
2. **出餐区在角落** → 传菜路径长
3. **动线交叉** → 容易碰撞、效率低

### 优化方案

**方案1：功能区重组（推荐）**
```
改造后布局：

收货区 → 存储区 → 备菜区 → 烹饪区 → 出餐区
(角落)   (角落)    (中左)   (中右)   (靠前厅)
                              ↓
                         传菜窗口
```

**具体改动：**
1. 冷库移到后厨最角落（存储区）
2. 切配台移到冷库旁边（备菜区）
3. 灶台移到出餐口正上方（缩短传菜）
4. 增加一条备菜线（双打餐台）

**方案2：动线优化（低成本）**
```
不改设备位置，优化动线：
1. 设定单向行走路线（地上划线）
2. 减少交叉点（固定岗位动线）
3. 增加备菜量（提前预制30%）

## 专家点评（避坑提示）

**后厨动线误区**：
1. **贪大求全** → 设备堆满，动线堵死
2. **忽视排油烟** → 油烟倒灌，影响出品
3. **不预留发展空间** → 以后扩展难

**正确原则**：
- 后厨是生产系统，不是仓库
- 动线比设备更重要
- 预留20%弹性空间
