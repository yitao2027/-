# L2-word-of-mouth
# 口碑营销与裂变增长体系

**层级：** L2 专项能力  
**部门归属：** 市场营销部  
**触发词：** 口碑营销、顾客裂变、老带新、口口相传、自然增长、口碑传播、用户推荐

---

## 一、Skill 定位

**解决什么问题：**  
帮助餐饮门店构建以顾客口碑为核心驱动力的自然增长体系，减少对付费流量的依赖，实现低成本持续获客。

**核心逻辑：**
- 付费流量：买一次用一次，成本递增
- 口碑流量：一个满意顾客可带来N个新顾客，成本趋零

**适用场景：**
- 社区/街边店：依赖周边自然流量+口碑扩散
- 新店开业：快速建立本地口碑
- 品牌修复：通过口碑重建信任
- 中小餐饮：预算有限，需最高ROI的营销方式

## 二、核心方法论

### 2.1 口碑三角模型

```
        【超预期体验】
           ↗       ↖
    【传播动机】 ← 【降低传播门槛】
```

**口碑产生的三个必要条件：**
1. **超预期体验**：顾客实际感受 > 来之前的期望值（哪怕超出10%也足够）
2. **传播动机**：顾客有理由、有意愿主动告诉别人（面子感/利益驱动/情感共鸣）
3. **低传播门槛**：让顾客想传播时极易操作（一键转发/扫码分享/话题标签）

### 2.2 口碑引爆点设计

**制造"超预期时刻"（MOT升级版）：**

| 触点 | 基础体验 | 超预期设计 | 传播潜力 |
|------|---------|-----------|---------|
| 等位 | 给号等候 | 等位小食+游戏/手工活动 | ★★★ |
| 上菜 | 正常出餐 | 服务员报菜名时有趣介绍/小故事 | ★★★★ |
| 特色菜 | 普通摆盘 | 视觉冲击性摆盘/互动式上菜仪式 | ★★★★★ |
| 结账 | 扫码支付 | 意外惊喜（小礼品/神秘折扣/幸运抽奖） | ★★★★ |
| 离店 | 礼貌送客 | 记住顾客姓名/个性化告别 | ★★★★★ |

**口碑话题设计（让顾客有内容可说）：**
- 产品故事：这道菜背后有什么独特来历/故事？
- 制作工艺：有没有让人惊叹的制作过程？（现切/现做/古法）
- 极致单品：打造一个让人"非推不可"的代表作
- 品牌性格：门店有没有鲜明的态度或主张让人认同？

### 2.3 老带新裂变机制

**三种主要裂变模式：**

**① 直接推荐奖励（利益驱动）**
```
老顾客推荐新顾客首次到店
→ 老顾客获得：优惠券/积分/赠品
→ 新顾客获得：首次到店礼遇（折扣/赠品）
→ 裂变链路：老带新→新变老→再带新
```
适合：有会员体系的连锁或中大型单店

**② 拼团/聚餐码（社交裂变）**
```
顾客发起"拼桌团"邀请
→ 邀请成功达到人数享团购价
→ 适合聚餐场景：火锅/烧烤/中式宴席
→ 关键：价格优惠幅度要让顾客有面子（≥8折）
```

**③ 内容裂变（素材驱动）**
```
提供拍照打卡专属位置/道具/背景墙
→ 顾客拍照→发朋友圈/抖音/小红书
→ 主动@门店账号可获小礼品
→ 门店收集UGC内容→二次传播→更多人知道
```
适合：有视觉特色/网红元素的店铺

### 2.4 口碑维护体系

**差评处理变口碑四步法：**
```
STEP 1 快速响应（2小时内）
→ 在评论/私信中真诚回复，不推卸责任

STEP 2 私信联系
→ 请顾客留联系方式，了解详情

STEP 3 实质性补偿
→ 退款/免单/邀请重新体验（根据严重程度）

STEP 4 跟进回访
→ 补偿后3-5天回访，询问是否满意
→ 满意后自然引导更新评价（不强制）
```

**关键认知：** 处理好的差评往往比好评更能建立信任——顾客看到商家如何应对问题，往往更放心。

### 2.5 口碑传播内容矩阵

```
高情绪传播力
     ↑
     │  【四象限】
  惊喜型  │  故事型
（感官冲击）│（情感共鸣）
─────────┼─────────
  功能型  │  互动型
（实用推荐）│（参与感强）
     │
     └──────────→ 高分享意愿
```

| 象限 | 内容类型 | 案例 | 触发平台 |
|------|---------|------|---------|
| 惊喜型 | 视觉/味觉超预期 | 超大分量/创意摆盘 | 抖音/小红书 |
| 故事型 | 情感/文化/人情 | 老板故事/食材溯源 | 公众号/朋友圈 |
| 功能型 | 性价比/专业度 | 年度必点榜/减脂套餐 | 大众点评/美团 |
| 互动型 | 游戏/参与/DIY | 自制酱料/互动菜单 | 全平台 |

## 三、口碑营销执行工具

### 3.1 口碑健康度诊断表

```
【口碑营销健康度自测】（每项满分5分）

一、体验层
□ 有没有至少一个让顾客"必须拍照"的视觉亮点？（___分）
□ 服务有没有超预期的"惊喜时刻"？（___分）
□ 顾客离店时满意率是否稳定超过85%？（___分）

二、传播层
□ 有没有清晰的品牌故事或产品故事？（___分）
□ 有没有方便顾客拍照/打卡的专属位置？（___分）
□ 是否有引导顾客分享的话术或流程？（___分）

三、裂变层
□ 是否有老带新的奖励机制？（___分）
□ 是否定期收集和转发顾客UGC内容？（___分）
□ 是否有会员体系留住老顾客？（___分）

四、修复层
□ 差评响应速度是否在2小时内？（___分）
□ 差评处理满意率是否超过70%？（___分）

总分：___/55分
评级：≥45分优秀 | 35-44分良好 | 25-34分待提升 | <25分需重建
```

## 四、触发条件与输出

**输入收集：**
```
请告诉我：
1. 门店类型和主要定位？（人均消费/主营品类/位置）
2. 目前口碑/评分情况？（大众点评分/主要评价特点）
3. 有没有现有的会员体系或老顾客群？
4. 主要目标：提升传播量？提升评分？还是裂变拉新？
5. 预算范围？（赠品/优惠券成本预算）
```

**输出内容：**
- 口碑健康度诊断报告
- 超预期体验改造建议（3-5个具体改进点）
- 裂变活动方案（含老带新机制设计）
- 内容传播日历（1个月）
- 差评应对话术包（5种常见场景）
