# L2-new-store-opening：新店筹备与开业引爆

> 系统规划新店从选址确定到开业引爆的全流程，确保开业即成功

---

## 触发场景

- 马上要开新店，不知道从何准备
- 新店开业效果不好，不知道哪里出了问题
- 开过店但开业时手忙脚乱
- 想让新店开业就一炮打响
- 不知道开业前要做哪些准备工作
- 开业后流量衰减，不知道怎么破局

---

## 核心方法论

### 一、新店筹备倒计时

#### 1. 120天筹备计划

```markdown
新店筹备时间轴：

【D-120 ~ D-90天：启动期】
□ 确定开店团队（店长/厨师长/核心人员）
□ 完成选址签约
□ 启动装修设计
□ 办理证照（工商/食安/消防）
□ 制定开业计划

【D-90 ~ D-60天：筹建期】
□ 装修施工
□ 招聘启动
□ 设备采购
□ 证照办理
□ 供应链对接

【D-60 ~ D-30天：准备期】
□ 人员培训开始
□ 设备安装调试
□ 物料采购储备
□ 试菜/产品定型
□ 开业方案确定

【D-30 ~ D-7天：冲刺期】
□ 装修收尾验收
□ 全员培训完成
□ 开业前内测
□ 宣传预热启动
□ 开业物料到位

【D-7 ~ D-1天：开业前夜】
□ 全面清洁消毒
□ 设备最终调试
□ 食材到位
□ 人员定岗
□ 开业彩排

【D-Day：开业日】
□ 开业仪式
□ 全员就位
□ 执行开业活动
□ 问题即时处理
□ 复盘总结
```

#### 2. 证照办理清单

```markdown
新店证照办理顺序（必须按顺序）：

第一步：工商营业执照
- 准备：身份证/租赁合同/房屋证明
- 时间：7-15个工作日
- 费用：免费（部分地区）

第二步：食品经营许可证
- 前提：营业执照+健康证
- 准备：布局图/设备清单/制度文件
- 时间：20-30个工作日
- 费用：免费

第三步：消防验收
- 前提：装修完成
- 准备：消防图纸/施工资质
- 时间：15-20个工作日

第四步：门头审批
- 准备：效果图/营业执照
- 时间：5-10个工作日

第五步：环评备案（如需）
- 餐饮：可能需要
- 小吃/饮品：一般不需要

并行办理项：
□ 税务登记
□ 社保账户
□ 银行账户
□ 团购平台入驻
```

### 二、团队组建与培训

#### 1. 人员到位时间表

```markdown
新店人员到位节奏：

店长：D-90天（提前介入筹备）
- 参与装修监督
- 负责团队组建
- 制定运营方案

厨师长/主厨：D-60天
- 产品定型
- 厨房管理
- 厨师团队组建

前厅主管：D-45天
- 前厅服务标准
- 接待流程
- 人员排班

核心员工：D-30天
- 骨干到位
- 开始系统培训

全员到岗：D-15天
- 全员培训
- 实操演练
- 开业前准备

参考配置（100㎡中餐）：
- 店长：1人
- 厨师长：1人
- 后厨人员：4-6人
- 前厅人员：4-6人
- 合计：10-14人
```

#### 2. 新店培训计划

```markdown
开业前培训安排（D-30 ~ D-1）：

第一周：企业文化+基础规范
- 品牌故事/价值观
- 仪容仪表/行为规范
- 安全培训（消防/食安）
- 考核方式：笔试

第二周：岗位技能
- 各岗位SOP培训
- 产品知识
- 服务流程
- 考核方式：实操

第三周：模拟运营
- 全流程模拟
- 问题演练
- 突发情况处理
- 考核方式：综合模拟

第四周：开业冲刺
- 开业流程演练
- 活动方案培训
- 开业准备
- 考核方式：通关考核

培训考核标准：
- 全员必须通过理论考试（≥80分）
- 全员必须通过实操考核（≥80分）
- 关键岗位必须达到优秀（≥90分）
```

### 四、开业预热与引流

#### 1. 开业预热节奏

```markdown
开业前预热计划：

D-30 ~ D-21：种草期
- 小红书/抖音种草笔记发布
- 目标：曝光10万+
- 达人合作：本地美食达人3-5名
- 内容：探店预告/新店剧透

D-20 ~ D-14：蓄水期
- 大众点评店铺上线
- 霸王餐活动报名
- 朋友圈广告投放
- 目标：收藏+预约1000+

D-13 ~ D-7：爆发期
- 朋友圈广告集中投放
- 社群推广启动
- 老客邀约
- 目标：开业前预约满座30%

D-6 ~ D-2：冲刺期
- 最后倒计时
- 限量抢购
- 媒体/大V探店
- 目标：制造话题热度

D-1：开业前夜
- 全员动员会
- 物料最后确认
- 流程最后彩排
- 士气激励
```

#### 2. 开业活动设计

```markdown
开业活动策划框架：

活动目标（SMART）：
- 目标1：曝光量__万
- 目标2：到店客流__人
- 目标3：大众点评收藏__个
- 目标4：开业前3天营业额__万

核心活动设计：

活动一：折扣引流
- 开业前3天：7折/5折/3折（限日）
- 注意：控制折扣力度，避免过度拥挤

活动二：限量抢购
- 推出100份开业特惠套餐
- 提前线上售卖，制造稀缺感

活动三：社交裂变
- 朋友圈转发享优惠
- 拍照打卡送菜品
- 抖音发布享折扣

活动四：会员沉淀
- 开业前3天：注册会员送好礼
- 开业首周：会员专属优惠
- 目标：沉淀500+会员

配套物料：
□ 开业海报（店内+线上）
□ 引导物料（拍照点/打卡墙）
□ 会员注册物料（二维码/礼品）
□ 优惠凭证（纸质/电子）
□ 员工话术手册
```

#### 2. 开业应急处理

```markdown
开业常见问题及处理：

问题1：排队过长
处理：
- 提前发号
- 等位服务（茶水/小吃/娱乐）
- 提前告知等位时间
- 必要时限流

问题2：出菜慢
处理：
- 提前备货充足
- 简化菜单
- 必要时退单安抚
- 赠送菜品补偿

问题3：顾客投诉
处理：
- 店长第一时间处理
- 真诚道歉
- 快速解决
- 必要时免单

问题4：设备故障
处理：
- 备用设备启用
- 暂停受影响产品
- 优先保障出品
- 事后维修

问题5：突发天气
处理：
- 提前关注天气预报
- 准备外卖兜底
- 灵活调整经营策略
```

## 关联技能

- **前置技能** → L1-opening-checklist（开店筹备清单）、L1-promotion（促销活动策划）
- **配套技能** → L2-store-checkup（门店巡检）、L2-training-plan（培训体系设计）
- **支持技能** → L2-waimai-operation（外卖运营）、L2-dianping-management（大众点评运营）

---

## 使用说明

1. **提前规划**：新店筹备至少提前120天开始
2. **细节为王**：开业成功的关键是准备充分
3. **团队为本**：人是开业成功的核心
4. **节奏把控**：按计划推进，不要仓促开业
5. **持续优化**：开业只是开始，持续运营才是关键
