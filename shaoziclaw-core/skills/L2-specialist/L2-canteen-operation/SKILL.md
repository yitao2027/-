### 触发场景描述
团餐是一个万亿级市场，但运营逻辑和散客餐饮完全不同。本skill帮助理解团餐运营特点，进入这个赛道。

## 核心方法论

### 团餐市场分类

```
团餐三大场景：

1. 企业食堂
   - 写字搂/工厂食堂
   - 自营 or 外包
   - 甲方付费，员工免费吃

2. 学校食堂
   - 中小学/大学食堂
   - 承包制为主
   - 政策监管严格

3. 活动团餐
   - 会议/赛事/展会
   - 项目制
   - 临时性强
```

### 团餐vs散客餐饮

```
核心差异：

| 维度 | 团餐 | 散客餐饮 |
|------|------|----------|
| 客群 | 固定/批量 | 分散/随机 |
| 决策者 | 采购/行政/工会 | 消费者本人 |
| 口味 | 众口难调 | 个人选择 |
| 价格 | 预算内 | 自付 |
| 频次 | 每天 | 偶尔 |
| 评价 | 满意度调查 | 自主点评 |
```

### 团餐运营要点

```
团餐成功关键：

1. 客户关系（最重要）
   - 搞定甲方是关键
   - 拍板人：行政/采购/工会
   - 使用者：员工/学生

2. 标准化能力
   - 出品稳定，大批量
   - 出餐快，时间集中
   - 成本可控

3. 供应链能力
   - 集中采购降低成本
   - 配送准时
   - 食品安全

4. 应急能力
   - 出问题能兜底
   - 备餐充足
   - 投诉处理快
```

## 操作流程

### Step 1：评估是否适合

```
适合做团餐的情况：
✓ 有批量出品能力
✓ 有稳定供应链
✓ 有客户关系资源
✓ 能接受账期
✓ 能接受价格竞争

不适合的情况：
✗ 规模太小
✗ 产品不适合大批量
✗ 现金流紧张
```

### Step 2：寻找客户

```
客户来源：
- 招标平台（阿里巴巴政务云等）
- 同行转介绍
- 主动拜访（写字楼/工厂）
- 招标代理
```

### Step 3：投标/报价

```
报价要素：
- 餐标（元/人/餐）
- 用餐人数（固定 or 浮动）
- 餐次（早/中/晚）
- 服务费
- 合同期
```

## 使用示例

### 场景：企业团餐投标

**用户输入**：
> 我是一家餐饮公司，想投标一个500人企业的食堂外包，月餐标20元/人，提供午餐，中标后签约2年，应该怎么准备？

**Skill输出**：
```
## 企业团餐投标方案

### 一、项目概况
| 项目 | 内容 |
|------|------|
| 客户类型 | 科技公司 |
| 人数 | 500人 |
| 餐标 | ¥20/人 |
| 餐次 | 午餐 |
| 服务期 | 2年 |
| 年营收预估 | ¥20×500×22×12=¥264万 |

### 二、投标准备

#### 资质准备
| 资质 | 要求 | 我方情况 |
|------|------|----------|
| 食品经营许可证 | 必须 | ✓ |
| 团餐运营资质 | 加分 | ✓ |
| ISO认证 | 加分 | 需办理 |
| 食品安全认证 | 加分 | 需办理 |

#### 方案准备
```
投标文件核心内容：
1. 公司介绍（资质/案例/团队）
2. 菜品方案（菜单设计）
3. 服务方案（流程/标准）
4. 卫生保障方案
5. 应急预案
6. 报价单
```

### 三、报价测算

#### 成本测算
| 成本项 | 单价 | 备注 |
|--------|------|------|
| 食材成本 | ¥8.5 | 42.5% |
| 人工成本 | ¥4 | 20% |
| 能源/耗材 | ¥1.5 | 7.5% |
| 管理费 | ¥2 | 10% |
| 税费 | ¥1.5 | 7.5% |
| 利润 | ¥2.5 | 12.5% |
| **合计** | **¥20** | |

#### 报价策略
| 策略 | 适用情况 | 风险 |
|------|----------|------|
| 低价抢标 | 急需业绩/树立案例 | 亏损风险 |
| 合理报价 | 正常情况 | 利润一般 |
| 高价保质 | 品质竞争 | 可能不中标 |

### 四、中标关键

**评标权重（通常）：**
| 维度 | 权重 | 关键点 |
|------|------|--------|
| 价格 | 30-40% | 不能最高 |
| 方案 | 30-40% | 差异化/专业性 |
| 资质 | 10-20% | 证书/案例 |
| 服务承诺 | 10-20% | 响应速度/应急 |

**加分项：**
- 类似项目经验
- 食品安全认证
- 信息化系统（扫码点餐等）
- 特色服务（营养分析等）

### 五、合同关键条款

| 条款 | 注意事项 |
|------|----------|
| 餐标调整 | 约定食材涨价时的调价机制 |
| 人数变动 | 约定浮动比例和结算方式 |
| 账期 | 通常月结30天 |
| 违约责任 | 食品安全事故的界定和处理 |
| 退出机制 | 提前多久通知 |

### 六、运营建议

**中标后关键动作：**
1. **客户关系维护**
   - 每月满意度调查
   - 重要节日福利活动
   - 及时响应投诉

2. **出品稳定**
   - 菜单提前沟通
   - 定期更换菜品
   - 特殊日期（节日/生日）关怀

3. **风险管理**
   - 食品安全是底线
   - 应急备餐
   - 备用供应商
```

## 专家点评（避坑提示）

**团餐误区**：
1. **以为简单** → 众口难调，投诉多
2. **账期长** → 回款压力大
3. **价格战** → 低利润甚至亏损

**正确姿势**：
- 团餐靠关系和口碑，不是价格
- 账期至少1个月，预留资金
- 食品安全是生命线，出一次事就完了
