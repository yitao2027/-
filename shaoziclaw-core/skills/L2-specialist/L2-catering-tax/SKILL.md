### 触发场景描述
餐饮行业税负较重，合理的税务筹划可以合法降低税负。本skill帮助餐饮老板了解税务知识，做好税务规划。

## 核心方法论

### 餐饮主要税种

```
餐饮企业主要税种：

1. 增值税
   - 小规模纳税人：3%（优惠1%）
   - 一般纳税人：6%
   - 进项税可抵扣

2. 企业所得税
   - 基本税率：25%
   - 小微优惠：5%/10%/20%
   - 优惠条件：年利润<300万

3. 个人所得税
   - 工资薪金：3-45%累进
   - 股东分红：20%

4. 附加税
   - 城建税：增值税×7%/5%/1%
   - 教育费附加：增值税×3%
   - 地方教育附加：增值税×2%
```

### 餐饮税务优惠

```
优惠政策：

1. 小规模纳税人优惠
   - 月销售额<10万：免增值税
   - 优惠税率1%（原3%）

2. 小微企业优惠
   - 年利润<100万：2.5%
   - 100-300万：10%
   - 300万以上：25%

3. 疫情优惠（延续政策）
   - 困难行业减免
   - 社保缓缴
```

### 成本发票管理

```
餐饮常见成本发票：

| 成本项 | 发票类型 | 可抵扣 | 备注 |
|--------|----------|--------|------|
| 食材采购 | 增值税专票 | ✓ | 一般纳税人可抵 |
| 房租 | 增值税专票 | ✓ | 进项10%/9% |
| 水电 | 增值税专票 | ✓ | 进项13% |
| 设备 | 增值税专票 | ✓ | 进项13% |
| 装修 | 增值税专票 | ✓ | 进项9% |
| 办公用品 | 增值税专票 | ✓ | 进项13% |
| 差旅 | 专票/火车票/机票 | ✓ | 进项有限 |
| 餐费 | 普通发票 | ✗ | 不可抵扣 |
```

### 税务筹划技巧

```
合法节税方法：

1. 供应商选择
   - 选择能开专票的供应商
   - 集采获得更好税点

2. 组织架构优化
   - 总部和门店分立
   - 分子公司享受小微优惠
   - 灵活用工降低社保

3. 员工结构优化
   - 灵活用工（兼职/外包）
   - 股权激励代替工资

4. 费用合规化
   - 报销凭证完整
   - 分摊合理
   - 不买发票
```

## 操作流程

### Step 1：评估税负现状

```
税负评估：
□ 毛利率
□ 各项成本占比
□ 发票获取情况
□ 税负率（税金/营收）
```

### Step 2：识别筹划空间

```
筹划点识别：
□ 供应商是否都能开专票
□ 人员结构是否合理
□ 费用报销是否规范
□ 组织架构是否最优
```

### Step 3：制定筹划方案

```
方案设计：
□ 供应商优化
□ 人员结构调整
□ 费用合规化
□ 组织架构调整
□ 税收优惠申请
```

### Step 4：执行与跟踪

```
执行要点：
□ 培训财务人员
□ 规范报销流程
□ 定期税负分析
□ 及时享受优惠
```

## 使用示例

### 场景：小微餐饮税务筹划

**用户输入**：
> 我是一家小餐饮店，小规模纳税人，月营收20万左右，税务方面怎么规划能省点钱？

**Skill输出**：
```
## 小餐饮店税务筹划方案

### 一、现状分析
| 项目 | 数值 |
|------|------|
| 性质 | 小规模纳税人 |
| 月营收 | ¥200,000 |
| 年营收 | ¥2,400,000 |
| 毛利率 | 60% |

### 二、当前税负

**小规模纳税人税负：**
| 税种 | 税率 | 年税额估算 |
|------|------|------------|
| 增值税 | 1%（优惠） | ¥24,000 |
| 附加税 | 12%附加 | ¥2,880 |
| 企业所得税 | 2.5%（小微） | ¥9,000（利润约36万） |
| **合计** | | **¥35,880** |

### 三、筹划空间

| 筹划点 | 说明 | 潜在收益 |
|--------|------|----------|
| 供应商优化 | 选择能开专票的供应商 | ¥5,000-10,000/年 |
| 费用合规化 | 规范报销，获取合规发票 | ¥2,000-5,000/年 |
| 优惠政策申请 | 应享尽享小微优惠 | ¥0（已是最低） |
| 季度申报优化 | 避免收入波动导致优惠中断 | ¥0 |

### 四、具体方案

#### 方案1：供应商优化（最重要）

**问题：** 食材采购多来自农贸市场/个人，无法取得发票

**解决：**
| 采购渠道 | 可获发票 | 建议 |
|----------|----------|------|
| 农贸市场 | 免税，无法开票 | 改变不了，接受 |
| 超市 | 可开普通票 | 尽量索取 |
| 配送公司 | 可开专票（需一般纳税人） | 优先选择 |
| 品牌供应商 | 可开专票 | 核心食材选品牌 |

**收益：** 虽然小规模不能抵扣专票，但：
- 发票可作为成本凭证
- 规范经营降低风险

#### 方案2：月销售额控制

**注意：小规模月销售额<10万免增值税**

```
你的情况：月20万 > 10万，无法享受免税

建议：
- 如果某月低于10万，尽量凑到10万以上（免了也是10万）
- 避免大幅波动，保持稳定
```

#### 方案3：成本费用规范

**可取得的合规发票：**
| 费用项 | 能否取得 | 建议 |
|--------|----------|------|
| 食材 | 部分可取 | 尽量从公司采购 |
| 房租 | 必须有 | 检查合同+发票 |
| 水电 | 必须有 | 检查发票 |
| 设备维修 | 必须有 | 找有资质的公司 |
| 办公用品 | 可取 | 京东/天猫采购 |

#### 方案4：人员结构优化

**员工社保筹划：**
| 方案 | 适用情况 | 注意事项 |
|------|----------|----------|
| 全职员工 | 核心员工 | 必须缴纳 |
| 灵活用工 | 兼职/小时工 | 可不缴社保 |
| 外包 | 非核心岗位 | 成本略高但省心 |

### 五、预期效果

| 措施 | 节省税额 | 实施难度 |
|------|----------|----------|
| 供应商优化 | ¥3,000-5,000 | 中 |
| 费用规范 | ¥1,000-2,000 | 低 |
| 季度均衡 | ¥0（防风险） | 低 |
| **合计** | **¥4,000-7,000/年** | |

### 六、提醒

**合法合规红线：**
- ❌ 买发票（违法）
- ❌ 虚列成本（违法）
- ❌ 隐匿收入（违法）
- ✅ 合理规划供应商
- ✅ 规范报销流程
- ✅ 享受应有优惠

**建议：**
1. 找一个靠谱的会计或代账公司
2. 每季度和会计复盘税负情况
3. 遇到不确定的，咨询专业税务师
```

## 专家点评（避坑提示）

**税务误区**：
1. **买发票** → 违法，风险巨大
2. **两套账** → 越来越难，迟早出事
3. **不懂政策** → 该享的优惠没享

**正确姿势**：
- 合规是底线，合法是原则
- 找专业会计，省小钱亏大钱
- 享受该有的优惠，不要白不要
