## 一、Skill 定位

**解决什么问题：**  
专门帮助新茶饮品类经营者解决品类独有挑战，包括高竞争环境下的产品差异化、出杯效率优化、原料成本管控和小程序/外卖双线运营。

**新茶饮品类核心特征：**
- 竞争极度白热化（头部品牌低至9.9元）
- 顾客复购频率高（可达每周1-3次）
- 高峰出杯压力大（排队体验影响口碑）
- 食材新鲜度要求高（当日制作/有效期短）
- 年轻客群主导（颜值+社交传播权重高）

## 二、核心方法论

### 2.1 新茶饮成本结构

```
新茶饮典型成本结构（以中端品牌为例，客单15-25元）：

原料成本：25-35%（行业均值约28%）
├── 茶底（茶叶/茶粉）：3-5%
├── 奶制品（鲜奶/奶油/芝士）：8-12%
├── 水果/小料（珍珠/布丁/椰果）：8-12%
└── 杯/封口膜/吸管/袋：2-4%

人力成本：20-28%（出杯效率是核心）
房租：15-25%（茶饮对位置依赖极强）
其他：5-8%
综合成本率：65-85%
净利润：15-35%（优秀门店≥25%）

关键认知：
- 茶饮利润率看起来高，但极度依赖高翻杯率
- 门店坪效=日出杯数×客单价÷面积
- 控制原料浪费是最直接的成本优化路径
```

### 2.2 出杯效率优化（核心运营指标）

```
出杯效率计算：
单店日出杯数 ÷ 营业时间（小时） = 时均出杯数

各规模参考基准：
- 小店（2-3人）：时均出杯 20-40杯（高峰期）
- 中等门店（3-5人）：时均出杯 40-70杯
- 旗舰店（5+人）：时均出杯 70-100杯+

出杯效率提升四要素：

① 动线设计
→ 操作区按「拿杯→制茶→加料→封口→出单」流线布局
→ 常用原料在伸手可及范围内（不要转身超过90°）
→ 备料区 vs 制作区分离（减少动线交叉）

② 人员分工
→ 高峰期明确岗位（收银1人/制作1-2人/备料1人/出单1人）
→ 兼岗要提前演练，不是随机指派

③ 预制前置
→ 高频小料（珍珠/椰果）提前煮好并标注时间
→ 茶底提前萃取好备用（茶底有效时长：2-4小时）
→ 水果提前切好备用量（按历史销量备1-2小时用量）

④ 设备效率
→ 封口机数量：≥高峰时均出杯数÷30（每台每分钟约封30杯）
→ 制冰机：日出冰量是否够用（冰块消耗约=日出杯数×200g）
→ 榨汁机/破壁机：按高峰出杯速度选配置
```

### 2.3 新茶饮产品结构设计

**新茶饮菜单黄金结构：**

```
菜单层次（以25款SKU为例）：

★★★★★ 引流款（3-5款）
→ 价格低（9.9-12元），高颜值，主打引流拉新
→ 运营逻辑：用低价引来新客，让新客爱上门店

★★★★ 主力款（8-12款）  
→ 价格中位（15-22元），稳定销量，贡献主要营收
→ 要求：口味有辨识度，不能轻易被模仿

★★★ 利润款（5-8款）
→ 价格偏高（22-35元），原料成本可控，拉高客单价
→ 产品逻辑：高端原料（进口奶油/稀有水果）做卖点

★★ 季节限定款（2-4款）
→ 限时上市，制造稀缺感和话题性
→ 不要求长期稳定销量，要求有传播效果
```

### 2.4 原料管理与新鲜度控制

```
新茶饮原料保质期管理（参考）：

┌──────────────────────────────────────────────┐
│原料类型    │存储方式│制备后有效期│使用完毕规则 │
│────────────┼───────┼─────────┼────────────│
│鲜奶        │冷藏    │开封后24h  │每日盘点用量  │
│鲜切水果    │冷藏    │切后4h     │超时必须丢弃  │
│煮好珍珠    │常温保温│4-6h       │超时弃用      │
│茶底（冲泡）│室温/冷藏│4h（室温）/│每批标注时间  │
│            │        │12h（冷藏）│              │
│芝士奶盖    │冷藏    │打发后2h   │新鲜打发为佳  │
│开封椰果    │冷藏    │3天内用完  │标注开封日期  │
└──────────────────────────────────────────────┘

强制执行原则：
❶ 所有自制原料必须标注「制备时间+有效期」
❷ 超过有效期的原料立即弃用，无论数量多少
❸ 每日盘点原料用量，提前备料避免断货/过量备料

每日损耗控制目标：
- 水果损耗率：≤5%（切丢/过期）
- 奶制品损耗：≤3%
- 茶底损耗：≤5%
```

### 2.5 小程序/外卖双线运营

```
线上运营双引擎：

① 品牌小程序（私域沉淀）
→ 目的：建立私域会员，减少外卖平台费率（约20%）
→ 关键数据：小程序月活用户数/会员复购率/自取比例
→ 拉取小程序订单的方式：
   - 扫码点单比外卖便宜（专属价）
   - 积分兑换体系（消费1元=1积分，100积分换免费小料）
   - 生日礼遇（生日当月专属优惠）

② 外卖平台（流量引入）
→ 美团/饿了么 作为新客获取渠道
→ 外卖专属产品：比堂食稍简（减少复杂配置，提升出杯速度）
→ 外卖定价：可比堂食高1-2元（含包装成本）
→ 外卖包装重点：防洒/保温/杯盖牢固

线上线下联动策略：
- 堂食→引导关注小程序（现场福利：+1元多一份小料）
- 外卖→包裹内放引流卡（扫码关注送下单券）
- 小程序→推出"自取优先通道"（减等待，提体验）
```

### 2.6 新茶饮选址核心逻辑

```
新茶饮选址五大核心要素（不同于正餐逻辑）：

① 人流量（权重40%）
→ 必须有稳定高密度人流（写字楼/学校/商场/地铁口）
→ 目标：门店前过客流量≥5000人/天（工作日）

② 竞品密度（权重25%）
→ 方圆200米内同类竞品数量
→ 超过5家同类品牌：极高竞争，慎入
→ 竞品密集≠不能做，但需要有明确差异化

③ 面积效率（权重15%）
→ 茶饮门店面积：20-50㎡最优（兼顾成本和运营）
→ 面积太大=房租压力大；太小=出杯能力受限

④ 租金房租比（权重10%）
→ 月租金 ÷ 预期月营业额 ≤ 20%（茶饮可以略高于正餐）
→ 超过25%=高风险

⑤ 政策合规（权重10%）
→ 确认可以开食品加工证照
→ 确认门牌/广告位是否允许
→ 排水/通风/电力是否满足需求
```
