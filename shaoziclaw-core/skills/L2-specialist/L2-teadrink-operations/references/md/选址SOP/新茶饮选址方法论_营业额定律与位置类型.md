## 三、选址核心公式

### 营业额预估公式
```
月营业额 = 客流量 × 客单价 × 30天 × 转化率
```

**实际应用示例：**
- 位置：县城商业街拐角
- 日均有效客流：500人（下午4-10点）
- 进店转化率：8%（40人进店）
- 客单价：18元
- 日营业额：40 × 18 = 720元
- 月营业额：720 × 30 = 21,600元 → **低于保本线（14万），风险极高**

### 租金占比法则
- **健康线：租金占营业额 ≤ 20%**
- **警戒线：租金占营业额 ≥ 25%**（三四月淡季+平台抽佣=利润归零）
- **极端风险：租金 > 营业额的30%** → 实质是给房东打工

### 保本点计算
```
月保本营业额 = 月固定成本 ÷ (1 - 毛利率)
```

**示例（古茗模型）：**
- 月固定成本（租金+人工+水电）= 5.35万元
- 毛利率 = 50%
- 保本营业额 = 5.35万 ÷ 0.5 = **10.7万元/月**
- 实际月流水22万 → 安全边际 = 22-10.7 = 11.3万（充足）

## 四、好店位置类型（优先级排序）

### 顶级位置（优先选择）
1. **核心商场美食区**（奶茶聚集地，品类互补）
2. **写字楼/商圈拐角**（白领刚需，午餐+下午茶双时段）
3. **大学城核心区域**（年轻人集中，性价比敏感）

### 优质位置（次选）
4. **社区商业街**（稳定复购，租金可控）
5. **地铁站出口50米内**（高人流，但租金高）
6. **网红打卡地附近**（自然流量，但要评估季节性）

### 避开位置（慎重）
- 二楼以上无电梯
- 同类奶茶店3家以内无差异化空间
- 人口稀疏的新开发区（养店周期长）
- 租金超过营业额25%的任何位置

## 五、选址自检清单（开店前必查）

### 基础数据收集
- [ ] 蹲守3天，分时段（早/中/晚/夜宵）数人流
- [ ] 统计周边500米内奶茶/茶饮店数量和客单价
- [ ] 计算本位置预估营业额 vs 保本点
- [ ] 确认租金占比（≤20%为健康）

### 竞争力评估
- [ ] 与最近奶茶店的差异化空间
- [ ] 本位置的自然客流来源（学生/白领/居民/游客）
- [ ] 是否有线上曝光优势（美团/小红书自然流量）

### 财务安全评估
- [ ] 租金/月 vs 预估月营业额 → 占比≤20%
- [ ] 设备+装修+首批物料投入预算
- [ ] 预留3个月运营流动资金
- [ ] 计划回本周期 vs 行业均值（13-21个月）
