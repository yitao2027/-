# 新茶饮 · 私域运营方法论

> **来源**：晏涛三寿/人人都是产品经理（2024-03-04）  
> **品牌案例**：古茗（3600万会员、万店规模、2024年冲击IPO）  
> **入库时间**：2026-03-29  
> **可执行程度**：★★★★★（古茗已验证）

---

## 一、引流矩阵（线上+线下全渠道）

### 线下门店引流
- **店员主动引导**：结账时引导顾客加群，领"30元券包"
- **物料布设**：饮品杯旁放社群入口海报，扫码即入
- **关键动作**：员工话术培训到位，每次结账必引导

### 私域平台引流
| 渠道 | 入口位置 | 钩子 |
|------|---------|------|
| 公众号 | 关注后自动回复 | 30元券包+门店企微 |
| 小程序 | 首页+点单页 | 入群领30元礼包 |
| 企微 | 个人号+社群 | 福利发放 |

### 公域平台引流
- **抖音**：首页→粉丝群/团购页面
- **视频号**：首页→添加企微入口
- **小红书/微博**：新品抽奖+互动活动→转化到店

## 二、私域IP打造（企微福利官）

| 要素 | 设置 |
|------|------|
| 名称 | 古茗福利官-XX（如"大树"） |
| 头像 | 品牌Logo |
| 定位 | 福利发放官（不发生活内容） |
| 欢迎语 | 自动发社群链接，强调"社群专享" |
| 朋友圈 | 每日1条（新品+福利为主）|

> **注意**：古茗的IP偏功能性，缺乏生活化内容，互动感弱——这是可以优化的点。

## 三、社群运营SOP（每周7天）

| 日期 | 主题 | 活动内容 | 目的 |
|------|------|---------|------|
| 周一 | 开工日 | 领17元券包 | 召回周末流失用户 |
| 周二 | 积分日 | 10积分抢1元奶茶 | 促进积分消耗+拉新 |
| 周三 | 会员日 | 多款饮品9.9元任选 | 提升复购 |
| 周四 | 新品日 | 猜新品赢免单 | 新品预热+互动 |
| 周五 | 抽奖日 | 抽奖活动 | 提升活跃度 |
| 周六 | 领好券 | 指定饮品9.9元券 | 周末到店转化 |
| 周日 | 福利日 | 积分加倍/专属折扣 | 提升忠诚度 |

## 四、会员体系（8级成长制）

### 等级设计
```
V1(9活力值) → V2 → V3 → V4 → V5 → V6 → V7 → V8(2000+活力值)
```

### 活力值规则
- **获取**：消费1元 = 1活力值（累计升级）
- **消耗**：积分兑换优惠券/折扣

### V8顶级会员权益
1. 积分加速（1:2，即消费1元得2积分）
2. 会员日买一送一
3. 专享新品优先体验

## 五、裂变玩法

| 玩法 | 机制 | 效果 |
|------|------|------|
| 猜新品赢免单 | 周四社群互动，猜中免单 | 新品预热+社群活跃 |
| 积分抢购 | 周二10积分抢1元奶茶 | 积分消耗+拉新 |
| 抽奖活动 | 周五抽奖 | 提升参与感 |

## 六、门店私域联动机制

```
门店引流 → 企微沉淀 → 社群运营 → 会员体系 → 复购转化
    ↑                                              ↓
    └───────────── 数据互通（小程度） ←────────────┘
```

- **每店独立社群**：社群名=古茗+门店名+福利群（如"古茗·拱墅金茂悦店福利群2"）
- **地推+线上转化**：线下引导扫码，线上社群运营
- **数据打通**：小程序会员体系与门店消费数据互通

## 七、可复用的执行清单（适合中小茶饮品牌）

### 第一步：建基础设施
- [ ] 申请企业微信（个人微信也可以起步）
- [ ] 设计"XX品牌福利官"IP（名称+头像+欢迎语）
- [ ] 制作社群入口海报（放在收银台/饮品杯旁）
- [ ] 设置公众号/小程序入群路径

### 第二步：设计引流钩子
- [ ] 设计30元/20元/10元券包（阶梯式）
- [ ] 写引导话术（员工培训用）
- [ ] 制定社群入群活码（避免个人号满员）

### 第三步：制定社群SOP
- [ ] 按上表制定7天活动日历
- [ ] 准备好每种活动的物料（图片/文案/小程序链接）
- [ ] 设置群公告（价值说明+禁止规则）

### 第四步：会员体系建设
- [ ] 设计会员等级（3-5级即可，不用太多）
- [ ] 设置积分规则（消费1元=N积分）
- [ ] 准备各等级权益（折扣/赠品/优先体验）

## 八、古茗踩过的坑（可借鉴）

| 问题 | 教训 |
|------|------|
| IP太功能性 | 福利官缺少生活化内容，互动感弱 |
| 内容太促销 | 社群内容以优惠为主，缺乏品牌故事和用户UGC |
| 裂变常规 | 没有大规模病毒式传播 |
