# 案例07：80万蜜雪冰城转让费——县城选址深层拆解

## 基本信息
- **来源**：勇哥/BV1grQ1BCEz3（3932字转录）
- **咨询者**：安徽合肥，想接手大学旁蜜雪冰城
- **核心问题**：转让费80万值不值

---

## 案例核心数据

### 转让标的（安徽合肥某大学旁）
| 项目 | 数据 |
|------|------|
| 转让费 | 80万（含半年房租+保证金+仓库货） |
| 店铺面积 | 30多㎡ |
| 总投入 | 实际成本约35万（装修+设备+加盟），转让费另加45万 |
| 去年营业额 | 约190万（实际到手155万） |
| 日均营业额 | ~4000元 |
| 毛利率 | 声称55%，勇哥判断最多45% |
| 外卖占比 | 75%（堂食仅25%） |
| 人工 | 4人×3500=1.4万 |
| 水电 | 4000/月 |
| 月净利 | 约3-4万 |

### 转让原因
- 合同是朋友签的（咨询者无资质加盟）
- 朋友有多家店，这家不想要了
- **新情报**：旁边大学4月新开一家蜜雪

---

## 勇哥选址现场核查

### 位置分析
- **位置**：合肥郊区，大学旁边
- **人流情况**：
  - 两个大社区背后，周围无底商
  - 唯一商业在直线1.5公里外
  - 大学大门朝向另一边，步行过来700-800米
  - 学生中午几乎不出来 → **只能做外卖**
- **竞品情况**：
  - 周边已有多个奶茶品牌（蜜雪/古茗/茶百道等）
  - 学校内有商业（去年新开超市+今年4月新开蜜雪）
  - **学校蜜雪把机会让给朋友？→ 朋友不要 → 说明不挣钱**

### 数据质疑
| 项目 | 咨询者说 | 勇哥判断 |
|------|---------|---------|
| 毛利率 | 55% | 最多45%（外卖平台扣点） |
| 实际日流水 | 4000 | 3000-3500更合理 |
| 市场产能 | 够大 | 越来越差，周边商业只会更多 |

---

## 勇哥核心判断

### 80万值不值？
**不值。原因：**
1. 80万可以在其他房租便宜的地方开2-3家
2. **市场在萎缩**：周边竞品越来越多，学校内部也有蜜雪
3. **外卖撑不起利润**：75%外卖=高平台扣点=低净利
4. **合同隐患**：朋友转让，你没有加盟资质，风险极大

### 超级酱幕（高位接盘侠）识别
> "有很大一批这种超级酱幕——不管是什么必胜、古茗、茶百道——他们都往外甩，都在找冤种，都在找高位接盘侠"

勇哥对咨询者的评价：
> "你是今天我见过的所有人里最冷静的，你今天来之前心里面大概已经有结论了，你只是来见见我"

## 核心教训

### 转让接手判断三问
1. **为什么要转？** 合同问题/不挣钱/高位套现
2. **数据是否真实？** 毛利率/外卖占比/平台扣点
3. **未来市场如何？** 竞品进入/消费趋势/内部商业变化

### 蜜雪冰城接手特别警告
- **资质问题**：加盟合同能否变更/转让
- **数据水分**：外卖占比高→实际净利比账面低
- **未来竞争**：大品牌区域加密→利润压缩
- **转让费陷阱**：转让费≠店铺价值，是溢价支付
