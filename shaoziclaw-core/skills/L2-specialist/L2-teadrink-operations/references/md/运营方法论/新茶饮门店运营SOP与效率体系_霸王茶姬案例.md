## 新茶饮门店标准SOP框架

### 开店前SOP（每日）
```
□ 检查设备（制冰机、冰箱、调饮机）是否正常
□ 核对食材库存，补充当日需求量
□ 检查各食材保质期，清除隔夜或过期原料
□ 准备当日外卖平台商品上架状态
□ 培训兼职员工（高峰期操作要点）
□ 确认当日营业时间、人员排班
```

### 出杯SOP（标准流程）
```
接单 → 核单（再次确认杯型/温度/糖度）→ 
取杯打标 → 按配方出料 → 封口 → 
质检（重量/外观）→ 出杯
标准时长：60-120秒/杯（人工），6-8秒/杯（智能设备）
```

### 品控关键节点
1. **食材验收**：每批次检查新鲜度+重量，拒收不达标
2. **配方执行**：严格按克数称量，不目测
3. **出品自检**：封口前检查颜色/浓度/珍珠量
4. **顾客反馈**：差评24小时内定位问题

### 关店SOP（每日）
```
□ 关闭外卖平台接单
□ 统计当日销量，记录高频问题
□ 清洗设备（制冰机每周深清一次）
□ 盘点剩余食材，预估明日备货量
□ 关闭冷链设备（冰箱除外）
□ 清洁卫生达标后离店
```

## 新茶饮品控三大死穴

### 死穴1：食材管理失控
- **表现**：珍珠煮好超过4小时继续用，水果切开超时不废弃
- **后果**：顾客反馈口感差，差评累积
- **解法**：设定每类食材"使用时限贴纸"，超时强制废弃

### 死穴2：高峰期抢速不抢质
- **表现**：排长队时为了出杯更快，配料开始目测
- **后果**：同一产品不同时间口味差异大，复购率下降
- **解法**：备配料预制化（底料预先称好），高峰前准备充足

### 死穴3：兼职操作失误
- **表现**：兼职员工配方记忆不准确，出品失标
- **后果**：高峰期差评集中
- **解法**：兼职只做简单工种（封口/贴标/取杯），复杂配方由全职操作
