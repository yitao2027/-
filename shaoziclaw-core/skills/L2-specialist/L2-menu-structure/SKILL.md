# 菜单结构诊断 SKILL

## Skill 元信息

**名称**：L2-menu-structure
**分类**：L2 专项能力 · 市场部
**级别**：中级 · 菜单专家
**版本**：1.0
**触发词**：「菜单诊断」「菜单结构」「菜品优化」「菜单分析」「菜品调整」「菜单升级」「砍菜品」「加菜品」

---

## 触发场景

当用户需要对现有菜单进行诊断、识别滞销菜品、设计优化方案、或为新品上市调整菜单结构时，启用此 Skill。

---

## 输入

- 业态类型
- 菜单结构（菜品列表+月销量+毛利率）
- 目标：提升营业额 / 提升利润 / 降低运营复杂度 / 精简菜单
- 门店规模：单店 / 连锁

---

## 工作流程

### Step 1：菜品分类与ABC分析

```
【ABC分类法】

A类菜品（贡献主力）：
- 占菜单10-20%的菜品
- 贡献50-60%的营业额
- 必须保留，持续优化

B类菜品（补充选择）：
- 占菜单30-40%的菜品
- 贡献20-30%的营业额
- 分析是否可升级为A类

C类菜品（待评估）：
- 占菜单40-50%的菜品
- 贡献10-20%的营业额
- 重点分析是否下架

【菜品分析数据表】
品名 | 月销量 | 销售额 | 毛利率 | 销售额占比 | 综合贡献 | ABC分类
─────────────────────────────────────────────────────────────────
[菜品A] | [X]份 | [Y]元 | [%] | [%] | [综合分] | A
[菜品B] | ... | ... | ... | ... | ... | B
[菜品C] | ... | ... | ... | ... | ... | C
```

### Step 2：菜品四象限分析

```
【菜品四象限分析矩阵】

                  高销量
                    △
                    │
   ┌────────────────┼────────────────┐
   │    明星菜品     │    问题菜品     │
   │ 高销量/高毛利  │ 高销量/低毛利  │
   │ 重点：优化毛利  │ 重点：提价/降成本│
   ├────────────────┼────────────────┤
   │    淘汰菜品     │   潜力菜品     │
   │ 低销量/低毛利  │ 低销量/高毛利  │
   │ 重点：下架     │ 重点：推广升级  │
   └────────────────┼────────────────┘
                    │
                  低销量
        低毛利 ◁━━━━━━━━━▷ 高毛利
```

| 象限 | 策略 |
|------|------|
| 明星（高销高毛）| 重点保护，持续优化，做成招牌 |
| 问题（高销低毛）| 提价或降成本，或作为引流牺牲 |
| 淘汰（低销低毛）| 下架，减少SKU |
| 潜力（低销高毛）| 加强推荐，可能是下一个爆款 |

### Step 3：菜单结构诊断

```
【菜单结构健康度评估】

□ 菜品数量：是否过多（顾客选择困难）？
□ 品类覆盖：是否覆盖主食/小吃/饮品/甜点？
□ 价格带：是否覆盖引流/主力/利润三档？
□ 季节性：是否有过季菜品未更新？
□ 组合逻辑：招牌/套餐/小菜/饮品结构是否清晰？
□ 呈现顺序：招牌是否在菜单前1/3处？
□ 毛利均衡：是否存在整体毛利偏低的风险？
□ 操作复杂度：复杂菜品是否过多，影响出餐效率？
```

### Step 4：菜单优化方案

```
【优化原则】
□ 保留A类：明星菜品，做强不做多
□ 升级B类：有机会的B类菜品，做推广或提价
□ 下架C类：无销量无毛利的菜品果断下架
□ 补位新品：按品类缺口补充新品
□ 控制总量：快餐≤30道，正餐≤50道

【菜单调整决策表】
菜品 | 当前销量 | 当前毛利 | 综合评分 | 决策
────────────────────────────────────────────────
[品A] | 高 | 高 | ★★★★★ | 保留，升级
[品B] | 高 | 低 | ★★★☆☆ | 提价/换配方
[品C] | 低 | 高 | ★★★☆☆ | 加强推荐
[品D] | 低 | 低 | ★☆☆☆☆ | 下架
```

## 核心方法论

### 菜单工程学（Menu Engineering）

```
销售指数 = 菜品销量 ÷ 平均销量
利润指数 = 菜品毛利 ÷ 平均毛利

高销高利 → 明星（保护）
高销低利 → 问题（提价/降成本）
低销高利 → 潜力（推广）
低销低利 → 淘汰（下架）
```

### 菜单黄金结构

- 引流菜（1-2道，价格最低，吸引进店）
- 主力菜（5-8道，价格中位，贡献主力营业额）
- 利润菜（2-3道，价格较高，贡献主要利润）
- 特色菜（1-2道，有故事有差异化，建立品牌记忆）
