## Skill 元信息

**名称**：L2-training-plan
**分类**：L2 专项能力 · 人力资源部
**级别**：中级 · 培训专家
**版本**：1.0
**触发词**：「培训体系」「员工培训」「新员工培训」「店长培训」「培训课程」「培训计划」「培训手册」「人才培养」「晋升培训」

---

## 触发场景

当用户需要建立培训体系、设计培训课程、制定新员工培训计划、或解决员工培训效果差的问题时，启用此 Skill。

---

## 输入

- 品牌规模：单店 / 2-10店 / 10店以上
- 培训对象：全员 / 店长 / 厨师 / 服务员 / 兼职
- 培训目的：入职培训 / 在岗提升 / 晋升培训 / 标准化复制

---

## 工作流程

### Step 1：培训体系框架设计

```
【三级培训体系】

第一级：入职培训（新员工）
目标：了解品牌，融入团队，掌握基础操作
时长：3-7天
内容：品牌文化→产品知识→服务标准→安全规范

第二级：在岗培训（在职员工）
目标：持续提升，解决实际问题
时长：每月固定培训日（2-4小时）
内容：SOP复训→问题反馈→技能提升→案例分享

第三级：晋升培训（储备干部）
目标：培养店长/厨师长等管理人才
时长：集中培训+门店实习（1-3个月）
内容：管理技能→数据分析→团队领导→危机处理
```

### Step 2：新员工培训设计

```
【新员工7天培训计划】

Day 1：入职与融入
□ 欢迎仪式，介绍团队
□ 品牌故事与文化
□ 门店基本规矩
□ 发放工服/工牌
□ 分配带教师傅

Day 2-3：产品知识
□ 菜单结构讲解
□ 核心菜品知识
□ 产品制作观摩
□ 食品安全基础

Day 4-5：服务技能
□ 服务标准流程
□ 服务话术
□ 模拟练习
□ 实际操作

Day 6-7：考核与上岗
□ 笔试+实操考核
□ 达标后分配岗位
□ 正式进入带教期
□ 7天后第一次评估

【带教期（第2-4周）】
□ 师傅一带一
□ 每日检查+反馈
□ 第14天中期评估
□ 第30天转正评估
```

### Step 3：培训内容设计

```
【服务员培训内容清单】

□ 品牌文化（为什么要做餐饮/我们的使命）
□ 产品知识（每道菜的原料/口味/吃法）
□ 服务标准（QSCV标准/服务五步曲）
□ 话术规范（迎宾/点单/送客/投诉）
□ 安全卫生（个人卫生/食品安全/设备安全）
□ 应急处理（火灾/受伤/投诉升级）
□ 操作技能（收银/打包/外卖）

【店长培训内容清单】

□ 门店管理（人员/货品/卫生/设备）
□ 数据分析（日报/月报/异常分析）
□ 客诉处理（差评预防/投诉处理）
□ 团队管理（排班/激励/面谈）
□ 成本控制（四项成本管控方法）
□ 外卖运营（平台规则/数据分析）
□ 公关意识（舆情监控/危机处理）
□ 财务基础（盈亏表/现金流）
```

### Step 4：培训方法选择

```
【培训方法矩阵】

| 培训方法 | 适用内容 | 优点 | 缺点 |
|----------|----------|------|------|
| 讲授法 | 知识/理念 | 效率高 | 被动接受 |
| 演示法 | 操作技能 | 直观 | 学员旁观 |
| 实操法 | 动手技能 | 印象深刻 | 耗时 |
| 案例法 | 问题解决 | 实用 | 需案例积累 |
| 角色扮演 | 服务话术 | 体验感强 | 难以标准化 |
| 视频教学 | 标准流程 | 可重复 | 缺互动 |
| 神秘顾客 | 综合验收 | 真实 | 成本高 |
```

### Step 5：培训考核设计

```
【考核方式】

□ 笔试：基础知识/品牌文化/安全规范（≥70分及格）
□ 实操：SOP执行/操作规范（≥80分及格）
□ 带教评估：师傅对徒弟的评价
□ 神秘顾客：第三方评估（进阶店长级）

【考核结果应用】
□ 达标：正式上岗/转正
□ 不达标：补训，补考（最多2次）
□ 连续不达标：岗位调整或劝退
□ 优秀：表彰+优先晋升机会
```

## 核心方法论

### 餐饮培训721法则

```
70% — 在岗实践（做中学，边做边练）
20% — 经验交流（案例分享/师徒带教）
10% — 课堂学习（理论知识/标准规范）

结论：课堂培训只是引子，真正的培训在日常工作中
```

### 好培训的标准

1. **可执行**：员工能学会，不是理论太高深
2. **可检查**：有明确的考核标准
3. **可持续**：不是一次性的，是持续性的
4. **有激励**：培训好的人有晋升机会
