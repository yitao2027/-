## 触发场景

当用户需要创作品牌超级符号、设计门头视觉、或提炼品牌视觉识别核心元素时，启用此 Skill。

---

## 输入

- 品牌名称与品类
- 目标客群
- 品牌核心价值主张
- 品牌已有元素（logo/色彩等）
- 使用场景：门头 / 产品包装 / 社交媒体 / 全媒体

## 工作流程

### Step 1：符号创作方向探索

```
【超级符号三个来源】

一、挖掘集体潜意识符号
- 人类文化中天然携带意义和情感的符号
- 例：红绿灯/箭头/手势/emoji/动物/食物/工具
- 优点：天然熟悉，降低认知成本

二、嫁接品牌关联词
- 品类名中的视觉元素
- 差异化卖点中的视觉载体
- 例：火锅→红色/热气/锅；茶→叶子/杯子/水滴

三、改造熟悉事物
- 把熟悉的东西换一种用法
- 例：把"✓"变成品牌符号；把箭头变成指引
- 优点：熟悉的形状+新鲜的使用方式
```

### Step 2：符号创作三步法

```
【第一步：找到符号原型】
□ 我品牌最强的差异化是什么？
□ 这个差异化可以用什么视觉形象表达？
□ 这个视觉形象是否在集体潜意识中有认知基础？
□ 有没有现成的符号可以嫁接/改造？

【第二步：测试符号三性】
□ 熟悉性：这个符号是人们熟悉的吗？
□ 独特性：这个符号能区分我们和竞品吗？
□ 转化性：这个符号能转化为产品/包装/门头吗？

【第三步：符号延展测试】
□ 能否做成门头Logo？
□ 能否做成产品包装？
□ 能否做成员工制服？
□ 能否做成社交媒体头像？
□ 能否做成广告素材？
□ 能否做成品牌周边？
```

### Step 3：符号创意方案

```
【方案一：品类符号法】
逻辑：用代表品类的符号+品牌名，建立品类=品牌的关联

示例：
- 把"碗"的形状做成品牌符号
- 把"火焰"做成品牌符号（与火锅关联）
- 把"叶子"做成品牌符号（与茶饮关联）

创作步骤：
1. 列出品类核心视觉元素
2. 提取最独特/最记忆点的元素
3. 简化/抽象化处理
4. 与品牌名/字体结合

【方案二：行动符号法】
逻辑：用代表品牌主张行动的符号，让人一看就想行动

示例：
- "辣"→辣椒符号
- "快"→闪电符号
- "香"→香味符号

【方案三：文化符号法】
逻辑：嫁接一个文化中的超级符号，借用其情感

示例：
- 借用中国传统文化符号（祥云/龙凤/铜钱）
- 借用网络文化符号（emoji/梗）
- 借用地域文化符号（四川脸谱/东北花布）

【方案四：问题解决符号法】
逻辑：直接用解决问题的方式做符号

示例：
- "饿了"→用碗筷符号
- "想喝"→用杯子符号
- "干净"→用"✓"符号
```

### Step 4：符号使用规范

```
【符号使用五原则】

1. 唯一性：只有我可以用这个符号代表这个品牌
2. 简洁性：简单到用一笔画出来
3. 可执行：能在任何场景中实现（印刷/刺绣/雕刻）
4. 记忆性：看一眼就能记住
5. 可延展：能从小到大扩展

【符号应用场景检查】
□ 门头：能否做成门头大Logo？
□ 菜单：能否做成菜品标签？
□ 包装：能否印在外卖盒/手提袋上？
□ 制服：能否绣在员工围裙上？
□ 社交：能否做成社交媒体头像/封面？
□ 物料：能否做成周边（贴纸/扇子/包装）？
```

## 核心方法论

### 超级符号判断标准

```
好符号 = 熟悉 × 简单 × 独特 × 可执行

□ 熟悉：不用解释，一眼看懂
□ 简单：5岁孩子能画出来
□ 独特：竞品没有，只有我有
□ 可执行：印刷/刺绣/雕刻都能实现
```

### 符号三大价值

1. **降低认知成本**：符号比文字传播更快
2. **激活情感记忆**：符号能唤起情感
3. **统一品牌认知**：所有触点使用同一符号，建立一致性
