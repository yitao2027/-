## 核心方法论

### 纯外卖vs堂食+外卖

```
核心差异对比：

| 维度 | 纯外卖店 | 堂食+外卖 |
|------|----------|------------|
| 选址 | 犄角旮旯也行 | 核心商圈/人流 |
| 面积 | 20-50㎡ | 80-200㎡ |
| 装修 | 极简 | 需要氛围 |
| 设备 | 专注出餐 | 堂食设备+外卖备 |
| 人员 | 3-8人 | 10-30人 |
| 投资 | 15-50万 | 50-200万 |
| 风险 | 平台依赖大 | 双重成本 |
```

### 纯外卖选址逻辑

```
纯外卖选址原则：

核心逻辑：不在于位置，在于配送范围内有多少目标用户

选址评估：
□ 3公里内目标用户密度
□ 竞品数量和评分
□ 租金性价比
□ 平台活动支持力度
□ 配送站距离

不适合做纯外卖的地方：
✗ 高租金商圈（成本太高）
✗ 竞品密集区（价格战）
✗ 配送范围覆盖差（偏远）
```

### 纯外卖成本结构

```
纯外卖成本占比（参考）：

| 成本项 | 占比 | 说明 |
|--------|------|------|
| 平台抽成 | 18-23% | 美团/饿了么 |
| 食材成本 | 28-35% | 需要优化 |
| 平台活动 | 8-12% | 满减/红包 |
| 房租 | 5-8% | 不用好位置 |
| 人工 | 12-18% | 精简团队 |
| 水电耗材 | 3-5% | |
| 其他 | 3-5% | |
| **合计** | **80-90%** | 利润10-20% |

盈亏平衡点：
毛利率 - (平台抽成 + 平台活动) > 房租 + 人工 + 其他
```

### 纯外卖爆款逻辑

```
纯外卖爆款特征：
1. 出餐快（3-5分钟）
2. 打包方便
3. 复购率高
4. 评价容易维护

不适合纯外卖的产品：
✗ 追求锅气的（炒菜等）
✗ 容易洒漏的（汤类）
✗ 等待时间长的
✗ 保存困难的
```

## 操作流程

### Step 1：评估是否适合

```
适合做纯外卖的情况：
✓ 有标准化出品能力
✓ 产品适合打包
✓ 了解平台规则
✓ 有成本控制能力
✓ 能接受平台依赖

不适合的情况：
✗ 产品依赖堂食体验
✗ 不了解平台规则
✗ 没有成本控制意识
```

### Step 2：选址评估

```
选址评估表：
| 维度 | 评估 | 权重 |
|------|------|------|
| 用户密度 | | 30% |
| 竞品情况 | | 20% |
| 租金性价比 | | 25% |
| 平台支持 | | 15% |
| 配送便利 | | 10% |
```

### Step 3：产品设计

```
产品调整：
□ 精简菜单（聚焦10-15款）
□ 优化打包（防洒/保温/美观）
□ 调整定价（覆盖平台抽成）
□ 设计套餐（提高客单价）
```

### Step 4：运营策略

```
运营重点：
1. 评分维护（>4.7）
2. 单量冲刺（冲榜）
3. 活动设计（满减/红包）
4. 复购引导（好评返券）
```

## 专家点评（避坑提示）

**纯外卖误区**：
1. **以为简单** → 平台规则复杂，水很深
2. **忽视评分** → 差评多就死
3. **不控制成本** → 平台抽完就没了

**正确姿势**：
- 纯外卖靠平台吃饭，评分是命
- 产品必须标准化，不然出餐跟不上
- 控制成本是核心竞争力
