## 📋 技巧总览（按场景分类）

### 🔴 一、新店起步（技巧1-14, 29-30）

#### 技巧1：恶意差评拉黑【美团/饿了么通用】
```
操作路径：
1. 打开规则中心 → 找到"风险顾客提示"
2. 查看系统推送的恶意差评顾客 → 选择"核实正常"或"确认异常"
3. 确认异常后系统自动追踪该客户，后续差评自动拦截
4. 后台服务中心→限制恶意下单中拉黑

同行抹黑应对话术：
"都是同行，公平竞争不好吗？拿你的口味和服务来打败我"
```

#### 技巧2：拉新和复购核心【美团/饿了么通用】
```
核心逻辑：老客获客成本远低于新客，复购率提升10%→利润增长30%+

拉新方法：
- 新人专享礼包（无门槛红包+满减券+赠品券）

复购判断指标：
- 定时下单转化率 ≥40%
- 首复购率 ≥10%
- 月复购率 ≥30%

复购提升四法：
1. 产品做稳（口味/份量统一）
2. 推陈出新（每月限定新品+半价尝鲜返券）
3. 定期召回（近30天未下单老客发满减券）
4. 精准营销（四季老客曝光设25-2）
```

#### 技巧3：172原则菜单设计【美团/饿了么通用】
```
SKU结构：
- 10%福利品（引流）：5个左右，如9.9元爆款，解决"黄金6秒"留存
- 70%正价品（成交）：主力赚钱款
- 20%利润品（提升客单价）：放在正价品后面形成反向对比

定价公式：成本 + 利润 + 配送费 + 平台扣点 + 活动

关键要求：
- 菜单SKU不低于50个
- 利润品成本与正价品一致，但利润需高于正价品1.5倍
- 价格带要拉宽
```

#### 技巧4：外卖基础知识体系【以美团为主，饿了么通用】
```
核心概念：
- 权重 = 店铺曝光度×排名展示能力，权重越高单量越多
- 前台搭建 = logo/海报/店招/店名/菜品图/菜单分组（复制+创新最有效）
- 双转 = 入店转化率+下单转化率

双转标准：
- 入店转化率：7%及格，8%以上优秀（低于7%优化头像/名称/满减/好评）
- 下单转化率：20%及格，25%以上优秀（低于20%优化分组/图片/描述）

四大必做活动：进店领券、下单返券、收藏有礼、减配送费
⚠️ 最坑活动：新客立减（顾客白占便宜还没效果）
```

#### 技巧5：负反馈限流申诉保姆教程【美团专属】
```
操作路径：规则中心→体检中心→查看食品安全和服务负反馈

申诉模板（通过率99%）：

【服务负反馈】
"尊敬的平台审核团队，我方已核实情况，外卖正常出餐，无用户反馈的负面情况。"
附：餐品图片或制作视频

【食品安全负反馈】
"尊敬的平台审核团队，我方已核实情况，确认无食品安全问题。用户反馈可能与保存方式有关，属非食安问题，申请撤销处罚。"
附：监控图片和采购记录截图

进阶技巧：
- 异物投诉："骑手告知此单为同行点单，相关差评已申诉通过"
- 包装破损："产品出品前已逐件检查，破损撒漏为配送导致"
- 支持二次申诉！找到订单明细写明多次类似差评属恶意评价
```

#### 技巧6：四大曝光渠道优化【美团专属】
```
四大渠道及优化方法：

① 列表曝光
- 进店率<4%说明无效流量多 → 优化前台搭建和活动设置

② 搜索曝光（转化率最高！）
- 点金推广做搜索加价
- 推广实况保持搜索排名前五
- 用袋鼠店长查看城市高交易量关键词 → 放入菜品名

③ 购物车曝光
- 提升加购率 → 将高加购率商品放菜单前面

④ 订单曝光
- 老客专属曝光 → 需提升复购率和老客活跃度

关键指标：新客曝光和新客转化需高于商圈均值，否则可能被限流
```

#### 技巧7：没单时先关推广！【美团/饿了么通用】
```
⚠️ 核心观点：90%老板犯的错——越没单越推广=恶性循环！

正确流程：
1. 先关推广（限流状态下推广会挤压自然曝光）
2. 诊断店铺：
   - 经营数据→流量→昨日曝光 vs 商圈同行对比
   - 顾客页面→老客对比商圈前十看复购率和人数
3. 针对性优化：
   - 复购率红+人数红 → 缺少老客曝光，给粉丝发券（门槛设客单价1.2倍）
   - 复购率绿+人数红 → 消费频次低，精准营销发券配合点金老客加0.2元
4. 双转优先于推广！

推广时机：双转达同行均值以上+日单量稳定30单以上再考虑
```

#### 技巧8：美团单量少关推广细节【美团专属】
```
美团算法特殊规则：
- 付费推广与自然曝光存在"此消彼长"关系
- 没单时推广抢占自然流量

单量翻倍技巧：
- 关闭推广后单量可能翻倍（尤其限流状态）
- 基础出价0.1，高峰期不超过0.3
- 主营品类加0.5买频道页流量，搜索加0.8买搜索流量
- 其他不加价

复购提升（美团版）：
- 精准营销给流失老客发券 + 点金推广老客加0.2元
- 四季老客曝光设置25-2，近7天复购率超10%即可

⚠️ 新店期不要猛砸推广，否则停推广后自然曝光也会停
```

#### 技巧11：确定新店日单量上限【美团&饿了么通用】

七日螺旋递增配合点金推广和活动优化，让日销量尽可能接近上限（⚠️ 靠真实订单增长，不靠补单）

#### 技巧32：曝光问题对症下药六步法【全平台通用】

- 点金推广定向投放，高峰期前半小时推

```
① 避免卡餐（掉单最大重灾区）
- 爆款高峰期提前备餐
- 主料配料提前准备
- 出餐稳时可适当提前点出餐（3-4分钟）

② 精准营销发券（每两天一次）
- 复购顾客 + 昨日进店未下单顾客
- 提升曝光+深度链接+提升复购率

③ 菜单优化
- 如果30单里20个是老顾客 → 优化菜单可涨至50单

④ 下单返券
- 金额2-3元，不用太大

⑤ 点金推广出价
- 黄线（系统推荐值的一半）
- 品类+0.3 + 搜索+0.3
- 配合精准营销发券
```

#### 技巧19：外卖运营十个关键问题【全平台通用】
```
1. 店铺权重=商圈排名，与订单量和总营业额有关
2. 进店率低→头像不好看/名字不吸引/配送费贵/评分低
3. 下单率低→价格贵/菜单乱/图片无食欲/套餐不合理
4. 点金推广→推不动+0.1，推太快-0.1，有用多推没用少推
5. 订单少→老客太多说明菜单有问题需优化
6. 有差评→正常现象，24h内回复+私信联系+合理补偿
7. 活动怎么设置→参考同行但要有差异化
8. 怎么提客单价→黄金位放利润品+引导加购
9. 新店怎么做→前30天定生死
10. 多平台运营→先做好一个再做第二个
```

#### 技巧31：单量差关注6个核心数据【全平台通用】
```
① 新老客占比：黄金比例5:5
② 新老客流量：分开分析定位问题
③ 流量趋势：今日vs昨日预判走势
④ 复购率：正常≥15%，7天新客复购<10%需紧急优化
⑤ 双转率：入店率6%及格/8%优秀；下单率高于商圈均值
⑥ 活动数据：各活动比例判断效果

单量公式：单量 = 曝光量 × 入店率 × 下单率
下滑时拆解各因子找问题！
```

#### 技巧34：骑手关系维护【全平台通用】
```
骑手搞黄一家店的方法：
- 连续差评 / 提前点到店却不取餐（5分钟以上判卡餐）/ 配送做手脚

维护技巧：
- 天热：免费水/绿豆汤/休息区
- 冬天：请骑手进屋暖和
- 骑手餐折扣（8折/5折）
- 出餐慢主动道歉换位思考
- 绝不正面冲突，实在不行后台悄悄拉黑
```

#### 技巧37：单子少的坑和解决方案【全平台通用】
```
最大坑：卡餐（出餐慢+频繁超时→平台认定无出餐能力→断流）
解决：爆款提前备餐+主料配料提前备+3-4分钟出餐

其他坑及解法：
- 产品不稳定→口味统一/分量标准/选品适配
- 随便关店→高峰期关店=跟平台翻脸
- 拒单→不管忙不过来还是不小心都会减少订单
- 批量下架产品→影响动销率和稳定性
- 盲目刷单→轻则限流重则关店
```

#### 技巧38：堂食外卖差异化定价【全平台通用】
```
万能定价公式：
定价 = 成本 + 平台扣点 + 配送费 + 膨胀红包 + 预期利润

例：排骨饭
- 成本8 + 扣点3 + 配送费4 + 膨胀红包3 + 利润5 = 23元
- 顾客用红包后到手11元，毛利率45.5%
- 综合膨胀券使用率50%→综合毛利率约54%

核心逻辑：先定到手价反推标价
外卖属于增量生意，边际成本低于堂食

⚠️ 避免为满减故意虚高定价→影响信任和复购
```

#### 技巧171：高峰期出单两步法【全平台通用】
```
Step1：提前备货
- 高峰期最好卖的几款预制好
- 出餐快→好评多→更多流量

Step2：高峰期专属活动
- 如满30减10再叠5元优惠券
- 活动中心人群营销→发放时间选高峰时段
- 拉高高峰期曝光和权重

预期效果：高峰期单量比平时翻倍
```

#### 技巧16：关掉远距离订单【全平台通用】
```
为什么要关：
- 配送费高+时间长→顾客不愿意进店
- 远距离流量拉低双转（入店率和下单率）
- 顾客期待值高→稍微有问题就差评

如何关闭：
配送服务→编辑→申请调整→需要缩小配送范围
补充说明："经理核实：同品类出单区域未覆盖远距离区域，
过多远距离配送导致差评过多，希望缩小范围提升体验"

⚠️ 提前跟业务经理说一声通过更快
```

#### 技巧36：突破单量上限三种拉新办法【全平台通用】
```
方法一：新客优惠券组合（三档）
- 第一档：新客专享3减1（2天有效）吸引首次下单
- 第二档：客单价1.3倍门槛2元券（7天有效）提升客单价+复购
- 第三档：神会员新客追加1-2元，全时段追加0.5元增加曝光

方法二：拉爆收藏有礼
- 活动中心→收藏有礼→满2减1
- 收藏能打标签→平台推更多新客流量
- ⚠️ 与店内领券互斥（避免补贴过多）

方法三：精准营销+搜索加价
- 高峰前1h给流失老客/昨日进店未下单发券
- 点金推广搜索加价（搜索转化率最高）
- 参考商圈前10%出单地理位置做定向推广
```

#### 技巧168：快速拉满评分细节【全平台通用】
```
新店前七天是扶持期，目标冲到4.9分：

操作清单：
□ 每单附赠精致打包盒+店铺小卡片（二维码+活动信息）
⚠️ 不要放"五星好评截图返红包"等好评引导卡片（平台判定为违规）
□ 下单后及时发消息告知预计送达时间
□ 差评24h内回复（态度诚恳+解决方案）
  话术："非常抱歉给您带来不好的体验，我们已复盘原因并改进了XX流程。下次下单备注您的偏好，我们免费送一份小吃表示歉意"
  ⚠️ 不用"返现""红包"等方式利诱顾客删差评或改评价

关键：一条回复到位的差评能让潜在顾客觉得你家负责任→转化不降反升
```

#### 技巧169：四个最容易踩的坑【全平台通用】
```
坑1：盲目跟风做活动（满减越大越好→亏本没人气）
     解：活动必须算ROI，不只看单量要看利润

坑2：菜单SKU太多什么都想卖→出餐慢投诉多限流
     解：15-25个高频快出餐产品即可

坑3：不重视评价管理差评不管→评分越来越低
     解：差评一条回复到位→转化不降反升

坑4：新店上来就开推广→钱花了权重坏了
     解：先基础优化拉转化再考虑推广
```

#### 技巧172：饿了么从32单拉到87单三步法【饿了么专属】
```
Step1：提升下单感知
- 商品管理→管理分组→第一个分组显示"近1小时89人下单"
- 顾客认为火爆→信任度↑→下单转化至少+5%

Step2：抢同行流量
- 经营数据→顾客→下单场景→商圈同行前10热门街区
- 确定是居民区/学校/写字楼
- 抖音推广区域类型加价0.2元抢同行流量

Step3：拉单量峰值破层级
- 高峰期集中做活动（满减叠加优惠券）
- 快速突破层级限制获得更多流量

案例效果：3天时间从32单→87单（翻倍+）
```
