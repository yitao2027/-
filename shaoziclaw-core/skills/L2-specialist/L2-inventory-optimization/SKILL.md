# L2-inventory-optimization：库存优化与周转管理

> 建立科学的库存管理体系，降低资金占用，减少损耗浪费

---

## 触发场景

- 仓库堆满货却总觉得缺货
- 食材过期损耗严重，每周扔掉大量食材
- 资金周转紧张，账上现金少
- 盘点总是对不上数，不知道哪里漏了
- 厨房催货紧急，采购却说要等货
- 淡旺季库存波动大，不知道怎么备货

---

## 核心方法论

### 一、库存ABC分类管理

#### 1. ABC分类标准

| 分类 | 价值占比 | 品种占比 | 管理策略 |
|------|----------|----------|----------|
| A类（重点） | 70-80% | 10-20% | 精确控制，每日盘点 |
| B类（一般） | 15-20% | 30-40% | 常规管理，每周盘点 |
| C类（次要） | 5-10% | 40-50% | 简化管理，每月盘点 |

#### 2. ABC分类实操

```markdown
Step 1：计算年度消耗金额
- 消耗金额 = 年消耗量 × 单价
- 数据来源：采购记录+财务数据

Step 2：按金额排序
- 从大到小排列
- 计算累计金额和累计占比

Step 3：确定分类
- 累计0-80%：A类
- 累计80-95%：B类
- 累计95-100%：C类

Step 4：差异化管控
- A类：精确订货点+安全库存+日盘
- B类：定期订货+周盘点
- C类：定量订货+月盘点
```

---

### 二、安全库存计算模型

#### 1. 安全库存公式

```
安全库存 = (最大日消耗 - 平均日消耗) × 交货周期
```

#### 2. 参数确定方法

| 参数 | 计算方式 | 数据来源 |
|------|----------|----------|
| 平均日消耗 | 近30天消耗总和 ÷ 30 | 门店报货记录 |
| 最大日消耗 | 近30天最大单日消耗 | 门店报货记录 |
| 交货周期 | 供应商承诺天数 | 合同/约定 |

#### 3. 安全库存调整因素

| 影响因素 | 调整方向 | 调整幅度 |
|----------|----------|----------|
| 供应商稳定 | 可降低 | -10~20% |
| 需求波动大 | 需提高 | +20~50% |
| 食材保鲜期短 | 需降低 | -30~50% |
| 旺季来临 | 需提高 | +30~100% |
| 资金紧张 | 尽量降低 | 接近下限 |

### 三、订货模型设计

#### 1. 定量订货法（Order Point, OP）

**适用场景**：A类食材、品牌食材、稳定消耗食材

```
订货点 = 日均消耗 × 交货周期 + 安全库存

例：猪肉
- 日均消耗：50kg
- 交货周期：2天
- 安全库存：30kg
- 订货点 = 50 × 2 + 30 = 130kg

当库存≤130kg时，订货200kg（标准箱）
```

#### 2. 定期订货法（Review Period, RP）

**适用场景**：B/C类食材、多供应商整合、降低采购频次

```markdown
订货量 = 目标库存 - 当前库存 - 在途库存 + 安全库存

例：大米
- 目标库存：300kg
- 当前库存：80kg
- 在途库存：100kg（已订未到）
- 安全库存：50kg
- 订货量 = 300 - 80 - 100 + 50 = 170kg
```

#### 3. 智能订货参考表

| 食材类型 | 建议方法 | 订货频次 | 建议供应商数 |
|----------|----------|----------|--------------|
| 鲜肉类 | 定量订货 | 每日 | 2-3家 |
| 蔬菜类 | 每日/隔日 | 每日 | 2-3家 |
| 冻品 | 定量订货 | 每周 | 1-2家 |
| 调味品 | 定期订货 | 每月 | 1家 |
| 干货 | 定期订货 | 每月 | 1-2家 |
| 一次性用品 | 定期订货 | 每月 | 1家 |

### 五、效期管理四步法

#### 1. 效期管理三三制

```markdown
"三先进"原则
- 先进先出（先入库先使用）
- 先进先出（先生产先使用）
- 先进先出（先到期先使用）

"三检查"制度
- 入库时检查：效期登记
- 存储中检查：周度效期检查
- 出库前检查：使用前再次确认

"三处理"流程
- 临期7天：优先使用+促销
- 临期3天：禁止出品+申请折价处理
- 已过期：立即下架+销毁登记
```

#### 2. 效期看板管理

```
每日开门检查表：
□ 冷藏库：逐项检查效期
□ 冷冻库：抽检重点品类
□ 常温库：检查高风险品类

效期预警标签（贴在食材上）：
┌─────────────────┐
│  [品类名称]      │
│  入库日期：____ │
│  效期至：____   │
│  责任人：____   │
└─────────────────┘
```

#### 3. 损耗率管控目标

|------|-------------|--------|
| 鲜肉类 | <3% | >5% |
| 蔬菜类 | <8% | >12% |
| 冻品类 | <1% | >2% |
| 调味品 | <0.5% | >1% |
| 整体 | <5% | >8% |

### 六、盘点管理流程

#### 1. 盘点类型

| 盘点类型 | 频率 | 参与人员 | 适用范围 |
|----------|------|----------|----------|
| 日盘 | 每日 | 库管 | A类食材 |
| 周盘 | 每周 | 库管+店长 | A+B类食材 |
| 月盘 | 每月 | 全员 | 全部食材 |
| 年盘 | 每年 | 公司财务 | 全部资产 |

#### 2. 月度盘点流程

```markdown
Step 1：盘点准备（盘点前1天）
- 整理仓库，做到整齐有序
- 打印盘点表（按区域/分类）
- 准备称重工具、记录本
- 通知相关部门暂停进出库

Step 2：执行盘点（盘点当日）
- 分区盘点，逐项记录
- 数量+重量双重确认
- 拍照留证
- 库管+监盘人双签字

Step 3：数据分析（盘点后1天）
- 计算理论库存 vs 实际库存
- 差异分析：正常损耗 vs 非正常损耗
- 损耗责任归属
- 形成盘点报告

Step 4：改进措施（盘点后3天）
- 损耗超标项：原因分析+整改
- 系统误差：核查录入准确性
- 盗窃损失：加强管理/安防
```

#### 3. 盘点准确率目标

| 指标 | 目标 | 预警 |
|------|------|------|
| 盘点准确率 | ≥99% | <98% |
| 损耗率 | <5% | >8% |
| 过期报损率 | <0.5% | >1% |

### 七、淡旺季备货策略

#### 1. 需求预测方法

```markdown
季节指数 = 当月平均销量 / 全年平均销量

例（某饮品品牌）：
- 全年平均月销量：10000杯
- 7月销量：18000杯
- 7月季节指数 = 18000/10000 = 1.8

备货调整：
- 旺季前1个月开始增量备货
- 旺季当月按季节指数1.5-2倍备货
- 旺季结束前2周开始减量
```

#### 2. 备货时间轴

```
淡旺季备货标准流程：

淡季（-60天）：维持正常库存
旺季前（-60~-30天）：开始增量采购，库存提升20%
旺季前（-30~-7天）：库存提升50%，重点备货
旺季中（-7~+7天）：最高库存水平
旺季后（+7~+30天）：逐步消化库存
淡季回归（+30天后）：恢复正常水平
```

#### 3. 极端情况应对

| 情况 | 风险 | 应对策略 |
|------|------|----------|
| 备货过多 | 滞销过期 | 促销消化/折价处理/员工福利 |
| 备货不足 | 断货损失 | 紧急补货/替代品/限量销售 |
| 天气突变 | 需求骤降 | 实时调整采购/外卖平台促销 |
| 疫情/突发事件 | 客流锐减 | 立即压缩采购/外卖为主 |

## 使用说明

1. **数据基础**：建立准确的消耗数据是库存管理的前提
2. **动态调整**：安全库存需要根据季节、天气、节假日动态调整
3. **责任到人**：每个仓库区域必须有明确的责任人
4. **工具辅助**：建议使用进销存系统，减少人工误差
5. **持续优化**：每月分析库存数据，持续改进
