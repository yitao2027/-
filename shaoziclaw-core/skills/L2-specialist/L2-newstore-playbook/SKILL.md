## 🎯 核心认知

### 为什么新店期定生死？

```
平台逻辑：
- 新店有唯一一次的新店扶持流量（自然加权+排名靠前）
- 这波流量用好了→店铺进入良性循环
- 浪费了→后续要花10倍代价才能拉回来

2026年新规变化（来自直播回放04-02）：
- 客单价权重变化最大（低客单快餐今年非常危险）
- 复购率权重提升
- 经营水平权重提升
- 配送时间由平台测算不能自己改了
- 低品质+低客单+纯外卖将不再有流量
- 神枪手要做套餐不做单品
```

## 📅 Phase 0：开业前3天准备

### 0.1 资质与注册

```
□ 营业执照（有效期内）
□ 食品经营许可证（或小餐饮登记证）
□ 法人身份证正反面
□ 门店实景照片≥5张（门头/后厨/操作间/堂食区）
□ 银行账户信息
□ 平台注册：美团 waimai.meituan.com / 饿了么 e.ele.me / 淘宝商家后台
```

### 0.2 前台搭建（影响入店率的核心！）

```
店铺头像：
❌ 不要开智能头像（美团会自动换成菜品图，降低辨识度）
✅ 用热气腾腾的招牌菜图+"现炒"/"手作"等关键词
✅ 或品牌LOGO+品类词组合

店铺名称结构：
"品牌名 + 核心品类 + 爆款单品"
例："张记纯手工生煎包·现炸5翻油头"
例："川香居·现炒黄牛肉饭"

店铺Banner：
✅ 展示爆品/活动/品牌卖点
✅ 定期更换保持新鲜感
```

### 0.3 菜单上传（黄金位决定客单价）

```
菜单数量要求：
- 总SKU ≥ 20个（建议40-50个）
- 分类 ≥ 5个
- 打造3道镇店招牌菜（带表情吸引眼球）

172原则SKU分布：
┌─────────────────────────────┐
│ 10% 福利品（引流）          │ ← 9.9元爆款，解决黄金6秒留存
│   ↓                          │
│ 70% 正价品（成交主力）       │ ← 成本+利润+扣点+配送费+活动
│   ↓                          │
│ 20% 利润品（提升客单价）     │ ← 放在正价品后面形成反向对比
└─────────────────────────────┘

菜单排序黄金法则：
位置1：爆款引流款（第1-3位，冲击力强的产品图）
位置2：凑单必备（9.9元小食/饮品，高性价比必点）
位置3：利润主力（高毛利产品+差异化组合套餐）
位置4：丰富选择（常规款覆盖长尾需求）
位置5：品牌特色（招牌菜/必吃推荐建立认知）

⚠️ 黄金位放的越丰富，客单价越高！（参考华莱士三件套/五件套逻辑）
```

### 0.4 四大必做活动配置

```
必须开的四个活动（按优先级排列）：

① 进店领券 ✅✅✅
   - 降低顾客进店门槛
   - 提升店铺列表点击率

② 下单返券 ✅✅✅
   - 金额2-3元，7天内使用
   - 最有效的复购工具之一

③ 收藏有礼 ✅✅
   - 满2减1即可
   - 收藏能打标签获得更多新客推送
   - ⚠️ 与店内领券互斥避免过度补贴

④ 减免配送费 ✅✅
   - 降低配送门槛
   - 提升下单转化

❌ 绝对不要做的：
- 新客立减（最坑！顾客白占便宜还没效果）
- 一键推广（烧钱无效果）
- 智能折扣（价格全变算不清利润）
- 智能头像（被自动替换菜品图）

神会员设置（美团）：
- 新客追加1-2元
- 全时段追加0.5元
- 增加商家列表曝光
```

### 0.5 其他基础配置

```
□ 打开预订单（不在营业时间也能被搜到）【重要！】
□ 到店自取一定要开（多一份曝光多一份机会）
□ 赏金联盟打开（佣金8%，比同行略高）
□ 营业时间精确到小时
□ 配送范围首次设1.5-3公里
□ 上传所有证照
□ 店铺简介写品牌故事/特色
□ 设置粉丝群入口
```

## 📅 Phase 1：第一周（第1-7天）螺旋递增期

### 1.1 核心目标：冲到商圈日单量上限

```
计算公式：
商圈同品类销量第一名月销量 ÷ 30 × 1.3 = 日单量上限

例：猪脚饭商圈第一月售4500单 → 上限 = 4500÷30×1.3 = 195单/天
```

### 1.2 七日螺旋递增操作表

| 天数 | 目标单量 | 核心动作 | 注意事项 |
|------|---------|---------|---------|
| D1 | 5-8单 | 补单为主，每单3图+50字好评 | 必须找亲朋好友真实体验后留评 |
| D2 | 10-15单 | 单量比D1增长150%-200% | 继续补单积累评价基数 |
| D3 | 18-25单 | 继续递增 | ⚠️**压力测试可能今天到来！** |
| D4 | 28-35单 | 开始观察双转和曝光 | 双转不低于商圈千分之十才正常 |
| D5 | 38-48单 | 可开始100-200元大单提客单价 | 大单连续做3天拉高消费群体 |
| D6 | 50-62单 | 继续递增 | 好评量不超过当天总单量25% |
| D7 | 65-80单 | 接近或达到上限 | 为第二周特权期做准备 |

### 1.3 第一周关键动作详解

```
评分冲刺（D1-D3最重要！）：
- 目标：冲到5.0分起步
- 每单必须有3张图+50字以上评价
- 找亲朋好友最稳妥
- 每单附赠好评卡："五星好评截图返2元红包"

补单注意事项：
- 时间：放在早高峰（正餐10:30-11:30）
- 渠道：可用霸王餐（平台正规渠道）
- ⚠️ 好评不超过当天总单量25%（否则判刷单）
- ⚠️ 绝对不能有差评出现

压力测试应对（通常D3-D7之间）：
⚠️ 什么是压力测试？平台测试你出餐能力，故意加大派单量
❌ 绝对不能做的：
   - 卡餐 = 出餐慢 + 频繁超时 = 平台判定你没出餐能力 = 断流！
   - 拒单 = 直接减少后续派单
   - 主动取消订单 = 权重暴跌
✅ 正确做法：
   - 爆款菜品提前备好半成品
   - 主料配料提前准备好
   - 出餐稳时可适当提前点出餐（3-4分钟内）
   - 全员上阵保证不超时
```

### 1.4 点亮星级

```
第一天目标：收集至少2条以上有效评价解锁店铺星级
方法：
- 亲朋好友真实下单体验
- 每单随包放手写小卡片引导评价
- 霸王餐渠道获取早期评价
```

## 📅 Phase 2：第二周（第8-14天）特权期

### 2.1 核心目标：稳住上限不下滑，自然订单替代补单

### 2.2 特权利用策略

```
美团七天流量特权：
- ✅ 需要连续开启（不能断！否则流量忽高忽低）
- 此时店铺单量已达该品类商圈上限
- 目标：稳住订单不下滑即可
- 补单逐渐被自然订单替代

新店排名加权：
- 开启后让店铺进入区域热门榜
- 利用特权期打造爆款提高复购率

关键数据盯紧：
- 每日：曝光量 / 进店转化率 / 下单转化率
- 每周一：查看店铺周报对比上周
```

### 2.3 第二周重点动作

```
菜单优化启动：
□ 分析最初7天数据（哪些卖得好/哪些没人点）
□ 把销量高的往前排
□ 低转化产品下架或改图
□ 调整活动力度（参考竞品对比）

打造爆款：
□ 选1-2款最有竞争力的产品集中推
□ 配合限时优惠/套餐形式
□ 目标：建立口碑传播点

复购布局：
□ 开始设置精准营销发券
□ 下单返券激活首单用户
□ 为第三周会员体系打基础
```

## 📅 Phase 3：第三-四周（第15-30天）稳定期

### 3.1 核心目标：优化利润、建立体系、测试推广

### 3.2 第三周动作

```
开通高级工具：
□ 开通袋鼠店长（美团）— 数据分析神器
□ 开始点金推广测试

点金推广测试方案（2天测试期）：
- 每天3个高峰期各投150元
- 对比：点金效果 vs 新店特权效果
- 如果特权更好→开袋鼠店长延长特权期
- 如果点金更好→正式切换到付费推广模式

点金基础出价策略：
- 黄线 = 系统推荐值的一半
- 品类加0.3 / 搜索加0.3
- 高峰期出价不超过0.3
- 推广进店率低就减定向，专注精准流量

活动调整：
□ 优化满减档位（参考盈亏测算）
□ 减少补贴力度（逐步过渡到正常经营）
□ 测试不同活动组合的ROI
```

### 3.3 第四周动作

```
客单价提升（2026年核心方向）：
□ 调整黄金位商品（更多利润品）
□ 设计多人套餐（双人/三人/四人餐）
  ⚠️ 双人餐定价≠单人餐×2（要有明显性价比优势！）
□ 引导加购（小吃/饮品/加料选项）
□ 神枪手用套餐不用单品（不影响综合客单价）

会员体系建设：
□ 设置粉丝专属优惠
□ 私域引流（随包卡片+二维码）
□ 精准营销定期发券（每两天一次）

数据分析体系建立：
□ 日度：订单/营业额/曝光/双转/客单价/评分
□ 周度：vs上周/爆款销量/差评分布/活动ROI
□ 月度：总单量额/获客成本/复购率/利润率/下月计划
```

## 🚨 新店绝对禁止的操作（6+3条）

### 致命6条（做了直接掉权重）

```
❌ 天天频繁编辑菜单栏 → 影响稳定性与权重
❌ 频繁修改原价 → 触发警告甚至限流
❌ 新品未稳定前频繁改图改名称 → 影响顾客认知
❌ 随意上下架库存按钮 → 影响流量计算
❌ 菜品没做好就点"出餐完成" → 卡餐判定
❌ 高峰期手动关店 → 降低配合度减少派单
```

### 额外3条禁忌

```
❌ 拒单（不管忙不过来还是不小心都拒单=少单）
❌ 卡餐提醒开着不处理（出现提示流量直接下降）
❌ 盲目刷单/虚假好评（轻则限流重则关店）
```

### 美团必关功能清单

```
❌ 流量助手（活动中心满减/折扣里）
❌ 智能折扣
❌ 智能头像
❌ 卡餐提醒
❌ 一键推广

✅ 要开的：
✅ 到店自取
✅ 赏金联盟（佣金8%）
✅ 预订单
```

## 📊 30天里程碑检查表

```
Week 1 结束检查：
□ 评分 ≥ 4.9
□ 日单量达到商圈上限60%+
□ 双转达到商圈前10%
□ 无卡餐记录
□ 无差评（或有但已妥善处理）

Week 2 结束检查：
□ 自然订单占比 > 50%
□ 复购率开始上升

Week 3-4 结束检查：
□ 日单量稳定在商圈上限80%+
□ 客单价比Week1提升10%+

□ 点金推广ROI为正

```
