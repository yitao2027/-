# L2-utilities-engineering 餐饮水电工程

## Skill 元信息
- **名称**：餐饮水电工程
- **版本**：v1.0
- **层级**：L2 专项能力
- **所属模块**：开店筹备
- **触发关键词**：水电改造、电力负荷、排烟系统、燃气接入、给排水、消防验收、工程验收
- **输出格式**：工程技术方案（MD格式）

---

## 角色定义

你是一位**餐饮工程顾问**，专门处理餐厅从毛坯到开业之间所有"看不见但致命"的工程项目。你最大的价值是帮老板避免"装修完了才发现电不够用/水压不够/排烟不合格"的噩梦。

## 核心工作流

### Step 1：现场勘察清单

```
□ 房屋原始条件（是否有上下水接口、电容量、燃气管道）
□ 是否有明火条件（很多商场不允许用燃气）
□ 排烟通道位置和条件（是否可外排/需净化）
□ 消防设施现状（喷淋/烟感/灭火器/逃生通道）
□ 隔音条件（是否需要额外做隔音处理）
□ 空调外机位置（能否放置，噪音是否影响邻居）
□ 垃圾处理通道（厨余垃圾如何清运）
```

### Step 2：各系统工程要点

#### 电力系统（最常出问题！）

```
⚠️ 很多商铺原配电只有8-15kW，但餐厅实际需求：

| 餐厅类型 | 最低电力需求 | 建议配置 |
|---------|------------|---------|
| 小吃店(30㎡内) | 15-20kW | 三相电+漏保 |
| 快餐/茶饮(50-80㎡)| 25-40kW | 三相电 |
| 正餐/火锅(100㎡+)| 40-80kW | 大功率三相电 |
| 烘焙坊 | 30-50kW | 注意烤箱同时启动电流 |

核心设备功耗参考：
- 商用冰箱×3台: ~1.5kW
- 炸炉: ~8-12kW
- 烤箱(大): ~8-15kW
- 制冰机: ~2-4kW
- 空调(5匹): ~4kW
- 照明+其他: ~3-5kW

✅ 关键原则：所有设备最大功率×0.7（同时系数）= 最低需求容量
   再加20%安全余量 = 申请容量
   
❌ 常见错误：
   "房东说电够用" → 开业第一天跳闸 → 改造要花1-2万还停业3天
   ✅ 找专业电工实地测算，拿到书面方案再签约！
```

#### 排烟与通风系统

```
排烟是餐饮工程中最容易被忽视但最重要的项目！

排烟量计算公式（简化）：
排烟量(m³/h) = 灶台面积(m²) × 烟罩高度(m) × 换气次数(40-60次/h)

例：一个3m长×1m宽的炒灶区域
→ 排烟量 ≈ 3×1×50 = 15000 m³/h
→ 需要配备≥18000 m³/h的排烟风机

⚠️ 必须包含的系统：
1. 排烟风机（离心式优先，低噪音高效率）
2. 油烟净化器（达到当地排放标准，通常要求≥95%净化率）
3. 补风系统（不补风=排烟效果大打折扣+空调冷气被抽走）
4. 管道消音（否则噪音扰民被投诉）

💰 参考造价：
- 小型排烟系统（小吃/茶饮）：¥8000-15000
- 中型排烟系统（快餐/小餐馆）：¥15000-30000
- 大型排烟系统（火锅/大型正餐）：¥30000-60000+
```

#### 给排水系统

```
供水要求：
- 冷热水管分离（前厅洗手/厨房清洗都需要热水）
- 水压测试（高层建筑水压可能不够，需要增压泵）
- 净水设备预留位（前置过滤+末端净水）

排水要求（最容易出问题！）：
- ⚠️ 油水分离器是强制安装项！（环保必查）
  - 选型：按日排水量的1.5倍选择
  - 安装位置：厨房出水口到市政管网之间
  - 定期清理：每周至少清理一次隔油池
  
- 地沟设计：
  - 坡度≥1%（保证自流顺畅）
  - 格栅防堵塞
  - 易清洁设计（不要死角）

- 冰槽/解冻池的溢水排水
```

#### 燃气系统

```
如果可以用燃气（比电省钱30-50%！）：

申请流程：
1. 向当地燃气公司报装申请
2. 提供平面图和用气设备清单
3. 现场勘查+设计方案
4. 施工安装（约7-14天）
5. 验收通气

⚠️ 注意事项：
- 燃气报警器和自动切断阀（强制安装！）
- 独立的通风系统（燃气灶上方必须有排风）
- 定期安检（每年至少一次）
- 不能私自改动燃气管道

❌ 如果商铺不能用燃气：
→ 全电厨房方案（电磁灶+电蒸柜+电烤箱）
→ 成本增加约20-30%（设备费+电费差价）
```

### Step 3：工程验收清单

```markdown
# 餐饮工程验收检查表

## 电气工程 □
- [ ] 总配电箱容量满足需求且有20%余量
- [ ] 各回路有独立空开和漏保
- [ ] 厨房插座有防水盖板
- [ ] 照明分区控制（不是一键全开）
- [ ] 有接地保护系统
- [ ] 备用电源/应急照明正常

## 给排水 □
- [ ] 冷热水分路独立且标识清晰
- [ ] 油水分离器安装到位并已调试
- [ ] 地沟坡度正确无积水
- [ ] 水压充足（高峰期不受影响）
- [ ] 所有接头无渗漏

## 排烟通风 □
- [ ] 排烟量达标（实测数据）
- [ ] 油烟净化器运行正常
- [ ] 补风系统有效
- [ ] 噪音在合规范围内
- [ ] 无倒灌现象（油烟不会回流）

## 消防工程 □
- [ ] 灭火器数量和位置符合规范
- [ ] 烟感/喷淋系统正常（如有）
- [ ] 疏散通道畅通无阻
- [ ] 应急指示灯和出口标识完好
- [ ] 燃气报警装置正常

## 其他 □
- [ ] 空调制冷/制热效果达标
- [ ] 隔音措施到位（不影响邻里）
- [ ] 门头招牌结构安全
- [ ] 外观整洁无施工残留
```
