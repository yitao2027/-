## 触发场景

- 私域现状：有无私域 / 已有社群数量 / 现有会员数

## 工作流程

### Step 1：私域搭建规划

```
【私域流量池架构】

第一层（公域引流）：门店/外卖/抖音/小红书/大众点评
        ↓
第二层（公转私）：添加企业微信/进群/关注公众号
        ↓
第三层（私域沉淀）：企业微信好友/微信社群/公众号粉丝
        ↓
第四层（分层运营）：超级用户/活跃用户/沉睡用户

【私域引流路径】
□ 门店引流：收银台/餐桌/门迎处放置"添加微信优惠"
□ 外卖引流：外卖包裹内放置"加群卡"（好评返现/专属优惠）
□ 抖音引流：评论区/私信引导加微信
□ 点评引流：回复差评/好评时私信
□ 员工引流：员工推荐顾客入群（有奖励）
```

### Step 2：社群分层运营

```
【社群分层策略】

A类社群：超级用户群（消费Top20%）
□ 门槛：月消费≥X次或累计消费≥X元
□ 人数：控制在200人以内
□ 运营：专属福利/新品优先/生日礼/专属客服
□ 频率：每周1-2次深度互动
□ 目标：年消费≥X次，客单价提升20%

B类社群：活跃用户群（月消费1-3次）
□ 门槛：有消费记录但不够活跃
□ 人数：不限
□ 运营：日常活动/限时优惠/节日关怀
□ 频率：每周2-3次（不能太频繁被拉黑）
□ 目标：月消费≥2次

C类社群：沉睡唤醒群
□ 门槛：30天未消费
□ 人数：不限
□ 运营：大额优惠/专属唤醒券/问卷调研
□ 频率：每月1-2次
□ 目标：重新激活消费
```

### Step 3：社群内容运营

```
【社群内容日历（周模板）】

| 日期 | 内容类型 | 示例 | 目的 |
|------|----------|------|------|
| 周一 | 产品种草 | 本周主推：[菜品名]，为什么值得吃 | 日常触达 |
| 周二 | 知识科普 | 告诉你一道菜背后的故事 | 增加价值感 |
| 周三 | 限时优惠 | 今日社群专享价，仅限群内 | 促进转化 |
| 周四 | 用户互动 | 晒单有奖/话题讨论 | 提升活跃度 |
| 周五 | 周末预告 | 周末优惠/新品/节日活动 | 引流到店 |
| 周六 | 活动促销 | 限时秒杀/满减活动 | 促进消费 |
| 周日 | 内容休息 | 祝福/生活类软内容 | 维护关系 |

【内容禁忌】
□ 纯广告（让人想退群）
□ 频繁@所有人
□ 无关内容（微商/八卦）
□ 负面/争议话题
□ 竞争对手信息
```

### Step 4：转化活动设计

```
【高频转化活动】

1. 限时秒杀
   - 每周固定时间（如周三20:00）
   - 限量10份/20份，超值价格
   - 制造紧迫感
   
2. 满减专享
   - 仅社群用户可用
   - 满100减20（高于平台活动）
   
3. 新品优先尝鲜
   - 新品上市，群内用户优先
   - 提前预订+额外赠品
   
4. 储值赠送
   - 充500送50/充1000送150
   - 仅限社群用户专享
   
5. 节日专属
   - 节日/生日提前发放专属券
   - 群内专属生日祝福
```

### Step 5：会员体系设计

```
【会员体系框架】

普通会员（注册即得）
├─ 注册礼：新人券包
├─ 基础权益：积分1元=1分
└─ 升级条件：消费满X元

银卡会员（累计消费X元）
├─ 升级礼：加赠X积分
├─ 进阶权益：生日双倍积分
├─ 专属活动：月度专享
└─ 升级条件：累计消费满X元

金卡会员（累计消费X元）
├─ 升级礼：专属礼品
├─ 高阶权益：优先预约/专属座位
├─ 专属客服：1对1服务
└─ 升级条件：累计消费满X元

黑卡会员（邀约制，不开放申请）
├─ 专属权益：全年免费试吃新品
├─ 定制服务：私人厨师/定制菜单
└─ 邀请人：品牌创始人/高管邀约
```

### Step 6：社群数据监控

```
【关键指标】

| 指标 | 定义 | 达标值 |
|------|------|--------|
| 入群率 | 添加微信/进群数 ÷ 到店顾客数 | ≥30% |
| 活跃率 | 月互动用户 ÷ 群总人数 | ≥20% |
| 转化率 | 社群用户消费 ÷ 社群总人数 | ≥10% |
| 客单价 | 社群用户平均消费额 | ≥非社群用户1.3倍 |
| 月留存率 | 月底活跃 ÷ 月初活跃 | ≥70% |
| 流失率 | 月退群 ÷ 月末群人数 | ≤5% |

【异常预警】
□ 活跃率<10%：内容需要调整
□ 流失率>10%：被过度打扰
□ 转化率<5%：活动设计有问题
```

## 核心方法论

### 私域运营三板斧

1. **引得进**：多渠道引流，进群率≥30%
2. **留得住**：有价值内容，流失率≤5%
3. **转化多**：精准活动，转化率≥10%

### 私域三角模型

```
        价值
       /    \
      /      \
     /   关系  \
    ───────────
   频率    内容
```

- **内容**：给用户一个留在群里的理由
- **频率**：不能太频繁（被拉黑）也不能太少（被遗忘）
- **关系**：从"商家-顾客"变成"朋友-朋友"

---

## 质量标准

| 维度 | 标准 |
|------|------|
| 路径完整 | 覆盖引流→沉淀→转化全链路 |
| 分层清晰 | 不同用户不同运营策略 |
| 内容有规划 | 不是随意发，有日历有节奏 |
| 转化可追踪 | 有数据指标和复盘 |

## 注意事项

1. **私域是服务，不是骚扰**：用户同意才拉群，随时可退
2. **价值要先于销售**：先提供价值（内容/福利），再谈转化
3. **企业微信>个人微信**：企业微信更专业，可监管，数据可分析
4. **复购靠产品，不只靠私域**：私域是放大器，不是万能药
5. **不要买粉丝**：虚假粉丝不仅无效，还会污染数据
