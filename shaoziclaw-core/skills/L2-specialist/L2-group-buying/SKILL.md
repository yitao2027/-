# 团购套餐设计与平台运营

**层级：** L2 专项能力  
**部门归属：** 市场营销部  
**触发词：** 团购、团购套餐、美团团购、抖音团购、团购设计、团购运营、套餐设计

---

## 一、Skill 定位

**解决什么问题：**  
帮助餐饮门店系统设计高转化率的团购套餐，选对平台，规避团购陷阱，实现低成本引流拉新，而非陷入"越卖越亏"的团购困境。

**团购核心认知：**
- 团购是引流工具，不是主要利润来源
- 好的团购套餐：引进新客→体验好→复购转化为会员
- 烂的团购套餐：拉来羊毛党→成本高→复购率接近0→越卖越亏

## 二、核心方法论

### 2.1 团购套餐设计五原则

```
原则1：成本可控（红线）
→ 团购套餐成本率上限：40%（不超过这个数，否则亏本引流）
→ 如何计算：套餐内所有菜品食材成本 ÷ 团购价 × 100%
→ 例：套餐标价88元，食材成本≤35.2元

原则2：体验吸引（钩子）
→ 套餐中必须有1款"值得体验"的核心单品
→ 不能全是边角料/卖不动的菜品凑套餐
→ 核心逻辑：让顾客感受到"值了"

原则3：引导复购（目标）
→ 套餐设计必须让顾客想"下次再来点XXX"
→ 不把最好的菜放进套餐（留一手，让顾客加单/下次来）

原则4：控制数量（节奏）
→ 每款团购每日可核销数量设上限（防止高峰期崩溃）
→ 建议：日均可核销数量 ≤ 高峰期接待量的30%

原则5：分析数据（复盘）
→ 每月分析：核销率/复购转化率/团购客单贡献
→ 按数据优化套餐，不靠感觉
```

### 2.2 平台选择与定位

**主要团购平台特点对比：**

| 平台 | 用户特征 | 适合场景 | 手续费/扣点 |
|------|---------|---------|------------|
| 美团团购 | 全年龄，本地化强 | 日常餐饮、家庭聚餐 | 5-8%（各城市不同） |
| 大众点评 | 25-45岁，精品意识强 | 中高档餐饮、节日聚餐 | 4-6% |
| 抖音团购 | 18-35岁，兴趣驱动 | 网红/特色/视觉型餐饮 | 2-6% |
| 口碑/饿了么 | 外卖+团购混合 | 快餐/轻餐 | 与外卖打通 |

**平台选择建议：**
```
快餐/大众餐：美团团购为主（覆盖面广）
网红/特色餐饮：抖音团购优先（流量大，新客多）
中高端正餐：大众点评为主（用户精准，消费力强）
多平台策略：3个平台同时开，但套餐设计有差异化
```

### 2.3 团购套餐类型设计

**三种主要套餐模式：**

**① 引流款套餐（低价大引流）**
```
目标：拉新，让更多顾客来体验
定价：比正常客单价低20-30%
内容：主食+1-2道基础菜（不含高成本食材）
风险：利润薄，必须靠复购消化
适合：新店开业/新客激活期
```

**② 体验款套餐（核心复购驱动）**
```
目标：让顾客充分体验门店特色
定价：接近正常客单价（打95折左右）
内容：门店主力菜品组合（含1-2道招牌）
价值：让顾客记住门店特色，提高复购意愿
适合：长期主力套餐
```

**③ 高端宴席套餐（大客单突破）**
```
目标：拓展聚餐/宴席客群
定价：4-6人餐/6-10人餐打包价
内容：全面展示门店实力菜品
价值：一单相当于普通团购3-5单
适合：中式正餐/火锅/烧烤
```

### 2.4 抖音团购专项策略

```
抖音团购 vs 传统团购的核心差异：
→ 抖音是内容驱动（视频/直播带货）
→ 传统团购是搜索驱动（顾客主动搜）

抖音团购成功公式：
好视频 × 好套餐 × 好评价 = 爆单

执行步骤：
STEP 1 视频内容（先有流量才有核销）
→ 拍摄门店特色场景（出餐/互动/特色环境）
→ 视频中自然出现套餐价格（不要太广告感）
→ 建议发布频率：每周至少2条

STEP 2 套餐设计（符合抖音用户偏好）
→ 价格要有"击穿感"（99元享原价150元的体验）
→ 套餐名称要有诱惑力（「镇店三宝套餐」而非「ABC套餐」）
→ 配图/主图要高颜值（抖音用户视觉驱动）

STEP 3 核销转化
→ 抖音团购买家进店：务必主动引导加入私域（微信/小程序）
→ 不能只当一次性流量，要转化为长期顾客

STEP 4 数据复盘
→ 每周查看：套餐曝光量/点击率/核销量/留评率
→ 核销后差评率>5%需立即优化套餐内容
```

### 2.5 团购陷阱规避

```
最常见的团购陷阱及规避方法：

❌ 陷阱1：无限量团购，被羊毛党刷
→ 规避：设每日上限（如每日可核销20张）

❌ 陷阱2：团购客与堂食客区别对待（被顾客察觉）
→ 规避：所有顾客同等服务，团购客反而更需要好服务（他们评价影响排名）

❌ 陷阱3：套餐成本算错，越卖越亏
→ 规避：上线前严格计算每个SKU成本，确认成本率≤40%

❌ 陷阱4：大量核销但零复购
→ 规避：每单必须引导顾客进私域（用小卡片/服务员话术）

❌ 陷阱5：团购评分拉低整体评分
→ 规避：团购页面与门店整体评分绑定，必须保证团购体验与堂食一致

❌ 陷阱6：过度依赖团购引流，停止后客流断崖
→ 规避：团购是辅助，私域沉淀是根本，逐步减少团购依赖
```

## 四、触发条件与输出

**输入收集：**
```
请告诉我：
1. 门店类型和定位？（人均消费/主营品类）
2. 目前是否已有团购套餐？（有/无，如有效果如何）
3. 团购目标是什么？（拉新/提营业额/消化平峰）
4. 准备主打哪个平台？（或全平台）
5. 哪些菜品可以做套餐主角？（招牌/特色菜）
```

**输出内容：**
- 团购套餐设计方案（3款推荐）
- 成本率核算报告（确保不亏本）
- 平台选择建议
- 抖音团购视频内容方向（如选择抖音）
- 复购转化策略
