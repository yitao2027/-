## 核心公式

```
预估月营业额 = 区域潜在客流量 × 捕获率 × 客单价
```

**本质理解**：租金就是购买流量的成本，选址即选择有效客流量

---

## 五步测算模型

### 第一步：明确门店类型

| 门店类型 | 核心客群 | 消费场景 | 特点 |
|---------|---------|---------|------|
| 社区店 | 周边住宅居民 | 家庭用餐、日常消费 | 复购稳定 |
| 商务区店 | 写字楼员工 | 午餐、晚餐、商务 | 工作日强，周末弱 |
| 商场店 | 购物中心客流 | 休闲购物餐饮 | 依赖商场整体人流 |
| 商圈/景区店 | 流动人口 | 旅游、逛街消费 | 人流大但转化难 |

### 第二步：测算区域潜在客流量

**操作工具**：贝壳找房、链家网（地图找房功能）

**实操步骤**：
1. 以预选门店为圆心，**1.5-2公里**为半径画圈
2. 统计范围内所有小区的**总户数**
3. 代入公式计算：

```
总居民数 = 总户数 × 每户平均人口数(2.5人) × 小区入住率(60%-80%)
```

**案例实操**：
- 贝壳统计：目标区域总户数 **15,820户**
- 入住率取80%：15,820 × 2.5 × 80% = **31,648人**
- 即该区域潜在客流量：约**3.2万人**

**注意**：宽阔主干道会阻隔人流，需单独评估

### 第三步：确定捕获率

**捕获率**：潜在客流中，实际会进店消费的比例

| 门店类型 | 捕获率参考 | 说明 |
|---------|-----------|------|
| 社区火锅店 | **5% - 10%** | 复购稳定，捕获率高 |
| 商务区火锅店 | **2.5% - 6%** | 场景单一，捕获率低 |
| 快餐/面馆 | **10% - 20%** | 刚需高频，捕获率高 |
| 茶饮店 | **3% - 8%** | 随机性强 |
| 烧烤/重餐 | **2% - 5%** | 目的性强，捕获率低 |

**调整因素**（实际使用时要浮动）：
- 品牌知名度（知名品牌的捕获率可上调50-100%）
- 竞品密度（竞品越多，捕获率越低）
- 门头可见度（越醒目，捕获率越高）

### 第四步：营业额预估

**公式**：
```
月营业额下限 = 潜在客流量 × 最低捕获率 × 客单价
月营业额上限 = 潜在客流量 × 最高捕获率 × 客单价
```

**案例（社区火锅店）**：
- 潜在客流量：31,648人
- 捕获率：5%-10%
- 客单价：100元
- **月营业额下限**：31,648 × 5% × 100 = **15.8万元**
- **月营业额上限**：31,648 × 10% × 100 = **31.6万元**

**结论**：该位置月营业额预估区间 **15.8-31.6万元**

### 第五步：盈亏平衡测算

```
盈亏平衡月营业额 = 月固定成本 ÷ 毛利率
```

**月固定成本包含**：
- 租金 + 物业费
- 人工成本
- 水电煤
- 其他固定支出

**判断标准**：
- 预估营业额 > 盈亏平衡点 → 可行
- 预估营业额 < 盈亏平衡点80% → 谨慎

## 不同店型客流数据来源

### 商务区店
- 统计范围内所有写字楼的**办公面积**
- 公式：`办公人口 = 办公总面积 × 入驻率 ÷ 人均办公面积(8-15㎡)`
- 加总：办公人口 + 酒店/公寓流动人口

### 商场店
- 查商场官方年客流量数据（除365得出日均）
- 或倒推：车位数量 × 3-5倍 = 预估日客流量

### 商圈/景区店
- 参考**地铁官网**的出站客流数据
- 或景区官方公布的游客数量

## 租金红线（必须记住）

```
日租金（含物业）≤ 预估日流水的 15%
```

**案例**：
- 目标日流水5,000元
- 日租金上限：5,000 × 15% = **750元/天**
- 月租金上限：750 × 30 = **22,500元/月**

## 避坑清单（实操版）

### 现场蹲点必做

- [ ] **3天蹲点**（含周末）：早中晚高峰数人头
- [ ] 记录人流**年龄结构**（判断目标客群匹配度）
- [ ] 记录行走方向（是否顺路经过你门前）
- [ ] 观察停留动作（是看店？还是只是路过）

### 政策风险排查

- [ ] 该地址能否办理**餐饮执照**？（直接问街道办/市场监管）
- [ ] 排烟管道是否具备改造条件？
- [ ] 燃气接入是否可行？
- [ ] 周边半年内是否有**修路/拆迁**规划？

### 极端天气测试

- [ ] 雨天去现场看人流是否锐减
- [ ] 高温/极寒天测试到达是否便利

## 快招加盟识别·选址专项

### 快招公司的选址陷阱特征

❌ 推荐"商住两用"地址（产权复杂，证照难办）
❌ 推荐"即将开通地铁"地址（画饼，实际无人流）
❌ 推荐"低价转让"铺子（往往是问题铺）
❌ 推荐"新商圈培育期"铺子（让你等商圈成熟，耗死你）

### 正确选址心态

✅ **宁可错过，不可错选** —— 省下的转让费即是第一笔利润
✅ **没有"绝对好铺"，只有"最适合你的铺"**
✅ 用**理性数据**代替**直觉判断**
