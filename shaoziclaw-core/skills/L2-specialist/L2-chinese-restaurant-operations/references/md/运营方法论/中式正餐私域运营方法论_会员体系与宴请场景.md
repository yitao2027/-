## 中式正餐业态特征（理解运营逻辑的前提）

| 特征 | 具体表现 | 运营影响 |
|------|---------|---------|
| **款项大** | 人均消费100-300元，婚宴/企业宴可达数万元 | 一单高价值，需要精准客户维护 |
| **回头客** | 宴请场景具有周期性（生日/纪念日/年节） | 复购率是生命线，不能靠流量 |
| **菜品多** | 菜单SKU普遍超100道 | 点菜体验和出品管理难度高 |
| **潮汐客流** | 婚宴/节假日爆满，平日空桌率高 | 私域是平滑客流最重要的工具 |

## 私域运营5步体系

### 第1步：数字化工具建立数据底座
- **核心工具**：扫码点餐 + 线上收银 + 会员系统
- **关键动作**：每桌强制扫码，沉淀会员信息
- **数据沉淀**：点了什么菜、消费金额、用餐场景（生日/宴请/商务）
- **降低依赖**：减少前厅服务员对复购的关键影响（服务员离职=客户流失）

### 第2步：会员分级体系
```
建议分级模型：
- 普通会员：消费1次，自动注册
- 银卡会员：年消费3次或金额≥1500元
- 金卡会员：年消费6次或金额≥5000元，含VIP专属包间预留权
- 企业会员：签约企业，享账期和专属菜单
```

### 第3步：宴请场景精细化运营（核心！）
- **宴前3小时**：客户经理联系确认菜品、忌口、特殊需求
- **宴前1小时**：后厨预制主要食材，保障准时出品
- **宴中服务**：专属服务员全程对接，不插手其他桌
- **宴后跟进**：次日发送宴请照片+感谢消息+下次预订优惠

### 第4步：私域内容运营
| 内容类型 | 频率 | 目标 |
|---------|------|------|
| 新菜推荐/季节菜单 | 每月1-2次 | 激活沉睡会员，刺激复购 |
| 节日提醒+预订优惠 | 节前1-2周 | 抢占节假日宴请 |
| 宴请案例展示 | 每周1-2次 | 建立宴请场景信任 |
| 会员专属活动 | 每季度1次 | 强化会员归属感 |

### 第5步：潮汐客流管理
- **低谷期引流**：私域发送"工作日套餐"、"会员专属折扣"
- **高峰期预约**：提前2-4周开放节假日预订，制造稀缺感
- **平峰期激活**：面向高价值会员（金卡）做专属品鉴活动

## 翻台率提升专项

### 中式正餐翻台率行业数据
- **行业均值**：2.1次/天（2024年）
- **优秀标准**：2.5次以上
- **限制因素**：宴请场景时间长（1.5-2小时），天然限制翻台

### 翻台率提升策略
1. **午市套餐化**：推出2-3人快捷套餐（45-60分钟出完，明显快于晚市宴请）
2. **包间分级定价**：小包间可接散客/商务局，而非仅保留宴请
3. **宴请场景时间管理**：服务员主动在1.5小时后礼貌提示，为下一场宴请做准备
4. **预约系统**：精确安排宴请时间档，避免撞场 = 白白损失一轮

## 宴请场景是中式正餐的护城河

**逻辑**：
- 宴请属于低频高价值场景（婚宴/寿宴/商务宴），顾客决策谨慎
- 一旦某家餐厅获得"宴请信任"，复购率极高（年均2-4次）
- 进入宴请推荐名单="口碑飞轮"：一次好宴请→带来10个潜在顾客

**建立宴请信任的核心**：
1. 菜品稳定性（每次口味一致）
2. 服务专属感（记住客户偏好）
3. 时间可靠性（出品不拖延）
4. 价格透明性（无隐性消费）
