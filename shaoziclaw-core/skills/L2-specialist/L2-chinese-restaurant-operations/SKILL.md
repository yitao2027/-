# L2-chinese-restaurant-operations
# 中式正餐门店核心运营体系

**层级：** L2 专项能力  
**部门归属：** 品类专项 - 中式正餐  
**触发词：** 中餐运营、正餐经营、中餐管理、宴席运营、包厢管理、高端中餐、商务宴请

---

## 一、Skill 定位

**解决什么问题：**  
专门帮助中式正餐品类经营者解决品类独有挑战，包括包厢管理、宴席接待、高端食材成本管控、服务标准化和淡旺季运营节奏。

**中式正餐品类核心特征：**
- 人均消费高（80-300元+）
- 宴席/聚餐场景主导
- 包厢资源是核心竞争力
- 厨师依赖程度高（技艺传承难）
- 服务标准复杂（比快餐高出数倍）
- 食材成本构成复杂（高端食材占比高）

---

## 二、核心方法论

### 2.1 正餐成本结构管理

```
中式正餐典型成本结构（人均80-150元）：

食材成本：38-45%（食材要求高，成本偏高）
├── 主食材（肉/海鲜/禽类）：20-28%
├── 蔬菜/时令食材：8-12%
├── 调料/高汤/用油：4-6%
└── 酒水/茶水（自带除外）：3-5%

人力成本：25-32%（厨师/服务员占比高）
房租：10-15%
其他：5-8%
综合成本率：78-92%
净利润：8-22%（正餐利润率往往低于想象）

核心管控难点：
- 高端食材（海鲜/生猛活体）损耗高
- 厨师人工占人力成本比例大（核心厨师工资高）
- 包厢空置率影响坪效（大包厢闲时等于成本）
```

### 2.2 包厢资源精细化管理

```
包厢是正餐门店核心资产，精细化运营核心：

① 包厢分类定价策略
→ 按面积/装修/位置设定最低消费（保底消费）
→ 示例：
  小包厢（6-8人）：最低消费1500-2000元
  中包厢（8-12人）：最低消费3000-5000元
  大包厢（12-20人）：最低消费8000-12000元
→ 合理设置保底消费：太低=亏本占用资源；太高=拒绝潜在客户

② 包厢预订管理系统
→ 必须有预订台账（日期/时间/人数/定金/特殊需求）
→ 定金规则：100-300元/桌（防止爽约）
→ 提前1天再次确认（减少临时取消）
→ 当天爽约处理：定金不退/优先保留重新预订优惠

③ 包厢空置率优化
→ 分析包厢使用数据：哪个时段/哪个包厢空置率高
→ 高空置时段：推出包厢特价套餐（午市/工作日）
→ 大包厢低谷期：改变用途（私人派对/生日庆典包场）

④ VIP客户包厢管理
→ 常客的偏好记录（习惯座位/饮食禁忌/特殊喜好）
→ 重要客户预留最优包厢（关系户管理）
→ 客户生日/纪念日主动提醒预订（精准维护）
```

### 2.3 宴席接待标准体系

```
宴席是正餐最重要的业务，标准化是核心：

宴席接待五步标准：

① 预订阶段（电话/到店咨询）
□ 了解需求：人数/预算/菜系偏好/忌口/特殊要求
□ 推荐套餐：3档选择（实惠/标准/精品）
□ 确认定金：签约宴席合同（正式宴席建议）
□ 特殊需求确认：寿桃/蛋糕/鲜花/布置等

② 准备阶段（提前1-2天）
□ 告知厨房宴席菜单
□ 特殊食材提前采购（活海鲜/高端食材预订）
□ 包厢/大厅布置确认（鲜花/装饰/名卡）
□ 服务人员分配（宴席专属服务员）

③ 迎接阶段（宴席当天）
□ 接待人员在门口等候（提前15分钟）
□ 茶水点心备好（等待期间款待）
□ 重要宾客座位安排（主宾位标注）
□ 特殊仪式安排就位（寿星出场/签到台等）

④ 用餐阶段
□ 上菜节奏控制（冷菜→汤→热菜→主食→甜品）
□ 服务员主动介绍每道菜（简短1-2句）
□ 主动续水/倒酒（不等顾客要）
□ 随时关注桌面需求

⑤ 结束阶段
□ 打包服务（主动提供，不浪费剩菜）
□ 结账服务（账单送到主宾）
□ 送客（门口送至车辆）
□ 后续：发感谢短信/微信（次日）
```

### 2.4 高端食材成本管控

```
正餐高端食材特殊管控：

【活体海鲜管理】
→ 养殖成本计算：每天损耗率 × 进价 = 日养殖成本
→ 活体损耗预警：超过5%/天需查原因（水质/密度/温度）
→ 售完时间目标：进货后3天内用完（损耗最小化）

【高档食材（燕窝/鲍鱼/松茸/鱼翅替代品）】
→ 独立储存（专柜/专区）
→ 专人保管签字交接
→ 每次使用称重记录（防止私下克扣）
→ 进销存日报：每日核对库存与使用量

【时令食材管理】
→ 按季节调整菜单（不强行用非当季食材，品质差且成本高）
→ 时令食材优先上菜单（新鲜感+成本相对低）
→ 当日采购当日用完（不隔夜冷藏）

成本率监控（高端食材）：
- 海鲜类：单独计算成本率（不混入整体）
- 目标：海鲜类成本率45-55%（比普通菜高，但溢价空间大）
- 红线：海鲜成本率超60%需重新定价
```

### 2.5 正餐厨师团队管理

```
中餐厨师是核心资产，也是最大风险点：

风险：关键厨师离职=菜品失去灵魂=顾客流失

降低厨师依赖风险的四个策略：

① 菜品标准化
→ 核心菜品的配方/用量/步骤文档化
→ 让二厨也能做出标准水平（关键菜拍摄操作视频）
→ 标准化程度高=主厨离职风险降低

② 厨师梯队建设
→ 主厨+二厨+学徒的梯级结构
→ 主厨专注创新和质量把控
→ 二厨负责主力出品，要培养到可以独立顶班

③ 薪酬留人
→ 主厨薪酬要有竞争力（不要等离职了才涨工资）
→ 绩效方案：营业额提成/利润分红（利益绑定）
→ 工作条件改善：厨房设备升级/改善工作环境

④ 竞业协议（谨慎使用）
→ 主厨签署竞业协议（合理范围内）
→ 核心菜品配方列为商业机密
→ 合法框架内保护核心竞争力
```

### 2.6 商务宴请场景设计

```
商务宴请是中式正餐核心场景，特殊需求：

【选包厢建议话术】
"您是商务宴请需要安静私密的氛围，我推荐我们的___包厢，独立空间，隔音效果好，配有专属服务员，您看适合吗？"

【菜单推荐逻辑】
→ 商务宴请：以"体面"为原则，不要过分节省
→ 推荐策略：1-2道主菜（有档次）+ 几道常规菜（不显寒酸）
→ 不推含海鲜的菜品（除非客户主动要求/了解口味）
→ 务必询问：是否有忌口/过敏/特殊饮食要求

【服务细节】
→ 话术：主动介绍菜品时注重"食材来源/特色做法"（有谈资）
→ 不主动提价格（让客人自在）
→ 倒酒添茶主动服务，不等顾客招手
→ 结账时：账单封闭式送到主人面前

【后续维护】
→ 宴席结束次日发感谢消息（礼貌不打扰）
→ 月度客户维护：节日问候/新菜推荐
→ 重要客户：老板/管理者亲自打招呼
```

## 四、触发条件与输出

**输入收集：**
```
请告诉我：
1. 餐厅规模？（面积/包厢数/座位数）
2. 人均消费定位？
3. 主要顾客类型？（商务宴请/家庭聚餐/婚宴/日常散客）
4. 最大经营痛点？（包厢空置/厨师不稳/成本高/客流少）
5. 是否有连锁扩张计划？
```

**输出内容：**
- 正餐经营健康度诊断
- 包厢管理优化方案
- 宴席接待标准化建议
- 高端食材成本控制方案
- 商务宴请服务提升方案
