# L2-waimai-operation：外卖精细化运营

> 系统提升外卖业务能力，实现外卖从"增量"到"增利"的转变
>
> **⚠️ 价值观红线：不作恶、诚信经营、食品安全是底线。** 本Skill所有方法论仅限合规使用。绝不建议刷单、虚假交易、引导好评等违规操作。

---

## 触发场景

- 外卖订单多但不赚钱，想提升盈利能力
- 外卖评分低，不知道怎么提升
- 不知道怎么做外卖活动才有效果
- 想提升外卖排名但找不到方法
- 被平台抽成太高，想降低成本
- 想开外卖但不知道怎么运营

## 核心方法论

### 一、外卖经营核心公式

```markdown
外卖净利润 = 曝光量 × 进店率 × 下单率 × 客单价 × 利润率 - 平台成本

各环节优化方向：
- 曝光量：提升排名/参加活动/投放推广
- 进店率：优化头像/店名/评分/活动
- 下单率：优化菜单/图片/价格/评价
- 客单价：满减设计/套餐推荐/加购引导
- 利润率：成本控制/定价策略/活动设计
- 平台成本：抽成优化/推广控制/履约效率
```

### 二、外卖曝光提升

#### 1. 排名权重解析

| 权重因素 | 占比 | 优化方向 |
|----------|------|----------|
| 主营品类相关性 | 15% | 主营品类准确 |
| 近期销量 | 20% | 提升订单量 |
| 活动力度 | 15% | 合理设置活动 |
| 店铺评分 | 15% | 提升服务/产品 |
| 客单价与品类均值比 | 10% | 定价合理 |
| 起送价与配送费 | 10% | 设置合理 |
| 店铺信息完整度 | 5% | 完善信息 |
| 异常订单率 | 10% | 减少差评/拒单 |

#### 2. 曝光提升三板斧

```markdown
第一斧：冲单量（核心权重）
- 新店期（前30天）：全力冲量
- 目标：冲到品类前20%
- 方法：限时折扣+新手券+新手任务

第二斧：做活动（活动加权）
- 必开活动：满减/折扣/新客立减
- 加权活动：津贴联盟/粉丝券/限时抢
- 活动设置：略低于竞品，确保加权优势

第三斧：投推广（付费流量）
- 品类关键词：精准触达目标用户
- 区域定向：覆盖目标配送范围
- 时段投放：高峰期前1小时开始
- 出价策略：逐步加价，找到最优出价
```

#### 1. 店铺门面优化

| 要素 | 优化标准 | 操作要点 |
|------|----------|----------|

| 评分/销量 | 真实展示 | 差评多时用时间积累稀释 |
| 配送信息 | 准确 | 配送费/预计时间/起送价 |
| 营业时间 | 标注清晰 | 避免非营业时间曝光 |

#### 2. 店铺信息完整度

```markdown

□ 店铺名称（品牌+品类）

□ 营业时间（精确到小时）
□ 配送信息（范围/费用/时间）

选填加分项：
□ 品牌故事

□ 视频展示
□ 粉丝群入口
```

### 四、下单转化提升

#### 1. 菜单结构设计

```markdown
外卖菜单结构黄金布局：

位置1：爆款引流（第1-3位）
- 门店最畅销的2-3款
- 限量折扣sku（成本可控）
- 冲击力强的产品图

位置2：凑单必备（引流产品）
- 9.9元小食/饮品
- 高性价比，用户必点
- 提升客单价利器

位置3：利润主力（核心利润款）
- 高毛利产品
- 差异化产品
- 组合套餐

位置4：丰富选择（常规款）
- 覆盖不同口味/需求
- 满足长尾需求
- 增加可逛性

位置5：品牌特色（认知款）
- 门店招牌/必吃推荐
- 建立品牌认知
- 提升品牌溢价
```

#### 2. 产品图优化

```markdown
外卖产品图拍摄标准：

基础要求：
- 分辨率：≥1280×720
- 比例：建议1:1或4:3
- 背景：纯色/简洁/与菜品有反差
- 光线：自然光或专业灯光，避免阴影

进阶技巧：
- 角度选择：
  * 45度角：最常用，百搭
  * 俯拍：适合有层次的产品
  * 特写：适合细节精致的产品
  
- 构图技巧：
  * 三分法构图
  * 留白适当（不要铺满）
  * 主体突出

- 后期处理：
  * 适度美化（不要过度失真）
  * 色彩调整（暖色调更诱人）
  * 添加阴影（增加立体感）
```

### 五、满减活动设计

#### 1. 满减设计原理

```markdown
满减设置公式：

满X减Y = 毛利率 × 满减门槛 + 让利空间

假设：
- 产品成本率：30%
- 目标满减让利：20%
- 合理满减设计：

方案A：满20减5（实收15元）
- 毛利率 = (15-4.5)/15 = 70%
- 让利 = 5/20 = 25%

方案B：满30减8（实收22元）
- 毛利率 = (22-6.6)/22 = 70%
- 让利 = 8/30 = 27%

方案C：满50减15（实收35元）
- 毛利率 = (35-10.5)/35 = 70%
- 让利 = 15/50 = 30%

设计原则：
1. 门槛要高于客单价20-30%
2. 减的金额要让用户有感
3. 确保毛利在60%以上
```

#### 2. 满减档位设计

```markdown
单档满减 vs 多档满减：

单档满减（简单粗暴）
- 适合：标准化套餐店
- 优点：用户决策简单
- 缺点：客单价提升空间有限
- 示例：满25减5

多档满减（引导加购）
- 适合：菜品丰富的正餐店
- 优点：引导用户加购，提升客单
- 缺点：设置复杂，用户选择难
- 示例：
  * 第一档：满20减4（凑单门槛）
  * 第二档：满35减8（主力门槛）
  * 第三档：满60减18（提升客单）

设计技巧：
- 第一档：略高于平均客单价
- 第二档：高于客单价20-30%
- 第三档：促进多人拼单
```

### 六、外卖评分管理

#### 1. 评分权重与计算

```markdown
外卖平台评分计算：

美团：最近6个月评价加权平均
饿了么：最近365天评价

好评权重因素：
- 有图评价权重更高
- 追加评价权重更高
- 评价时间越近权重越高

差评影响：
- 单差评可拉低0.1-0.3分
- 差评回复不及时加重影响
- 差评聚集（同类问题）毁灭性影响
```

#### 2. 差评预防与处理

```markdown
差评预防SOP：

出餐前：
- 产品出餐前检查
- 打包密封检查
- 核对订单备注

配送中：
- 选择优质骑手
- 保温措施到位
- 叮嘱骑手轻拿轻放

差评处理：
1. 差评预警（平台通知后30分钟内响应）
2. 私信联系（真诚道歉+解决方案）
3. 差评回复（公开回复展示态度）
4. 原因分析（归类统计，持续改进）

差评回复模板：

[口味问题]
亲，非常抱歉给您带来不好的体验。您反馈的口味偏咸/偏辣问题我们已经反馈给后厨，会在制作时调整。您的建议是我们进步的动力，期待下次为您呈现更好的产品~

[分量问题]
亲爱的顾客，看到您的反馈我们深感抱歉。小份确实分量较少，建议您下次选择大份或加量哦~ 感谢您的支持，我们会继续努力！

[配送问题]
亲爱的，非常抱歉配送超时/包装破损给您带来困扰。我们会加强与骑手的沟通，也欢迎下次直接联系我们，我们会第一时间为您处理~
```

### 七、外卖成本控制

#### 1. 外卖成本结构

```markdown
外卖综合成本拆解：

假设客单价30元，实际到手22元：

| 成本项 | 金额 | 占比 |
|--------|------|------|
| 产品成本 | 9元 | 30% |
| 平台抽成 | 4.5元 | 15% |
| 推广费用 | 1.5元 | 5% |
| 包装成本 | 1元 | 3.3% |
| 配送补贴 | 2元 | 6.7% |
| 其他 | 1元 | 3.3% |
| 合计成本 | 19元 | 63.3% |
| 实际毛利 | 3元 | 10% |

成本优化方向：
1. 降低产品成本（采购/损耗）
2. 降低平台抽成（谈判/提升单量）
3. 控制推广费用（精细投放）
4. 降低包装成本（集采/简化包装）
5. 优化配送（合理定价减少补贴）
```

#### 2. 盈亏平衡测算

```markdown
外卖盈亏平衡分析：

固定成本（不分摊）：
- 平台保证金：一次性
- 店铺装修：一次性

变动成本：
- 每单产品成本：__元
- 每单平台抽成：__%
- 每单推广费用：__元
- 每单包装：__元

盈亏平衡点：
每月固定成本 ÷ (客单价 - 每单变动成本) = 每月保底订单量

例：
- 每月固定成本：2000元（人员/设备折旧）
- 客单价：30元
- 产品成本率：30%
- 平台抽成：18%
- 推广费用：5%
- 包装：1元

每单变动成本 = 9 + 5.4 + 1.5 + 1 = 16.9元
每单毛利 = 30 - 16.9 = 13.1元

盈亏平衡 = 2000 ÷ 13.1 ≈ 153单/月
每日保底 = 153 ÷ 30 ≈ 5单/天
```

## 使用说明

1. **数据驱动**：每天关注数据变化，及时调整策略
2. **用户为本**：所有优化都以用户满意为目标
3. **长期主义**：不要为了订单牺牲利润
4. **持续迭代**：外卖竞争激烈，要持续学习优化
5. **合规经营**：遵守平台规则，避免违规扣分
