## 触发场景

当用户需要制定抖音/美团/小红书等平台广告投放策略、评估投放效果、或优化投放账户时，启用此 Skill。

## 输入

- 投放目的：品牌曝光 / 引流到店 / 外卖转化 / 私域获客
- 投放平台：抖音（DOU+/千川）/ 美团推广通 / 小红书蒲公英
- 预算范围
- 门店/品牌基础数据

## 工作流程

### Step 1：投放目标与渠道选择

```
【投放目标选择】

| 目标 | 适合平台 | 适用阶段 | 考核指标 |
|------|----------|----------|----------|
| 品牌曝光 | 抖音信息流 | 新店开业/品牌升级 | 播放量/CPM |
| 引流到店 | 抖音本地推广 | 日常运营 | 到店核销率 |
| 外卖转化 | 美团推广通 | 外卖为主 | 下单数/CPS |
| 私域获客 | 抖音/小红书 | 私域搭建期 | 加粉成本 |
```

### Step 2：抖音DOU+投放策略

```
【DOU+适合场景】
□ 单条视频自然流量差，需要助推
□ 新店开业，快速获取初始流量
□ 优质内容希望更多人看到
□ 测投新内容方向

【DOU+投放设置】
□ 目标用户：
  - 相似达人粉丝（找到对标账号的粉丝）
  - 地域定向（门店周边X公里）
  - 兴趣标签（美食/餐饮/本地生活）
  
□ 投放金额：
  - 首次测试：100-300元/条
  - 爆款续投：按ROI持续追加
  - 日预算上限：设定防止超支

□ 投放时长：
  - 短期测试：6-12小时
  - 爆款续热：持续投放直到ROI下降

【DOU+ vs 千川选择】
DOU+：适合内容加热，不能挂载团购/外卖
千川：适合本地推广，可以挂载POI/团购，转化链路更短
```

### Step 3：投放内容设计

```
【高转化投放内容特征】
□ 前3秒强开场：快速抓住注意力
□ 15-30秒黄金时长：不要太长，降低跳出率
□ 明确召唤动作：立即点击/立即购买/立即预约
□ 门店信息清晰：价格/地址/活动一目了然
□ 真实可信：不是明显的广告感

【投放素材类型】
□ 探店类：达人探店，展示真实体验
□ 产品展示类：产品特写，激发食欲
□ 优惠信息类：大幅优惠，直接召唤
□ 场景营造类：营造氛围感/生活方式
```

### Step 4：ROI评估与优化

```
【关键投放指标】

| 指标 | 定义 | 达标值 |
|------|------|--------|
| 播放成本 | 100元播放 ÷ 播放量 | <0.5元/播放 |
| 互动成本 | 100元互动 ÷ 点赞+评论 | <2元/互动 |
| 到店成本 | 100元消耗 ÷ 到店核销数 | <30元/人 |
| 投产比(ROI) | 到店消费额 ÷ 投放金额 | >3倍 |

【ROI分析】
□ ROI>3：持续投放，扩大预算
□ ROI 1.5-3：优化素材或定向，持续测试
□ ROI<1.5：暂停投放，分析原因

【投放优化方向】
□ 素材不行 → 换新脚本
□ 定向不准 → 调整人群包
□ 落地页差 → 优化购买/预约流程
□ 时段不对 → 调整投放时间
```

## 核心方法论

### 投放内容黄金公式

```
高转化内容 = 强开场（前3秒）× 价值内容（中间）× 明确召唤（结尾）

开场5种：
1. 数字："只要X元，XX元的产品带回家"
2. 反差："在我店吃了一顿饭，我哭了出来"
3. 提问："你真的知道XX是什么吗？"
4. 直接展示：展示最终产品/结果
5. 限时感："今天最后一天，过期不候"
```

### 投放三阶段

1. **测试期**（1-2周）：小额测试（300-500元/天），测素材/定向
2. **放量期**：找到跑得动的素材，大幅追加（1000-3000元/天）
3. **稳定期**：ROI稳定，精细化运营，控制成本
