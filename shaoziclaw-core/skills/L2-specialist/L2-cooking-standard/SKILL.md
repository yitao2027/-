- 出餐标准化

- 出品管理

### 触发场景描述
出品不稳定是餐饮门店的致命问题。本skill帮助建立出餐标准化体系，确保每一份菜品品质一致。

## 核心方法论

### 出餐标准化三要素

```
出餐标准化 = 配方标准化 × 操作标准化 × 考核标准化
```

### 配方标准化

```
标准化配方包含：
1. 食材规格（品牌/重量/数量）
2. 调味料配比（精确到克）
3. 加工步骤（时间/温度/顺序）
4. 成品标准（图片+文字）
```

### 操作标准化

```
标准化操作包含：
1. 设备参数（温度/时间/压力）
2. 操作步骤（动作分解）
3. 时限要求（每步几分钟）
4. 异常处理（失败怎么办）
```

### 考核标准化

```
标准化考核包含：
1. 巡检制度（定时/定量）
2. 抽检机制（随机/专项）
3. 评分标准（量化指标）
4. 奖惩制度（和工资挂钩）
```

### 出餐时间标准

| 业态 | 出餐时限 | 说明 |
|------|----------|------|
| 快餐 | 3-5分钟 | 预制为主 |
| 茶饮 | 30秒-2分钟 | 流水线操作 |
| 正餐 | 15-20分钟 | 现点现做 |
| 火锅 | 10-15分钟 | 备菜为主 |

## 操作流程

### Step 1：梳理菜单

```
筛选需要标准化的菜品：
□ 点击率前20%的菜品
□ 出品问题多的菜品
□ 新员工容易出错的菜品
□ 客诉率高的菜品
```

### Step 2：编写标准卡

```
标准卡格式：
- 菜品名称
- 配方（食材+调料+用量）
- 操作步骤（分解到每个动作）
- 设备参数（温度/时间）
- 成品标准（图片+感官描述）
- 常见问题及处理
```

### Step 3：培训与执行

```
培训流程：
1. 理论讲解（为什么要这么做）
2. 演示操作（师傅做一遍）
3. 学员实操（跟着做）
4. 考核认证（达标才能上岗）
5. 定期复训（防止遗忘）
```

### Step 4：检查与改进

```
检查机制：
- 每日：出品抽检3-5份
- 每周：全项目检查
- 每月：客诉分析+改进
```

```
### 第三步：培训体系

**认证流程：**
```
新员工入职
    ↓
总部培训（3天）
    ↓
理论考核（80分及格）
    ↓
实操考核（标准卡为依据）
    ↓
门店带训（7天）
    ↓
独立操作认证
    ↓
定期复训（每月）
```

**培训内容：**
| 阶段 | 内容 | 时长 | 考核 |
|------|------|------|------|
| 理论 | 标准重要性、配方记忆 | 1天 | 笔试 |
| 演示 | 师傅示范操作 | 1天 | - |
| 实操 | 学员跟着做 | 3天 | 实操 |
| 带训 | 门店实战 | 7天 | 综合 |

### 第四步：检查机制

**三级检查体系：**
| 级别 | 频率 | 执行人 | 检查内容 |
|------|------|--------|----------|
| 自检 | 每份出品 | 操作员 | 外观/温度/份量 |
| 互检 | 每天3次 | 值班长 | 随机抽检 |
| 巡检 | 每周1次 | 督导 | 全项目检查 |
| 飞检 | 每月2次 | 总部 | 不通知抽查 |

**评分标准：**
| 分值 | 评级 | 处理 |
|------|------|------|
| 90-100 | 优秀 | 表扬+奖励 |
| 80-89 | 合格 | 保持 |
| 70-79 | 警告 | 整改 |
| <70 | 不合格 | 停岗培训 |

### 第五步：持续改进

```
客诉反馈 → 问题分析 → 标准优化 → 培训更新 → 执行落地
```

**月度复盘内容：**
1. 客诉TOP3问题
2. 抽检不合格项
3. 新品标准化需求
4. 标准卡更新版本

### 预期效果
| 指标 | 现状 | 目标 | 提升 |
|------|------|------|------|
| 口味一致率 | 70% | 95% | +25% |
| 出品投诉 | 10次/月 | 2次/月 | -80% |
| 培训周期 | 无标准 | 2周认证 | - |
```

## 专家点评（避坑提示）

**SOP常见误区**：
1. **标准太复杂** → 员工记不住，等于没做
2. **只做不检查** → 执行不下去
3. **一次做到位** → 持续迭代才有效

**正确姿势**：
- 先核心菜品，再全面覆盖
- 标准要简单到员工能记住
- 检查和奖惩必须跟上
