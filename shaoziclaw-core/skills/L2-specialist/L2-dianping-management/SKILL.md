## 触发场景

当用户需要提升大众点评星级、冲榜单、处理差评、或系统化运营点评平台时，启用此 Skill。

---

## 输入

- 当前星级：X星（4.0/4.5等）
- 当前月评价数
- 主要问题：星级低 / 差评多 / 无榜单 / 曝光少

## 工作流程

### Step 1：现状诊断

```
【星级计算公式】
注：以下为参考逻辑，实际算法由平台决定
综合评分 = (评价加权分总和) ÷ (有效评价数)

【星级影响因素】
□ 评价数量（需要足够的评价基数）
□ 评价质量（文字+图片+内容质量）
□ 评价用户等级（高等级用户权重更高）
□ 评价时间（近期评价权重更高）
□ 评价分布（不能全是5星，要有梯度）

【当前诊断】
当前星级：[     ]
月均评价数：[     ]条
近30天新增：[     ]条
好评率：[     ]%
差评数（近30天）：[     ]条
当前是否在榜单：[榜单名称]
```

### Step 2：好评获取策略

```
【合规邀评话术】

□ 收银台/餐桌卡：
  "您的用餐体验如何？满意的话欢迎在大众点评给我们一颗星，  
  您的反馈是我们进步的动力！"

□ 收银时：
  "感谢您今天的光临，方便的话可以帮我们在大众点评上写两句  
  评价吗？您的支持是我们最大的动力！"

□ 外卖小票：
  "感谢您的订单！满意的话欢迎在大童点评写下您的体验，  
  我们会继续努力～"

【邀评禁区】（平台明确禁止）
⚠ 不能用优惠/现金换取好评
⚠ 不能要求用户只能写好评
⚠ 不能引导用户修改/删除差评
⚠ 不能自己写虚假评价
```

### Step 3：差评预防与应对

```
【差评预防】
□ 服务敏感时刻主动关怀：
  - 等位超15分钟
  - 上菜超20分钟
  - 菜品出现问题
  
□ 主动道歉+补偿：
  - 小问题：送菜/打折
  - 中等问题：免单部分+道歉
  - 大问题：全单减免+负责人道歉

【差评回复标准模板】

普通差评回复：
"您好，感谢您的反馈。[具体问题]确实是我们的不足，  
我们已[具体处理措施]，欢迎下次光临时验证我们的改变。"

菜品问题：
"感谢指出，关于[菜品名]的口味问题，我们已反馈给厨师长，  
会着重改进，期待下次为您呈现更好的体验。"

服务问题：
"您好，服务不周是我们的问题，[服务改进措施]，  
店长[联系方式]，期待您再次光临。"

恶意差评：
"您好，对于您的反馈我们非常重视。门店一贯坚持[标准]，  
如方便欢迎联系我们进一步沟通，我们将积极处理。"

【差评回复原则】
- 24小时内回复
- 态度真诚，不狡辩
- 有具体改进措施
- 不暴露顾客隐私
```

### Step 4：榜单冲榜策略

```
【主流榜单类型】

| 榜单 | 核心标准 | 冲榜策略 |
|------|----------|----------|
| 必吃榜 | 口味/服务/体验综合评分top | 提升整体体验 |
| 热门榜 | 近期热度+评分 | 持续产出内容 |
| 好评榜 | 好评数量+质量 | 邀好评+好评率 |
| 回头客榜 | 复购率 | 提升顾客复购 |
| 星级榜 | 综合评分 | 提升评分+邀评 |

【冲榜行动计划】
□ 每日目标评价：≥3条（保持热度）
□ 每月目标评价：≥100条（建立基数）
□ 好评率目标：≥90%
□ 差评响应率：100%（24小时内）
□ 门店图片：≥50张（多角度/多场景）
□ 菜品数量：完整展示菜单
```

### Step 5：平台曝光优化

```
【店铺信息完整度检查】
□ 店名包含品类关键词
□ 营业时间准确
□ 联系方式准确
□ 地址定位精确（微调位置更靠近客流方向）
□ 头图精美（体现品质感，不只是logo）
□ 相册丰富：环境/菜品/服务/门店全景
□ 团购套餐：设置2-3个价格档位
□ 关键词：在简介中覆盖品类关键词

【曝光提升技巧】
□ 每周更新3-5张新图片
□ 参与平台活动（节日/平台营销）
□ 及时回复所有评价（平台权重因子）
□ 开通推广通（付费流量补充）
```

## 核心方法论

### 星级提升三要素

1. **量**：足够的评价数量（至少100条起）
2. **质**：评价内容有深度（文字+图片，50字以上）
3. **新**：近期评价权重更高，持续有新增

### 平台算法逻辑（参考）

- 评价时间：近30天>近90天>更早
- 用户等级：Lv5+权重>Lv3>Lv1
- 内容质量：带图长文>简短文字>仅打分
- 回复率：回复差评→平台认为你重视用户体验
