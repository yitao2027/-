### 触发场景描述
区域保护是加盟体系稳定的基础。本skill帮助品牌方设计合理的区域保护政策，平衡品牌扩张和加盟商利益。

## 核心方法论

### 区域保护模式

```
三大模式：

模式A：城市独家
- 以城市为单位，独家授权
- 适合：直营+加盟混合

模式B：商圈独家
- 以商圈/街道为单位授权
- 适合：密集扩张型品牌

模式C：距离保护
- 固定距离内不开第二家
- 适合：初期扩张阶段
```

### 保护范围设计

```
保护范围考量因素：

1. 城市级别
   - 一线城市：按区划分
   - 二线城市：按区/商圈划分
   - 三四线：按城市划分

2. 业态类型
   - 高密度型（茶饮/快餐）：500米保护
   - 中密度型（正餐）：1公里保护
   - 低密度型（宴请/高端）：全城保护

3. 城市规模
   - 小城市（50万人口）：1家足够
   - 中城市（50-200万）：按区域2-3家
   - 大城市（200万+）：按商圈授权
```

### 保护条件

```
保护权不是白给的，需要达成条件：

保护条件：
□ 首年开店数量
□ 年度业绩要求
□ 品牌授权费缴纳
□ 物料采购达标
□ 接受督导管理

未达标后果：
- 部分取消保护
- 取消独家资格
- 合同终止
```

## 操作流程

### Step 1：确定保护模式

```
选择保护模式：
□ 城市独家
□ 商圈独家
□ 距离保护
□ 组合模式
```

### Step 2：划定保护范围

```
区域划分依据：
□ 行政区划
□ 商圈分布
□ 人口密度
□ 消费能力
□ 交通便利度
```

### Step 3：设定保护条件

```
保护条件设计：
□ 开店门槛（首批开店数量）
□ 业绩门槛（年销售额/客流）
□ 费用要求（加盟费/保证金）
□ 行为约束（不允许什么）
```

### Step 4：写入合同

```
合同必备条款：
□ 保护范围明确（地图标注）
□ 保护条件明确
□ 违约责任明确
□ 退出机制明确
□ 争议解决机制
```

## 使用示例

### 场景：茶饮品牌区域保护设计

**用户输入**：
> 我是茶饮连锁品牌，准备开放加盟，想设计区域保护政策，应该怎么设定保护范围和条件？

**Skill输出**：
```
## 茶饮连锁区域保护政策

### 一、保护模式选择

**推荐：商圈独家+距离保护组合**

| 城市级别 | 保护模式 | 保护距离 |
|----------|----------|----------|
| 一线城市 | 商圈独家 | 500米内不重复授权 |
| 二线城市 | 商圈独家 | 500米内不重复授权 |
| 三四线城市 | 城市独家 | 整个城市独家 |

### 二、保护范围划分

#### 一线城市（以区为单位）
```
以区为单位授权

示例（上海）：
| 区域 | 商圈数 | 规划门店 |
|------|--------|----------|
| 浦东新区 | 10个 | 10-15家 |
| 静安区 | 5个 | 5-8家 |
| 黄浦区 | 4个 | 4-6家 |
```

#### 二线城市（以区为单位）
```
以区为单位授权

示例（成都）：
| 区域 | 商圈数 | 规划门店 |
|------|--------|----------|
| 武侯区 | 6个 | 6-10家 |
| 锦江区 | 5个 | 5-8家 |
```

#### 三四线城市（城市独家）
```
整个城市独家授权

适用城市：
- 县级市：1家
- 地级市：2-3家
- 省会城市：按区划分
```

### 三、保护条件

#### 首批开店要求
| 城市级别 | 首批最低 | 时间要求 |
|----------|----------|----------|
| 一线城市 | 2家 | 签约后12个月 |
| 二线城市 | 2家 | 签约后12个月 |
| 三四线城市 | 1家 | 签约后12个月 |

#### 年度续约条件
| 条件 | 要求 | 达标奖励 |
|------|------|----------|
| 年营业额 | ≥¥100万 | 续约保护 |
| 物料采购率 | ≥90% | 续约保护 |
| 督导合格 | ≥80分 | 续约保护 |

### 四、违约处理

#### 品牌方违约
| 违约类型 | 责任 |
|----------|------|
| 在保护范围内授权第三方 | 退还加盟费+赔偿损失 |
| 未按约定支持 | 整改+补偿 |

#### 加盟商违约
| 违约类型 | 处理 |
|----------|------|
| 未达首批开店要求 | 取消独家资格 |
| 年度业绩不达标 | 取消下一年保护 |
| 私采物料 | 暂停授权+整改 |
| 严重违规 | 解约+追责 |

### 五、退出机制

| 退出类型 | 品牌方处理 | 加盟商处理 |
|----------|------------|------------|
| 主动退出（提前6个月通知） | 退还剩余物料 | 退还保证金 |
| 被动退出（违规/不达标） | 没收保证金 | 无补偿 |
| 合同到期不续约 | 无 | 退还保证金 |

### 六、合同模板关键条款

```
第三条 区域保护
3.1 甲方在【城市/区域】授予乙方独家加盟权。
3.2 保护范围：以本合同签署地为中心，半径【500米/1公里】范围内，甲方不再授权第三方开设同品牌门店。
3.3 乙方须在签约后12个月内开设不少于【2】家门店，方可享有独家保护权。

第四条 续约条件
4.1 乙方须在每个合同年度达成以下条件，方可续约并延续保护权：
    （1）年营业额不低于人民币【100】万元；
    （2）物料采购率不低于【90】%；
    （3）督导评分不低于【80】分。

第五条 违约责任
5.1 甲方违反区域保护条款，应退还乙方已缴纳费用并赔偿损失人民币【10】万元。
5.2 乙方违反本合同条款，甲方有权暂停或终止授权。

## 专家点评（避坑提示）

**区域保护误区**：
1. **保护范围太大** → 品牌扩张受限
2. **保护范围太小** → 加盟商不赚钱
3. **条件太松** → 保护变空文
4. **条件太严** → 加盟商积极性低

**正确姿势**：
- 保护是为了让加盟商赚钱，不是让他躺赢
- 保护有条件，达标才有
- 动态调整，保护和发展平衡
