# 节假日营销全案策划

**层级：** L2 专项能力  
**部门归属：** 市场营销部  
**触发词：** 节假日活动、节日策划、双旦活动、春节营销、情人节活动、五一大促、节庆营销

---

## 一、Skill 定位

**解决什么问题：**  
帮助餐饮门店系统规划全年节假日营销，每个节点精准打法，既提升营业额又积累品牌认知，避免盲目跟风式节日促销导致的利润损失。

**核心认知：**
- 节日≠打折，打折是最低级的节日营销
- 好的节日营销 = 借势 + 创造体验 + 情感连接
- 每个节日有不同的顾客心理需求，营销逻辑不同

## 二、核心方法论

### 2.1 全年节日营销日历（核心节点）

```
【Q1：1-3月】
├── 元旦（1/1）：年度开门红，主题年夜饭预订
├── 春节（农历正月初一）：★★★★★ 全年最重要
│   └── 关键动作：年夜饭预订、新年限定菜、年货礼盒
├── 元宵节（正月十五）：汤圆主题、家庭聚餐
└── 情人节（2/14）：★★★★ 双人套餐、仪式感场景

【Q2：4-6月】
├── 清明（4/4前后）：踏青场景、外卖春日限定
├── 五一（5/1-5/5）：★★★★ 长假堂食+外卖双线
├── 母亲节（5月第二个周日）：亲情主题、女性优待
└── 儿童节（6/1）：亲子场景、儿童套餐、互动活动

【Q3：7-9月】
├── 七夕（农历七月初七）：★★★★ 情侣营销第二波
├── 中元节（7月15日）：低调，不做负面联想营销
└── 中秋节（农历八月十五）：★★★★ 月饼礼盒、家庭团圆

【Q4：10-12月】
├── 国庆（10/1-10/7）：★★★★ 假期流量收割
├── 重阳节（9/9）：敬老主题，银发客群专属
├── 双十一（11/11）：外卖/预售/囤券活动
├── 圣诞（12/25）：★★★ 西化氛围+年轻客群
└── 元旦前夜（12/31）：跨年主题、倒计时活动
```

### 2.2 节日营销四象限策略

```
                营业额拉升
                    ↑
        低利润高流量  │  高利润高流量
       （引流型节日）  │  （收割型节日）
──────────────────┼──────────────────
        低利润低流量  │  高利润低流量
       （可选择做/不做）│  （品牌型节日）
                    └──────────────→ 品牌价值积累
```

| 节日类型 | 代表节日 | 核心策略 |
|---------|---------|---------|
| 收割型 | 春节/五一/国庆 | 提前预订+溢价套餐+最大化翻台 |
| 引流型 | 情人节/七夕/圣诞 | 氛围营造+仪式感套餐+拍照传播 |
| 品牌型 | 母亲节/重阳/儿童节 | 情感共鸣+公益活动+媒体曝光 |
| 可选型 | 清明/元宵/端午 | 顺势推限定产品，不强推活动 |

### 2.3 节日营销黄金公式

```
成功的节日营销 = 
  情感触点 × 消费场景 × 传播素材 × 执行节奏
```

**情感触点：** 这个节日顾客最核心的情感需求是什么？
- 春节：团圆感/仪式感/年味
- 情人节/七夕：被重视/被惊喜/创造回忆
- 母亲节：表达感恩/亲情连接
- 儿童节：亲子互动/快乐记忆

**消费场景设计：**
- 定义谁来（客群）+ 为什么来（动机）+ 几个人（人均桌）

**传播素材准备：**
- 节日前1-2周开始预热内容
- 活动期间主推拍照场景
- 活动后收集UGC反馈

**执行节奏（标准提前量）：**
```
节日前30天：确定活动方案，物料设计
节日前21天：预售/预订开始（重大节日）
节日前14天：全渠道预热推广
节日前7天：员工培训完成
节日前1-3天：门店布置/物料到位
节日当天：全力执行，实时监控
节日后3-7天：复盘总结，记录数据
```

### 2.4 节日套餐设计原则

**避坑清单（节日套餐最常犯的错误）：**
- ❌ 套餐菜品太少，顾客觉得贵不值
- ❌ 套餐利润太薄，忙了白忙
- ❌ 套餐复杂度高，后厨压垮
- ❌ 没有"仪式感"加持，套餐=普通拼盘
- ❌ 没有传播钩子，活动做完无痕迹

**正确做法：**
```
节日套餐设计三原则：
1. 主打"体验"而非"优惠"（贵10%也能卖）
2. 必须有1-2个视觉亮点（适合拍照发圈）
3. 后厨出品时间控制在平时的120%以内（不能拖太久）

定价策略：
- 套餐溢价空间：节日套餐允许比日常客单高15-25%
- 松竹梅三档：标准套餐/精品套餐/尊享套餐（让顾客自主选择）
- 提前预订优惠：提前7天订享9折（锁定订单+缓解当天压力）
```

## 四、触发条件与输出

**输入收集：**
```
请告诉我：
1. 是哪个节日？（节日名称/时间）
2. 门店类型？（人均消费/主要场景：聚餐/约会/家庭）
3. 历史该节日表现如何？（高峰/低谷）
4. 本次活动目标：提升营业额？获取新顾客？传播品牌？
5. 可投入的营销预算大概多少？
```

**输出内容：**
- 节日营销执行方案（含套餐设计、活动策划、传播计划）
- 节日传播物料清单（需制作什么）
- 执行时间倒计时表（提前30天起的关键节点）
- 员工培训要点（节日服务话术、配合事项）
- 复盘指标设定（活动结束后如何评估效果）
