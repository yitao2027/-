# L2-store-checkup：门店巡检与神秘顾客

> 建立系统化的门店巡检体系，确保运营标准落地

---

## 触发场景

- 门店数量多了，质量参差不齐
- 督导巡店流于形式，发现不了真正问题
- 顾客投诉的问题和督导检查的结果对不上
- 想引进神秘顾客机制但不知道怎么操作
- 总部制定的SOP门店不执行
- 新店开业不知道如何验收

---

## 核心方法论

### 一、巡检体系设计

#### 1. 巡检类型矩阵

| 巡检类型 | 执行人 | 频次 | 侧重点 | 时长 |
|----------|--------|------|--------|------|
| 日检 | 店长/组长 | 每日2-3次 | 基础运营/发现问题 | 30分钟 |
| 周检 | 区域督导 | 每周1次 | 重点问题跟进 | 1-2小时 |
| 月检 | 区域经理 | 每月1次 | 全面评估 | 2-3小时 |
| 季检 | 总部职能部门 | 每季度1次 | 专项检查 | 半天 |
| 神秘顾客 | 第三方 | 每月2-4次 | 真实顾客视角 | 完整用餐 |

#### 2. 三级巡检架构

```markdown
Level 1：门店自查（日检）
- 执行人：店长+当班组长
- 频次：每日开业/午高峰/晚高峰后
- 内容：核心指标+即时问题
- 目的：问题早发现早处理

Level 2：督导巡店（周检）
- 执行人：区域督导
- 频次：每店每月2-4次（不预告）
- 内容：全维度检查+重点跟进
- 目的：监督标准执行+问题整改

Level 3：总部飞检（季检）
- 执行人：总部职能部门
- 频次：每季度覆盖所有门店
- 内容：专项检查+体系评估
- 目的：顶层监督+体系优化
```

### 三、神秘顾客机制

#### 1. 神秘顾客执行规范

```markdown
神秘顾客定义：
通过扮演普通顾客，体验完整服务流程，评估门店真实运营水平的检查方式。

核心优势：
- 真实顾客视角
- 员工无防备
- 发现表面检查看不到的问题

执行要求：
□ 消费真实（必须下单消费）
□ 体验完整（从进店到离店）
□ 记录详细（时间/菜品/对话/细节）
□ 反馈及时（24小时内提交报告）
□ 身份保密（绝对不能让门店识别）
```

#### 3. 神秘顾客管理规范

```markdown
神秘顾客团队组建：

内部神秘顾客：
- 优点：成本低、可复用
- 缺点：可能被识别
- 适用：日常监控

外部第三方：
- 优点：专业、客观
- 缺点：成本高
- 适用：季度评估/重要节点

机构选择标准：
□ 有餐饮行业经验
□ 覆盖目标城市
□ 报告质量高
□ 价格合理
□ 保密性强

检查频次：
- 重点门店：每月4次
- 普通门店：每月2次
- 新开业门店：前3月每月4次
```

### 四、巡检结果应用

#### 1. 评分与分级

```markdown
巡检评分计算：
总分 = 产品品质×25% + 服务体验×25% + 环境卫生×20% + 运营规范×15% + 品牌形象×15%

评级标准：
| 评级 | 分数区间 | 定义 |
|------|----------|------|
| A级（优秀） | 90-100分 | 标杆门店，可复制优秀经验 |
| B级（良好） | 80-89分 | 合格门店，保持稳定 |
| C级（及格） | 70-79分 | 需改进，有明显短板 |
| D级（不合格）| <70分 | 需停业整顿 |

神秘顾客评分（单独计算）：
| 等级 | 分数区间 | 处理方式 |
|------|----------|----------|
| 优秀 | 4.5-5分 | 表扬+奖励 |
| 良好 | 4.0-4.4分 | 维持 |
| 一般 | 3.0-3.9分 | 改进 |
| 较差 | <3分 | 重点整改 |
```

#### 2. 问题整改闭环

```markdown
整改流程：

Step 1：问题记录（巡检当场）
- 拍照/视频留证
- 填写问题清单
- 当场告知店长

Step 2：问题分类（24小时内）
□ 需立即整改（P0-致命）
□ 限期整改（P1-重要）
□ 持续优化（P2-一般）

Step 3：整改跟踪
- P0：24小时内必须完成
- P1：72小时内完成
- P2：7天内完成

Step 4：整改验收
- 门店提交整改报告（照片/说明）
- 督导复检确认
- 闭环存档

Step 5：预防机制
- 同类问题归类分析
- SOP更新完善
- 全员培训提醒
```

### 五、督导巡店技巧

#### 1. 高效巡店流程

```markdown
督导巡店标准流程（约90分钟）：

【进场前】（10分钟）
- 到达前5分钟通知店长
- 观察门店外围（门头/招牌/外部卫生）
- 进店观察第一印象

【后厨检查】（30分钟）
- 食品安全规范执行
- 产品制作标准
- 食材储存管理
- 设备维护状态
- 清洁卫生状况

【前厅检查】（20分钟）
- 服务标准执行
- 环境卫生
- 运营规范
- 氛围营造
- 员工状态

【数据核查】（15分钟）
- 翻阅台账/记录
- 核对报表数据
- 检查物料库存

【沟通反馈】（15分钟）
- 总结巡检发现
- 重点问题沟通
- 整改计划确认
- 需求支持了解

【离场后】
- 填写巡检报告（24小时内）
- 系统录入评分
- 跟踪整改落实
```

#### 2. 督导沟通技巧

```markdown
沟通原则：
- 以事实为依据，不带情绪
- 先肯定后建议，正向引导
- 具体问题具体分析
- 提供解决方案而非只提问题

沟通话术模板：

【开场白】
"XX店长，今天我们来巡检，整体感觉XX门店比上次有进步，特别是XX方面做得不错。今天我们重点看一下XX问题，上次也提过，现在来看看改善情况。"

【问题反馈】
"刚才我们在检查时发现了一个小问题，XX。这个按照标准应该XX，实际观察到XX。我拍了个照片，我们一起来看看。"

【改进建议】
"针对这个问题，我建议可以从XX方面入手调整，这边有其他门店的一个做法你可以参考一下。如果有困难可以跟我说，我们一起想办法。"

【结束语】
"今天整体巡检情况还不错，评分XX分，比上次提升了XX分，值得肯定。核心问题就是XX，记得在XX日前整改完成。有什么需要支持的随时联系我。"
```

### 六、门店自检体系

#### 1. 店长日检流程

```markdown
店长每日三巡检：

第一巡：开业前（15分钟）
- 员工到岗/仪容仪表
- 环境卫生（地面/桌面/卫生间）
- 设备检查（冰柜温度/灶台/空调）
- 物料备货（食材/包材/调料）
- 晨会/士气激励

第二巡：午/晚高峰（30分钟）
- 服务质量现场监督
- 出品品质抽检
- 问题现场处理
- 突发情况协调

第三巡：营业结束后（30分钟）
- 收市卫生检查
- 设备检查（关电/关气）
- 食材储存检查
- 今日总结/明日计划
- 安全检查
```

## 关联技能

- **前置技能** → L1-qscv-standard（QSCV标准化运营）、L1-food-safety（食品安全合规）
- **配套技能** → L2-training-plan（培训体系设计）、L2-loss-control（损耗控制）
- **支持系统** → L0-catering-data-analyzer（数据分析）
- **进阶技能** → L2-franchise-design（加盟体系设计）

---

## 使用说明

1. **常态化执行**：巡检不是运动式，要建立长效机制
2. **公正客观**：评分标准统一，避免人情分
3. **闭环整改**：发现问题必须跟踪到底
4. **正向引导**：以奖励为主，惩罚为辅
5. **持续优化**：根据问题调整检查标准，与时俱进
