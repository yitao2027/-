**层级：** L2 专项能力  
**部门归属：** 品类专项 - 烧烤/烤肉  
**触发词：** 烧烤运营、烤肉门店、烧烤成本、炭火烧烤、自助烤肉、串串香、BBQ经营

## 一、Skill 定位

**解决什么问题：**  
专门帮助烧烤/烤肉品类经营者解决品类独有挑战，包括食材损耗管理、夏季旺季运营、食品安全合规和差异化竞争策略。

**烧烤品类核心特征：**
- 季节性强（夏季旺季/冬季明显分化）
- 社交聚会属性高（人均消费高/消费时长长）
- 食品安全风险高（明火/生肉/高温）
- 食材损耗大（油脂流失/过火/切割损耗）
- 人力密集型（服务员工作量大）

## 二、核心方法论

### 2.1 烧烤成本结构管理

```
烧烤典型成本结构（人均60-120元）：

食材成本：35-45%（高于行业平均，因食材损耗）
├── 肉类（猪/牛/羊/海鲜）：22-28%
├── 蔬菜/素串：8-12%
├── 腌料/调料/蘸料：3-5%
└── 烧烤耗材（炭/竹签/锡纸）：2-4%

人力成本：22-30%
房租：10-18%
其他：5-8%
综合成本率：72-90%
净利润：10-28%

核心控制点：
- 肉类腌制损耗（腌制后重量变化）
- 烤制损耗（高温导致水分/油脂流失：约15-25%）
- 分切标准（每串克重必须标准化）
```

### 2.2 食材损耗精细管理

**烧烤食材损耗特殊性：**

```
烧烤食材三阶段损耗管理：

【阶段一：采购→处理损耗】
- 肉类剔骨/去筋/切割损耗：10-25%（因部位不同差异大）
- 蔬菜清洗切割损耗：15-20%
- 海鲜去壳/清洗损耗：30-50%（如鲜虾）

【阶段二：腌制损耗】
- 腌制中肉类可能吸水（重量增加3-5%，实际出成率降低）
- 腌料标准化：每公斤肉用多少腌料（精确配比，不凭感觉）

【阶段三：烤制损耗】
- 高温烤制水分/油脂流失：15-25%
- 计算方法：（生重-熟重）÷生重 = 烤制损耗率
- 各类食材烤制损耗参考：
  · 猪五花：20-25%
  · 牛肉串：18-22%
  · 羊肉串：20-25%
  · 鸡翅：10-15%
  · 蔬菜：15-20%

实际售价计算：
每串售价 ≥ 原材料成本 ÷ (1 - 烤制损耗率) ÷ (1 - 目标成本率)
```

### 2.3 食品安全强化管理（烧烤高风险项）

```
烧烤食品安全高风险点及管控：

①【生熟分开】(绝对红线)
→ 生肉与熟食绝对分离（案板/刀具/容器颜色区分）
→ 服务员夹生食的工具不能接触烤好的食物
→ 检查频率：每班次开餐前检查1次

②【肉类保鲜】
→ 猪肉/牛肉/羊肉冷藏≤0-4℃，不超过3天
→ 海鲜：当日到当日用，隔夜处理需特别谨慎
→ 冷冻食材解冻：冷藏室低温解冻（12-24小时），不用常温水泡

③【腌制食材管理】
→ 腌制肉类冷藏腌制（不室温腌制）
→ 标注腌制时间，超过48小时腌制品不使用
→ 腌料容器：每日清洗消毒

④【炭火/明火安全】
→ 通风排烟系统检查（每日开餐前）
→ 燃气管道检查（每周1次，每年专业检测1次）
→ 灭火器位置：厨房1个/就餐区1个，月度检查压力表

⑤【检查记录】
→ 每日食品安全检查表（签字留档，备查）
```

### 2.4 旺旺季运营策略

**夏季旺季（6-9月）运营重点：**

```
夏季旺季三大动作：

① 产能最大化
→ 增加炭火位（室外区域利用/自助烤肉模式）
→ 人手扩充：临时工/兼职增加20-30%
→ 采购量提前计划（避免旺季缺货涨价）

② 体验差异化
→ 室外/半露天场景（夏夜烧烤 = 独特体验）
→ 冷饮/啤酒/果汁配套推广（高利润搭配销售）
→ 等位体验（户外等位区/小吃/冰镇饮品）

③ 私域积累
→ 旺季到店顾客引导进私域（微信/小程序）
→ 淡季用私域维持复购

冬季淡季（12-2月）生存策略：
→ 推出"暖冬"系列：烤串+暖汤/暖锅结合
→ 扩大外卖：烤串外卖包/半成品自烤套装
→ 包场活动：年会/团建/生日聚会（冬季包场需求大）
→ 减少堂食座位，节省水电人工
```

### 2.5 烧烤差异化竞争四策略

```
① 烤法差异化
→ 炭火明火 vs 电烤/气烤 vs 纸上烤 vs 煤气石板烤
→ 选择一种成为主打标签（炭火 = 香气特有优势）

② 食材差异化
→ 本地特色食材（本地特产/地方风味腌制法）
→ 精品小众食材（少见部位/进口食材）
→ 现切现烤（当着顾客面现切，信任感+体验感）

③ 服务模式差异化
→ 自助烤：顾客体验感强，省人力
→ 代烤：服务专业，适合高端定位
→ 半自助：热门选择，结合两者优势

④ 场景差异化
→ 网红/打卡场景设计（户外灯串/特色烤炉）
→ 包厢式独立烤肉（高端/私密）
→ 市井小排档风格（实惠/热闹/有烟火气）
```
