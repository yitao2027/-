## 二、勇哥县城烧烤运营核心要点

### 1. 选址逻辑：县城商业街 > 商场店

**县城烧烤 vs 商场烧烤（勇哥核心观点）：**
- 县城烧烤必须是社区型/街道型，贴近本地居民
- 县城没有写字楼午餐需求，不要幻想商场模式
- 商业街或居民区交汇处是最佳位置

**县城商业街特征：**
- 晚上人流集中（夜经济主力）
- 复购客群相对固定（回头客生意）
- 租金相对可控

### 2. 布局设计：L型布局节省空间

- 县城烧烤面积建议控制在合理范围（不是越大越好）
- L型布局可以在有限空间内最大化座位数
- 注重翻台率而非面积

### 3. 产品定位：现金为王，少做外卖

**县城烧烤的核心逻辑：**
- 现金收款，不赊账
- 少做外卖（县城外卖平台抽成高，压缩利润）
- 线下客流+复购是主要营收
- 控制平台依赖，保持利润率

### 4. 运营关键：县城人情社会

- 县城是熟人社会，口碑传播快
- 第一批客人往往是周围邻居朋友
- 要有"让人愿意带朋友来"的产品和服务
- 不能只靠促销拉新，要有真实复购

## 三、县城烧烤 vs 城市烧烤对比

| 维度 | 县城烧烤 | 城市烧烤 |
|------|---------|---------|
| 选址 | 商业街/社区交汇处 | 商圈/步行街/美食街 |
| 面积 | 60-120㎡ | 100-200㎡ |
| 租金 | 低（5000-10000/月） | 高（20000+/月） |
| 主力时段 | 晚上+周末 | 全天+夜宵 |
| 外卖依赖 | 低 | 中高 |
| 复购来源 | 熟人+口碑 | 平台+内容 |
| 人力成本 | 低（家庭式4-6人） | 高（专业团队8-12人） |

## 四、参考执行清单

**县城烧烤开店前检查：**
- [ ] 位置：县城商业街或主干道边，晚上6-10点人流观察
- [ ] 竞品：半径500米内烧烤店数量和生意情况
- [ ] 产品：主打1-2个特色菜，不要追求大而全
- [ ] 面积：县城建议80-120㎡，L型或矩形布局
- [ ] 现金流：开业第一个月主抓现金收款，不欠账
- [ ] 外卖：县城慎重上外卖平台，先做线下口碑
- [ ] 复购：设计让客人带朋友来的理由（菜品/价格/氛围）
