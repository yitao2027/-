## 触发场景

### 核心触发词
- 翻台率
- 等位太长
- 提高效率
- 出餐太慢
- 座位周转

### 触发场景描述
翻台率是餐饮门店最核心的效率指标。本skill帮助分析翻台率问题，找到瓶颈，提供系统性优化方案。

## 核心方法论

### 翻台率计算

```
翻台率 = 总接待桌数 ÷ 座位数

参考值：
- 快餐：3-5翻（午高峰+晚高峰）
- 茶饮：5-10翻（高流动性）
- 中式正餐：2-3翻（客单价高，时间长）
- 火锅：1.5-2.5翻（边吃边聊时间长）
```

### 翻台率漏斗分析

```
客人进店 → 等位 → 入座 → 点单 → 上菜 → 用餐 → 结账 → 离店
    ↑        ↑      ↑      ↑      ↑      ↑      ↑
  门口转化  等位效率  入座速度  点单速度  出餐速度  用餐时间  结账速度

每个环节都有优化空间
```

### 翻台率瓶颈诊断

| 环节 | 问题表现 | 优化方向 |
|------|----------|----------|
| 等位 | 等位流失率高 | 缩短等位时间、提供等位服务 |
| 入座 | 入座慢、找不到位置 | 预分区、领位培训 |
| 点单 | 点单时间长 | 优化菜单、预点单系统 |
| 出餐 | 菜品等待久 | 预制、出餐SOP、后厨协调 |
| 用餐 | 聊天拖延 | 翻台提示、音乐节奏 |
| 结账 | 结账等待 | 预结账、分区收银 |

### 翻台率优化四板斧

```
1. 提速：每个环节都快一点
2. 分流：高峰期和非高峰期区别对待
3. 引导：用服务和环境引导客人节奏
4. 激励：员工翻台激励政策
```

## 操作流程

### Step 1：测量现状

```
收集数据：
- 日均翻台次数
- 各环节平均耗时
- 高峰时段翻台率
- 流失率（等位流失/中途离开）
```

### Step 2：找到瓶颈

```
时间最长环节 = 翻台瓶颈

诊断问题：
- 等位>20分钟 → 等位环节问题
- 入座>5分钟 → 入座环节问题
- 点单>10分钟 → 点单环节问题
- 出餐>15分钟 → 出餐环节问题
- 用餐>60分钟 → 用餐习惯问题
- 结账>5分钟 → 结账环节问题
```

### Step 3：针对性优化

```
按瓶颈环节给出对应方案（见下方方案库）
```

### Step 4：激励政策

```
员工翻台激励：
- 午餐/晚餐高峰翻台达标奖
- 投诉/差评扣罚
- 主动服务奖励
```

## 使用示例

### 场景：火锅店翻台率优化

**用户输入**：
> 我是一家社区火锅店，中午翻台1.5次，晚上2次，但周末高峰期等位流失很严重，客人等半小时就走了，怎么提升翻台率？

**Skill输出**：
```
## 火锅店翻台率优化方案

### 现状诊断
| 指标 | 现状 | 问题 |
|------|------|------|
| 午市翻台 | 1.5次 | ⚠️ 偏低 |
| 晚市翻台 | 2次 | ⚠️ 可接受 |
| 周末翻台 | 2.5次 | ⚠️ 高峰期压力大 |
| 等位流失 | 30%+ | 🔴 严重 |

### 环节耗时分析
| 环节 | 现状 | 参考值 | 问题 |
|------|------|--------|------|
| 等位 | 35分钟 | 15-20分钟 | 🔴 |
| 入座 | 3分钟 | 2-3分钟 | ✅ 正常 |
| 点单 | 12分钟 | 8-10分钟 | 🟡 |
| 出餐 | 20分钟 | 15-20分钟 | ✅ 正常 |
| 用餐 | 75分钟 | 60-90分钟 | ✅ 火锅正常 |
| 结账 | 4分钟 | 2-3分钟 | 🟡 |

### 核心问题：等位流失严重

**解决方案：**

1. **等位环节优化**
   - 取号系统升级（实时叫号）
   - 等位区提供小零食+茶水
   - 等位超15分钟送小吃
   - 缩短等位感知时间（叫号提前5分钟通知）

2. **点单环节优化**
   - 桌角二维码预点单
   - 入座即可点单，后厨提前备菜
   - 套餐推荐减少选择困难
   - 点单话术培训（3分钟完成点单）

3. **结账环节优化**
   - 桌角扫码结账
   - 会员预充值免密支付
   - 分区收银，减少等待
```

## 专家点评（避坑提示）

**勇哥原话**："翻台率不是越快越好。太快赶客人，差评就来了。要在客人满意的前提下提速。"

**常见错误**：
1. **强迫翻台** → 赶客差评
2. **只优化一个环节** → 木桶效应，其他环节拖后腿
3. **忽视员工激励** → 服务员没动力，效率上不去
