## 触发场景

当用户需要用专业量化方法评估铺面价值、做选址决策、说服投资人/合伙人/上级认可选址决策时，启用此 Skill。

## 输入

- 目标铺面位置描述
- 目标业态与客单价
- 目标客群描述
- 可采集的量化数据（人流计数/竞品数量/租金等）

```

总得分 = 商圈潜力分 + 竞争环境分 + 位置属性分 + 经营条件分
满分1000分，各维度权重分配如下：

┌─────────────────────────────────────────────────┐
│  商圈潜力（300分）                               │
│  ├─ 自然人流（100分）                            │
│  ├─ 有效客流（80分）                             │
│  ├─ 客群匹配（60分）                             │
│  └─ 发展潜力（60分）                              │
├─────────────────────────────────────────────────┤
│  竞争环境（250分）                               │
│  ├─ 竞品数量（80分）                             │
│  ├─ 竞品质量（70分）                              │
│  ├─ 差异化空间（50分）                            │
│  └─ 饱和度评估（50分）                           │
├─────────────────────────────────────────────────┤
│  位置属性（250分）                               │
│  ├─ 可见性（80分）                               │
│  ├─ 可达性（70分）                               │
│  ├─ 展示面（50分）                                │
│  └─ 面积与结构（50分）                            │
├─────────────────────────────────────────────────┤
│  经营条件（200分）                               │
│  ├─ 租金性价比（80分）                            │
│  ├─ 硬件条件（50分）                              │
│  ├─ 法律合规（40分）                              │
│  └─ 转让条件（30分）                               │
└─────────────────────────────────────────────────┘
```

### Step 2：商圈潜力评分（300分）

**自然人流评分（100分）**

```
测评方法：三段计时法（早/中/晚各30分钟）
公式：日均人流 = 三段合计×系数

| 时段 | 30分钟人流 | 日均估算 | 得分 |
|------|-----------|----------|------|
| ≥300人 | ≥1200人 | 100分 |
| 200-299人 | 800-1199人 | 80分 |
| 100-199人 | 400-799人 | 60分 |
| 50-99人 | 200-399人 | 40分 |
| <50人 | <200人 | 20分 |
```

**有效客流评分（80分）**

```
测算方法：自然人流 × 品类目标客群占比 × 目标客群进店意愿

| 有效客流估算 | 得分 |
|--------------|------|
| ≥150人/天 | 80分 |
| 100-149人/天 | 60分 |
| 60-99人/天 | 40分 |
| 30-59人/天 | 20分 |
| <30人/天 | 0分 |
```

**客群匹配评分（60分）**

```
| 客群匹配度 | 得分 |
|-----------|------|
| 完全匹配（≥80%路人为目标客群）| 60分 |
| 较高匹配（60-79%）| 45分 |
| 一般匹配（40-59%）| 30分 |
| 较低匹配（20-39%）| 15分 |
| 不匹配（<20%）| 0分 |
```

**租金性价比评分（80分）**

```

| 租金占比 | 得分 |
|---------|------|
| ≤8% | 80分 |
| 8-12% | 65分 |
| 12-15% | 50分 |
| 15-18% | 35分 |
| >18% | 0分 |
```

```
【评分汇总】

| 维度 | 满分 | 得分 | 得分率 |
|------|------|------|--------|
| 商圈潜力 | 300 | | /300 |
| 竞争环境 | 250 | | /250 |
| 位置属性 | 250 | | /250 |
| 经营条件 | 200 | | /200 |

【决策标准】

| 总分 | 评价 | 建议 |
|------|------|------|
| ≥750分 | 优秀铺面 | 强烈推荐，快速签约 |
| 600-749分 | 良好铺面 | 推荐，可进入深度评估 |
```

## 核心方法论

### 千分选址三步法

1. **量**——用数据说话，不凭感觉（实测人流/统计竞品）
2. **算**——用公式计算，不是拍脑袋（营业额预估/租金占比）
3. **比**——用分数比较，有客观依据（各位置横向对比）

### 选址常见的三个陷阱

1. **人流错觉**：看起来人多≠有效客流（目标客群匹配度低）
2. **租金幻觉**：便宜≠划算（坪效太低）
3. **竞品忽视**：有竞品≠不能做（有竞品=验证了需求，但要看差异化空间）

## 质量标准

| 维度 | 标准 |
|------|------|
| 数据量化 | 核心数据有人流计数支撑 |
| 评分客观 | 打分有明确标准，不是印象分 |
| 决策清晰 | 有明确分数对应决策 |
| 敏感性分析 | 评估关键假设变化的影响 |

## 注意事项

1. **数据要实地采集**：网上的数据和实际可能差距很大
2. **工作日vs周末要区分**：最好各测3天
3. **雨天和晴天要区分**：客流会变化
4. **打分要客观**：不要因为喜欢这个位置就主观打高分
5. **对比决策**：至少对比3个位置再决定
