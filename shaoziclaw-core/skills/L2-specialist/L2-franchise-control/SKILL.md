## 触发场景

### 核心触发词
- 加盟商管理
- 管控加盟商
- 加盟商不听

### 触发场景描述
加盟商管控是连锁品牌的核心能力。本skill帮助品牌方建立有效的加盟商管控体系，保证品牌一致性。

## 核心方法论

### 管控四力模型

```
管控力 = 利益捆绑力 × 督导力 × 培训力 × 淘汰力
```

### 利益捆绑力

```
加盟商管控的本质是利益共同体

利益捆绑方式：
1. 股权绑定（入股品牌公司）
2. 业绩挂钩（保证金/返利与业绩挂钩）
3. 独家授权（区域独家保护）
4. 供应链利润（通过供应链盈利）
```

### 督导体系

```
三级督导体系：
总部督导 → 区域督导 → 门店自查

督导频次：
| 督导级别 | 频次 | 检查内容 |
|----------|------|----------|
| 总部飞检 | 每月1-2次 | 全项目 |
| 区域督导 | 每周1次 | 重点项 |
| 门店自检 | 每天 | 基础项 |
```

### 违规处理分级

```
违规分级与处理：

A级（严重违规）
- 食品安全问题
- 品牌侵权
- 合同欺诈
→ 处理：直接解约、追责、法律途径

B级（较大违规）
- 连续不达标
- 私采物料
- 拒不接受督导
→ 处理：警告→整改通知→暂停授权

C级（一般违规）
- 轻微操作失误
- 偶发服务问题
→ 处理：口头/书面警告、培训
```

## 操作流程

### Step 1：建立标准体系

```
品牌标准包含：
□ 视觉标准（门头/装修/工服）
□ 产品标准（配方/工艺/品质）
□ 服务标准（话术/流程/态度）
□ 运营标准（价格/活动/物料）
□ 数据标准（日报/月报/分析）
```

### Step 2：设计督导体系

```
督导体系设计：
□ 督导频次
□ 督导内容清单
□ 评分标准
□ 整改流程
□ 奖惩机制
```

### Step 3：建立沟通机制

```
沟通机制：
□ 微信群（日常通知、快速响应）
□ 月度会议（复盘、培训）
□ 季度巡访（实地走访、关系维护）
□ 年度大会（表彰、规划）
```

### Step 4：违规处理

```
违规处理流程：
发现问题 → 证据收集 → 分级评估 → 处理执行 → 整改跟踪 → 结果反馈
```

## 使用示例

### 场景：品牌方管控加盟商

**用户输入**：
> 我是连锁餐饮品牌，已经发展了50家加盟商，但管控力度不够，加盟商各做各的，品牌形象不一致，督导也不知道怎么管，应该怎么办？

**Skill输出**：
```
## 50家加盟商管控体系方案

### 问题诊断
| 问题 | 严重程度 | 原因 |
|------|----------|------|
| 品牌形象不统一 | 🔴 严重 | 标准不清晰/督导不到位 |
| 督导执行弱 | 🟠 较大 | 督导体系不完善 |
| 加盟商不听 | 🟠 较大 | 利益捆绑不够 |
| 信息不通畅 | 🟡 一般 | 沟通机制缺失 |

### 解决方案

#### 1. 完善品牌标准体系

**建立5本手册：**
1. 《视觉标准手册》（门头/装修/物料）
2. 《产品标准手册》（配方/工艺/出餐）
3. 《服务标准手册》（话术/流程/态度）
4. 《运营标准手册》（定价/活动/外卖）
5. 《数据标准手册》（日报/月报/分析）

**标准数字化：**
- 图片化标准（拍照存档）
- 视频化SOP（操作演示）
- 清单化检查（逐项打勾）

#### 2. 建立三级督导体系

```
总部督导（3人）
    ↓ 负责50家，每月飞检2次
区域督导（5人）
    ↓ 负责10家/区域，每周巡检1次
门店自检（每日）
    ↓ 拍照打卡，总部审核
```

**督导检查表（示例）：**
| 检查项 | 标准 | 扣分 | 备注 |
|--------|------|------|------|
| 门头形象 | 与标准一致 | | |
| 工服整洁 | 统一着装 | | |
| 产品出品 | 符合标准 | | |
| 服务态度 | 标准话术 | | |
| 环境卫生 | 达标 | | |

#### 3. 利益捆绑机制

**改进方案：**
1. 供应链利润共享（加盟商采购物料有返点）
2. 年终返利与合规挂钩
3. 优秀加盟商可入股区域公司
4. 设立投诉保证金（违规扣款）

#### 4. 违规处理分级

```
A级违规（立即解约）：
- 食品安全事故
- 使用假冒食材
- 偷逃货款
- 品牌侵权

B级违规（整改+处罚）：
- 连续3次督导不合格
- 私采物料
- 拒不接受督导
- 价格违规

C级违规（警告+培训）：
- 单次轻微不合格
- 报表迟报
- 物料摆放不规范
```

#### 5. 沟通机制

| 机制 | 频率 | 参与者 | 内容 |
|------|------|--------|------|
| 微信群 | 实时 | 全体 | 通知/答疑 |
| 月度视频会 | 每月 | 区域+总部 | 复盘/培训 |
| 季度巡访 | 每季度 | 总部+加盟商 | 实地走访 |
| 年度大会 | 每年 | 全体 | 表彰/规划 |

### 落地执行计划

| 阶段 | 时间 | 内容 | 负责人 |
|------|------|------|--------|
| 第一阶段 | 第1月 | 标准手册完善 | 产品部 |
```

## 专家点评（避坑提示）

**加盟管控误区**：
1. **管控太松** → 品牌名存实亡
2. **管控太严** → 加盟商反水
3. **只罚不奖** → 积极性下降

**正确姿势**：
- 管和帮结合，帮助加盟商赚钱
- 奖罚分明，优秀者有好处
- 督导是教练，不是警察
