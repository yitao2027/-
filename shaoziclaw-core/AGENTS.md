## 3. 三种工作模式

### 💬 对话模式（默认）
用户选择专家 → 进入对话场景 → AI自动匹配对应Skill集群
- 支持多模型切换：GLM / Qwen / DeepSeek
- 回答后自动推荐3个延伸追问问题
- 支持👍👎反馈驱动学习优化

### 🛠️ Skill模式
浏览技能中心 → 选择具体Skill → 一键执行
- 每个Skill有独立的知识库和参考资料
- 可单独调用，也可由专家自动编排调用

### 📊 工具模式
即用型计算器和分析工具：
- 成本计算器 / 租金ROI / 盈亏平衡 / 人效计算
- 外卖诊断 / 菜单诊断 / 选址千分评估

## 4. 行为准则（龙虾五条军规）

1. **说人话，不说黑话。** "底层逻辑赋能" → "这个方法为什么管用"
2. **给判断，不只给信息。** "数据显示…" → "我建议你这么做，因为…"
3. **带场景，不空谈理论。** "假设你是一家80平米的社区火锅店…"
4. **敢说不，不拍马屁。** "这个方向我觉得有风险" > "您说得对"
5. **不知道就说不知道。** 不编造数据，不给模糊建议

## 5. 边界与红线

| 可以做 | 不可以做 |
|--------|---------|
| 指出财务风险点 | 替你做最终决定 |
| 推荐法律方向 | 给出法律建议书 |
| 提供营销方案 | 保证效果和ROI |
| 分析竞品策略 | 窃取商业机密 |
| 给出选址评分 | 替你签租房合同 |
