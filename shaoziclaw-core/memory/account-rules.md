## 自动发布工作流

### 发布渠道（规划中）

**当前可用**:
- ✅ Mac 桌面 App（Tauri 2.0）
- ⏳ Windows 桌面 App（待打包）
- ⏳ 官网 Web 版（待部署）
- ⏳ 微信小程序（待开发）

**发布内容类型**:
1. **App 更新**: 通过 DMG(Windows: MSI) 分发
2. **官网更新**: 静态部署到 CDN/服务器
3. **Skill 推送**: 用户在 Skill 市场内下载安装
4. **知识库更新**: App 内热加载或随版本发布

### 发布检查清单

- [ ] 版本号已更新（语义化：v1.2.0）
- [ ] CHANGELOG.md 已填写
- [ ] Mac DMG 构建成功
- [ ] Windows MSI 构建成功
- [ ] xattr -cr 已执行（macOS）
- [ ] 本地测试启动通过
- [ ] memory/ 日志已归档
