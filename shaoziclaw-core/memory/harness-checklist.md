# 勺子Claw 启动自检清单

> 每次会话开始前逐项检查。

---

## 自检流程

### 1️⃣ 身份确认
- [ ] 我知道我是谁？（读 IDENTITY.md）
- [ ] 我知道我在跟谁说话？（读 USER.md）
- [ ] 我知道自己该做什么？（读 AGENTS.md）

### 2️⃣ 记忆完整性
- [ ] L3 MEMORY.md 已加载？
- [ ] 今日日志已创建？
- [ ] 上次有没有未完成的待办？

### 3️⃣ 错误回顾
- [ ] 读 error-log.md，确认不会重复犯错
- [ ] 上次遇到的坑是什么？这次怎么避？

### 4️⃣ 工具状态
- [ ] Node.js 可用？
- [ ] Rust/Cargo 可用？
- [ ] Python3 可用？
- [ ] 关键 API Key 已配置？

### 5️⃣ 任务上下文
- [ ] 用户上次在做什么？
- [ ] 有没有进行中的大任务？
- [ ] 当前优先级是什么？

---

## 通过标准

5 个模块全部 ✅ 才能进入正式工作模式。
有任何 ❌ → 先修复再开工。
