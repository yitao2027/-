# 勺子Claw 核心决策记录

> 产品方向、技术选型、用户体验等关键决策。一旦写入，后续执行必须遵守。

---

## 1. 技术栈决策 (2026-04-10)

**决策**: 使用 Tauri 2.0 + React + TypeScript + Tailwind CSS

**理由**:
- Tauri 2.0 打包体积小（<5MB vs Electron >100MB）
- Rust 后端性能高、安全性强
- 前端 React 生态成熟，组件可复用
- 不基于 OpenClaw（太重不适合餐饮用户）

**约束**:
- 必须用 Tauri 2.0 语法（⚠️ 不是 1.x！）
- shell plugin 只支持 `open` 字段
- fs plugin 只支持 `requireLiteralLeadingDot`

**状态**: ✅ 已实施

---

## 2. 品牌视觉决策 (2026-04-12)

**决策**: 品牌主色调 = 品牌黄 #FFD600

**理由**:
- 基于 Logo 设计（黄色背景 + 黑色龙虾面具）
- 黄色在餐饮行业代表活力、食欲、温暖
- 与竞品（蓝色/灰色系）形成差异化

**执行标准**:
- 主按钮: #FFD600
- 侧边栏选中态: #FFD600 浅底
- Logo 必须出现在侧边栏顶部和官网首页

**状态**: ✅ 已实施

---

## 3. App UI架构决策 (2026-04-15)

**决策**: 首页 = AI对话页（仿 WorkBuddy 白色简洁风）

**页面层级**:
- **L1 一级页面**: 对话（Chat）
- **L2 二级页面**: 专家中心 / 技能中心 / 自动化
- **Skill市场**: 嵌入技能二级页面中

**理由**:
- 用户打开App的第一需求是"问问题"，不是"看专家"
- WorkBuddy 的白色简洁风格已被验证有效
- 专家作为入口而非首页，降低认知负担

**状态**: ✅ 已实施
